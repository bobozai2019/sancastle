# 水草与岸草

两个正式场景共用九种装饰植被：海草、海带、红藻、水牛草、灰色丛草、柳枝稷、麦草、西洋蓍草和一枝黄花。固定层级在[VegetationLayer](../scenes/components/vegetation_layer.tscn)，网格、材质、完整图集与实例矩阵预存于 `assets/vegetation/`；运行时只更新实例状态，不重建节点或网格。

## 外观资源与来源

当前使用用户提供竞品包中的九张完整多视角图集及配套代理网格，替换原先程序生成的宽叶草簇。资源映射、原容器及对象字节范围、外部网格payload、导出工具和输出SHA256见[资源清单](../assets/vegetation/competitor/manifest.json)。来源证据和原作/适配边界见[竞品分析](competitor/水草与岸草功能分析.md)。这些是原包专有资源，未确认可再分发许可。

[导出器](../tools/vegetation/import_competitor.py)先核对原包与 `.resS` 的 SHA256，再对照已保留的对象原字节，使用 UnityPy 解码完整分辨率 PNG 及网格顶点、法线和三角形。`*_proxy.json` 是可复验的中间数据；离线[构建器](../tools/vegetation/build_assets.gd)据此固化 Godot ArrayMesh、MultiMesh 和材质。图集导入保留RGBA，生成mipmap，关闭透明边缘修补、预乘Alpha与自动有损压缩；Alpha是打包深度，不能作为普通透明贴图修补。

[草丛Shader](../shaders/visual/vegetation.gdshader)用局部视线方向选择半球八面体网格中相邻三个视角，并按权重混合。每个视角把观察射线投影到对应平面，用材质的 `pivot_offset` 和 `atlas_grid` 定位图集；轮廓覆盖由 `smoothstep(0,0.4,alpha)` 得到，再以0.5裁剪。图集Alpha增大表示朝观察者移动；相机指向草的射线使用 `(alpha-0.5)/(pivot_offset.w*dot(n,ray))` 偏移，避免反转前后深度。三视角采样深度重建可见点，写入Godot投影深度，使沙面和水面按植被轮廓遮挡与折射。没有把图集当成一张普通十字草贴图。Godot的光照、流速响应、坐标变换和深度适配独立于原作，不能据此宣称逐像素复现原作。

海草关闭投影，另外八类开启。剔除代理背面，不透明裁剪，接受现有光照；模型整体按随机尺寸、朝向和颜色变化。流动引起的线性剪切作用于整丛并固定根部，使局部射线逆变换与深度重建一致；不再使用旧版逐高度平方弯曲。颜色来自原图集，不由原先四套纯色材质代替。

## 分布与配置

[默认Profile](../assets/vegetation/default_profile.tres)版本2，引用九个精确类型的Species资源。入口把快照冻结到 `environment.vegetation_profile`，参与来源与配置身份校验。活动域不重新分布；修改资源在新建域后生效。

每类2048个候选，共18432槽，状态纹理128×144。种子62143决定抖动位置、尺寸和随机值；容量不等于可见数量。main范围X/Z均−14.8至14.8m；test1_geometry为X=−14.7至14.7m、Z=−7.2至7.2m。每类以64×32分层抖动覆盖范围，共用世界坐标0.30倍采样的平滑分布场，形成混生草甸与留白。默认密度概率为原包外观适配初版的1/8；固定种子与候选位置保持，因此实际存活数量约为1/8，槽容量、图集内存及固定调度开销不随密度同步降低。通过分布区间后，密度概率还乘分布区间下缘0.12宽的平滑权重，边缘逐渐稀疏。

## 根部、水流与发布

[GPU更新](../shaders/simulation/vegetation_step_momentum.glsl)沿公共Visuals尾链读取同一完成布局的rock、sand、水深、动量和障碍，不修改权威水沙、源汇或账本。床高与沙面共用单元三角形重建，水深和动量四点插值。水平位置及存活标记在生成后保持；根部按 `new_y=min(old_y,visible_bed)` 降低，填高时不被顶起，由实际沙面遮埋。

水速度 `momentum/max(depth,0.005m)` 乘类型响应，以及水深0.002–0.05m间的平滑权重，目标倾斜长度限制0.65。临界阻尼解析更新沿用实际接受的dt：令d=b−a、c=v+ωd、e=exp(−ωdt)，则新倾斜a+(d+c·dt)e，新速度(v−ωc·dt)e。暂停无新水步；编辑dt=0只更新根部。出现缩放读取公共完成时钟，由25%过渡至全尺寸并轻微超调，暂停不随墙钟推进。

[Vegetation](../scripts/simulation/unified_edit/vegetation.gd)由公共Visuals调用；纹理、缓冲、核和绑定归Water所有者释放，无私有RD、队列、逐株CPU采样或运行时读回。

| 字段 | RGBA32F语义 |
|---|---|
| roots / vegetation_roots | 世界X、根部Y、世界Z、原网格缩放；缩放0表示未存活 |
| motion / vegetation_motion | X/Z倾斜、X/Z倾斜速度 |

私有与发布共四张128×144纹理，合计1179648B；配置缓冲464B。work_seal后与原完成态沿同一RD顺序发布，故障不更新可见副本。Views把Texture2DRD绑定到九个预存材质，换代先恢复旧绑定再装新绑定。每类2048槽批量绘制，死槽退化为不可见几何；没有存活压紧或距离LOD，原图集mipmap会降低远处细叶细节。

## 保存、恢复与限制

植被不增加水沙检查点字段。两个正式入口默认启用湿痕，使用SANDUE07；关闭湿痕的配置使用SANDUE06，native3权威布局相同。恢复、重进或切场景时，以恢复后的完整床水与固定种子重新筛选，初始化根部并清零倾斜，不保存此前单丛的遮埋历史或姿态。水沙检查点仍保存白沫、受支持的前缘、碎石及启用时的表面湿痕历史。当前及退休代共用原Views解绑、最后读者证明与Water释放流程，初始化或恢复失败不释放正在使用的旧代资源。

没有种草/擦草、光标拨动、独立风场、逐叶柔体、拔根漂流、繁殖、枯萎或双向阻水。当前是装饰植被，不改变权威水沙物理。多视角图集仅有原包记录的视角及分辨率，极近距离、视角边界、反射或水下深度组合仍受代理表面和采样精度限制。
