## 当前处理原则：效果先行，卡顿不阻断开发

1. 当前先把玩家能看到、能操作、能理解的水沙与沙堡效果做出来，再集中分析和优化性能。帧率、碰撞延迟等性能指标暂时未达标时，如实记录为待回收项，但**不得仅因卡顿停止 T04–T07 的效果开发**，也不得为追求暂时流畅而删掉计划中的功能。
2. 卡顿妨碍操作或测试时，先改用较小地图/局部场景或开发画质档继续迭代；已有数值测试可用 64²。GPU 主预览当前固定 256²，若需要小地图交互演示，先建立并验证相应开发入口，不把“缩图尚未接入”当成停止效果开发的理由。每份效果证据注明网格尺寸、物理范围和画质档。
3. 效果迭代仍检查守恒、非负/NaN、命令一致性和可重复性；小地图或低画质结果只证明该开发配置的效果与正确性。效果闭环后由 T08 回到 256²/30 Hz、目标硬件 1080p 和长稳态，逐项回收性能债；正式 Gate 未过前不标记通过。

## 1. MVP 边界

### 必须完成（MVP）

1. 2.5D 沙地挖、堆、抹平、拍实，工具沙量有账户且可重放。
2. 潮汐、沟渠、沙墙、洼地上的保守水流；生产求解器由 CPU 对照试验决定。
3. GPU 计算状态与地形、水面同源显示；无正常帧循环全图同步回读。
4. 侵蚀、悬沙搬运、沉积、水下编辑体积重映射，水沙均有守恒账本。
5. 湿度、压实、坡面松弛；预定义墙/塔构件的支持驱动破坏。
6. 分块碰撞代理、存档恢复、30 分钟稳定性及目标硬件性能验收。

### 占位但不验收（placeholder）

1. 近景沙粒、白沫、细波等表现层接口。
2. 动态船、铲子、桶的连续尾流与异步浮力探针接口。
3. 多分辨率/远区降频接口；仅当单域 256² 已达标才实现。

### vNext

1. 任意位置局部体素/SDF 雕刻、拱洞、悬挑和横向掏空。
2. 漂浮刚体、连续移动障碍与完整尾流系统。
3. 512² 或更大域、跨域/多后端水体融合。

### 明确不做（out_of_scope）

1. 全 3D Navier–Stokes、SPH/FLIP、真实破碎浪和飞溅粒子物理。
2. 沙粒级全局模拟。
3. 对原作内部算法或 shader 的精确还原声明。

## 5. 谨慎并发窗口

允许并发：

1. T00 的四个独立风险原型可并发，但共享契约和场景归主 agent 合并。
2. Gate 0 后，T01 的工具/沙地 CPU 参考与 T02 的水流 CPU 参考可并发。
3. T04 契约冻结后，T07 可先做不改变物理状态的表现层原型。

禁止并发：

1. 求解器未选定时实现生产 GPU 内核。
2. 多个执行者同时修改状态格式、单位、通量方向或命令排序契约。
3. 结构几何、障碍、水体积和碰撞作为不同任务独立提交。
