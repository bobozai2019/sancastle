# T03 GPU 工具下一渲染帧可见（2026-09-28）

状态：T03 G02 的工具显示延迟验收通过；不是五分钟帧性能验收。

## 方法与结果

- 256² GPU 预览暂停后取稳定基线图，提交一次 0.12 m³ 挖沙命令；随后按 `RenderingServer.frame_post_draw` 逐帧读取实际视口，并只比较 HUD 之外的场景区域像素。`tests/run_gpu_tool_visibility.ps1` 保存逐帧 `frame_offset,elapsed_ms,changed_samples,patch_batches` 到 `T03_gpu_tool_visibility.csv`。
- 首轮第 1 张后续渲染帧已有 8 个明显变化采样点，GPU 补丁批次已完成；第 2–5 张帧保持同一结果。
- 独立重复五次均在 frame offset 1 可见；提交到该帧的墙钟延迟分别为 35.340、35.212、38.541、40.643、38.799 ms。本机窗口、截图读取及测试同步都会影响墙钟数；这里证明的是“下一张实际渲染帧”，不能当成 1080p p99 帧耗时。后者另按 ADR-007 的口径验收。
- GPU 材质在水 tick 后或暂停工具补丁后采样当前求解器 RID；主入口三个固定场景、GPU/CPU 往返和沙/水同源显示已由此前报告验证。
