# T03 GPU 同 tick 撤销/重做（2026-09-28）

状态：G03 局部通过；跨 tick 重放后来已另行实现并验证，见 `T03_GPU跨Tick重放与全域碰撞_20260928.md`。

## 实现

- 256² GPU 场景暂停且无在途 tick/命令时，Z/Y 分别调用命令队列的真实快照撤销/重做，不提交“负强度画笔”。
- 对撤销前后 CPU 影子沙层/压实度逐格求差，仅把真正变化的格按索引排序成工具补丁，写入 GPU 两份 ping-pong 沙/压实状态；按变更格更新脏块碰撞，不作逐帧全图回读。
- 桶账户由队列快照恢复；GPU 水和动量在同 tick 暂停编辑过程中不回退。完成水 tick 后的跨 tick 撤销当前明确返回 false，避免只改床面却保留错误水历史。

## 验证

- `tests/run_gpu_preview_undo.ps1`：暂停挖沙→Z→Y，逐步检查沙层全格、桶账户、GPU 沙纹理全格（容差 1 μm）和实际变更格所属碰撞块的射线高度（容差 1 格）。三个补丁批次全部通过，模拟 tick 保持不变。
- 再推进一个水 tick 后测试跨 tick 撤销被拒绝；完整 `tests/run_gpu.ps1` 回归通过。
