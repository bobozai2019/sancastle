# T04 GPU 主预览耦合起步（2026-09-28）

状态：可选耦合路径及跨 tick 内存回放局部通过；默认主入口、完整性能门、跨进程存档和 NUM-08 尚未验收。

## 接线

- `gpu_water_preview.gd` 增加 `enable_erosion` 开关（暂默认关闭以保留既有 T03 基线）。开启时潮汐边界翻转后复制沙/悬沙状态，每个 CFL 水子步后派发悬沙搬运/侵蚀/沉积 pass，材质继续采样同一完成态 RID。
- 正常 tick 仅等待 GPU 脏块摘要，不回读整张沙层/悬沙。CPU 影子分别记录沙层与全域双字段的 GPU revision；工具命令将应用前只异步同步沙层，检查点将截取前与明确的调试请求再同步沙/悬沙两张 256² R32F 纹理，并验证非有限/负值。工具由同步完成回调继续，避免用旧沙覆盖 GPU 侵蚀结果；检查点的沙/悬沙快照与同 revision GPU 完成态一致。
- GPU 每 32² 块 `R32UI` 原子最大沙高变化摘要，256² 域每 tick 只异步回读 8×8×4 = 256 字节。多子步时用“最大子步变化 × 子步数”给出该 tick 净变化的保守上界；相对最近碰撞请求累计到 0.001 m 时，由摘要选择碰撞块，连同可能共享边界样本的左/上邻块一起请求现有 GPU 打包/异步形状替换。被请求块的累计上界清零，未请求块继续累计。
- 按需同步后 CPU 影子在普通运行间隔内可能滞后；碰撞差异调试视图此时显示“待同步”而不显示伪精确误差，暂停后请求当前 revision 影子同步再逐块显示。探针逐格核对 GPU/影子与 64 个碰撞块全部 33×33 样本。
- 主场景创建回放候选时继承当前 GPU 耦合开关，保持同一物理路径。跨 tick 撤销/重做、失败候选保留原权威场景、tick 120 检查点恢复至 tick 130，分别用独立全回放对照水、双向动量、沙、悬沙和账本。
