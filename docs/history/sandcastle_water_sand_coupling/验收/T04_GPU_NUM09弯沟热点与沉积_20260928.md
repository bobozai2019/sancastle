# T04 GPU NUM-09 弯沟热点与沉积探针（2026-09-28）

状态：独立 256² GPU 数值探针通过；主预览、工具/碰撞/存档耦合及无遮挡录像尚未验收。

## 输入与方法

- 使用冻结的 SCN-02 弯沟与洼地生成器（种子 202、0.125 m 格距），256² 对应 32×32 m；每 tick 以固定潮位函数更新 X=0 水库并记水源汇，经 CFL 计算子步，依次派发浅水 pass 和同一步水通量驱动的悬沙搬运/侵蚀/沉积 pass。边界导致的 ping-pong 翻转后，先复制沙与悬沙到新的状态槽。
- 运行 9,000 tick / 300 秒模拟时间；每 tick 异步 tile 审计水、沙/悬沙及完成态非有限/负值；每 300 tick 回读沙层与四向通量，记录累计及区间侵蚀热点、弯沟内外侵蚀和 x>0.7 下游沉积。逐步原始数据为 `T04_num09_gpu_256_9000.csv`，由 `tests/erosion/run_gpu_num09.ps1 -GridSize 256 -Ticks 9000` 生成。
- 封闭沙边界、无工具输入，因此沙源/沙汇均为 0；水源/水汇来自潮汐边界账本。区间热点用前后两次快照间的正沙层损失加权求 X 质心，不把从初态累积的入口侵蚀误判为仍在移动的热点。

## 结果

| 指标 | 256² / 300 秒结果 |
|---|---:|
| 最大水账户绝对闭合差 | 0.000018466 m³ |
| 最大沙账户绝对闭合差 | 0.000894000 m³（约初始沙量的 0.00023%） |
| 完成态负水/负沙/非有限格 | 每 tick 均为 0 |
| 悬沙存量峰值 / 最终值 | 0.845177484 / 0.224688456 m³ |
| 30 个区间的热点 X 质心范围 | 0.090253–0.459841 域宽，跨度 0.369588 |
| 区间侵蚀位于弯沟带内的最低占比 | 88.55% |
| 最终下游净沉积（x>0.7） | 0.050477903 m³ |

探针门槛：水账户逐 tick ≤0.5%，沙账户逐 tick ≤1%；9,000 tick 场景另要求热点 X 跨度 ≥0.20 域宽、每个区间弯沟内侵蚀占比 ≥80%、下游净沉积 ≥0.01 m³、悬沙峰值 ≥0.1 m³。实测均通过。这里的“热点迁移”限定为弯沟场景内随时变化的区间侵蚀位置；后续玩家挖/放沙筑坝改道对照见 `T04_GPU玩家筑坝改道与热点_20260928.md`。
