## 工具碰撞采用同 revision 沙层影子

分段计时先把慢命令拆为提交→CPU 应用→碰撞请求→GPU 读回→物理形状替换；原路径的尖峰既有提交至应用等待（短测最高 82.608 ms），也有渲染线程接收碰撞请求前的等待（一次一分钟测试最高 37.969 ms）。仅将播放状态下的空闲工具命令立即派发，一分钟仍出现 113.951 ms 最高延迟，故未把该改动单独计为过门。

工具应用前，耦合预览会将 GPU 沙层同步到 CPU 影子同一 revision；工具事务同时更新这份影子和 GPU 补丁。因此工具碰撞块现在在 GPU 补丁派发后，直接从 `rock + sand` 影子构造 33×33 高度形状，沿用同一网格索引和边缘夹取规则；侵蚀造成的后续脏块仍走 GPU 打包读回。旧 revision 的异步结果不会覆盖新碰撞形状。播放中没有水步运行时，也立即派发到期工具命令，不再等待下一个水步。
