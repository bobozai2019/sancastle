# T03 GPU 预览五分钟帧分布（2026-09-28）

结论：最低目标机 GTX 1050／D3D12 Forward+，实际全屏 1920×1080、VSync 关闭，256² GPU 预览预热 90 帧后连续采样 300.003 秒，墙钟 p99 为 8.688 ms，低于初定 33.3 ms 门槛。此为当前静态预览场景的性能证据，**不是**包含连续编辑、碰撞重建、侵蚀沉积和结构的完整测试场发布门验收。

执行：`powershell -NoProfile -File tests/run_gpu_preview_frame_baseline.ps1 -Seconds 300`。脚本在开始采样前检查实际视口 1920×1080 与 VSync 关闭；CSV 为 `T03_1080p_gpu_preview_frames_5min.csv`，每帧记录墙钟、process、视口 CPU/GPU 渲染、显存、水 tick、子步及等待状态。无 `-Seconds` 参数时保留原 600 帧短测行为与独立 CSV。

| 指标 | 结果 |
|---|---:|
| 样本帧数／时长 | 90,571 帧／300.003 秒 |
| 水 tick 差值 | 9,000，平均 30.0 tick/s |
| 墙钟帧 p50／p95／p99 | 2.930／7.123／8.688 ms |
| 超过 33.3 ms 的帧 | 112 帧，约 0.124% |
| 最大单帧墙钟 | 75.294 ms |
| 视频内存监控区间 | 恒为 118,521,856 B |

CSV 逐行重算时长、tick 差、超门帧数及显存范围，与程序汇总相符。p99 合格不表示没有尖峰；此测试每帧写 CSV，包含探针自身开销，也不能说明后续完整场景性能。下一步须在同一目标机、同一视口口径下跑完整场景五分钟，分别记录首编译尖峰与稳定区间。
