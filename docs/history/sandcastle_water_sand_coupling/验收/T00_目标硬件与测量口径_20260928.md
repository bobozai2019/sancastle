## 命令与门槛

目标配置核验：

```powershell
powershell -NoProfile -File tests/run_target_profile.ps1
```

原型帧采样：

```powershell
powershell -NoProfile -File tests/run_frame_baseline.ps1
```

两条命令都使用 `--rendering-driver d3d12 --fullscreen --resolution 1920x1080 --disable-vsync`。在此机器上，单独 `--resolution 1920x1080` 的窗口客户区实际仅为 1920×1055，已被探针拒绝，不可当作 1080p 验收。测量输出须保留每帧 CSV、预热帧数、场景/种子、CPU/GPU/整帧 p50/p95/p99 和 Godot 报告显存。

发布目标暂定完整三场景各取预热后连续五分钟稳定区间，1080p 整帧 p99 ≤33.3 ms，且数值/守恒门槛不降；首次 shader 编译尖峰单列。当前 60 帧/场景仅是 S0 首次 CPU 参考基线，详见 `T00_阶段进展_20260928.md` 和 `T00_1080p_cpu_reference_frames.csv`，并且明显未达目标。S3 须增量测“仅模拟→沙地→透明水→表现层→结构”，S8 才能宣称最低目标机器通过。若后续此档无法达标，必须以 ADR 明确优化或改档，不能悄悄改门槛。

Godot 主 RD 资源 150 次重建的逐次 `Performance.RENDER_VIDEO_MEM_USED`/静态内存见 `T00_gpu_lifecycle_memory_150_cycles.csv`。视频内存从第 1 到第 150 次释放后恒为 44,621,824 字节；这说明该原型未见逐轮 GPU 资源累积，不替代完整产品的长时显存稳定性验收。
