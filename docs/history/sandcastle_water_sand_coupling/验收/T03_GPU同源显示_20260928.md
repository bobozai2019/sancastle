# T03 GPU 求解器同源显示起步：2026-09-28

结论：新增 `scenes/gpu_water_preview.tscn` 作为可运行的 256² GPU 场景入口。`GpuWaterPreview` 在主 RenderingDevice 上初始化正式浅水求解器，按工具补丁→潮位边界→异步 1 KiB 源汇→异步 4 KiB CFL→保守子步推进，并把该完成态的 `rock/sand/wetness/water` RID 发布给 `Texture2DRD` 材质。沙地顶点由 `rock+sand` 位移；水面顶点由同一床面与 `water` 位移，干格片元丢弃。主 `main.tscn` 仍是 CPU 工具演示，尚未切换权威域；本证据不能证明碰撞或帧性能门通过。

运行命令：`powershell -NoProfile -File tests/run_gpu_solver_display.ps1`。Godot 4.7.2.stable.steam.ed1daf0bf，GTX 1050 / D3D12 Forward+。

第 3 个完成 tick 后暂停、再渲染 6 帧：测试确认沙、湿度、水材质包装器的 RID 分别等于求解器当下的有效状态 RID；截图像素采样得到沙地 5503、水面 1255 个采样像素。截图：`GPU_solver_display_20260928.png`。场景可直接打开 `scenes/gpu_water_preview.tscn`；空格暂停/继续。该截图显示的地形和水是 GPU 求解器纹理，不是固定棋盘测试纹理。

暂停后的 256² 挖沙探针另确认 32 个脏格、背包增加 0.080000 m³、GPU 沙厚逐格与 CPU 影子域一致，材质 RID 对准当前纹理；隔点截图比较在 HUD 外有 6 个变化像素，截图 `GPU_tool_edit_20260928.png`。这证明有视觉响应，但响应较弱，未测量事件到显示的帧延迟。详见 `T03_GPU命令批量上传_20260928.md`。
