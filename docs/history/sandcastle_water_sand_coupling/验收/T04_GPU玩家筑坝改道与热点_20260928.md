## 方法

运行 `tests/erosion/run_gpu_num09_reroute.ps1`：SCN-02 256²、同种子、同潮位，分别跑 3,600 tick（120 秒模拟时间）。两组在前 900 tick 的逐步 CSV 逐行完全相同。筑坝组在 tick 900 先用 `ToolCommandQueue` 的 `remove_sand` 命令从远处干沙地挖取 0.6 m³，再以 `place_sand` 扫掠笔刷在弯沟南半幅堆沙；命令按同一 tick 的 ID 顺序应用，真实上传 368 个脏格到 GPU 双缓冲，库存回到零。编辑前先回读当前 GPU 沙层作为工具基线，避免用初始沙高覆盖前 900 tick 的侵蚀。无坝组不编辑。逐 tick 审计水/沙/悬沙与源汇，每 300 tick 记录沙层和四向水通量快照。

CSV：`T04_num09_gpu_256_3600.csv`、`T04_num09_gpu_256_3600_berm.csv`。比较器只在局部侵蚀量 >0.001 m³ 时判定热点移动，只在两组坝下游截面 +X 通量均 >0.01 m³/s 时判定南北分流，避免把退潮近零通量的比例噪声当作改道。
