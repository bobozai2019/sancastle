## G01 湿润、扩散和干燥

`material_step.glsl` 的规则：有水时按固定速率推进到 `clamp(depth/soak_depth, 0, 1)` 的目标，无水时按固定速率排向残值 0.050，另加共享边对称扩散（只重分配，按契约只要求有界）。

固定速率而非「按剩余距离的百分比」是有意的：R16F 存不下小于一个 ulp 的增量，百分比式增益会停在饱和值下方约 2%（实测停在 0.980957）。改为固定速率后吸满值精确为 1.000000。

64² 用例（湿半域初始 0.5 + 水深 0.30，干半域初始 0.9 + 无水，1800 子步 = 15 秒模拟时间）：

| 指标 | 实测 |
|---|---:|
| 湿半域最终湿度 | 1.000000 |
| 干半域最终湿度 | 0.049988（残值 0.0500） |
| 干半域湿度轨迹（每 2.5 秒） | 0.8989 → 0.6060 → 0.3599 → 0.1584 → 0.0500 → 0.0500 |
| 湿半域压实度 / 干燥后半域压实度 | 0.383301 / 0.125000 |
| 1800 子步内越界或非有限值 | 0 |

轨迹单调递减且无跳变，即「退潮湿区连续干燥」。

## G02 压实和强度曲线

压实规则：仅当湿度高于残值时才压实，速率 `compact_rate × (1 − compaction)`，因此渐近到 1 且不可逆（「不得无限叠加压实」）。

强度曲线沿用 `sediment_step.glsl` 既有定义（本报告只做正交测试，未改公式）：`strength = mix(0.7, 1.8, compaction) × mix(1.0, 1.25, wetness)`，容量按 `1/strength` 缩放。

同一强迫下三个 64² 床面各跑 400 子步的累计侵蚀量：

| 床面 | 累计侵蚀 | 相对松散床 |
|---|---:|---:|
| 松散干燥（compaction 0，wetness 0） | 1.212463881 m³ | — |
| 完全压实（compaction 1，wetness 0） | 0.459961639 m³ | −62.1% |
| 松散湿润（compaction 0，wetness 1） | 0.962308107 m³ | −20.6% |

压实与湿润都降低侵蚀，方向与强度曲线一致。这同时关闭 T04 G01 遗留的「参数/单位专项」中的强度因子一项。

## G03 守恒坡面松弛

`slope_relax.glsl` 的规则：每条共享边由两个单元用同一份输入独立求值，供体减、受体加，故沙总量按构造不变；单边转移量上限为供体存量的 1/4，使一格四边之和不超过其存量，因此无需任何 clamp。没有高度滤波。

64² 用例（干沙金字塔，中心高 1.6 m、四周递减，平 rock，6000 子步 = 50 秒）：

| 指标 | 实测 |
|---|---:|
| 沙闭合差 | 0.000010899734 m³（5.1293 ppm，即 0.0005%） |
| 名义休止角落差（`tan34° × Δx`） | 0.084250 m |
| 稳定后最大相邻落差 | 0.086287 m（高于名义值 24.2‰） |
| 最大落差轨迹（每 12.5 秒） | 0.20000 → 0.08637 → 0.08629 → 0.08629 |
| 末段 1500 子步最大落差变化 | 0.000001 m |
| 负沙单元 | 0 |

落差在 12.5 秒内收敛并停止变化，沙误差远小于验收要求的 1%。

**已知偏差（如实记录）**：共享边交换只能重分配沙、不能改变均匀坡度，因此稳定后的坡面停在名义休止角之上约 2.4%，且收敛是扩散式的（约 23 格的坡面需 4000 子步量级）。这不是收敛不足，而是该格式的一个不动点性质；若要精确休止角需改为非对称松弛，见 ADR-011。

## G04 压实几何变化决策

见 `决策记录.md` ADR-011：**T05 v1 不启用密度曲线**，保持 `bed = rock + sand`。压实通过抗侵蚀强度和休止角起作用，不改变绘制高度。契约要求的「启用前必须先定义体积重映射」因此不触发。若后续需要「压实可见变矮」，须另立 ADR 定义邻水回填与沙账户不变的重映射事务。

## 阶段结论

通过（四项小目标）：

- [x] G01 湿度：吸满、连续排泄、有界、横向扩散有界。
- [x] G02 压实与强度：压实单调渐近、仅由水驱动；压实与湿润均降低侵蚀，方向与既有强度曲线一致。
- [x] G03 守恒坡面松弛：沙误差 5.1 ppm，收敛后停止，无高度滤波，无 clamp。
- [x] G04：ADR-011 明确不启用密度曲线。

验收项对照：

- [x] 陡坡滑落后停止且沙误差 ≤1%（实测 5.1 ppm，末段停止）。
- [x] 退潮湿区连续干燥（轨迹单调、退潮静帧可见湿晕）。
- [ ] 三墙破坏顺序稳定（NUM-10）——属 T06，本报告不声明。
- [x] 密度曲线未启用，故「启用时沙账户不变且邻水回填」不适用；已在 ADR-011 写明启用前置条件。

## 未达标 / 待回收

1. **材料物理与侵蚀共用 `enable_erosion` 开关。** 主入口默认关闭耦合，因此默认入口看不到湿度/坡面效果。湿度与坡面本不依赖侵蚀，后续应把开关拆开。
2. **坡面松弛高于名义休止角 24.2‰**，见 ADR-011「已知偏差」。
3. **每水子步新增 3 次 256² dispatch**（湿度/压实、坡面、回拷）。256² 耦合预览 150 tick 回归通过，但未在真 1080p 下测 p99；按 ADR-010 记债 T08。
4. **湿度/压实回读只在完整影子同步时发生**，所以二者比 GPU 落后最多一个同步间隔。检查点与调试视图前都会做完整同步，运行中的 HUD 不显示它们。

## 新风险

- 完整影子同步字节数由每格 8 B 增到 12 B，4 次同步共 3 MB；若 T08 需要压缩，湿度和压实可只在检查点路径同步。
- 坡面松弛会在地形陡峭处持续产生少量床面变化，进而周期性触发碰撞块刷新。256² 场景下摘要非零 tick 为 150/150，长期成本需在 T08 与碰撞延迟一起测量。
