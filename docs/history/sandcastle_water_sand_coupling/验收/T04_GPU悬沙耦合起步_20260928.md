# T04 GPU 悬沙耦合起步（2026-09-28）

状态：记录独立 GPU 数值 pass 的首轮结果；后续主预览接线、NUM-09 与跨 tick 回放见 `T04_GPU主预览耦合起步_20260928.md`、`T04_GPU_NUM09弯沟热点与沉积_20260928.md`。NUM-08 仍待验收。

## 实现

- `shaders/simulation/erosion/sediment_step.glsl` 在每个浅水子步后读取同一步的完成态四向非负水通量，以旧水深和旧悬沙计算上游浓度，搬运悬沙；每条边的转移量由供体与受体用同一公式求得，防御性出流限额保持供体非负与全域守恒。
- 同 pass 按流速、水深、湿度和压实度计算可携沙量，再以显式每秒侵蚀/沉积率在沙层与悬沙间转移；干格悬沙沉积。`rock` 不写入。输出写到与当前水完成态相同的 ping-pong 槽，输入来自上一槽，避免同纹理读写。
- `scripts/simulation/erosion/gpu_sediment_coupler.gd` 负责两套 uniform set、派发、GPU pass 时间戳和 RID 释放。参数起点为可携沙系数 0.08 s/m、侵蚀率 0.35 s⁻¹、沉积率 0.45 s⁻¹、干格阈值 0.001 m；这还是待 NUM-09 场景校准的初值。
- 潮汐/注水边界会翻转浅水状态槽但不直接更新沙层，故新增 `copy_after_boundary.glsl` 把已完成的沙层/悬沙复制到新槽；“耦合子步—边界—耦合子步”探针在边界前后逐格比较两张纹理完全一致（`copy_exact=true`），最终闭合差 0.000000009 m³，防止下一个水步读到旧沙。
