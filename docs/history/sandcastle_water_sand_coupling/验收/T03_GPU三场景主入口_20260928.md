# T03 GPU 三固定场景主入口（2026-09-28）

状态：三场景初始化与切换通过；T03/Gate 2 未完成。

## 实现

- 主入口的 1/2/3 键在 256² GPU 和 64² CPU 参考两种后端中都选择 `standard_scenarios.gd` 的对应固定种子场景。GPU 切换会替换旧场景并重新初始化主 RenderingDevice 状态；不是运行态无缝迁移。
- HUD 标出当前场景编号与预设名。F9 往返后保留当前预设编号，但不保留模拟进度、工具历史或水沙状态。

## 验证

- `tests/run_gpu_main_entry.ps1` 顺序切换三预设：每个 256² CPU 初态的岩/沙/水/湿度哈希匹配 Gate 1C 冻结值；各运行至少 3 tick；对 GPU 沙纹理全 65,536 格异步回读，与相应场景沙层逐格误差 ≤0.000001 m。
- 随后连续快速切换 1→3，最终 3 号场景运行至少 3 tick，没有旧 generation 的报错；F9 切 CPU 时为 3 号场景，F9 返回 GPU 仍为 3 号场景。
- 三张实际场景截图：`GPU_main_preset_1_20260928.png`、`GPU_main_preset_2_20260928.png`、`GPU_main_preset_3_20260928.png`。人工目视可区分斜海岸、弯沟和沙墙；沙墙双塔在当前远镜头下不够显著，T07 视觉可读性仍需处理。
- 完整 `tests/run_gpu.ps1` 回归通过。

## 范围边界

本证据只覆盖初态、沙纹理、短 tick 和切换生命周期。未证明各场景长时行为、运行态存档/恢复、GPU 跨 tick 撤销、悬沙/侵蚀或结构破坏。
