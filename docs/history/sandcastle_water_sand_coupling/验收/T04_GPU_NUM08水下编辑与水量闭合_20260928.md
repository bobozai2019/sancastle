## 方法

运行 `tests/erosion/run_gpu_num08_underwater_edit.ps1`，使用 SCN-02 耦合 GPU 主预览，自动选择内部有水且有沙的格子（83,107；编辑前水深 0.072100 m）。在 tick 10 暂停，按同一位置挖沙 0.010 m³、再从库存填沙 0.010 m³。每次编辑后逐格回读 GPU 水深与沙层，核对水深纹理不变、沙层确实变化、水源汇账本不变。然后继续至 tick 1800（60 秒模拟时间），逐 tick 记录源汇及最近一次 GPU 水审计，再全域回读水深，与编辑前水量加净边界源汇对账。CSV：`T04_num08_gpu_256_1800.csv`。

## 边界

这里验证的是 2.5D 床面升降时保留 `water=h`，由后续水通量自然重新平衡，不是把深度重置为“旧海平面－新床高”。它并未测试移动/新增实体改变有效流体面积的保守位移；该部分须在 T06 结构障碍实现时单列。CSV 的 `last_audit_*` 是最近一次异步 GPU 审计值，含其 revision；每 tick 源汇账本为当前值，`exact_water_m3` 只在编辑事件和最终回读填写。
