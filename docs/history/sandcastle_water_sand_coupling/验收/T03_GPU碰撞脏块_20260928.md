# T03 GPU 沙地脏块碰撞：2026-09-28

结论：G05 的真实求解器接线已完成局部验证，尚非 G05 或 Gate 2 放行。独立 256² GPU 预览现在将完成态 `rock+sand` 通过主 RenderingDevice 的计算 pass 打包为异步回读块，并在主线程替换 `HeightMapShape3D`；正常 tick 不做全图同步回读。初始地形分 4 批创建 64 块碰撞，此后仅请求工具结果涉及的脏块。

每块覆盖 32×32 个单元，碰撞高度图使用 33×33 个共享边界样本；编辑落在块首行/首列时，左/上/左上邻块也标脏。最初的 32×32 独立高度图在 x=0 边界射线漏检，已由 33×33 重叠采样修复，并将边界命中加入回归。

环境：Godot 4.7.2.stable.steam.ed1daf0bf，GTX 1050，D3D12 Forward+。运行 `powershell -NoProfile -File tests/run_gpu_preview_tool.ps1`；该探针已接入 `tests/run_gpu.ps1`，整套通过。

暂停后在原点挖沙 0.080000 m³，GPU 沙厚逐格等于 CPU 工具影子域。编辑块 36 的物理射线命中高度与对应完成态床高差约 0.000001 m；x=0 块缝射线命中。六次独立进程实测：提交到形状替换约 13.5–24.4 ms，提交到至少两个物理帧后射线命中约 29.9–80.2 ms；该小样本满足 ≤100 ms 的局部目标。异步回读约 3.3–3.7 ms、形状替换约 1.1–2.2 ms，数值随运行波动，不可当成 1080p/长期 p99 证明。

实现：`scripts/collision/gpu_collision_proxy.gd`、`shaders/simulation/shallow_collision_pack.glsl`；接线：`scripts/demo/gpu_water_preview.gd`；回归：`tests/gpu_preview_tool_probe.gd`。仍需多块连续挖堆、队列合并/旧 generation 回调、极端地形高度、10 分钟资源趋势和主场景集成的正式验收。
