# T03 GPU 主入口切换（2026-09-28）

状态：GPU 已是项目默认入口；T03/Gate 2 未完成。

## 变更

- `project.godot` 仍启动 `scenes/main.tscn`，该场景现由 `scripts/demo/sandcastle_main.gd` 加载 256² GPU 场景作为默认权威运行域。
- F9 可切到 `scenes/cpu_reference.tscn` 中完整保留的 64² CPU 参考演示，再按 F9 切回 GPU。切换前从树中移除旧场景，以触发 GPU generation 失效和渲染资源释放；切换不是运行态迁移，水沙状态不会跨后端保存。
- 原 CPU 场景回归/截图测试改为显式载入 `cpu_reference.tscn`，避免把入口改变误判成 CPU 数值回归。

## 证据

- `tests/run_gpu_main_entry.ps1`：默认 GPU 256² 可完成至少 3 tick，沙纹理 RID 与当前求解器状态一致；F9 切 CPU 64² 后仍在树中运行；再次 F9 重建 GPU 并完成至少 3 tick。实际截图为 `GPU_main_entry_20260928.png`。
- `tests/run.ps1`：17 项模拟契约、3 个标准场景集成及构件拓扑测试通过。
- `tests/run_gpu.ps1`：完整 GPU 回归通过，包含上述主入口往返测试。

## 限制

GPU 主场景现已补上三个预设切换（另见 `T03_GPU三场景主入口_20260928.md`），但尚未具备 CPU 参考场景的跨 tick 撤销/重做、日志保存/加载以及后续水沙耦合功能。F9 是开发期参考入口，不是可序列化的状态切换。当前不能据此宣称 T03 G02、T04 或 Gate 2 全部通过。
