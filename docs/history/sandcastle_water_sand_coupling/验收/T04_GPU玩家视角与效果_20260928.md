## 目的

`细则/T04_侵蚀搬运沉积.md` G05 与 `契约/证据规范.md` 第 3 条要求 T03–T08 每阶段至少一段无遮挡、无剪辑的 30 秒录像。此前主场景只有一台固定鸟瞰相机（`GpuOverviewCamera`，位置由 `Scenarios.camera_position()` 给出），且 HUD 文本无法关闭，因此不存在“玩家视角”证据。本次补齐两件事：玩家相机 + HUD 开关，以及一段按真实工具命令路径操演的录像。

## 可重现输入

```
powershell -NoProfile -ExecutionPolicy Bypass -File tests/erosion/run_gpu_player_view.ps1
```

加 `-StillsOnly` 可只出五张关键帧、不录制影片。录制脚本内部时间线（tick，30 Hz）：

| tick | 玩家动作 | 命令数 | 体量 |
|---:|---|---:|---:|
| 0–200 | 无编辑，潮位抬升、水道充水 | — | — |
| 200 | 沿南岸开挖导水沟（4 遍扫掠 × 3 段） | 12 | 挖 0.72 m³ |
| 300 | 前滩取沙坑（5 遍 × 2 段） | 10 | 挖 0.60 m³ |
| 420 | 跨水道筑坝（11 遍扫掠） | 11 | 放 1.32 m³ |
| 500–900 | 观察 | — | — |

所有编辑都走 `preview._submit_brush()`——即鼠标左键挖 / 右键放的同一个函数（`gpu_water_preview.gd:_unhandled_input` → `_submit_brush`），笔刷半径 0.38 m 与玩家一致；差别只是由脚本按固定 tick 触发，而非人工拖动。录制期间不切调试视图（保持「画面」）、HUD 关闭。

关键帧均由同一次录制运行输出，未做任何后期处理。

## 阶段结论

通过（玩家视角与效果证据）：

- [x] 主入口 256² 耦合路径可连续运行 900 tick，无负值、无 NaN、沙账户闭合 2.6e−5 m³。
- [x] 存在无遮挡、无剪辑、时长 ≥30 秒的玩家视角录像。
- [x] 玩家开挖与筑坝在画面中可见：导水沟成为贯穿岸坡的暗色切沟，沙坝成为横跨水道的浅色脊，坝上游水位抬升、下游偏干。
- [x] 编辑全部经生产工具命令路径（`_submit_brush`）提交，桶账本零残差。

## 未达标 / 待回收

1. **默认主入口仍未开启耦合。** `sandcastle_main.gd` 的 `enable_gpu_erosion` 默认 `false`。本次录像是在主入口上把该导出置为 true 后录制的；一分钟连续编辑的最高碰撞延迟仍未稳定过 100 ms 门（`T04_GPU真1080p帧与连续编辑_20260928.md`），按 ADR-010 记债留 T08。
2. **因果强度仅由数值对照支撑。** 本录像证明“玩家的挖/放改变了画面中的水路”，不单独证明“侵蚀热点位移量”。后者由 `T04_GPU玩家筑坝改道与热点_20260928.md` 的同种子对照运行给出（4 个有效区间热点位移 >0.02 域宽、4 个区间分流比例变化 >0.10）。
3. **下游净沉积只有 0.006 m³**（30 秒窗口）。数量级小是真实结果，不作为 5 分钟 ≤1% 门槛的替代；该门槛仍以 NUM-09 与独立 300 秒封闭域运行计。
4. **本录像不覆盖 T06 的不透水实体占水重映射**，也不覆盖动态障碍。

## 新风险

- 录制帧率高于模拟步进率会让影片以约 0.5 倍速播放。若后续要求“影片时长 = 模拟时长”，需改用 `--fixed-fps 15` 或提高模拟吞吐；当前按 ADR-010 不为此调整。
- 玩家相机的取景位置写死在 `record_player_view.gd` 常量里；若场景地形改版需同步调整 `CAMERA_POSITION` / `CAMERA_TARGET`。
