## 计划审阅与实际验收分开

竞品专用资料的整理与来源核对见[知识归档记录](竞品知识归档_20261027.md)；它不代替未完成的核验证或技术 Gate。

原计划结构审阅内容为：链接可达、任务／小目标数量、需求到契约／Gate映射、DAG及进度一致性。审阅记录保存为ASCII路径下的[plan_review.json](../verification/plan_review.json)；其通过不能推进G0或任何技术进度。

实际执行后才创建`G0_<run_id>.md`至`G6_<run_id>.md`和T04审阅记录。不要预建内容为PASS的报告或空白数据以占位。每个报告指向正式证据manifest；大量原始字节不放在本目录。

## Gate报告最小字段

- Gate／任务／小目标／需求／契约版本及hash。
- 原始来源身份、工具版本与源码hash、环境、实际命令、起止时间和退出码。
- 实验假设、固定输入、唯一变化因素、实际步骤及预期区分能力。
- 原始artifact与selector、导出完整性、配对类别、观测时钟和错误／缺失。
- 冻结的验收判据、实测数据、正例与相关负例、失败位置和范围。
- `operation_status`与`verification_status`分别给出，区分操作成功和技术判断通过。
- C0–C3陈述、反证、未知项、适用范围、下一步或停止理由。
