# 取证接口与来源

状态：v1.0，T00冻结字段、方法与隔离边界；阶段选择器、数值预算及观测窗口按各后续任务冻结。关联需求R01–R06、R10–R11；关联任务T00–T07。

## C01：来源与文件身份

原始RDC、原包、外部payload只读。开始时记录路径、大小、SHA256；使用不同副本前比较hash。源文件改变后禁止继续复用事件号／ResourceId，应新建run并重新定位。

| 字段 | 类型／约束 | 含义 |
|---|---|---|
| schema_version | string，初版拟定`1.0` | 不兼容变更升级版本 |
| run_id | ASCII string，唯一 | 一次方法和配置明确的实验；不能复用覆盖 |
| source_id | string | 由来源类型与内容hash确定的身份，不用文件名代替 |
| source_path | 绝对路径 | 原文件真实位置；原文件名含中文时保留真实位置，执行用经核验的ASCII副本 |
| source_size / source_sha256 | uint64／64位hex | 读取前身份，必要时记录读取后身份 |
| object_selector | object或null | 包文件hash、对象PathID／类型、对象字节范围及外部payload范围 |
| capture_selector | object或null | capture hash、event ID、ResourceId、shader hash、阶段、重放边界；每个捕帧独立映射 |
| tool | object | 工具名称、版本、源码／二进制hash、实际命令、工作目录 |
| environment | object | OS、GPU、驱动、图形后端、RenderDoc／Godot版本；未使用项显式null |
| artifacts | ArtifactRef[] | 原始及派生文件清单，失败或部分导出也有记录 |
| limitations / errors | array | 缺失、范围、解析失败、工具限制；不得静默省略 |

ArtifactRef字段：`artifact_id`、`path`（机器产物完整ASCII绝对路径）、`size_bytes`、`sha256`、`kind`（`raw_object/raw_payload/raw_snapshot/program/decoded/plot/log`）、`source_ids`、`parent_artifact_ids`、`selector`、`completeness`（`complete/partial/missing`）。不存在文件时size／hash为null且必须说明原因。raw_object不包含外部payload时不能标为完整资源。

buffer选择器包含byte_offset、byte_length、stride、element_count、format；texture包含mip、array_slice、plane、尺寸、格式与row_pitch。完整范围不足时记录实际导出范围；不得把补零当原始数据。可读JSON、PNG、反汇编、图表分别指回原始字节；它们不是独立来源。

正式证据根：`D:/godot/project/sandcastle/docs/competitor/evidence/water_solver_reconstruction/<run_id>/`。目录包含manifest.json、raw、derived、sources、logs。必要工具源码和配置保存快照，所有文件有hash。test_output只用于可重建临时文件；正式引用前迁移并重验。原始文件不复制时必须记录本机可用性及恢复途径，不能声称证据包已自包含。

每条重要结论单独记录`claim_id`、陈述、`claim_kind`（observed/inferred/godot_adaptation）、C0–C3、证据定位、复验方法、替代解释／反证、适用条件、未知项、数据可用性。不能给整份报告笼统打C3。

## C02：本地取证接口

工具采用JSON请求和manifest响应；实际CLI由任务实现，不虚构现成命令。

| 请求字段 | 类型／规则 |
|---|---|
| schema_version / run_id | 与C01一致 |
| mode | static_audit / rdc_replay / native_reference / replay_instrumented / runtime_trace / godot_probe |
| operation | audit / sync_graph / snapshot_pair / repeat / trace / compare |
| source | C01来源身份；多源时数组 |
| selector | 精确capture／程序／对象选择器，不接受只有资源名 |
| fixed_inputs | ArtifactRef[]；全部实际读依赖、常量、视图和初态 |
| repeat_index / replay_instance_id | 非负整数／唯一字符串；仅追踪，不作为配对证据 |
| variation | 本轮唯一改变的因素、旧值、新值；基线为null |
| output_root | 新建的ASCII绝对目录，禁止指向原包或覆盖既有run |
| environment / tool | C01版本及hash信息 |

| 响应字段 | 类型／规则 |
|---|---|
| operation_status | complete / partial / failed；只说明操作完成程度 |
| verification_status | passed / failed / not_evaluated；独立于操作状态 |
| artifacts / errors | C01条目及结构化错误列表 |
| dependencies_complete | boolean，附逐绑定资源覆盖表；false不能做完整算法判定 |
| pairing | input_event、output_event、stage、phase、pairing_kind、method、proof_artifact_ids、execution_instance_id |
| observations | 已观察值及可信度／范围；不得用假默认值补缺失 |
| clocks | C04时钟记录；没有时间依据时为空且解释原因 |
| unknowns | 缺失字段、影响、候选解释、下一次可区分观测 |

`pairing_kind`为`same_execution`、`reconstructed_controlled`或`unproven`。前者必须证明快照包围实际同一次dispatch；后者必须证明参考执行前恢复了全部依赖、绑定和初态。两个重放的event相邻、同一controller、同一进程、手工相同pair ID都不构成证明。

RDC阶段边界需明示“某dispatch之前／之后”，记录实际取得方法。`SetFrameEvent(event, force)`的force含义不能当成前／后开关。普通API无法取得真正前态时标记unproven，交T03选择替代方法。

依赖清单覆盖SRV／UAV／CBV、纹理采样器、buffer stride与offset、descriptor视图、dispatch尺寸、读写范围、跨核资源状态、UAV／transition／aliasing barrier、队列和Signal／Wait。无barrier也须用完整相关API范围支持，不能仅凭dispatch列表认定不存在。

结构化错误至少包含code、message、selector、artifact_refs、retry_condition。拟定代码：SOURCE_IDENTITY_MISMATCH、SELECTOR_MISMATCH、DEPENDENCY_MISSING、PAIRING_UNPROVEN、UNSUPPORTED_BACKEND、REFERENCE_UNSTABLE、LOG_DROPPED、CLOCK_UNMAPPED、SOURCE_CHANGED。空输出、缺字节或不支持格式必须partial／failed；不能输出“导出PASS”作为验收PASS。

负例必须覆盖错hash、错选择器、截断buffer、缺依赖、不可写输出及错误配对。非确定性本身可作为完整操作的观测结果，但必须报告REFERENCE_UNSTABLE及其分布，不能悄悄筛掉不同结果。
