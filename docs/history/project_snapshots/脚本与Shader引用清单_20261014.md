## 7. 限制与清理影响

- 本轮仅执行引用分析，没有修改或删除已有脚本和 shader，也没有运行旧测试。
- 资源和代码中的静态路径、继承、UID、class_name、shader include 及三处主运行动态加载均已纳入。可选分支和默认配置按保守方式视作依赖。
- 旧测试仍保留了已经删除的 .tscn 路径；例如 sandcastle_main.gd 预加载 cpu_reference.tscn，已经不能作为旧 CPU 切换入口运行。这些问题不进入两个正式入口的依赖链。
- .uid 是配套身份文件；如果后续删除脚本或 shader，应同时检查并清理相应 .uid。生成缓存不作为现用源码调用方。
- 历史文档及取证索引中的路径和哈希保持原始身份，不把它们混作当前运行依赖。
