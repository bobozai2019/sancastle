## 当前版本：复用 main 水沙材质

2026-10-12按用户进一步要求，样片接入 main 实际生效的水、沙、细沫、岸边接触材质，以及完整mip的3D焦散和法线贴图。水直接使用 `assets/water_material_natural_candidate/rdc_water.gdshader`，沙直接使用 `rdc_bed.gdshader`；静态参数从 main 初始化完成态烘焙到 `assets/test1_water_motion/main_*.tres`。四种shader及静态参数核对一致，运行绑定由测试完成态提供，详见[烘焙身份和参数](../../../assets/test1_water_motion/main_presentation.json)。原简化水shader只用于“流向”诊断，不再用于正常水体。

现有已编译材质固定读取256×256、32单位方形显示域。新增显示桥将原512×256水场双线性采样到这份显示契约，水深为 `max(amount−0.05,0)`，动量按各源格 `velocity×depth` 后插值，Godot Z速度反号。显示网格沿用main的顶点、UV及三角形对角线，只保留捕帧实际30×15范围；水、沙、白沫、岸脚共用这些床面和水深。权威捕帧求解仍保持512×256，转换结果不会写回求解器。

白沫历史与局部波前复用当前项目原有GPU计算；水法线、沙底焦散共享tick/40显示时钟；反射使用main的相机镜像与y=0平面。湿沙退水痕迹采用显示专用20实验秒衰减，压实度为0，这两项不冒称竞品公式或正式沙状态。显示重采样会损失一部分细沙形体；继承的浪头方向、白沫形状仍需要对照原作调整。

![main材质下40实验秒退水](../../../test_output/test1_water_motion/main_material_release_v1/frame_1600.png)

实际可见窗口D3D12/Godot4.7.1/GTX1050/1280×720验证：退水40实验秒、周期32实验秒，暂停/继续/复位/流向切换通过，水沙时钟相同，完成generation一致，运行日志无错误。退水仍在11秒转向海侧，20秒/40秒岸上水量代理分别较峰值下降82.01%/99.87%。14份显示场样本与独立CPU转换核对，最大容差为0.0001场景单位（包含float32运算及陡床插值舍入）；关闭细法线或关闭焦散均改变实际画面，且原水场字节保持不变。源快照、原字段、显示字段和对照图见[本次实测](../../../test_output/test1_water_motion/main_material_review_v1/summary.json)与[本次索引](../../../test_output/test1_water_motion/main_material_review_v1/inventory.json)。

与旧独立GPU实验相比，前若干tick逐位相同，后续局部速度出现差异；输入与求解kernel的hash相同，床面不变，整体退水趋势吻合，**不声明逐位确定性**。旧错误和本次修复前失败日志保留，不改判为通过。未进行成本验收。

此样片用于优化当前项目水沙技术：同一套main着色接在已解析的运动场上，便于区分运动、床面采样与光学差异。正式main目前仍使用原权威求解器；换核接入必须继续满足源汇账本、湿干、障碍、堆挖与检查点恢复契约。下一项技术缺口是原作带时间戳的海侧输入时序，以及在项目原床形、原参数下验证持续上滩/回流；独立场代理量不等于正式水量账本。

## 以下为材质接入前的历史结果

![上滩与退水](../../../test_output/test1_water_motion/review_v1/runup_backwash_review.png)

![实测量与流向](../../../test_output/test1_water_motion/review_v1/measured_motion.png)

回落实验中，岸上水量代理在8秒达到峰值；11秒岸区平均流向转向海侧；20秒较峰值减少82.0%，40秒减少99.87%。保持输入的对照在20秒仍有137.618场景单位³的岸上水量代理；周期适配32秒观察到两次上滩与回流。实际GPU字段无NaN/负amount、床面逐位不变；暂停、继续、流向显示和复位检查通过，普通直接启动无引擎错误。详细采样与源码快照见 [实测汇总](../../../test_output/test1_water_motion/review_v1/summary.json) 和 [产物索引](../../../test_output/test1_water_motion/evidence_inventory.json)。

这些秒数来自实验tick/40；捕帧内三轮积分deltaTime与UpdateAmount deltaTime分别保留，尚未统一为原作真实秒数。customWave的下降曲线和16秒循环不是原作已恢复时序。上方两张拼图及曲线是接入main材质前的历史证据；当时使用简化观察材质，未复建完整白沫/光学链，当前版本以本页新增章节为准。原作完整沙绘制patch和独立模型仍未复建。
