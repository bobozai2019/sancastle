## HIT-CONFIG-01：Ground 没有包内预存碰撞组件

- 分类/可信度：观察事实，C3，本次直接读取原始对象和内置 typetree；仅限上述 level0。
- 定位：GameObject PathID72，原文件偏移22944、长47，组件列表只有本文件 Transform188 和 MonoBehaviour541；layer=6、active=true。Transform188 偏移32128、长68，`m_Children=[]`，局部位置零、旋转单位、缩放一，父节点180。
- 结论：该 Ground 对象自身和预存子树没有碰撞体；并非包内已保存的 Heightfield/TerrainCollider 或分块 MeshCollider 层级。不能从这个事实推出运行时没有碰撞体。
- 原始证据：targeted_probe/index.json（文件缺失；旧定位`../../test_output/brush_hit_competitor/targeted_probe/index.json`），内含 raw 路径、对象hash、字节范围及解码字段。
- 独立边界核对：所读序列化文件内有22个 MeshCollider、88个 BoxCollider、16个 SphereCollider、27个 CapsuleCollider，未见 TerrainCollider/TerrainData。level0 只有 MeshCollider235（所属 GameObject90，名称 Slice）和5个 BoxCollider；其余在 sharedassets0.assets。完整对象表见 verification.json（文件缺失；旧定位`../../test_output/brush_hit_competitor/package_probe/verification.json`）。这是包内机械统计，不是运行时活动碰撞体数量；不分析其他对象业务用途。
- 反证：运行时可以新增/替换碰撞组件，或者由另一节点承担沙面代理碰撞。Slice 的存在不证明笔刷射线会命中它；mesh 引用尚未建立沙面几何同一性，未宣称 mesh/external payload 完整恢复。
- 未知：运行时对象创建、碰撞更新、射线mask、最近命中筛选、可见面与碰撞面一致性。

## HIT-CONFIG-02：Ground/Readback 自定义配置解析不完整

- 分类/可信度：解析状态观察 C3；字段语义 C0。
- Readback GameObject78 仅引用 Transform192 和 MonoBehaviour546，Transform无子节点。Ground541对象116字节；Readback546对象64字节。两者 raw 均已完整保存，偏移分别83200、83680。
- UnityPy 自定义 typetree 分别报 `Expected to read 116 bytes, but only read 32 bytes`、`Expected to read 64 bytes, but only read 32 bytes`。失败进入 targeted 索引；未强行补结构或把未读字节猜为高度场/碰撞配置。
- 包内技术类型 Ground、Readback、Brush、CameraRig 的 MonoScript 类名仅为 C1 线索；不证明方法、依赖或算法。类型字段和原字节在机械索引中，但不开展 C#/IL2CPP 方法反编译。
- 复验：读取 targeted raw，与对应源文件字节范围比对；如以后有合法类型字段布局，只解码命中必需字段并保留此失败记录。
