# 竞品技术知识

本目录按主题记录原包与RDC支持的事实、算法推断、Godot适配及未知项。可信度只适用于条目声明的捕帧、版本和证据范围；历史确认不等于当前数据仍完整，也不等于当前项目已通过相同验证。维护规则见[记录规范](记录规范.md)。

当前项目使用main与test1_geometry两个正式入口，默认MUSCL二阶水传播、RG32F动量、随流孔洞泡沫和独立湿痕；两场均已接入三件漂浮道具，两场均有装饰植被。项目实现以[技术方案](../当前项目技术方案.md)和[技术规格](../当前技术规格.md)为准。

## 证据可用性与复验

先查[证据与未知项](证据与未知项.md)，再查对应来源索引和原始文件。旧临时证据中仍有缺失文件，具体缺口在相应主题注明；索引存在不代表其内部raw齐全，专项复取也不补齐所有旧快照。

复验前核对原包／RDC完整路径、大小与SHA256，使用同一事件、资源、阶段及selector。缺失原始数据先恢复或重新导出；输出使用新的完整英文目录，记录工具版本、命令和产物hash。原作墙钟时序、跨帧因果、完整守恒、实际性能及资源制作方法，只能按各主题已确认范围引用。

项目采用的波包、MUSCL、动量B、湿痕保持时间和消费者生命周期都是项目实现，不能反向作为原作证据。原调查过程、旧判定和失败保留在[调查报告](../search/README.md)与[历史文档](../history/README.md)，不累计成当前版本完成状态。
