# ADR v1.36：完整redo回退与前态读回关闭

2026-10-11，仅完整同tick协调器边界补证，G4仍未放行。

redo目标核对失败时，已执行真实新事务；回退前保留消费过的新ID高水位，使用原完整基线经隔离候选恢复，generation递增。回退revision取当前完成态revision+1，避免以历史revision退回而违反同tick操作单调契约。GPU前态owner受控转移后，丢弃失败redo新产生的一份记录，保留redo分支；对正确目标再次尝试，使用更高新身份，不复用已消费ID。

显式undo的10张前态读回独立计数。关闭禁止新输入并等待undo协调器结束；真实异步回调全部到主线程后，才能释放历史纹理，之后释放owner solver与碰撞。默认关闭的观察信号仅用于精确阶段测试，不以计时猜测代替实际提交。记录最后callback、历史释放及owner释放时间，验证先后关系。

候选运行工具先执行check-only编译并记录独立编译PID/命令/日志；失败不启动真实运行。观察超时仍只返回该活目标PID，不重启。该编译成功与功能、字段、成本验收分别判定。
