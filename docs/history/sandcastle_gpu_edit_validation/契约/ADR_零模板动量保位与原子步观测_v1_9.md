# ADR：零模板动量保位与原子步观测 v1.9

日期2026-10-11。EV-010。数值公式/原门不变，修实现的零增量漂移；诊断不进入正式成本backend。

040358扩展矩阵56项中6个center/非零speed样本失败：h=.08、hu=.1，circle中心与单元中心精确重合，理论delta_u=0，但`(q/h+delta_u)*h`使hu一个浮点位漂移。逐格容差可能允许该值差，专门零方向恒等门必须拒绝；原数据保留。

改用数学等价的`q_raw=q_before+h*delta_u`，某分量dq=0直接复制原分量（保留signed zero），之后按raw_q/h只计算向量限速，未限速时不再重新乘h重写q。被限速的q仍按同一4m/s因子缩放；raw/actual/removed动量和动能账目跟随实际R32F候选。040713全域56项、040807局部56项通过；未增大任何水/沙/动量/能量预算。

为记录原求解器的干清零/原速度限制损失，建立原shallow_update_state的只观察副本shallow_update_diagnostic：原水/hu/hv/flux计算不改，额外SSBO按格累计removed hu/hv、可定义的单位密度动能损失及事件。depth=0时能量表达式未定义则计数单列，不以0冒称已知；removed momentum仍记录。诊断副本只用于取证，额外buffer/指令/读回不作为成本结果。

040128两域 × D正常/阈值干化/强制native限速，共6组原版与观察版15tick对照，10权威+2发布字段初始/终态逐位相等，干化及限速的非零事件已触发。该样本直接支持观察无数值副作用，不泛化所有硬件或未测后端。后续0–5秒观察版另与原版逐样本配对再作证据。
042032观察版0–5秒56样本与035633原版672份字段bin逐位一致。SSBO的events.w低24bit为零深度未定义能量事件，高8bit累计每个完成水子步的非有限水深/动量、负水深、干区非零动量；当前全部高位标志0。只观察副本未替代成本backend。复验脚本inspect_step_loss.py与post_analysis_index保留哈希及输入路径。
