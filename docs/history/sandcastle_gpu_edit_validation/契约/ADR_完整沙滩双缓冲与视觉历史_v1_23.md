# ADR v1.23：完整沙滩双缓冲与视觉历史

2026-10-11。候选恢复原语，T05 G03进行中，G4未放行。

完整耦合沙滩的检查点增加checksummed `gpu_beach_native` v1：十份当前原生物理字段、八份可交换物理字段的备用槽、solver当前槽索引，以及两份RG32泡沫和两份R32床面历史、泡沫当前槽索引。local_front沿用原检查点原生float32历史。保持SANDCP01/v1、对象反序列化关闭、32MiB上限和create-only语义。

候选lab_solver的冷恢复新增可选备用槽与索引；数值候选原调用仍复制当前态至两槽。所有字段长度和目标槽类型在复制前核对。完整沙滩不能把备用物理槽默认镜像成当前槽：本轮该做法在tick15恢复时当前字段及像素相同，却在tick22产生两格沙各一ULP差异；补齐备用槽/索引后通过同输入配对。原因定位至恢复状态遗漏，尚未逐条确定哪个备用字段/索引是最小必要因素。

生产foam增加默认返回原始初始化字节的工厂钩子，生产preview增加默认构造原foam的工厂；候选只在cold restore初始化时传入四份原生历史和当前索引。禁止复制至缺少COPY_TO的生产纹理，禁止改写泡沫计算公式。原生产默认路径不变。

候选预检覆盖主/备用字段格式、有限值、半精度范围、非负沙水悬沙、障碍编码、泡沫范围及旧water/q/foam投影字节一致。原检查点加载继续校验原配置与wave记录。额外contact_history/rise_front开启时明确拒绝保存，尚不支持其历史。候选额外字段仍缺完整源码/profile/SPIRV配置签名预检，不宣称正式通用恢复。

此实现尚未整合新GPU编辑调度、快照关闭边界、混合操作全账本配对及跨tick undo/redo。仅完整原负载无编辑的恢复/继续短窗口已经验证。
