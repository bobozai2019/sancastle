# ADR v1.61：碰撞共享边界候选

2026-10-11。状态：[候选，默认关闭]。角色：frozen_contract。

`--beach-bounded-collision` 仅选择GPU回执后的碰撞块集合。32×32权威格分块、33×33高度图采样和边界夹取保持原定义：块基址至基址+32的采样顶点，末端夹到255。脏格在块内时，该格也可能属于左/上相邻块的共享顶点；不要求每个脏块无条件扩张九宫格。

候选按回执dirty_mask中的每个32×32块与dirty_rect的交集确定可能改变的格，再覆盖其自身及左/上/左上33×33采样矩形的相交块。排序和去重保持；非法/空/越界矩形或mask块与矩形不一致时回退原九宫格集合。回执mask/矩形必须继续按既有GPU实际改动契约产生，不能以估计笔刷半径替代回执。普通恢复配置签名明确记录开关。

不改变权威沙/水/库存、shader算术、发布顺序、revision/generation、形状顶点或两次物理帧反馈边界；仍使用原HeightMapShape3D创建路径。资源复用保持关闭。本候选未通过性能门，未加入G4已放行配置、未切换正式入口，也未宣称原生等待根因已解决。

验收和成本分别记录在[候选证据](../验收/T06_碰撞共享边界候选与等待定位.md)。恢复、真实交互及长稳若决定采用须验证受影响范围，不以纯集合测试替代。
