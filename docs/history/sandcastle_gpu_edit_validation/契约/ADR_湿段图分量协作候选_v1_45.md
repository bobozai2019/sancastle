# ADR v1.45：湿段图分量协作候选

日期2026-10-11。候选默认关闭，开关`--connected-runs`；原water_full_wet/water_displace着色器不改。用户取消撤销范围依ADR v1.44。

事实：121215初态wet=h>0.001且obstacle<0.5，实际40972格/347个水平湿段，每行最多3段；4邻接有两个分量40298格与674格，不能合并水洼。原全湿快判回退，C/E displace约209ms。

适配候选：每行水平连续湿段是一个节点；相邻行的闭区间在相同x重叠才建边，严格等价4邻接。64线程单工作组构造图，原子CAS仅在较大节点仍为根时把它连向较小根；失败重新找根，不重接已有非根，无环且根单调下降；barrier后按根的首格row-major顺序编号，写入water_scratch的每格分量label。shared三张2048项uint数组、256行计数及原协作tile，总大小<32KiB。尺寸>256、每行>8段、无湿格或输入非法时回退原BFS，不伪造连通。

各分量按原first-cell顺序处理，读取协作tile但lane0仍按row-major Kahan累计。水/悬沙/动量分配、干水动量损失、残差修正上限、有限/非负/容量/预算与结果回执不放宽；无需求分量保持原样。私有water_receipt word27标记候选执行，允许与原路径单独排除，其余收据与字段要求逐位。

尚未验证：GPU算法、原子并查集合并、共享内存/编译后端及字段等价。理论说明不是验收。先64²/256²拓扑正负例与CPU oracle、原GPU bin逐位，再原有特殊状态/速度组合受影响回归，最后完整沙滩同输入反馈定位；未通过前不切默认，也不执行正式长稳。

验证补充：初版atomicMin重接非根可能丢失旧边；122550收据3分量与初态CPU两种方法2分量冲突，该成本不作为正确候选收益。改CAS及拒绝时回退原BFS后，123641与123043的644语义bin逐位一致。14前态临时收据另列，原新用例失败仍保留；完整负载成本待修正版复测。
