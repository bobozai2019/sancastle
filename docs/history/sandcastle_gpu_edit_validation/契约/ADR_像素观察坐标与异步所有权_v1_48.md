# ADR v1.48：像素观察坐标与异步所有权

2026-10-11。仅诊断探针，不改编辑算法或默认入口。承接v1.46/v1.47候选。

实际viewport逻辑1280×720、主窗口图像1920×1080。camera.unproject_position给逻辑坐标，鼠标事件采用final_transform后的物理坐标；ROI按图像/逻辑尺寸比例映射，不能直接裁逻辑坐标。记录全部尺寸/位置及原GPU格式。

冻结表现时钟、相机，隐藏HUD与笔刷；编辑前3个无编辑ROI须逐位稳定。固定128×128 ROI，变化>=32字节才记录。这个阈值是归因检测条件，不用于放宽100ms门。

整帧同步get_image会阻塞CPU和推迟发布，不作低干扰性能证据。改GPU texture_copy同格式小ROI，再texture_get_data_async；流模式每帧请求最多8份在途，回调释放自有ROI texture后交主线程，关闭前排空。源viewport texture只借用，不能释放。RGBA8/BGRA8/16F/32F显式解码后RGBA8检测，未知格式必须失败。

请求CPU时间不是GPU复制/显示完成时间。变化回调的接收时间是包含GPU/回调延迟的观察上界；它超过100ms只能说明尚不能证明首可见满足门，不独立证明实际显示超时。禁止用CPU发布/复制请求时刻替换首可见。物理屏幕时间戳及正式成本尚无证据。

134048流模式C/E观察上界125.508/104.693ms，均未证明100ms；发布68.400/65.791ms不替代它。ROI稳定、编辑变化、发布/碰撞及回调排空已验。完整队列134238七项PASS、65终态与两容量拒绝不证明持续30Hz或首可见门。G4不放行。
