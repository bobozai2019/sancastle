# ADR v1.58：用户接受当前性能基线

日期：2026-10-11。状态：[已采纳]。角色：frozen_contract。

用户明确指示：“这个效果可以了，按这个作为完成标准，写到文档里”，所引用的结果是模拟完成速率约15–16次/秒、p99帧耗时49–63ms、暂停单次编辑碰撞反馈89–98ms。该授权替换本轮性能完成指标，不修改模拟公式或数值/恢复契约。

| 本轮性能完成指标 | 判定界限 | 已接受效果基线 |
|---|---|---|
| 实际模拟完成速率 | ≥15次/秒，按完成时间戳及测量窗口统计 | 约15–16次/秒；高于16不视为失败 |
| p99帧耗时 | ≤63ms | 49–63ms；低于49不视为失败 |
| 暂停单次编辑碰撞反馈 | ≤100ms | 89–98ms，用户接受其现有余量 |

旧30次/秒、p99≤33.3ms转为后续优化目标，不再阻塞本轮性能完成。旧“无可重复编辑相关>50ms帧”不再作为独立硬门，以新的p99门及稳定性验证判定；最大帧/p99.9和偶发600–728ms停顿继续如实记录，不宣称根因已解决。首可见耗时继续记录，不用碰撞反馈替代；首可见≤100ms作为后续优化目标，不加入本次三项性能完成硬门。

当前用户接受的是上述短测效果；不把它称为已完成300秒A/B或30分钟长稳。原计划的验证窗口、对照、稳定性和选型交付仍保留，并按新指标判定。实际负载条件仍为可见1920×1080、GTX1050、D3D12、VSync关闭、完整浪/侵蚀/堆挖；有效profile、外部负载和候选开关必须留证。

30Hz固定模拟时间步（1/30秒）及CFL仍保持；墙钟完成吞吐目标降为15次/秒不意味着改成1/15秒物理步，也不能混淆模拟时间与墙钟时间。数值正确性、沙水守恒、库存、完成态发布、拾取碰撞、generation、普通保存恢复及严格继续等要求保持。撤销/重做继续按v1.44取消。

历史结果保持原始PASS/FAIL；新标准判断另记验收，不覆盖旧证据。各项具体通过结果放入验收文档，计划/执行状态分别同步。
