# ADR v1.44：取消撤销与重做范围

日期：2026-10-11。依据：用户明确要求“只取消撤销，把任务文档改下，继续推进”。本版本覆盖早期文档中撤销相关的执行与验收要求。

取消本专项的堆挖撤销及对应重做：同tick GPU前态历史、跨tick原/目标分支重演、磁盘redo、撤销专用CPU混合重演及worker关闭，不再是T05/G4或任务完成条件，也不再继续这些专项探针和引擎屏障调查。已产生的代码、ADR、失败/PASS与原始证据保留为历史，不计作新范围的新增完成。

保留GPU堆挖、水位移/速度、账本/库存预留、真实拾取与碰撞、快速队列、暂停/冻结、generation、检查点保存/冷恢复/活动原子恢复、旧回调/失败/退出，以及T06完整成本与长稳。普通保存恢复仍须完整字段/账本/视觉history及同输入继续严格配对；已出现的D3D12冷恢复继续ULP差异仍是检查点问题，不能因取消撤销而忽略。CPU smooth/compact的现有行为与普通保存恢复兼容要求保留；仅其撤销/redo分支测试取消。

T05 G03改为“暂停/检查点保存恢复与继续配对”。仍进行中，不能由取消子范围直接标记完成。G01冷首笔136.776ms反馈FAIL、T06未验收及母任务旧性能FAIL保留。任务维持7项/21小目标，已完成16/21（76.2%），下一步优先定位冷首笔交互反馈，并在普通恢复路径复核严格继续差异。

此次不删除既有候选功能，不替换正式入口。若将来恢复撤销需求，须重新授权并复核历史证据。
