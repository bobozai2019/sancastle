# ADR：位移残差逐格有界结算 v1.4

日期2026-10-11。候选适配记录EV-006。保守位移的需求、组件、容量、悬沙/动量公式保持v1；不修改水/沙逐格与量预算。

024452首轮GPU候选的24项中13项失败：总水量闭合，但R32F在大量接纳格的相同方向舍入残差被全部结算到第一个接纳格。256²深水样本最大水深差0.000850664564232995m，超过原逐格预算。闭合成功不构成分布正确证明，原FAIL与全部input/receipt/候选原始bin保留。

结算仍按组件内固定行主序最多N²格查找合法非供体接纳格，每格修正深度上限`max(1e-7m,8*ULP32(max(abs(old_h),abs(candidate_h))))`，并夹在old_h与eta_limit-new_bed之间。它取原逐格门的保守一半，为初次比例分配的舍入留下余量；不增加最终逐格门。实际R32F修正量更新剩余残差，不能用名义修正量冒称闭合。小于1e-8m³的归约底噪可停止查找，但最终依然执行冻结的完整水/悬沙量审计；未能在合法容量内满足原预算则候选拒绝并恢复原始四字段。

需要区分：最后残差可能在多个合法格结算；不得把一个组件总量预算当成单格预算。无需求组件不进行位移或结算；零容量则留水并报capacity_status=1。GPU供体携带物以实际R32F减少水深计算比例，回执moved记录实际供体减少量，retained为未移需求。

目前shader仅生成隔离候选，尚无live texture commit。测试中的momentum逐格数值诊断采用相同浮点表达式但单位m²/s，积分预算单位m³/s；不能把诊断系数当已完成的CFL/限速/连续动量门。新G3仍必须经过独立速度、实际求解和组合验证。

024712/024846各40项通过。256²深水最大逐格水差9.40748315025886e-7m，单格最大修正9.5367431640625e-7m；cap20最大水差9.50700642377011e-8m。原EPS、ULP系数、容量+0.02m以及水沙账本上限均未放宽。GPU实际指令hash与原始数据见对应manifest和shader字段，不声称恢复竞品原公式。
