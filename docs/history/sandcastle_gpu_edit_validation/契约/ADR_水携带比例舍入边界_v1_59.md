# ADR v1.59：水携带比例舍入边界

2026-10-11。状态：[已采纳]，仅补偿容量候选。角色：frozen_contract。

数学模型中供水格的实际移出水深不超过原水深，携带比例应位于[0,1]。直接float32除法及后续乘法的舍入可能使排空格产生负的携带剩余，破坏已有非负约束。修正补偿串行、连续索引补偿及容量缓存三个候选的proportion为`clamp(actual_depth/old_depth,0,1)`。

该修正把数学上已有的比例边界显式落实到浮点实现，不直接截断悬沙输出，不放宽沙/水/悬沙/动量预算，不增加源汇或读回、不改变物理步、容量规则、行序、接口或buffer。原未补偿shader保持历史实现；补偿/packed/cached仍通过原默认关闭开关选择。数值、负例、组合及恢复的影响验收另记。

事实C3：诊断shader直接记录沙审计量和预算；失败case在预算内、原候选及收据与观测版逐位一致。后续water receipt为status2/error4，merge将其投影为沙/水事务error7/flags4。水诊断直接捕获第1951格水深0、悬沙负值；拒绝逻辑保持原样。

推断C2：负值恰为原悬沙乘-2^-23，结合bounded ratio单变量修正后原失败用例通过，支持携带比例舍入越界解释。未捕获具体驱动除法/收缩指令，不把除法近似、FMA或某driver实现细节称C3。

重要纠正：此前把error7/flags4单独归为沙审计拒绝不准确。它是通用事务投影，必须读取原water receipt确认阶段；具体旧报告增加勘误，原始FAIL及产物不修改。验证结果见[携带边界验收](../验收/T05_水携带比例边界修正.md)。
