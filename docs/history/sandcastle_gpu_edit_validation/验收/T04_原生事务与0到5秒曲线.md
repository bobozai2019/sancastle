## 原生事务判定

B/C初态逐位相等、沙完成态逐位相等；C水四字段与独立float64 oracle按原逐格/量预算对照，rock/compaction/wetness/obstacle/flux不变。实际moved进入既有main回执；发布沙/水与完成态逐位相等，publish时间不早于CPU结算。0.12m³圆笔刷有16格床面超过原eta，0.48m³有80格，两者出水格完成编辑后h<=1e-4m。

本原生样本使用现有**加权圆笔刷**，不是平顶20/80cm帽：0.48m³、r0.75的实际沙场保存在bin中，不能将amount改称固定高度。平顶/圆顶等策略输入仍以先前GPU隔离40项的原始old/new bed为证；后续需补充特殊状态的原生bridge覆盖。

删水负例在候选阶段故意将水置0，原量审计返回拒绝并阻止沙/水两个commit，没有改源汇。运输负例在沙/水共同提交后强制失败，回滚物理沙和四水字段、显示不发布；CPU库存和revision未改变。运输失败的main CPU回执为空是未读回，不冒称有效128byte回执。只读forensic路径可取失败backend的数据，不使其重新ready。

## 时间曲线观察

每组从相同的沙输入开始，读取实际完成tick：0、3、8、15、30、60、150。请求0.25秒对应tick8=0.2666667秒，CSV同时保留request/actual/墙钟、generation/revision。1280/1080p性能口径不适用于此960×540取证窗口；全量取证会扰动墙钟，禁止据此算反馈或吞吐PASS。

| 域/策略 | 提交后笔刷区水量 m³ | 0.2667s m³ | 5s m³ |
|---|---:|---:|---:|
| 64² B legacy | 0.2099999953 | 0.1083874397 | 0.0294400129 |
| 64² C 位移 | 0.0273136776 | 0.0284175657 | 0.0287777086 |
| 256² B legacy | 0.2099999953 | 0.1083874439 | 0.0273447521 |
| 256² C 位移 | 0.0273136850 | 0.0273795124 | 0.0274033091 |

C在完成事务时已把可位移量移到同组件接纳区，边缘未露出床的水和后续回流仍存在；不能把整个footprint剩余水都要求为0。B随后通过求解逐渐排出。两域的物理尺寸分别8m/32m，床基准也不同，跨域差异不可当作只改变网格数的单变量结果。

全部采样h有限非负，干格momentum严格0，无CFL overload；B最多2子步、C最多1子步，显示读同完成态。连续原求解器保留原`max(1.5,3*sqrt(g*h))`速度限制，本轮没有将其改成新速度模板的4m/s注入上限。两域/策略最大观测水量相对漂移<1.4e-8；探针连续段沿原求解器0.5%守恒上限作粗负例门，与编辑瞬间严格ULP审计分开，不能声称已经建立逐子步新审计。
