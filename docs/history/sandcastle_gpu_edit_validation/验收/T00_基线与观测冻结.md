## G01 执行基线与输入

正式场景为`scenes/sandcastle_test1_beach_coupled.tscn`，诊断继承场景为`tests/edit_validation/edit_baseline_trace.tscn`。Godot 4.7.2 stable steam / ed1daf0bf，GTX1050、D3D12 Forward+、VSync disabled，输出1920×1080。相机投影/输入使用1280×720逻辑坐标，像素ROI按输出/逻辑尺寸比例映射；二者不是两个不同机位。

初始化采用现有fixture/profile；实际提交到solver.initialize的Domain快照保存在`initial_domain.bin`，SHA256为`b779fda26994446c24d47e3e3783ab5ebb56b7c895b31a013ab8fa193521d714`。5个新运行的该字节文件一致。该快照是CPU初始化输入，不冒称完整GPU检查点；初始momentum由现有initialize空参数归零，wetness/compaction由原路径转R16F，依据源码及各run manifest的hash定位。初始化无新增随机数；每笔seed等于command_id。

固定tick重复运行：`evidence/20261011_010200_baseline_trace/`与`evidence/20261011_010328_baseline_trace/`。两次20笔完整命令JSON规范化逐字段一致：ID1–20，target tick=2+24×index；0.01m³、radius0.38、circle，remove/place交替，位置(-2+0.04×index,0,1)。两次初态hash一致。探针通过原ToolCommandQueue入队，沿原CPU工具/patch路径执行；采用预先入队到未来tick来消除在途水tick造成的目标tick歧义，**包含等待未来tick的总反馈不能与立即鼠标提交直接对比**。早期墙钟/自动目标tick窗口另存，不累计为确定性重放证据。

实际requested/effective profile、资源/脚本hash、引擎二进制hash、启动参数、原始命令、窗口边界均在manifest/runtime。旧报告与部分manifest迁入docs/history；T01进一步发现两份旧analysis JSON本地缺失（EV-002），不再将其视为已复验输入。新T00实测证据独立保留。

## G02 同钟阶段与首绘制

所有CPU/worker/render事件用Time.get_ticks_usec单调时钟。trace.json/trace.csv记录：submit、sand_readback_request（callback方法区分prefetch/sync）、回调、解码校验起止、shadow_publish、cpu_tool起止、patch_cpu_dispatch起止、collision_publish起止、revision后的首post_draw、patch异步沙读回完成上界，以及tick_completed_callback。

末次20秒运行有20次patch提交、20次完成上界、20笔碰撞发布及20次post_draw；536个tick完成回调落在[start_us,end_us]窗口。20次额外patch沙读回分别落盘`patch_NNN_sand.bin`，它们是诊断证据开销，性能探针不得开启。GPU真正开始/结束的设备时间仍unknown；`patch_cpu_dispatch`是CPU录制，`patch_readback_completion_upper_bound`是提交后的完成回调上界，不能相减后称GPU执行时间。

冻结首可见观测：轻追踪只记录`first_post_draw_after_revision`代理，不冒称像素已变；像素确认独立跑暂停状态配对图。`evidence/20261011_010246_baseline_trace/`：tick=0、无brush indicator、同机位，before→no_edit_control ROI变化0像素，before→after变化639像素（96×96 ROI、RGB差>2/255、>20像素预设阈值）。实际0.05m³挖沙导致可见改变；首次被截图观测到改变上界174.743ms。取图与GPU完成回读影响时序，该结果不用于100ms性能门。坐标未换算的失败`005926`保留，其修正中间证据`010019`也保留。

## G03 观测分类与归因冻结

新分析固定按提交时间±100ms分类；轻成本另须按实际执行/可见时间覆盖未来tick入队等待。分位采用nearest rank、不删除长帧。原帧间隔不是GPU耗时；取数模式不判性能。

末次固定tick诊断：CPU工具最大0.547ms，碰撞发布最大0.804ms，patch提交→读回上界最大23.136ms；所有帧p99 27.535ms、最大249.142ms，编辑附近最大249.142ms、其他最大47.181ms。另一窗口`010049`非编辑段有112.795ms；初轮墙钟窗口有388.11ms。因此“所有长尾都来自笔刷计算”被本地证据反驳；GPU迁移收益仍unknown，不能用这些窗口证明正式成本。

外部Godot编辑器进程21316被manifest记录，实际GPU工作负载unknown。冷启动长间隔、额外回读、截图和未来tick等待均是替代解释；T06以无重取数、同态交错A/B裁决，不能回写旧FAIL。

### 冻结字段/未知值规则

| 字段 | 口径 | 缺失处理 |
|---|---|---|
| submit | 探针入队调用前 | missing |
| request/callback | 原RD请求与回调CPU时钟 | 按revision/callback关联；不伪造0 |
| decode_validate | 工作线程/主线程校验起止 | 分开记录 |
| CPU tool | apply_due至patch建立 | 不称GPU时间 |
| GPU patch | CPU录制、异步完成上界；真实设备时长unknown | T06若需GPU时长另取timestamp |
| settle/publish | shadow赋值和command revision发布 | future tick排队等待单列 |
| collision | 原apply_shadow_chunks起止 | 仅这次调用的成本，交互高度差待T05 |
| visible | post_draw代理、独立像素确认上界 | 不能互相替代 |
| tick throughput | 完成回调落在窗口内计数/实际窗口时长 | 端点差单列，诊断不判30Hz成本 |
