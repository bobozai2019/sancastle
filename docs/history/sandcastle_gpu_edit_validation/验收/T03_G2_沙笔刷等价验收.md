## G2逐条判定

- 原权重、行优先Kahan、4轮可挖分配与CPU对照：圆/扫掠/退化、三半径、薄沙/空沙/边角/大高度及微小量有逐笔原始场与命令证据。
- 非负与有限：上述全部完成态逐格检查，原参数非有限/旧代/旧revision拒绝不污染权威态；不声称涵盖独立显存损坏检测。
- 实际量与库存：实际GPU场delta对照128byte回执；CPU桶差按原逐笔预算累加，临界负库存使用signed balance+EPS，没有每笔重开信用。
- 顺序：同tick串行due命令与单调ID、重复ID拒绝、64bit运输及revision进位验证；当前一次只准1笔在途。真正异步快速重叠的64待排队在T05验收。
- legacy_depth：沙编辑时其余9权威字段逐位不变；smooth/compact回退先同步同revision，compact采用旧路径原生R16编码逐位门。
- 候选/提交/回执：CPU只发128byte参数、GPU独立candidate与条件提交、实际量小回执、CPU结算后显示复制；重复/失效回执及失败回滚有相应样本。合成释放后回调不替代真实pending退出。

判定适用于本任务隔离实验入口、已初始化的有限非负完成态、legacy_depth及当前shader版本。没有宣布实际鼠标、碰撞100ms、撤销/检查点、完整场成本或30分钟稳定性通过。局部只改变派发窗口，性能收益unknown，默认候选仍用全域。
