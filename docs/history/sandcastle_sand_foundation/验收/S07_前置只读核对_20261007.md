## S08/S09 接线核对

- 结构建造入口在 `scripts/demo/gpu_water_preview.gd` 的 `request_build_structure` / `_render_build_structure`：结构层 `add` 先修改 CPU 权威字段，然后同步 GPU patch 和碰撞 chunk。玩家当前 B/N 两键的预设分别是 7×30 格墙与 9×9 格塔，支付工具库存。
- `scripts/structures/structure_field.gd` 用 `structure.cells()` 决定障碍掩码与湿度平均；`structure_state.gd` 的矩形 `contains`、`cells`、`height_at`、`volume_m3` 和 `build` 需共同采用新形状掩码，否则圆塔空角会出现支撑、碰撞或计账分歧。
- `scripts/sand/tool_command_queue.gd` 目前只接受 circle / swept_segment 工具命令，其 undo/redo 保存域快照和刷子日志。结构建造经上述独立入口，不在该队列；S08 的造型撤销/重做与恢复要求不能仅复用现有刷子 undo。结构 checkpoint 另经 `structure_field.to_dict` 与 `scripts/simulation/checkpoint_store.gd` 验证。
- `scripts/visual/sand_display_sampler.gd` 与 `gpu_sand_coupled_fast.gdshader` 的顶点高度都采用同一对角的分片三角插值；后者片元沙/岩分类仍取 `texture(sand_state, UV)` 最近邻值。S09 应用同一三角权重重建沙分量，同时保留真正零沙格的岩面分支，且不改顶点床高。

这些是源码路径与风险定位，不是实现或运行时验证；正式水体改动落地后需重新核对。
