## 证据格式与成功条件

每份报告记实际命令、输入/profile请求及实际消费、源码SHA、镜头/灯光/分辨率、完成tick/generation/revision、运行硬件、状态审计、图/录像、PASS/FAIL/partial和延期项。

成功须exit code、预期PASS、无SHADER/SCRIPT ERROR/FAIL、新鲜run_id/产物与正确profile/source hash；GPU数据先查齐全/非空/长度/源实例完整态，缺失不能以默认空数组相等通过。旧证据前后hash核对。

比较固定尺度和照明下的基本造型/沙色/颗粒/投影，功能有效与参考视觉分别记录。全部灰壁根因、细城垛保形、陡壁折角、垂向湿度和动态碎块不属于本包已解决项。

性能沿水体已冻结的代表性合法活动负载，不能单发短wave后采静水。正式可见1080p/VSync off/预热30秒/采样300秒：总体与活动段p99≤33.3ms、模拟≥30tick/s；同分辨率联合长稳30分钟。性能失败只做对应优化/复验，不无理由重跑全部长稳。

新增堆/挖编辑负载用固定轨迹、频率、沙量和同镜头空操作对照；独立/联合各至少三次，单次与连续拖动都要覆盖。逐帧记录p99/p99.9/最大耗时、tick/s、操作时间戳与命令到可见更新延迟，并将耗时阶段与账本/碰撞状态一起核对。任何可复现的编辑相关>50ms长帧或仍明显的停顿均不放行。
