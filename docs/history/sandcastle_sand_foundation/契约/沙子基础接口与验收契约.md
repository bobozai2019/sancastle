# 沙子基础接口与验收契约

角色：contract。状态：draft，S07冻结。日期：2026-10-07。

## 1. 造型与状态边界

物理仍256²、0.125m/格、32m、30Hz；bed=rock+sand。rock可为负高程，sand/water非负。新增造型只写权威沙状态，显示/拾取/碰撞读取同完成态generation/revision。

以下为拟定本地字段，S07定schema、S08接线；不是新增HTTP接口：

| 字段 | 类型/单位 | 规则 |
|---|---|---|
| shape_id | enum | legacy、round_tower、tapered_tower、wide_wall、mound、pit、channel；旧缺字段默认legacy |
| origin / size | Vector2i / Vector2i，格 | 原结构字段语义不变、域内/正尺寸；形状枚举与旧Kind语义分开 |
| height_m / taper_slope_m | float米 / 沿原字段单位 | 沿现有范围，所选基本尺寸明显大于单格；不包含薄城垛/悬挑 |
| operation | enum | add/remove；移除不能产生负沙，实际挖出量入库存或源汇 |
| compaction / wetness | float，[0,1] | 使用现有字段与默认；不改材料模型 |
| funded_by_bucket | bool | 支付能力先核对；不足拒绝交易，造型不制造未入账沙量 |
| result | 本地结果/manifest | ok/code、实际体积m³、修改格数、完成tick/revision、库存/源汇变化 |

新shape不得重编号旧Kind值；保持旧造型输入/输出和存档默认结果。新增字段需要版本/默认值、校验和round-trip；旧事件代号正确换代。挖/堆/成型、撤销/重做沿现有有账本命令，不用独立显示mesh绕开沙量与碰撞。

新造型的有效footprint、contains/cells、体积和支持边界沿同一个形状掩码，圆塔包围矩形的空角不能当已建沙或支撑。坑/沟走已有移除交易，按实际可挖沙量统计，不作为负高度结构加入账本；未改变的格不重写压实度或湿度。

## 2. 采样与材质

S09沿当前三角平面高度重建，rock/sand分类取同权重的重建分量；wetness/compaction插值有界。明确零沙、薄沙、邻格高度差的行为。分类修复不改实际沙高、显示高度或碰撞拓扑。

确有重建沙厚的边缘不能因最近邻选到邻接零沙格而涂灰；真实无沙基岩仍按岩面分支。残留灰壁另行归因，不为隐藏它扩大水面不透明度或修改沙量。

基础材质以世界空间绑定颗粒/法线，屏幕导数进行远景淡出；颜色/粗糙度/高光沿已有wetness与compaction。S11不新增塔身垂向湿润历史，颜色开关不修改物理字段。

## 3. 与水体接口及profile

复用水体WR-G3冻结的profile loader、时钟、可见床面接口、相机和水下亮纹。拟新增sand_foundation_v1：schema_version、stage、shape配置、沙色、grain尺度/强度、roughness/specular映射、光照/阴影、water_profile_id/hash、源码/resource hash、实际消费能力。

S07冻结字段/单位/默认/范围，S10完成加载接线，S12冻结参数。staging允许尚未实现组件显式pending/禁用，不能计视觉完成；release必须本轮全部P0启用/消费。水体P0不得关闭，水下颜色不重复染色。参数回读保存requested/effective hash与资源；未知版本、缺已启用必需资源、无消费参数必FAIL。

共享床面shader改动只影响已规定沙分支/接口，水体shader和求解器不在本轮默认修改范围。旧profile和旧证据只读；新增入口共用初始化/时钟，不能依靠录像脚本修正实机表现。

## 4. 基础验收目标

| 项 | 本轮完成条件 | 不代表 |
|---|---|---|
| 造型 | 六类基本形状可辨，确写入权威高度；账本闭合、碰撞对应，保存重启形状正确 | 细城垛可保形、悬挑洞穴已支持 |
| 分类 | 构造插值沙边缘不误判裸岩，实际裸岩保留；几何/state hash不变 | 所有灰壁根因均已修复 |
| 受光 | 真实太阳/材质响应、投影、转镜头有效，联合入口实际生效 | 已复原竞品全部光照算法 |
| 质感 | 冻结参考ROI中偏浅暖、细腻哑光，无显眼块状纹理/规则重复/移动闪烁；已有湿度变化产生合理映射 | 塔脚/塔身垂向湿润已完成 |
| 集成 | 同正式配置、时钟和真实资源，在参考型独立/联合入口完整消费，水体回归与性能通过 | 竞品所有形态/动态效果已对齐 |
| 挖堆响应 | 真实连续堆沙/挖沙不再产生可复现的明显卡顿；有空操作对照、帧时间尾部、tick/s和命令到可见更新延迟的前后数据 | 静态画面帧率代表编辑流畅度 |

S07先冻结具体镜头、输入尺寸、材质参考ROI、图像目标/失败样例和相关数值容差。S12本轮目标逐项判定；未通过不以旧8/10或“改了shader”放行，延期项保持明确。

证据包含run_id、源代码SHA、profile请求/消费值、水体版本、实际viewport/引擎/硬件、相机、tick/generation/revision、造型/源汇/碰撞、效果开关、截图/录像、阶段性能与遗留。GPU回读先验证齐全、非空、长度、完成态再比较。

真实GTX1050/D3D12/可见1080p/VSync off，预热30秒采样300秒，总体和冻结代表性活动段p99≤33.3ms、模拟≥30tick/s；同分辨率耦合30分钟长稳。沿水体的合法波包/覆盖/活动负载规则，不用一发短波后静水代表整套成本。

编辑活动段必须分别包含真实堆沙和挖沙：固定轨迹/频率/沙量，对空操作、单次、连续拖动及新造型接线做同状态对照，独立/联合入口各至少三次。除p99外记录p99.9、最大帧时间、编辑事件时间戳及命令提交到可见更新延迟；不得出现可重复的编辑相关>50ms长帧。该阈值与现有33.3ms p99门同时生效，仍可见的停顿须归因并修复，不能只以统计通过放行。
