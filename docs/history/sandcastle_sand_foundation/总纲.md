## 6. Gates

### SF-G0

- [ ] 水体接口已冻结，参考型场景/镜头/源码hash可复现。
- [ ] 本轮基础目标与延期项明确，造型尺寸/材质对照/判定方式先冻结。
- [ ] Shape/profile字段、单位、兼容默认值和实际消费接口完整。

### SF-G1

- [ ] 六类基本造型实际写入沙字段，挖/堆量入账，拾取/碰撞匹配，旧默认输入不变。
- [ ] 当前堆/挖卡顿有同负载前后证据；连续操作的可复现长帧被消除，未牺牲账本、碰撞或水体效果。
- [ ] 几何和材质分类同一重建；插值有沙的测试边缘不误判裸岩，真实裸岩仍正常。
- [ ] 不以shader假位移、全域平滑或增加不透明水掩盖问题。

### SF-G2

- [ ] 独立/联合受光和阴影真实生效，转光源/转镜头响应正确；阶段性成本测量达标。
- [ ] 沙色/细颗粒不出现显眼大色块/规则重复/移动闪烁，现有wetness/compaction映射有可辨响应。
- [ ] 水底亮纹、薄水、岸线及既有水profile消费完整；待验证P0不能被算入本轮已完成。

### SF-G3

- [ ] 当前基础目标逐项对照通过，新增形状与材质有真实证据，剩余几何/动态差距单列。
- [ ] 同一正式配置用于直接启动/捕图/录像/性能，相关质量账本、碰撞、旧存档和水体回归通过。
- [ ] 真实1080p预热30秒/采样300秒，总体及代表性活动段p99≤33.3ms、模拟≥30tick/s，联合30分钟长稳无新增异常；不得为通过关闭本轮必需阴影或冻结水体P0效果。
- [ ] 独立及联合场景的真实堆沙/挖沙活动分别通过，逐帧尾部和命令到可见更新延迟可审计；三次同负载复测无可重复的编辑相关>50ms长帧或明显停顿。

功能路径确定不代表成本已实测，性能失败标[需返工]并优化同效果实现；本包不自动降低最终目标或追加高风险架构。
