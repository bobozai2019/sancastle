# P03 G02 沙材质、浅水与底面亮纹

日期：2026-10-10。固定样片 `scenes/sandcastle_test1_beach_fixed.tscn`，seed 74021、tick 0、generation 1，1280×720、Godot v4.7.beta.custom_build、D3D12 Forward+、GTX 1050。有效 profile SHA256 `c63c7ec0fdeac21c34ffdd77a5a508157d971da5cd81ca1e86126ab8059ed1d5`。启动/捕图使用同一 profile 路径 `implementation/test1_beach_v8_base.json`。证据与源码/截图哈希见 [G02 manifest](g02_manifest.json)。

## 分项与选择

- 床面采用新的 lit shader `test1_bed_lit.gdshader`，继承v8的湿度、压实、世界空间颗粒和底面亮纹采样；显示法线显式由可见高度场转到视空间，避免从网格背面观看时光照法线被翻转。沙量、湿度与求解器未改。关闭颗粒后干沙ROI平均绝对RGB差4.038/255，深水ROI差0；近景颗粒与坡面保持附着。
- screen optics 开启时浅水可读沙底，远水呈蓝绿色；关闭时浅水ROI平均绝对RGB差12.719/255，深水8.722/255，干沙仅0.704/255。关闭planar reflection深水差4.66/255，干沙0.029/255，表明各层能分开调节。此处是Godot视觉贡献，不是原作折射/反射公式验证。
- 底面亮纹使用现有 fold pattern，UV尺度从1.1单独试到2.0，再将强度从0.5单独试到0.8；选择细密版写入新样片profile，未覆盖旧v8。关闭亮纹后湿床ROI平均绝对RGB差5.564/255，干沙仅0.251/255，符合亮纹主要落在水底而非干地。与参考相比线条仍有程序纹理感，后续可按Q-CAUSTICS-01查3D纹理内容；当前样片可用。
- 近景、主机位均保留沙体受光、水下底形与高沙体遮挡。前景物体的折射边缘还需G03/G05在运动浪与多机位检查，不据本次静帧宣称全部遮挡完成。

消融顺序每次只改一个shader开关，所有截图在同一tick=0；起止权威rock/sand/water数组hash分别始终为 `2750211136 / 915864041 / 2415034743`。`g02_capture/`是接受profile的基线及四个消融；`g02_capture_candidate/`与`g02_capture_test1_beach_caustic_strength08_candidate/`保留两个先后单因素试验。不同场景、机位和曝光的参考图仅按形状、层次、接触特征比较，未用整图像素相似度。

结论：G02 静态分层与负例通过。动态亮纹随时间的效果、浪前白沫与水沙接触进入G03；与原作有效3D纹理是否同源仍为C1。
