## 可见贡献与绘制状态

事件 6196 是 `ExecuteIndirect` 的索引实例绘制：6 个索引、29,950 实例，输出场景 HDR `ResourceId::3354`。6184 与 6196 的同一 1280×720 HDR 输出预览见 [目标板](reference_board.md)；6196 后推进浪的明亮细线和浅水岸脚碎白更加明显。6195 是 `ExecuteIndirect` push marker，6195/6196 原始 RGBA16F 取数与 SHA 见 `evidence/p02_foam_upstream.json` 和 `evidence/p02_foam_quantified.json`。两次单独重放的 HDR 相减改变范围很广（阈值 0.001 时约 45 万像素），不能把这个差分数字全算作 6196 的覆盖或亮度。由事件、输入、状态、图像共同支持“独立亮沫绘制”，精确像素贡献仍待受控消融或 pixel history。

`evidence/p02_water_state.json`：6196 开启 SrcAlpha/InvSrcAlpha，GreaterEqual 深度测试，不写深度；水面 draw 则写深度。`event_6196_pixel_disassembly.txt` 的 6–13 行根据方形 UV 到中心距离生成圆形 alpha，14–24 行采 `ResourceId::139723` (`t2`) 作局部色/遮罩，35–68 行从 `ResourceId::139590` (`t1`) 读取网格字段并插值，69–78 行做阴影比较，79–84 行参与照明后输出。它并非一张不随状态变化的白色覆盖图；具体粒子色与贴图通道语义没有完整解码。

## 几何、位置和参数边界

`data/raw/rdc/test1/event_6196_vsout.bin` 为完整 4,792,000 字节，每个实例四个 40 字节 VSOut 顶点；`tools/p02_foam_quantify.py` 复算结果在 `evidence/p02_foam_quantified.json`。29,950 个实例的四顶点均位于同一 Y 平面，UV 恒为 (0,0),(1,0),(0,1),(1,1)；片宽中位 0.04168、5–95 百分位约 0.02158–0.07896 场景单位，X/Z 宽一致。中心 Y 范围 0.9964–1.9953，中位 1.5228；X 为 -2.6657–13.2580，Z 为 -7.5–7.4993。VS 指令 `event_6196_vertex_disassembly.txt`：先用 t1 `ResourceId::139575` 索引 t0 `ResourceId::139582`（16 字节/记录），t0 的 `.x` 经指数函数调整片宽，又经 `saturate(10*x)*0.4` 传为片内一致的 v2.z，最后将四个顶点变换为世界位置。v2.z 取值 0.1639–0.4。它是透明度/强度输入；**不能仅凭这些字节命名为年龄或寿命**。片层位置与图中推进浪、岸脚亮带相符；单帧无法证明每片由哪次破浪生成。

## 岸脚与时序边界；Godot 适配

水面和沙面必须共享可见床面/表面基准；优先在 `water_height - visible_sand_height` 接近零、坡面低于浪前且有局部水运动时放少量碎片。浪峰白沫与岸脚细线分开调密度，障碍脚遮挡靠深度而不是常驻白环。实例面片随水面高度并保留小量偏置，近距离观察不得穿岸或悬空。浅水底面亮纹是另一路，不应加到泡沫源上。

原作推进速度、退浪、平流、衰减、侵蚀因果均为 C0；若能取得同机位带时间戳连续运行可再查。P03 采用固定 seed/tick 的独立 Godot 运动模型作为**适配**：主浪相位驱动岸向推进，局部速度/曲率及接触权重发射细碎短时片层，随运动场平流并衰减；实时、冻结、暂停、恢复共用表现时钟。实施时消融浪前/岸脚源并检查连续 60 秒与遮挡负例，确认不会出现永久白环或亮沫逆向漂移。适配不声称复原原作公式。
