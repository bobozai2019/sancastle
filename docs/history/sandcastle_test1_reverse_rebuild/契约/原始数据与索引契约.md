# 原始数据与索引契约

日期：2026-10-09。角色：contract。状态：draft，RG1冻结。

范围约束：索引服务视觉效果技术取证。全量机械目录允许登记业务相关对象，但不解释或恢复业务逻辑；C#/IL2CPP只辅助必要视觉类型/字段/配置解码，不采集或分析业务方法体。Shader/ComputeShader的计算指令和伪代码仍在范围内。

## 1. 原始与派生数据

| 类别 | 定义 | 保存方式 |
|---|---|---|
| source_file | 未改动竞品文件 | 原路径+全文件SHA256；需要快照时复制并核对hash |
| serialized_object | 对象在序列化文件里的字节 | `.bin`+file_id/path_id/绝对文件偏移/长度/对象hash |
| streamed_payload | Texture/Mesh等外部资源字节 | `.bin`+`.resS/.resource`来源/偏移/长度/hash；无外部数据也明确 |
| compiled_shader | 原始Shader/ComputeShader对象与捕帧实际shader字节码 | 包内对象字节及RDC stage/event/variant分别登记 |
| runtime_snapshot | RDC指定事件的buffer/纹理/VSOut/常量原始数据 | 记录capture hash、事件、ResourceId、subresource、格式、stride、单位解码状态 |
| decoded/derived | typetree JSON、PNG、OBJ、反汇编、伪代码、图表 | 原始数据ID+解码工具/version/参数/变换说明；不能冒称原始数据 |

RDC快照是捕帧中运行期的数据，不等于包内资产。RenderDoc导出纹理应注明API返回的格式/行布局、mip/slice/sample和是否解压/转换，不承诺等于GPU显存物理排布；HDR到PNG的曝光/色调映射单列。

## 2. 目录与身份

所有机器产物写到任务根下英文目录`data/`、`tools/`、`evidence/`；原包只读。运行ID为`YYYYMMDD_HHMMSS_<step>_<short-id>`，各次导出独立目录，不静默覆盖。

| ID | 定义 |
|---|---|
| file_id | `src:<SHA256>`，原文件内容身份；路径为可变定位信息 |
| object_id | `asset:<容器SHA256>:<signed_path_id>`，仅使用PathID不足以唯一定位 |
| payload_id | `payload:<源SHA256>:<offset>:<length>` |
| symbol_id | `symbol:<metadataSHA256>:<kind>:<token或table_index>`；无解码只能生成独立string_hit ID |
| rdc_id | `rdc:<captureSHA256>:<event>:<resource>:<stage或subresource>` |
| artifact_id | 导出内容hash+类型+run_id；与parent_ids建立溯源 |

PathID、偏移和GPUResourceId作为十进制/十六进制字符串输出，防止JS数值精度丢失。RDC ResourceId只在同一捕帧内有效。

## 3. 索引文件与字段

JSONL为权威索引；CSV/HTML导航可由它生成。没有取得的数据使用`null`+原因，不用0或空数组伪装成功。

| 文件 | 必需字段 |
|---|---|
| source_files.jsonl | schema_version, file_id, source_relpath, absolute_path, sha256, bytes, role, unity_version, metadata_version, run_id |
| assets.jsonl | object_id, file_id, path_id, class_id, type_name, name, container_path, byte_offset, byte_length, raw_path, raw_sha256, decoded_paths, parse_status, error, stream_ids, dependency_ids, run_id |
| payloads.jsonl | payload_id, owner_object_id, source_file_id, byte_offset, byte_length, raw_path, raw_sha256, format_metadata, status, error |
| dependencies.jsonl | from_id, to_id, reference_kind, field_path, file_index, path_id, resolved, unresolved_reason |
| visual_config.jsonl | config_id, object_id, field_path, raw_locator, value, value_type, unit, unit_status, decode_status, symbol_ids, runtime_binding_ids, evidence_ids, limitations |
| symbols.jsonl（按需） | symbol_id, assembly, namespace, type, field, kind, token, metadata_location, field_offset, field_type, derived_paths, confidence；kind仅type/field |
| rdc_events.jsonl | capture_id, capture_sha256, event_id, marker_path, action_type, stage, shader_id, pipeline_state_path, output_ids, observation |
| bindings.jsonl | capture_id, event_id, stage, register_or_binding, space_or_set, array_index, resource_id, view_format, byte_offset, byte_length, subresource, raw_path, decoded_path |
| artifacts.jsonl | artifact_id, parent_ids, kind, path, sha256, bytes, tool_id, tool_version, command_ref, run_id, conversion, completeness, error |
| asset_rdc_mapping.jsonl | object_id, rdc_id, match_basis, confidence, evidence_ids, limitations |
| tools.json | 下载来源、版本/commit、二进制hash、完整命令/参数、环境、日期、兼容性探针结果 |

字段约束：`parse_status/decode_status`为`ok/partial/raw_only/failed`；`unit_status`为`confirmed/inferred/unknown`；`completeness`为`complete/partial/failed`。声明complete须含预期数量和实际数量。引用必须解析到已登记ID或有明确unresolved记录。无需IL2CPP辅助时显式登记原因，不能把空符号文件称作类型恢复成功。

asset→RDC映射须用格式/尺寸/数据hash、绑定、内容或多证据判定，名称相同不足以认定。包内默认值与捕帧有效值同时保存并标明差异。

## 4. 取数接口（P01 G05实现后可用）

这些CLI是本计划要求实现的接口，当前不是已存在工具：

```powershell
$planRoot = 'D:/godot/project/sandcastle/task/sandcastle_test1_reverse_rebuild'
python "$planRoot/tools/query_index.py" --root $planRoot --kind asset --name 'Lit/Water'
python "$planRoot/tools/query_index.py" --root $planRoot --kind rdc --capture test1 --event 6196
python "$planRoot/tools/get_raw.py" --root $planRoot --id '<索引返回ID>' --out "$planRoot/evidence/retrieved.bin" --verify
python "$planRoot/tools/validate_index.py" --root $planRoot
```

`query_index`支持kind/name/type/id/capture/event；名字匹配返回全部候选，不自动选第一个。响应包含稳定ID、源定位、原始/可读/依赖路径、parse_status和限制。

`get_raw`仅按索引查找；拒绝越界/父路径逃逸和输出到原包，不覆盖现有文件。对象与payload可从源字节范围复取并核对hash；shader反汇编/PNG不属于raw接口结果。RDC记录优先返回已导出的快照，缺快照时返回重放脚本及精确选择器，不能从压缩RDC容器按猜测文件偏移切数据。输入/输出源hash不符立即失败。

标准响应：`{ok:boolean, code:string, id:string, artifact_path:string|null, sha256:string|null, source:object, limitations:string[]}`。错误code至少包括`not_found/ambiguous_id/source_hash_mismatch/out_of_range/raw_unavailable/replay_required/output_exists`；失败退出非0。

## 5. 校验

源文件前后hash一致；字节范围满足`0≤offset`、`offset+length≤source_bytes`；对象raw长度与对象目录一致；外部payload单独核对；索引相对路径存在且hash一致。已解析容器的对象总数与索引逐类型计数一致，所有失败进入失败表。P0依赖不允许无说明消失。

空缓冲/无目标、解析失败、缺外部资源、反编译空方法不得判PASS。schema和工具版本在RG1冻结，后续变更须记录迁移及旧索引兼容。
