# W07 浅底形体归因（2026-10-07）

结论：当前自然岸线候选下，0.02–0.08m 的可见浅水主要是带周期起伏的连续宽带；对照 test35 的沙舌和沟脊仍缺有辨识度的床形。一条局部沙舌/水沟试验改变了真实水深场，但在正常水材质中只留下很淡的线。单纯增强床面坡度明暗或增加透射长度也没有使其达到 V01。试验源码开关已撤回，三个原型文件的 SHA256 恢复到前轮自然岸线候选的记录值。

## 参考与现状

[test35 最终重放图](../rdc_evidence/test35-frame20641_color_after_5593.png)的浅滩有宽沙舌、邻接暗沟以及多尺度水底变化。自然岸线固定 tick120 的[实际可见水深图](W07_浅底形体归因_20261007/fixed_natural_depth120_water_oblique.png)按 shader 重建水深着色，红色是 0.02–0.08m、蓝色是 ≥0.20m。红带在前景呈周期摆动；[正常材质图](W07_自然岸线输入诊断_20261007/fixed_natural_wide_optical_tick120_water_oblique.png)虽有浅深水色，却没有参考那种可追踪的沙舌/沟脊。这里比较可见形态，不把参考图和原型图的像素坐标当成同一世界位置。

## 隔离试验

临时床面试验在自然岸线输入上加一条 z≈8m、横向略弯的局部沙舌（峰值 +0.040m）和邻接水沟（谷值 -0.032m），并在浅水区更广地压低原周期沙脊。第一次较宽版本把沙舌推出干岸，在[正常材质图](W07_浅底形体归因_20261007/fixed_relief_optical120_water_oblique.png)形成突兀沙嘴，淘汰。第二次收窄后，[深度图](W07_浅底形体归因_20261007/fixed_relief_depth120_water_oblique.png)确认局部沟脊落在浅水：对前轮自然岸线水深 F32 的差分有 32,258 格 >1e-5m、最大 0.0663m；湿→干、干→湿均为 0 格。这 32,258 格还包括压低原周期沙脊的广域变化，不能全归于局部沙舌。

同一收窄床面、固定 tick120、1920×1080、相同水面 shader 下，分别捕获[原材质且无亮纹](W07_浅底形体归因_20261007/fixed_relief_submerged120_water_oblique.png)、[床面水下坡度明暗加至 12 的图](W07_浅底形体归因_20261007/fixed_relief_form_probe120_water_oblique.png)、[水面透射消光长度 0.11→0.25m 的图](W07_浅底形体归因_20261007/fixed_relief_clear025120_water_oblique.png)。无亮纹用于隔离底形，不能作为 V04 的效果替代。沙舌仅留细淡纹，远不及 test35 可辨底形；加明暗或拉长透射没有修复。

[复算脚本](W07_浅底形体归因_20261007/analyze_shallow_relief.py)与[指标 JSON](W07_浅底形体归因_20261007/shallow_relief_metrics.json)保存水深差分及同一候选深度 mask 下的 RGB 均值中位代理。俯斜深/浅比：自然岸线 0.723、收窄沙舌 0.716、加床面坡度明暗 0.710、消光长度 0.25m 时 0.763。该 mask 来自收窄沙舌深度图，且关闭了亮纹，只能比较方向；它不构成 V02 同态验收或 V01 可读性通过证据。消光长度增加反而削弱了深浅分层。

所有试验捕图器输出 PASS，目标图像已实际生成；试验开关在本轮末撤回，不再接受这些旧命令生成新 manifest。当前自然岸线候选源码 SHA256 重新核对为 `reference_bed.gd` `FBBCA9271EC6CA0A425C738A22100CB0CC562E057B89FE3CADF998E23A964294`、`reference_preview.gd` `283114A0B1C7F18BA11CFF6E8B47774B403D6672CC41F9F549730CAE86E483CA`、`capture_reference.gd` `E14CD557FBB6C3A84E1452C2D464DF2826B1A5CD10D2D428237CD4F74F62CFE0`。

后续应把参考床形与底材质作为一个可见目标共同设计：扩大沙舌/沟脊在三个深度层的空间覆盖，使用可解释的床高或材质差异，再核对水面透射、遮挡和 0.02/0.08/0.25m 可追踪边界。不能用深浅亮度比单项或提高水面透明度替代 V01。V01/V02/V06、WR-G0 仍不通过。
