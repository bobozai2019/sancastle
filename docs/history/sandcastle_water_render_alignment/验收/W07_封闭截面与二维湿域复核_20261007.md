# W07 封闭截面与二维湿域复核（2026-10-07）

## 封闭截面试验

WR56 的开放翻卷折面在深度写入下看不到回折下表面。本轮做一个默认关闭、**环形截面闭合但两端未封盖**的诊断浪体：每个岸行 24 段椭圆截面，沿 z 接成网格；表面读取同一 rock+sand+water 重建高度，中心读取已有 256×1 前缘字段，七点邻行支持控制半径，向岸一侧按湿水距离缩短；青色不透明材质写深度。`--crest-volume-debug` 用纯色区分前侧、上侧和其余面。它不修改水沙求解，也不接入正式入口。

耦合参考床面 tick 390、一个合法波包/无额外波，D3D12/GTX 1050、1920×1080 全屏，六机位捕图均退出 0，manifest/PNG 在[证据目录](W07_封闭卷浪体原型_20261007)。与同态关闭浪体、关闭主水面泡沫的基线相比，有波 RGB 最大通道绝对差 >12 的像素为：oblique 12467、close 21072、grazing 21719、wavefront_side 136059、crest_profile 171967、crest_cross 170475；无额外波六机位均 **0**。两组 `foam_summary` 与初始 rock/sand/water 哈希同态。

[俯斜图](W07_封闭卷浪体原型_20261007/volume_wave390_coupled_oblique.png)中浪体成为细长断续青管，浅岸有突出片段；[横截面](W07_封闭卷浪体原型_20261007/volume_wave390_coupled_crest_cross.png)中管体从前景伸向远处，与主水面呈独立实体。[分区纯色横截面](W07_封闭卷浪体原型_20261007/volume_debug_wave390_coupled_crest_cross.png)证明闭合截面各面在正确深度次序下均可见；但可见性本身没有解决共享水面、局部朝向和水沙接触。这是 V03/V06 明确失败，不选此表示。

## 同态二维字段读回

在同一个 tick 390 有波状态，用 `--front-field --write-water-field --write-bed-fields --write-previous-foam --write-front-field` 导出 256² 当前水深、rock、sand、前 tick RG32F 泡沫状态及 256×1 前缘字段；[原始 manifest 和二进制](W07_局部前缘字段诊断_20261007)保留。脚本 [analyze_fields.py](W07_局部前缘字段诊断_20261007/analyze_fields.py)按原 compute 的 `max(now−previous_depth,0) × smoothstep(0.01,0.04,now)` 重算前缘。与 GPU 输出的最大峰误差 `9.4e−10`，前缘 x 最大误差 `7.2e−5` 格，证实读取/公式对应，而非数据时序错位。[完整统计 JSON](W07_局部前缘字段诊断_20261007/fields_wave390_topology.json)给出逐距离干格行。

| 同态空间事实 | tick 390 结果 | 含义 |
|---|---:|---|
| 前缘峰 >0.0025 | 199/256 行 | 本帧活动支持范围 |
| 水深 >0.001m 的一行有至少两段独立湿水区 | 40 行 | 单 x 前缘不能表示整行湿域拓扑；z=100 行为 x `[0,93)` 与 `[131,199)` |
| 上升分数 >0.0025 的一行有两段 | 0 行 | 此帧活动上升带本身通常是一段，不能把双湿域误称为双上升前缘 |
| 前缘向岸 +0.125m 的格水深 <0.01m | 0/199 行 | 近侧一格在此帧仍湿 |
| +0.25m / +0.30m | 4 / 9 行 | 固定体宽开始跨入干格 |
| +0.58m | 59 行 | 宽前端与湿域显著冲突 |

统计以 `round(front.x + extent/0.125)` 所在物理格判干，不是连续可见岸线的最终交点。与 WR53 采用的逐行扫描/几何门口径不同，59 行不能直接替换其 40 行结论。世界坐标、渲染插值和跨行三角仍需单独核查。

## 判定与下一输入

闭合截面让前、上、背面在深度写入下可见，但作为独立长管无法形成连续水面或合格浪前；单行前缘场精确却丢失湿域的二维分支和局部岸线宽度。下一路线需要以二维水深、上升/泡沫历史及床面共同定义局部前缘位置、法向、湿域交点和显示拓扑，使抬升面与主水面相连；细小水平亮沫片只能随后贴在该表面上。V03/V05/V06/V08、W07 G03、WR-G0 不通过，活动成本和完整生命周期未测。
