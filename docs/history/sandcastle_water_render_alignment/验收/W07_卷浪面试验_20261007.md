# W07 浪前抬升面着色与前移试验

日期：2026-10-07。结论：**抬升面随泡沫着白可作为后续局部视觉候选；仅将顶点前移 0.12 m 的卷浪尝试淘汰。V03/V05 仍未通过。** 原侧视中的青色浪脊在着白后出现可辨亮面；前移本身几乎没有形成卷曲、厚亮芯或岸线接触改善。耦合场景俯斜图的浪前更亮，但依然接近一条沿岸的宽白带，侧视可见竖向采样条纹，与原参考的连续曲率/破碎结构仍有主要差距。

只改 W07 `prototypes/reference_water.gdshader`：默认关闭的 `prototype_crest_white_face` 用已计算的显示浪脊抬升量和湿深，给抬升面增加随固定世界噪声变化的白沫着色；`prototype_curl_forward_m` 使深水中的抬升顶点沿波前方向最多前移 0.12 m，近干岸由水深门控制。两者只改变显示，不写回水、沙、泡沫或物理账本。`capture_reference.gd` 新增同名参数并写 manifest；生产 shader 和 solver 不变。
