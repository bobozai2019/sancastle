# W07 抬升水面亮沫片试验（2026-10-07）

结论：**可把水平亮沫片贴到二维局部前缘主水面的实际抬升高度，并用投影尺度抑制近景大白点；但可见结果仍是散点和细亮线，V03/V05 未通过。** 本轮只修改默认关闭的隔离原型，WR-G0 仍不通过。

## 构造

上一轮[浪唇开关归因](W07_连续浪唇原型_20261007.md#有波同-tick-浪唇开关归因)证明横剖长青片来自独立不透明行带。本轮在现有水平片 shader 增加 `raised_local_front`：每片按与 `reference_water_local_front.gdshader` 相同的局部前缘距离、上升强度、水深门和 0.25m 高度计算主水面抬升。`--foam-front-raised` 仅适用于局部前缘主水面及前缘片层。新 `--foam-front-pixel-sized` 用视距、投影矩阵和 1080p 高度，把片直径设为约 3.5 投影像素，并保留随机尺寸变化；这只是水平面的尺度近似，视角倾斜仍会压缩投影。两项开关均默认关闭。

使用 8192 个逐行前缘小片（32×256），`--foam-front-only --foam-splats-fine`，关闭主面泡沫以隔离片层。Godot `v4.7.beta.custom_build.dff2b9bb6`，D3D12/GTX 1050，耦合参考床面，合法 seed31/0.18m 波包、tick390、1920×1080 六机位。三个有波组的 manifest 除指定开关、run ID 和输出路径外一致，捕图日志均 `PASS`，没有 shader/script ERROR。

[复算脚本](W07_抬升水面亮沫片_20261007/analyze_front_splats.py)逐图比较最大 RGB 通道差。`平高度→贴合抬升` 的 >12 差异像素：俯斜 1,993、近景 1,452、低角 1,045、侧面 7,685、纵剖 9,980、横剖 19,637。`固定世界尺寸→投影尺寸` 分别为 5,608、1,245、865、6,625、9,673、19,289。这证明两项变化实际影响六个投影视角，但差异像素数本身不证明视觉达标。

无额外波 tick390，`raised_pixel_front_nowave390` 对关闭片层的 `front_off_nowave390`，六机位 RGB 逐像素零差；manifest 仅片层开关、run ID 和输出路径不同。这支持静水负例门控，未验证其他时间、障碍接触或多波场景。

## 判定与下一步

“抬升共高”是可用的片层定位组件；当前行前缘 32 片的固定位置和静态密度仍形成断续描边/散点。主水面本身也只有低矮抬升，无法靠细小水平片补足 V03 要求的厚亮芯和前脸。先修正主水面浪前截面与投影，再依据泡沫历史、湿域及投影像素校准片层的密度和生命周期；需另外验证多相位、障碍接触、V06 近岸剖面和 V08 联合成本。V03/V05/V06/V08、G03、WR-G0 均保持未通过。
