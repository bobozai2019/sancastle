# W07 亮纹及联合水面暂停/恢复一致性（2026-10-07）

结论：**隔离耦合原型在所测完成 tick 暂停三秒，俯斜画面完全静止；恢复到即时、短程和较长程目标 tick 后，与同配置连续运行的画面逐像素相同。** 这验证了 V07 的暂停/恢复一致性组件，尚未覆盖交互入口的连续录像、帧间观感、保存/加载或所有 P0 效果；V07/WR-G0 整体仍未放行。

## 捕图方法

隔离捕图器新增可选 `--pause-hold-ms` 与 `--resume-target-ticks`。到目标完成 tick 后停止自动 tick，设 `visual_time_s=tick/30`；俯斜相机预热 30 绘制帧后捕第一张，保持同一相机、tick、时间至少指定墙钟毫秒，再捕第二张。若 tick 在等待期间变化、GPU 仍有待完成 tick、时间/相机变化或等待超时，脚本失败。恢复检查开启自动播放，目标前再停止并精确完成目标 tick；每个目标更新仿真可视时间，俯斜相机预热后捕图。manifest 保留原目标 tick/revision，另外记录暂停实测时长、绘制帧数、恢复 tick/revision/时间/相机与图片路径。

使用真实可见全屏 1920×1080、GTX1050/D3D12、同一初始 rock/sand/water 哈希 `1625571958/2318428149/4161789743`。所有捕图日志 `PASS`，无 shader/script ERROR；折叠纹理 `Image.load_from_file()` 的桌面导出兼容 warning 尚存。分析脚本同时核对两条路径的相机、波包、全部 `prototype_*` 开关、网格与物理规格、初始哈希、视口、驱动/设备、目标 revision 和时间。
