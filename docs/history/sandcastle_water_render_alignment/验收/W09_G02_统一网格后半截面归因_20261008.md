# W09 G02 统一网格后半截面归因（2026-10-08）

结论：**左侧大三角面的直接显示来源是统一网格卷浪截面后半段，V03/V06 仍未通过**。这缩小了下次拓扑改造范围，不代表浪形已修复。所有试验为默认关闭的隔离原型，W09 性能仍 **0/10**。

在[二维前缘限域](W09_G02_统一网格二维前缘限域_20261008.md)的同一曲流入海口耦合、80 波包 tick240、D3D12/GTX 1050、1920×1080、二倍显示细分下，`unified2ddebug240` 用已有分区调试色显示离岸主水面为红、卷浪截面为绿/黄/紫、向岸主水面为蓝；`unified2dprobe1_240` 仅去掉卷浪截面参数 `t<0.5` 的后半段。两次受检捕图 PASS。[完整侧视](W09_G02_局部主网格_20261008/unified2ddebug240_coupled_wavefront_side.png)与[消融侧视](W09_G02_局部主网格_20261008/unified2dprobe1_240_coupled_wavefront_side.png)的左侧异常片在消融后露出沙床。按固定 ROI `x=0..499,y=250..599`，[复算器](W09_G02_局部主网格_20261008/analyze_backface_probe.py)和[指标](W09_G02_局部主网格_20261008/backface_probe_analysis.json)给出 51,334 个 >12/255 差异像素，绿色卷浪后半截面精确调试色像素从 48,885 降至 0；红色离岸主水面 59,064→59,170，蓝色向岸主水面 62,062→62,062。该 ROI 归因不能自动推断所有视角的缺陷都来自同一段。

为检验活动段终点，另试验在二维局部前缘同 X 的 ±2/±4 行采样并短距离延续支撑。`unified2dsmooth240` 相对原二维限域的有波侧视改变 7,405 个 >12/255 像素，但三角面仍在；`unified2dsmooth300nowave` 无额外波包四机位无显著差异。配对泡沫 PNG SHA 相同，水深与行前缘为运行间浮点微差。[指标](W09_G02_局部主网格_20261008/seam_join_analysis.json)和[侧视图](W09_G02_局部主网格_20261008/unified2dsmooth240_coupled_wavefront_side.png)保留此负例。多采样 shader/CLI 开关已撤回，不作为后续路线。

当前源码严格 staging 的 `stagingbackfaceoff240` 固定/耦合双场景受检包装器 PASS；六张默认机位图与撤回前 `staging2dflagoff240` 逐张 SHA 相同。下一步应在统一网格的卷浪后半截面与离岸主水面的共享连接、沿岸活动段端帽和二维湿域裁切处重构；继续拓宽同一行掩码不解决可见三角片。
