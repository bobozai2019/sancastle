这证明此前“没有环境输入”是平面反射观感缺口的一部分，而非投影路径完全不起作用。首版三块球形岩体在主镜头读成突兀的玩具形体，故没有将首版选入正式 v7。

## 第二版：静态资源粗效果

用[离线生成脚本](../../../../tests/visual_water_alignment/prototypes/build_reflection_rock_meshes.gd)一次生成三份不规则低多边形岩块 `.tres`；[岩岸场景](../../../../tests/visual_water_alignment/prototypes/reflection_rock_environment.tscn)固定位置、层级、材质与资源绑定，不在 `_ready()` 重建静态节点。两条独立候选场景：[固定](../../../../scenes/water_render_demo_rock_reflection_candidate.tscn)、[耦合](../../../../scenes/water_render_coupled_rock_reflection_candidate.tscn)，以[候选入口脚本](../../../../tests/visual_water_alignment/prototypes/rock_reflection_candidate_entry.gd)驱动场景中已保存的 960×540 反射视口和镜像相机。原 v7 profile 只用作基底，候选反射能力未写入该 profile，故这两条入口明确是**隔离候选**，不是正式同 profile 交付。

[第二版掠射图](W10_G07_v7环境形体反射_20261009/w10g07v7rock2_240_grazing_projected.png)可辨不规则岩岸与水面倒影，比首版球形剪影更接近粗效果。[双场景直接入口探针](../../../../tests/visual_water_alignment/prototypes/probe_rock_reflection_candidate.gd)在 D3D12、GTX 1050、1920×1080、VSync off 下，固定/耦合 tick30 与 tick240 均退出 0/PASS；[tick240 manifest](W10_G07_v7环境形体反射_20261009/w10g07candidate240tri_manifest.json)列出两模式三机位 PNG、F32 字段与有效 v7 profile SHA。[耦合掠射直接预览](W10_G07_v7环境形体反射_20261009/w10g07candidate240tri_coupled_grazing.png)与第二版隔离投影图一致。对既有 v7 tick240 F32：固定岩/沙/水逐字节同态；耦合岩同态，沙/水最大差分别为 1.79e−7m / 1.56e−7m，无 >1e−5m 格差。

此阶段只完成“有可辨环境倒影”的粗效果候选。对照 [test1 RDC 画面](../rdc_evidence/test1_color_after_6196.png)，参考沙岸、植被、深水层次仍未达到；RDC 静帧也不能证明原作反射算法。候选没有正式 profile/effective 回读、动态转镜头、遮挡、真实活动成本或长稳，故 V02/WR-G1 **仍 FAIL**，不计性能轮。G07 粗效果交付到此，下一项继续独立验收，不修改海浪。
