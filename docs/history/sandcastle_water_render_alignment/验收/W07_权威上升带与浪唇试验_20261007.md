# W07 权威水深上升带与浪唇试验

日期：2026-10-07。结论：**相邻 tick 的水深上升带能比泡沫覆盖更稳定地定位当前波包前缘；统一纹理采样并按无波背景设阈值后，误判尖纹和无波白线消失。** 它仍只构成厚白脊/局部薄唇，没有达到 V03 卷浪曲率、V05 白沫碎裂或 V06 接触目标；W07 G03 与 WR-G0 不通过。

## 物理场诊断

在耦合参考床面上，使用同一初态、tick、D3D12 1920×1080，分别以合法 `test_packet` 波请求和无额外波包运行至 tick 330/390，导出原始 `water` R32F。波包在 x=0 边界注入，沿 +x 传播；[边界实现](../../../../shaders/simulation/shallow_tide_boundary.glsl)的水深/动量注入由原求解器处理。差分 `有波水深−无额外波包水深` 是离线归因对照，不是运行时可用的输入。

| tick | 差分 > 1 cm 格数 | 逐行正峰位置 x 格 p10 / p50 / p90 | 逐行正峰幅度 m p10 / p50 / p90 |
|---:|---:|---|---|
| 330 | 29674 | 114.5 / 134.5 / 148.0 | 0.0643 / 0.0986 / 0.1104 |
| 390 | 32115 | 132.0 / 157.0 / 172.0 | 0.0698 / 0.0921 / 0.1003 |

逐行峰位先对 x 作 7 格均值，在 x=30–219 内取最大；两相位 256 行均有正峰 >1 cm。中位 x 随 60 tick 推进约 22.5 格，但这只是两个快照的轨迹证据，不证明恒速或参考录像速度。原始 float32 场、截图、manifest 与日志位于[物理场目录](W07_权威浪前场诊断_20261007)；[分析脚本](W07_上升带浪唇原型_20261007/analyze_rise_front.py)和[JSON](W07_上升带浪唇原型_20261007/rise_front_summary.json)保留可复算统计。

再独立捕 tick 389/390 的水深、床高，并回读 `gpu_foam_field` 两个 ping-pong 纹理：**渲染绑定的历史纹理 G 通道与独立 tick 389 水深逐格完全相等**，当前水纹理与独立 tick 390 水深也完全相等。该历史状态是泡沫计算本就保存的上一 tick 深度，不增加物理输入或 CPU 数值反馈。耦合场逐行 x=115–249、当前水深 >1 cm 的最大正上升量：有波 p50 0.005436 m、220/256 行 >0.0025 m；无额外波包 p50 0.001126 m、最大 0.002434 m、0 行 >0.0025 m。阈值是此负例负载下的诊断分界，不是跨场景通用常数。源于潮位变化的上升量也属于权威状态，不能直接称作浪前。

## 显示原型与隔离结果

W07 原型提供默认关闭的 `--crest-rise-ribbon` 与 `--rise-crest`。前者用当前水深减泡沫历史 G 通道，在 256 行的已湿区域搜索向岸上升峰，驱动七层附着截面；后者在现有主水面网格上按局部上升带抬升并着白。两者都只读取现有 GPU 状态，不改求解器、泡沫演化或正式 shader。`--write-water-field`、`--write-bed-fields`、`--write-previous-foam` 只为 W07 诊断导出原始场。所有捕图 exit 0、PASS；与旧写深度基线相比，tick=390、revision、初态哈希、波请求、foam 统计及四镜头一致。

初版主水面原型把当前水深按最近邻、历史水深按线性采样，在 2 倍细分顶点把空间水深坡度误作时间上升，产生大片周期尖纹；[初版图](W07_上升带浪唇原型_20261007/rise_crest390_coupled_oblique.png)仅用于失败诊断。历史纹理也改为最近邻后，[修正图](W07_上升带浪唇原型_20261007/rise_crest_nearest390_coupled_oblique.png)消除尖纹，留下连贯岸向白脊。将主浪面与独立浪唇合用的[中间图](W07_上升带浪唇原型_20261007/rise_combo390_coupled_wavefront_side.png)仍缺下翻厚芯。

最初浪唇阈值过低，[无额外波包俯斜图](W07_上升带浪唇原型_20261007/rise_still390_coupled_oblique.png)出现与波包无关的完整白线。按上述有/无波逐行峰值收紧主水面和浪唇阈值后，[无波俯斜图](W07_上升带浪唇原型_20261007/rise_gated_still390_coupled_oblique.png)不再有该白线；[有波俯斜图](W07_上升带浪唇原型_20261007/rise_gated_wave390_coupled_oblique.png)仍有明显沿岸白脊，[有波侧视图](W07_上升带浪唇原型_20261007/rise_gated_wave390_coupled_wavefront_side.png)仍是横向厚白带和局部薄唇，不能判 V03/V05 PASS。与同态旧基线比较，最终有波组四镜头明显变化像素为侧视 84913、俯斜 36920、近景 19448、掠射 10284（全图 RGB 最大通道差 >16）；变化量只证明原型生效。

当前[最终源码快照与 SHA256](W07_上升带浪唇原型_20261007/source_sha256.txt)、四镜头 PNG、manifest、日志和原始历史纹理均保留在[原型证据目录](W07_上升带浪唇原型_20261007)。最终阈值仅在 tick 390 波包/无额外波包对照验证；多相位、多波叠加、不同床面、暂停/恢复、透明遮挡与 30+60 秒活动成本未验。主水面原型每次浪脊采样增加多次纹理读取，成本上界未知。该组合保持默认关闭，不接正式效果。下一步宜把连续前缘先缩减成低成本、时间连续的跟踪字段，再设计与主水面共边的翻卷截面和泡沫分层；需先在代表负载下通过视觉与成本门。
