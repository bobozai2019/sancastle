# W08 G01 参考入口能力起点

日期：2026-10-07。状态：[进行中]。本记录只建立 staging 入口的现有能力与差异，不把 W07 原型当成正式 profile 或 WR-G0 PASS。

两个现有原型场景都继承 `scenes/gpu_water_preview.tscn` 并复用 `reference_preview.gd`：固定入口 `reference_fixed.tscn` 的 fixture 为 `water_render_demo_v2`、`enable_erosion=false`；耦合入口 `reference_coupled.tscn` 的 fixture 为 `water_render_coupled_v2`、`enable_erosion=true`。两者均使用 2× 显示细分、关闭结构物和 HUD。参考床面的 `WaterFixture.initialize` 与 `SandFixture.initialize` 接收相同自然岸线/结构化床面参数。已捕获的结构化床面固定 tick120 与耦合 tick390 manifest 初始哈希完全一致：rock `639217814`、sand `1069331530`、water `774098242`。这验证输入一致，不代表两个不同 tick 的物理状态相同。

| 能力/资源 | 固定原型 | 耦合原型 | W08 待办 |
|---|---|---|---|
| 初始 rock/sand/water | 同哈希 | 同哈希 | 将输入纳入统一 staging profile 与直接启动入口 |
| 床面材质 | `reference_terrain.gdshader` | `reference_coupled_bed.gdshader` | 逐参数回读实际消费，尤其水底亮纹/湿度/沉积 |
| 水面材质 | 所测配置为 `reference_water_local_front.gdshader` | 同一 shader | 从原型 CLI 迁移到唯一 loader，不再靠捕图器补设参数 |
| 水沙物理 | 固定沙层，水求解 | 启用侵蚀、沉积和材料耦合 | 不更改现有求解与账本；同完成态比较显示能力 |
| 光学/深度 | 所测配置 `screen_optics=true`、`depth_write=true` | 同值 | 明确 requested/effective 配置及资源清单 |
| 亮纹 | 原型开关，固定床面可启用 | 原型开关，需显式请求 | staging 默认 pending/禁用，启用 pending 必须失败 |

原有 manifest 仅记录 `profile_id=prototype_reference_fixed/coupled` 和多个原型开关，尚无 W08 要求的正式 `schema_version`、requested/effective profile 哈希、材质逐参数消费证明，也没有直接启动、录像、性能探针共用的单一 loader。本报告先补运行时能力证据；后续[W08 G02 staging 接线](W08_G02_staging入口与共享Profile_20261007.md)已让直接入口与捕图器共用 loader，录像/性能仍待接。G01 仍在进行中，WR-G0/V08 的失败数值保留，W07 性能部分已按[总纲十轮规则](../总纲.md#性能迭代上限与移交)移交。

## 运行时资源与亮纹实际消费

捕图器新增显式 `--capability-probe`：在 tick 捕图完成后读取正在使用的床面/水面 ShaderMaterial，确认所需 `sampler2D` 声明与 Texture2D 绑定，并记录类型、尺寸、有效 shader 路径及亮纹/屏幕光学/坡度法线开关；缺绑定或开关值不符会 FAIL。该探针默认关闭，不改变原有捕图配置。固定与耦合模式各在 tick120、真实 1920×1080、D3D12/GTX 1050 对同一结构化床面运行亮纹开/关两组，四组均 exit 0、捕图 PASS、无 shader/script ERROR，初始 rock/sand/water 哈希均为 `639217814/1069331530/774098242`、revision 均为 360。

两模式的床面 `rock/sand/wetness/compaction/water` 五张纹理与水面 `rock/sand/water/momentum_x/momentum_z/foam/local_front` 七张纹理均在运行时绑定为 256² `Texture2DRD`；折叠亮纹纹理为 1024² `ImageTexture`。两模式使用同一 `reference_water_local_front.gdshader`，床面 shader 分别为 `reference_terrain.gdshader` 与 `reference_coupled_bed.gdshader`。两模式的 `prototype_screen_optics` 和 `prototype_eta_normals` 有效值均为 true。以上证明资源声明及绑定，不单独证明每张纹理对最终像素有贡献。

固定模式开启探针的 oblique PNG 与上轮未开启探针、同配置同 tick 的 PNG SHA256 均为 `4E6DC3399EEAA9876F6A7AE909C4F71FA41B700090F62B256AE441D5DE2AA714`，说明此次清单探针没有改变该画面的像素。

第三组在固定、耦合模式均注入相同合法波包，在各自 tick390 完成态仅切换 `phase2_foam`。每对内的初始哈希、波包请求、完成 revision、完整水深 F32 文件 SHA256 与泡沫字段 PNG SHA256 相同；固定对为 revision 1493，耦合对为 1495，**不以两模式之间的字段相同为前提**。主水面白沫开关的三镜头 >12/255 差分：

这证明同状态白沫字段在两个模式的水面 shader 中都有可见贡献。该试验没有检验白沫形态是否达到 V05，也没有检验连续动态、持久化或性能。G01 此时已有亮纹、屏幕光学和活动白沫的局部消费证据；后续[staging 湿度与局部前缘消费](W08_G01_staging湿度前缘消费_20261007.md)又补齐两项同态 A/B。未实现效果仍须后续工作包处理，完整 release schema、参考画面对位和正式性能均未通过，G01 保持 [进行中]。
