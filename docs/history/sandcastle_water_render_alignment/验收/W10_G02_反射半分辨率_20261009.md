# W10 G02 平面反射半分辨率诊断（2026-10-09）

结论：将隔离镜像视图由 960×540 缩至 480×270，固定 tick390 的三机位水面画面几乎不变，且单次耦合掠射成本样本的整帧 p99 降低 2.156ms。但半分辨率组模拟速率 29.997 tick/s，低于 ≥30 的 V08 数值门；原尺寸组本次为 30.013 tick/s。两组仅为一次同配置 A/B，前一次 W07 原尺寸测量也曾失败，不能据单次样本选择正式反射路线。候选保持隔离、默认关闭，W10 G02/V02/V08/WR-G1 未通过。
