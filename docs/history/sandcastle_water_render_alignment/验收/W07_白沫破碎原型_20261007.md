# W07 隔离原型：白沫破碎图案

日期：2026-10-07。状态：**v1 淘汰；v2 留作候选，V03/V05 仍未通过**。本实验在已验证的 tick 360 浪前上进行；参考型固定床面、可见全屏 1920×1080、D3D12/GTX 1050，统一 `crest-height=0.16`、真实坡度法线和同一波包。仅改复制的显示 shader，没有改变求解器或泡沫场。

原显示 shader 的泡沫破碎由两组正弦相乘，俯斜镜头可见沿浪前重复的鱼骨状白纹。[浪前场回读](W07_浪前时序与浪脊原型_20261007.md)表明，物理泡沫覆盖本身也呈窄带与斜纹，单纯调整颜色无法彻底解决形体。

试验了固定世界坐标的双尺度值噪声。v1 直接用噪声阈值切泡沫，结果 [俯斜图](irregular_foam_prototype_20261007/wr_w07_irregular_20261007_water_oblique.png) 出现块状亮片，[侧视图](irregular_foam_prototype_20261007/wr_w07_irregular_20261007_water_wavefront_side.png) 丢失连续亮芯，因此淘汰。[v1 shader 快照](irregular_foam_prototype_20261007/reference_water_irregular_v1_snapshot.gdshader) SHA256 `77DFB50B7A622D8CAE95D47BD8B595080578DDE2211353C39286514E877FA3B2`。

v2 保留泡沫场覆盖为主体，用更细的双尺度噪声调制亮度，并给亮芯保留最低 35% 权重。同源码、同完成状态下的对照：

两组均为 tick 360、revision 1403、同 rock/sand/water 初始哈希 `1625571958 / 2318428149 / 4161789743`，泡沫场 `coverage_05=4814`、sum `1826.015`，四镜头 transform/FOV 一致。对应运行日志 `periodic_v2_run.log`、`irregular_v2_run.log` 无 shader/script ERROR。俯斜诊断 ROI `[1080,470,1310,1050]` 中，8-bit Rec.709 亮度 >225 的像素由 16,299 增至 20,605；这只说明亮面积变化，不能替代参考图的形状判断。

目视 v2 减弱了旧正弦的重复鱼骨纹，但亮带仍窄、部分噪声有方块感；侧视亮芯也没有达到 `test1` 的厚浪前。噪声固定在世界坐标，当前静帧尚不能证明它随泡沫输运、暂停、恢复时无滑移。应在连续时序和真实成本下继续验证；在此之前 **不选择 v2 为正式路线**。
