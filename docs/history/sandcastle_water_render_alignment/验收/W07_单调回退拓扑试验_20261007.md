# W07 单调回退拓扑试验（2026-10-07）

## 问题与改动

[前缘位置与门控归因](W07_前缘位置与门控归因_20261007.md)发现：预置在 x≈4m 的静止卷唇列可缩短活动行与非活动行之间的长横条，但若静止列沿用回折截面，无波会留下贯穿接缝。本轮增加默认关闭的 `--unified-monotonic-base`：同一单网格的非活动卷唇列按 x=3.30→4.58m 单调平铺，左右水面仍连到各自边界；活动时沿用原 11 点卷唇、稀疏白沫和本行强度门控。x≈4m 是此参考夹具的诊断中心，尚非可迁移的动态字段方案。

## 判定

单调平坦的非活动截面是**有效回退拓扑组件**，但固定 x≈4m 只适合此诊断夹具；还必须由可跨相位、可区分岛两侧分支的前缘字段提供稳定回退中心。当前局部门控导致的沙色三角未修复，V03 厚亮芯、V05 完整生命周期、V06 >4px 近岸门和 V08 正式活动成本均未通过。W07 G03 与 WR-G0 不通过；开关默认关闭。
