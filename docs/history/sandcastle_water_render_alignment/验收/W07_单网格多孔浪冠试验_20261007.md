# W07 单网格多孔浪冠试验（2026-10-07）

## 试验

在 [单网格卷浪拓扑](W07_单网格卷浪拓扑试验_20261007.md)的封口版本上，增加默认关闭的 `--unified-porous-cap`。它只改变同一卷唇片元的白沫着色：沿岸与截面两尺度固定空间噪声打散亮芯，并在外缘加入少量碎点；几何、求解器、浪前字段和静水回退不变。该开关要求 `--unified-curl --unified-sealed`，只供 W07 原型捕图。

耦合参考床面、tick 330 活动波、tick 390 无额外波，D3D12/GTX 1050、1920×1080；Godot 可执行文件实际横幅为 `v4.7.beta.custom_build.dff2b9bb6`。两次六机位捕图均退出 0。原图、manifest 和[同态比较](W07_非对称浪前原型_20261007/comparison.json)保存在[证据目录](W07_非对称浪前原型_20261007)。比较脚本先核对 case、夹具、tick、初始状态 hash、波请求、泡沫摘要和相机。

## 判定

这是白沫形状的局部候选，**不通过 V03/V05**：虽打破连续白带，前缘整体仍近似等宽青白条，横截面亮斑呈明显粗面片形状，没有参考的弯曲厚亮芯与细碎生命周期。V06 岸边 >4px 接触门没有执行，V08 30+60 秒三镜头和 30 分钟稳定成本没有执行；W07 G03 与 WR-G0 仍不通过。下一步要把卷浪截面、着沫密度和网格细度一起设计，并用活动相位与近岸交线验证；单纯提高噪声频率不能证明形体达标。
