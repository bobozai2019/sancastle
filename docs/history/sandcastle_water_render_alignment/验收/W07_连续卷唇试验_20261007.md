# W07 连续卷唇网格显示试验

日期：2026-10-07。结论：**仅留作局部形态候选；V03/V05/V06/V08 与 WR-G0 均未通过。** 相比逐格帘面，沿泡沫前缘连接的卷唇在侧视形成较连贯的白色顶部；但原水面竖条仍能看见，俯斜镜头变化很小，耦合岸线锯齿未改善。当前形体与原 RDC 的厚亮芯、曲率及破碎结构仍有主要差距。

W07 隔离预览新增默认关闭的 `prototype_crest_ribbon`。shader 沿 z 方向从现有泡沫场搜索向 +x 的前缘，连接每行 7 个截面顶点形成弯曲薄片；网格 1792 顶点、3060 三角形。只读已有水/沙/泡沫纹理，只影响显示。`capture_reference.gd` 和成本探针提供 `--crest-ribbon`，manifest 记录开关；生产材质、求解器和 profile 未改。

## 短成本诊断

耦合 oblique、真实 1080p、VSync off、持续波包，2 秒预热 + 5 秒活动：基线/卷唇为 **27.152/26.956 tick/s**，整帧 p99 **37.899/36.559 ms**，渲染 GPU p99 **6.849/6.779 ms**。两组均不满足 30 tick/s 与 33.3 ms；短样本波动不能判定卷唇的稳定成本增量，更不能替代正式三镜头 30 秒预热与各 60 秒活动采样。由于视觉门未过，暂不为此局部候选执行正式长成本门。

下一步需把卷唇与主浪面连接成可从侧视及俯斜同时读出的连续三维形体，处理原主浪面的竖条和湿干接触，再用动态录像查白沫生命周期。保留默认关闭的原型供同态比较，不选作正式路线。
