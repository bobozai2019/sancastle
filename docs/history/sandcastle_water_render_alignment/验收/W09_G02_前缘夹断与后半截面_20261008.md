# W09 G02 前缘夹断与后半截面（2026-10-08）

结论：**统一网格把行前缘硬夹在 X≥112，确实使左侧卷浪过早终止；把下界放宽至现有扫描范围 X=80 后，又形成更长的白青色墙面、沙地薄片与不闭合的岸边端点，不能选型。** 这进一步限定问题为单行前缘中心驱动连续整张水面的拓扑，而不是单一透明度或局部回退参数。V03/V06/WR-G0 仍 FAIL；W09 G02 [进行中]、0/3，性能 **0/10**。本轮是视觉/字段诊断，不计性能轮次。

## GPU 字段定位

[逐行后半截面复算器](W09_G02_局部主网格_20261008/analyze_backface_edges.py)使用既有 `unified2d240` 的行前缘、水深，及同一初态、相同 80 波包请求的 `rowbase_repro240` 二维局部前缘 RG32F。配对水深最大绝对差 7.45×10⁻⁸m。当前 shader 在 `prototype_unified_field_base` 中将 `front.x` 夹在 112–248；实际行前缘在第 60–83 行约从 112.57 连续移至 93.68，二维局部前缘则继续跟随真实位置。第 67/68 行输入前缘为 109.10/108.53，shader 均夹为 112；二维同 X 前缘位置门约从 0.677 降至 0.429。按当前顶点公式重建，卷浪后半截面这两行的最大 X 边长约 0.532m，而行距只有 0.125m。第 70/71 行位置门约 0.037→0，卷浪在仍有局部前缘峰值约 0.0047 的地方归零。以上边长为字段驱动的顶点公式复算，不是 GPU 顶点读回；[原始数值](W09_G02_局部主网格_20261008/backface_edge_analysis.json)可重算。

## 隔离候选与控制

新增默认关闭的 `--unified-expanded-front-range` 仅在统一网格、字段主面和二维支撑同时启用时允许，把前缘下界从 112 改成 80。曲流入海口耦合、80 波包 tick240、二倍显示细分、D3D12/GTX 1050、1920×1080 四机位受检捕图 PASS。相对原 `unified2d240`，初态哈希、波包请求、泡沫 PNG SHA 一致；水深最大差 6.71×10⁻⁸m，行前缘最大差 3.05×10⁻⁵ 格。俯斜/近景/掠射/侧视的 >12/255 差异像素分别为 56,625/160,260/136,462/147,189。[侧视](W09_G02_局部主网格_20261008/unified2drange240_coupled_wavefront_side.png)与[俯斜](W09_G02_局部主网格_20261008/unified2drange240_coupled_oblique.png)表明左侧卷浪延伸成大片直墙，岛边出现竖直端点，俯斜水面出现跨沙地的片面；不满足厚卷浪与湿域安全。

无额外波包 tick300 的同配置控制捕图 PASS；与 `unified2d300nowave` 配对，四机位均 **0 个 >12/255** 像素，最大差 ≤1/255，泡沫 SHA 相同，水深和前缘只有运行间浮点微差。[四机位完整指标](W09_G02_局部主网格_20261008/seam_join_analysis.json)由现有脚本逐项复算。当前源码严格 staging 的 `stagingrangeoff240` 固定/耦合受检包装器 PASS，六张默认机位图及两份水深 F32 与 `stagingbackfaceoff240` 逐字节同 SHA；原 profile 和默认渲染未改变。

后续必须让每条二维活动前缘分支拥有自己的有限浪体和闭合端帽，并在其两侧共享或可靠回接稳定主水面。X 下界修正可作为该路线的局部字段输入，但不能单独放行统一网格候选。
