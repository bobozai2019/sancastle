# W09 G02 连续行脊线复合材质负例（2026-10-08）

结论：**未通过 V03/V06，候选保持默认关闭**。二维前缘 tick240 的每个强活动行虽只有一个 X 连通段，原每行单中心带配合既有端帽、柔和半透明材质与两端主面贴合，也没有形成合格的连通浪体。它在俯斜图成为细而间断的亮片；侧视在沙舌两侧出现尖片与悬空段。仅使活动行使用单中心，不足以让独立带与主水面共边。

输入：D3D12/GTX 1050、1920×1080、耦合参考床、80 波包、tick240、四倍显示细分、`--local-front-continuous-lip --branch-face-soft-material --branch-face-surface-join`，主泡沫关闭。受检捕图 `rowsoftjoin240` 退出 0/PASS，无 shader/script ERROR。[俯斜图](W09_G02_连续脊线复合材质_20261008/rowsoftjoin240_coupled_oblique.png)、[侧视图](W09_G02_连续脊线复合材质_20261008/rowsoftjoin240_coupled_wavefront_side.png)、[manifest](W09_G02_连续脊线复合材质_20261008/rowsoftjoin240_coupled_manifest.json)和日志在证据目录。

与先前同输入 `broken240` 比较，泡沫 PNG SHA 相同，水深 F32 最大绝对差约 1.83×10⁻⁷m，前缘 RG32F 最大差约 0.0174（含 X 中心坐标）；这些运行间微差不支持逐字节同态的说法，也不能解释可见几何断裂。该组合为视觉诊断，**不计 W09 性能轮次，仍 0/10**。下一版需要在同一拓扑中共享主水面连接边和动态浪脊顶点，并在活动段终点封口；单独材质和顶点位置贴合不足以放行。
