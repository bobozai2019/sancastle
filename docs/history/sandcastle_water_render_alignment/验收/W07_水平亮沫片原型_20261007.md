# W07 水平亮沫片原型（2026-10-07）

## 输入与实现

[RDC 几何复核](W07_RDC分辨率与浪前绘制复核_20261007.md)确认三帧参考的强亮层是数万枚 X/Z 水平四边形，单枚在 1280×720 场景图投影中位宽约 2–4px。本轮只验证亮沫表示：在旧平面水体上加 128×256 个独立小片（每两列物理格一枚），每片顶点取同一 rock+sand+water 重建表面高度并上偏 0.018m；片元从权威水深和现有 RG32F foam_history 取湿域/强度，干格丢弃，不用 `TIME`。片层参与深度检验，不写深度。主水面原泡沫着色关闭，以便隔离贡献。没有改水沙求解或正式入口。

开关 `--foam-splats` 使用规则中心；`--foam-splats-jitter` 在同一网格上按固定哈希扰动位置（±0.10m），仍只由物理场决定出现/消退。两个开关默认关闭，且当前与 unified curl 组合被入口拒绝：片层仅与平面水面共高，不能假称已经解决卷浪体遮挡。

## 对照证据

Godot 横幅 `v4.7.beta.custom_build.dff2b9bb6`，D3D12/GTX 1050，1920×1080 全屏，耦合参考床面 tick 390，eta normals、depth write、irregular foam，六机位。以同态 `--no-main-foam` 为基线；有波输入一个合法波包，无额外波为负例。各运行 manifest/PNG 在[证据目录](W07_水平亮沫片原型_20261007)，全部命令退出 0、完成 tick 390；有波各组 `foam_summary` 与初始 rock/sand/water 哈希全同，泡沫 `coverage_05=4933`、`dry_foam=0`，无额外波 `coverage_05=17`。示例复现命令：

```powershell
$out='D:/godot/project/sandcastle/task/sandcastle_water_render_alignment/验收/W07_水平亮沫片原型_20261007'
& 'D:/godot/Godot_v4.6.2/godot.exe' --path . --rendering-driver d3d12 --fullscreen --resolution 1920x1080 --script res://tests/visual_water_alignment/prototypes/capture_reference.gd -- '--case=coupled' "--output=$out" '--run-id=splats_jitter_wave390' '--tick=390' --wave --eta-normals --require-1080p --readback-foam --foam-splats-jitter --depth-write --irregular-foam --wavefront-camera --crest-profile-camera
```

## 判定与后续

小水平片确能由当前泡沫历史驱动，静水负例不误触发；规则全域布点密度太低且暴露网格。确定性扰动修饰位置但仍不能形成参考主浪的密集碎裂亮芯。当前片层仅留作候选组件，**不放行**。下一原型应将片密度集中到预计算前缘的有效活动段，同时保存局部散点，并让亮层与真正卷浪体共用高度/湿域；随后重新查遮挡、接触、生命周期和成本，不能只靠扩大圆点。
