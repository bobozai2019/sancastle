# W10 G02：折射屏幕边界与前景遮挡（2026-10-08）

状态：**D3D12 阶段探针 PASS；G02 [进行中]，W10 0/3**。当前只验证一个不透明前景物体和两机位的屏幕边界；反射路线、透明物体及完整遮挡视觉门仍未通过。

## 修正

原屏幕光学将 `SCREEN_UV + offset` 直接夹到 `[0.001,0.999]`，越界时可能反复取屏幕边缘的颜色。现在越界时改取原 `SCREEN_UV`；候选采样点在水面前方时继续按已有深度保护回退。旧边缘夹取作为默认关闭的诊断开关保留，以便同状态 A/B；正常 staging profile 未改参数。新增诊断图把越界标红、深度保护标蓝、有效偏移标绿。

## 同态证据

耦合 staging、连续 80 波包、完成 tick240、D3D12 / GTX 1050、可见 1920×1080、VSync off。以正常 profile 的折射强度捕正常俯斜/掠射图；同完成态将强度暂设为 `-0.2` 作越界压力，分别捕新回退、旧夹取和分支诊断图，然后恢复 profile 值。`-0.2` 不是推荐视觉参数。[证据目录](W10_G02_屏幕边界回退_20261008)含图像、F32、manifest；[复算脚本](W10_G02_屏幕边界回退_20261008/analyze_refraction_edge.py)核对 shader SHA、profile、水深字段与旧 tick240 样本并从 PNG 重新统计[指标](W10_G02_屏幕边界回退_20261008/refraction_edge_metrics.json)，PASS。

| 机位 | 压力下越界像素 | 深度保护像素 | 新旧边缘方案差异 >12/255 | 差异落在越界掩码外 |
|---|---:|---:|---:|---:|
| 俯斜 | 4,001 | 344 | 0 | 0 |
| 掠射 | 26,759 | 6,082 | 40 | 0 |

两机位超过 2/255 的新旧差异为 11/708 像素，说明新路径确实在越界区域生效，但正常机位的可见收益很小。新 shader 的正常参数图与改前旧 tick240 图相比，>12/255 像素为俯斜 83、掠射 8；不能把压力试验的越界格数当作正常观感改善量。

另加一个纯洋红不透明方块（世界位置 `(0,1,7)`，尺寸 `1.5×2×0.25m`）作前景诊断。同一 tick 保存有水图、隐藏水面的投影对照、折射压力图。无水对照的方块内部 10,177 像素中，正常/压力图都仅有底部 348 像素被水遮住，范围是图像 y=780–787 的浸水底缘；方块外扩 2 像素以外无洋红串色，方块附近有 2,305 个深度保护诊断像素。该结果支持当前不透明前景的深度顺序，没有证明陡岸、薄水、透明物体、屏幕四角或运动时都正确。

W07 的 12 步屏幕反射只命中部分岸岛，平面反射候选活动成本不达 V08；本轮未改反射路线，故 V02、V06、WR-G0 与 W10 G02 仍未通过。未改物理、水量、床形或 performance profile；不计 W10 性能轮次。
