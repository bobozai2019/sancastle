# W13 G01：薄水透明度下限失败对照

日期：2026-10-08。结论：**不选透明度下限候选；W13 G01/V06/WR-G2 未通过，性能 0/10**。

在[透明度归因](W13_G01_薄水透明度归因_20261008.md)确认右岸存在低 alpha 水片后，以相同严格 staging 耦合场景、tick600、1920×1080、D3D12/GTX 1050、连续 80 波包，临时试验 `ALPHA = max(ALPHA, floor × smoothstep(0.001m, 0.010m, depth))`，`floor` 为 0.2/0.4/1.0。每档在同一完成态保存正常画面和水片 alpha 分档图，之后恢复原值。该 uniform 与捕图开关已在分析后撤回，当前运行时仍采用原默认画面。

[独立复算](W13_G01_薄水透明度候选复核_20261008/analyze_alpha_floor.py)验证本次三镜头正常图、白遮罩、原 alpha 图及 R32F 水深与上轮逐字节相同；候选分档图的红/黄/绿覆盖与白遮罩完全一致。结果见[指标 JSON](W13_G01_薄水透明度候选复核_20261008/alpha_floor_metrics.json)。

| 镜头 | 基线 α<0.20 | floor 0.2：画面 >2/255 像素 | floor 0.4：画面 >2/255 像素 | floor 1.0：α<0.20 / 画面 >2/255 / >12/255 像素 |
|---|---:|---:|---:|---:|
| 俯斜 | 10,244 | 0 | 0 | 4,227 / 13,120 / 0 |
| 近景 | 440 | 0 | 0 | 263 / 315 / 3 |
| 掠射 | 532 | 0 | 1 | 336 / 689 / 8 |

即使最高档显著减少低 alpha 片元，俯斜画面最大单通道差也只有 9/255，且无 >12/255 像素；[基线](W13_G01_薄水透明度候选复核_20261008/floorcheck600_coupled_oblique.png)与[最高档](W13_G01_薄水透明度候选复核_20261008/floorcheck600_coupled_oblique_alpha_floor_100.png)的右岸线没有可确认的形体改善。近景与掠射的少数差异也不足以通过 V06。这个实验说明**单独抬高 alpha 不是当前沙色交线的有效修复**；薄水着色与床面接近是与结果相符的解释，但尚未单独测量，不能当作已证根因。

后续应检查右岸实际床面/水面颜色与可见交线，再比较局部光学或形体候选，同时保持权威湿域和干格安全门。该失败对照未修改共享 profile 或求解器，也不计性能轮次。临时试验的 PNG、manifest、水深和分析器保留在[证据目录](W13_G01_薄水透明度候选复核_20261008)；复现这些候选需按上式重加临时 uniform，当前代码只保留默认关闭的透明度诊断。
