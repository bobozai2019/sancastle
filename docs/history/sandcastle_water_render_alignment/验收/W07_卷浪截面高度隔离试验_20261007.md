# W07 卷浪截面高度隔离试验（2026-10-07）

## 问题与改动

[沿岸强度门与断浪试验](W07_沿岸强度门与断浪试验_20261007.md)使活动浪段更连贯，却仍是长岸线亮边。现有 11 点卷唇截面最高只抬 `0.25m`，水材质为 `unshaded`，无光照法线体积线索。本轮只把卷唇截面高度乘 2（最高 `0.50m`），前缘位置、湿域前端、七点加权门、稀疏着沫和 alpha 均不变，检验高度是否为 V03 缺失厚芯的充分原因。`--unified-body-scale=2.0` 是默认关闭的 W07 原型开关。

## 同态结果

耦合参考床面 tick 390 有波/无额外波，D3D12/GTX 1050、1920×1080；Godot 横幅 `v4.7.beta.custom_build.dff2b9bb6`。两组六机位捕图退出 0，[PNG、manifest、比较 JSON](W07_非对称浪前原型_20261007)在同一证据目录。[比较脚本](W07_非对称浪前原型_20261007/analyze_front_profile.py)先核对状态与镜头。RGB 最大通道差 >12 的像素数：

[原横截面](W07_非对称浪前原型_20261007/unified_smooth_support_wave390_coupled_crest_cross.png)为浅坡；[高度 ×2 横截面](W07_非对称浪前原型_20261007/unified_tall_smooth_wave390_coupled_crest_cross.png)显著升高，却形成大块单调陡坡。[沿岸侧视](W07_非对称浪前原型_20261007/unified_tall_smooth_wave390_coupled_wavefront_side.png)接近连续青色墙面，[俯斜](W07_非对称浪前原型_20261007/unified_tall_smooth_wave390_coupled_oblique.png)依然是狭长着白岸线；浅岸锯齿仍在。大量侧视像素变化证明高度实际生效，不代表参考体量达标。

## 判定

单纯放大现有开放折面高度不是 V03 路线。当前需要能显示前探、下翻、厚度与遮挡关系的浪体截面及其着色，而非再把同一坡面抬高；这还必须与权威湿域、沿岸支持和白沫生命周期共用边界。高度开关默认关闭，仅留否决证据。V03/V05/V06/V08、W07 G03 与 WR-G0 不通过。
