# W09 G02 静态接缝重定位失败对照（2026-10-08）

结论：把统一网格的静态卷浪接缝从约 X=-0.6/+0.6m 移到入海口活动前缘附近 X=-3.65/-2.25m，**没有消除左侧大三角片**，反而使其成为更明显的沙色菱形；与 X≥80 前缘范围组合时仍形成长青墙、岸边硬端和沙地片面。两档均否决，试验开关已从运行时代码撤回。W09 G02/V03/V06/WR-G0 继续 FAIL，性能 **0/10**；这是几何视觉诊断，不计性能轮次。

既有局部主网格在弱活动行把卷浪顶点退回均匀静态格，约位于 X=-0.6m，而此入海口的实际前缘在 X≈-4.3…-1.4m。为检验接缝距离是否主因，临时 `--unified-shifted-seam-base` 将离岸/向岸静态共享边分别设为 -3.65/-2.25m，中间十段按 X 单调铺开；shader 的局部化主面接边使用同一静态坐标。顶点索引、二维活动门、抬升与物理字段不变。另与先前默认关闭的 `--unified-expanded-front-range` 交叉试验。该固定坐标只针对本床形验证，不是通用分支布局。

曲流入海口耦合、80 波包 tick240 与无额外波包 tick300，二倍显示细分、D3D12/GTX 1050、1920×1080 四机位，四次严格包装器捕图均 PASS。每组配对初态哈希和波包请求一致、泡沫 PNG SHA 一致，水深最大差 ≤1.20×10⁻⁷m、行前缘最大差 ≤2.29×10⁻⁵ 格。[逐图复算器](W09_G02_局部主网格_20261008/analyze_seam_join.py)与[完整指标](W09_G02_局部主网格_20261008/seam_join_analysis.json)存档。
