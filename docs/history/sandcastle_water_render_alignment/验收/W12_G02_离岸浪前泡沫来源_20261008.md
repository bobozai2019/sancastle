# W12 G02：离岸活动浪前缺泡沫来源（2026-10-08）

状态：**深水来源缺口归因成立；宽门控及局部峰值门控均未选型**。W12 G01/G02、V03/V05/WR-G2 仍 FAIL；本轮只有完成态视觉/字段诊断，性能保持 1/10。

现行 `visual_foam_step.glsl` 的生成量乘以 `contact = clamp(shallow + 0.35*slope)`；`shallow` 在水深超过 0.22m 后归零。以[曲流入海口候选床面](W07_曲流入海口床面候选_20261008.md)、耦合 `continuous_packets_v1`、tick240、0.25m 浪脊高度、1920×1080 的权威水深、局部浪前 RG32F 和泡沫场对照，定义活动格为浪前强度 ≥0.0012：

| 活动格水深 | 活动格数 | 原泡沫 >0.05 | 原泡沫 >0.20 |
|---|---:|---:|---:|
| <0.07m | 726 | 212 | 196 |
| 0.07–0.14m | 745 | 240 | 210 |
| 0.14–0.22m | 887 | 558 | 323 |
| 0.22–0.40m | 2,541 | 134 | **17** |
| ≥0.40m | 3,100 | 0 | **0** |

活动浪前在深水确实存在，主泡沫却几乎只在浅水/岸脚生成。该统计支持来源门控是离岸亮芯缺失的一个原因，但浪前强度阈值本身不能证明每个深格都应起泡。

为测来源上界，将生产泡沫 compute 复制成默认关闭的隔离 `reference_visual_foam_offshore.glsl`。只修改 `contact` 权重：弱档 `max(contact, 0.35*smoothstep(0.18,0.25,depth)*smoothstep(0.06,0.16,rise_rate))`；强档 `max(contact, smoothstep(0.18,0.25,depth)*smoothstep(0.04,0.12,rise_rate))`。强档源码留存为[快照](W07_曲流入海口床面候选_20261008/reference_visual_foam_offshore_strong.glsl)；当前隔离 shader 已改为下文的局部峰值门控。正式 compute 与 profile 未改。捕图显式 `--offshore-foam-source`，弱档在源码参数升为强档前采集，命令/manifest 的 run id 分别为 `estuarycontinuous240offshore` 与 `estuarycontinuous240offshorestrong`。两档 D3D12/GTX 1050、真实 1080p 均 exit 0 / PASS；相比基线水深 F32 最大差分别为 7.83×10⁻⁸m 和 1.35×10⁻⁷m。

| 活动格水深 | 原泡沫 >0.05 / >0.20 | 弱档 | 强档 |
|---|---:|---:|---:|
| 0.22–0.40m | 134 / 17 | 629 / 56 | 1,376 / 635 |
| ≥0.40m | 0 / 0 | 8 / 0 | 208 / 14 |

弱档[俯斜图](W07_曲流入海口床面候选_20261008/estuarycontinuous240offshore_coupled_oblique.png)几乎没有新增可读离岸亮芯，俯斜 ROI 高亮白像素 5,573→5,626。强档[掠射图](W07_曲流入海口床面候选_20261008/estuarycontinuous240offshorestrong_coupled_grazing.png)出现跨水面的模糊白片，掠射高亮像素 525→4,729，俯斜 5,573→6,487。强档再叠加[非周期碎裂与浪前窄带](W12_G01_非周期泡沫侵蚀候选_20261008.md)后，[掠射图](W07_曲流入海口床面候选_20261008/estuarycontinuous240offshorestrongribbon_coupled_grazing.png)收窄，但高亮仍为 2,603，仍缺参考的厚亮芯和连续浪体。故不能通过增强所有深水上涨格来补离岸浪前。

无额外波包、相同床面/局部浪前显示的 tick300 与 tick600 分别作基线/强档配对。两时刻泡沫场 PNG 逐字节相同；tick300 三镜头最大差 ≤1/255，tick600 三镜头没有 >12/255 变化。因此上述强档在这两个无波完成态没有产生可见伪泡沫；它仍未覆盖长期稳态/侵蚀负例。严格 staging 无候选 tick300 的水深、泡沫场与三镜头和改动前逐字节相同。

进一步读取同一 tick 的上一帧水深，计算每格自由表面上涨速度及横向 ±2 格的局部峰值。0.22–0.40m 活动格共 2,541 格，其中上涨速度 >0.04m/s 有 1,821 格，但横向峰值差 >0.01m/s 仅 76 格；≥0.40m 活动格中满足该峰值差的为 0 格。当前隔离 shader 用 `smoothstep(0.002,0.014,across_peak)` 限制强档来源，另试 3 倍注入；run id 为 `estuarycontinuous240offshoreridge` 和 `estuarycontinuous240offshoreridge3`。两次耦合捕图均 PASS。按同一活动格口径：

| 活动格水深 | 原泡沫 >0.05 / >0.20 | 峰值门控 1 倍 | 峰值门控 3 倍 |
|---|---:|---:|---:|
| 0.22–0.40m | 134 / 17 | 373 / 17 | 663 / 62 |
| ≥0.40m | 0 / 0 | 0 / 0 | 2 / 0 |

[3 倍掠射图](W07_曲流入海口床面候选_20261008/estuarycontinuous240offshoreridge3_coupled_grazing.png)只留下薄白带，尚无参考的厚亮芯；门控也几乎排除了 ≥0.40m 的活动浪前。峰值门控可以收窄生成范围，但单独放大峰值格无法补全破碎相位和浪体形状。此轮未运行新性能测试，W12 性能仍为 1/10。

结论是泡沫**生成位置**需要与可见浪前脊线/破碎相位共同定义，单纯放宽深度门会把整片上涨水面染白；仅用横向上涨峰值又太稀疏。下一候选应输出单独离岸破碎来源或按局部前缘距离限制注入，并同时保留岸脚接触来源、无波负例、恢复与成本门。当前隔离 compute 保持默认关闭，未进入 staging。
