# W07 浪唇沿岸窗口试验（2026-10-07）

## 问题与数据归因

[共截面实体浪唇](W07_共截面实体浪唇试验_20261007.md)在俯斜图里断成青白块。原 ribbon mesh 的相邻行本来由三角面连接；真正使截面在行间收缩或消失的是 `ribbon_mask`：本行前缘峰值门乘以本行前缘水深门。使用此前捕获的 tick 390 `front_rg32f` 和 `water_f32`，[离线复算脚本](W07_非对称浪前原型_20261007/analyze_row_mask.py)近似重建行中心采样，见 [row_mask_analysis.json](W07_非对称浪前原型_20261007/row_mask_analysis.json)。原门在 256 行中有 175 行超过半强度、13 次开关跳变；浅水和低峰值均造成间隙。

独立 `reference_crest_smoothed_lip.gdshader` 保持同一浪唇网格、截面位置与着色，仅把峰值门改为本行及前后 4/8/12 行共 7 点最大值，水深门从 0.018–0.06 m 改为 0.012–0.04 m。离线同公式近似复算有 240 行超过半强度、3 次开关跳变。无波 tick 390 前缘峰值最大 0.0022166，低于起跳阈值 0.0025。该 7 次顶点采样只是视觉诊断；若选用这条路线，应在 GPU 前缘计算阶段预处理，不应直接当作成本合格实现。

## 判定

沿岸窗口是修复条带断块的有效线索，当前 `--crest-smooth-window` 原型默认关闭。修复断块不等于卷浪体量成立；下一表示需要能在俯斜与横截面同时呈现连续、非重复的三维弯曲，并处理岸边安全遮挡。视觉门失败，未运行正式 V08 成本。W07 G03 与 WR-G0 不通过。
