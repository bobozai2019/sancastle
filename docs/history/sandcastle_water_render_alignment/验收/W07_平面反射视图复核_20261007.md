# W07 平面反射视图复核（2026-10-07）

结论：**隔离的镜像相机能取得水面上方的岛体和岸线，并在水面下方呈现连续倒影，覆盖明显超出上一轮屏幕射线。** 这是一条可继续验证的 V02 候选，但画面仍有大片沙色映射与锯齿岸缘，参考颜色/遮挡/成本未达验收；WR-G0 不放行。

## 实现与同态捕获

捕图器的默认关闭 `--planar-reflection-probe` 在 960×540 SubViewport 中共用场景 World3D，按每个主相机关于 y=0 水平面镜像位置、前向和上向。反射专用相机只看复制的床面层；床面复制材质用片元世界高度裁去 y<0 的部分，水面不进入反射视图。`--planar-reflection-projected` 将镜像相机的投影矩阵传给局部前缘水面 shader，按实际水面片元世界位置取样；`--planar-reflection-debug` 可直接显示源颜色。Godot 的 [Viewport 世界共享机制](https://docs.godotengine.org/en/4.6/tutorials/rendering/viewports.html)、[Camera3D 投影和层遮罩](https://docs.godotengine.org/en/4.5/classes/class_camera3d.html)及[空间 shader 坐标约定](https://docs.godotengine.org/en/4.6/tutorials/shaders/shader_reference/spatial_shader.html)用于确认这一路径。

初始镜像视图未裁水下床面时，整片海床遮住岛体；裁切后岛岸进入视图。[耦合俯斜反射源](W07_平面反射视图_20261007/planar_projected_final390_coupled_oblique_reflected.png)与[投影调试图](W07_平面反射视图_20261007/planar_projected_debug_wave390_coupled_oblique.png)显示：按片元世界位置投影后，中央岛的像出现在岛下方的水面，简单的 `SCREEN_UV` 水平翻转不能正确处理抬升浪面。固定场景第一次复制材质误用只在耦合 shader 中存在的 `sand_world_position`，编译失败却仍打印 PASS；改用两个床面 shader 共有的视空间片元位置重建后重捕，删除无效文件。下表只使用日志无 shader/script ERROR 的捕获。

同态 A/B：耦合 seed31/0.18m 波包 tick390/revision1492，固定 tick120/revision360；均为局部前缘 shader、0.25m 高度配置、eta 法线、屏幕光学 0.02 折射与可见面法线，D3D12/GTX1050，1920×1080。耦合另开折叠亮纹。基线与候选都运行反射 SubViewport，只切水面取样；各自 manifest 的完成 tick、revision、初态哈希、相机和其余参数相同，仅 `prototype_planar_reflection_water/projected` 不同。统计为全图任一 RGB 通道的绝对差值：
