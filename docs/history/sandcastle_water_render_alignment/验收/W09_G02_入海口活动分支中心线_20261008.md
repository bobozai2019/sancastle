# W09 G02 入海口活动分支中心线（2026-10-08）

结论：80 波包 tick240 的入海口局部前缘为**四段沿 Z 分离的强活动分支**；194 个强活动行内每行只有一个连续 X 段，现有行前缘中心在多数行与该段接近，但端点有偏移。以每四格一条固定候选带直接画二维前脸时，同一行可归给两条带；用行中心强制唯一归属又会漏掉七行。因此下一几何实现需先确定每段唯一、连续的中心线和端帽，再与稳定主水面共边，而不能直接扩展整张统一网格或简单删重候选带。W09 G02/V03/V06/WR-G0 仍 FAIL，性能 **0/10**；这是字段/拓扑诊断，不计性能轮次。

[复算器](W09_G02_局部主网格_20261008/analyze_estuary_branches.py)读取 `rowbase_repro240` 的局部 RG32F 前缘和水深、`unified2d240` 的行前缘。两次捕图同初态哈希、同 80 个波包请求，配对水深最大差 7.45×10⁻⁸m。以局部峰值 ≥0.0045 且水深 >0.001m 为强活动格，用八邻接求连通分支；[完整指标](W09_G02_局部主网格_20261008/estuary_branch_analysis.json)可复算。

共 1,369 个强活动格、194 个活动行，**0 行**有两个及以上不连续强 X 段。行前缘 X 对各行局部中心的绝对误差中位 0.151 格、p95 1.046 格；5 个端点行的行中心偏出强活动 X 范围 ±1 格，最大中心误差 6.167 格。这足以说明当前样本可从分段行中心起步，也说明端点不能完全由已有 256×1 行中心决定。此结论仅覆盖该完成态，不保证其他波包时刻和床形也只有一个 X 段。

既有每四格一条候选带、阈值 0.003 的采样在 217 行共选中 266 条候选带，其中 49 行双归属。直接把归属限制为最接近行前缘 X 的候选带，虽消除双归属，却只覆盖 210 行，漏掉第 80、82、83、114、115、120、169 行。该规则会在真正活动段产生孔洞，不应作为修复。当前默认渲染和 shader 未因本次字段分析改变。

下一步的可验收几何约束：按二维连通分支生成有限长度截面；每段端帽沿 Z 收到局部水面且不跨越无活动行；浪体离岸和向岸两端与稳定主水面按同一床高/水深采样共边；每个有波完成态检查分支唯一归属、无沙地投影，另保留无波与严格 staging 对照。当前四分支表是定位依据，不作为静态写死的运行时拓扑。
