## 证据与判断

[证据目录](W10_G04_v4浅水保纹复核_20261009)中的 v4 配对诊断为 D3D12 / GTX 1050、可见 1920×1080、80 连续波包、tick240；[复算](W10_G04_v4浅水保纹复核_20261009/shallow_preserve_metrics.json)显示耦合 0.08m 层的水面高通幅度/床色由 0.684→0.993，相关由 0.506→0.655；0.02m 相关 0.770→0.798；0.25m 无亮纹水色在层内零差。俯斜、近景和掠射图中右岸、沙舌及岛后的沙色/亮纹更可见，深水外观基本延续原状。粗观感优于 v4，尚未声称与 RDC 同尺度匹配。

正式 v5 通过固定/耦合两场景 tick240 严格捕图、入口 `probe_staging_entry.gd`、真实场景 `probe_staging_export.tscn`、profile 正反例验证。有效配置中两模式均回读 `shallow_preserve=true`；v5 profile 文件 SHA256 为 `7c6597708ec44b7be8ee0cc40aeda7c1c3eeb1ac1e828e13f42abc7f59164b88`。[v4/v5 复算](W10_G04_v4浅水保纹复核_20261009/v5_regression_metrics.json)显示活动 80 波包与无波 0 波包的水场最大差分别 1.12e-7m / 2.31e-7m，三层深度图逐像素相同；无波床色图逐像素相同，活动床色最大仅 1/255（极少像素）。水面图按预期发生浅水颜色变化。无波负例没有引入额外波包或改变湿域。

这项完成的是 **v5 光学粗效果接线**，不替代 G01–G03 原验收。掠射倒影、真实透明物体、参考 ROI、活动段完整成本及长期稳定性仍需后续处理；当前海浪按用户要求保持 v4 效果，不再在此目标上调浪形。

W14 随后发现存档校验器尚未接受 v5 身份，已补 `checkpoint_store.gd` 的显式白名单。[v5 保存/恢复复验](W14_G02_v5保存恢复回归_20261009.md)在固定/耦合 tick240、270、600 的五份 GPU 字段、图片和表现时钟均通过，保证本配置可续跑。
