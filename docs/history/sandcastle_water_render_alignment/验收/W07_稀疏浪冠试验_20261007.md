# W07 稀疏浪冠试验（2026-10-07）

## 目标与实现

[多孔浪冠](W07_单网格多孔浪冠试验_20261007.md)保留了至少 48% 的连续白色亮芯，所以粗白块和沿岸亮条仍突出。此轮在同一封口卷唇片元上增加默认关闭的 `--unified-sparse-cap`：沿岸慢变噪声调整亮芯中心和宽度，较细的两尺度噪声形成真实的着白缺口，少量外围亮斑作为飞沫代理。几何、前缘字段、求解器状态、卷唇 alpha 和深度模式保持不变；该开关与旧多孔着沫互斥。

耦合参考床面、tick 330/390 有波及 tick 390 无额外波，各六机位，D3D12/GTX 1050、1920×1080；Godot 横幅 `v4.7.beta.custom_build.dff2b9bb6`。三次捕图均退出 0。[证据目录](W07_非对称浪前原型_20261007)含 PNG/manifest，[比较脚本](W07_非对称浪前原型_20261007/analyze_front_profile.py)确认相同 tick、夹具、初始状态 hash、波请求、泡沫摘要和相机，[数值](W07_非对称浪前原型_20261007/comparison.json)如下。

## 判定

稀疏掩膜比旧固定最低白度更接近 V05 所需的缺口、散点，是**部分着沫组件候选**；它没有形成 V03 的弯曲厚亮芯或解决浅岸接触，不能作为卷浪路线放行。两个活动截帧和一个无波负例不足以证明入浪→绕流→退浪的连续生命周期，未做 V06 >4px 近岸门、V08 30+60 秒三镜头和 30 分钟稳定成本；W07 G03 与 WR-G0 不通过。接下来需要把碎沫与真实前缘相位、卷浪体量和沿岸活动窗口统一，而不是继续只调颜色掩膜。
