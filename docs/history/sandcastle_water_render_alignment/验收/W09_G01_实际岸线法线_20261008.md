# W09 G01：实际耦合岸线的法线空间复核（2026-10-08）

状态：**D3D12 阶段探针 PASS；G01 仍 [进行中]，W09 0/3**。这是对实际完成态字段的诊断，不是动态高光外观或 V03 验收。

## 输入与方法

将已保存的连续 80 波包耦合场 tick180/240/300 的 rock、sand、water 三个 256² RF 字段直接装入独立 GPU 法线探针。字段来自 [动态岸线完成态](W09_G03_动态岸线完成态_20261008.md)，每个源文件 SHA256 存在 [manifest](W09_G01_实际岸线法线_20261008/real_dynamic_manifest.json)。三个 tick 均在 D3D12 / GTX 1050 下各捕顶视、斜视法线编码图，及世界/视图法线差异图和世界/视图光方向点积差异图；斜视还改变世界光方向。共 21 张 512² PNG。

[复算脚本](W09_G01_实际岸线法线_20261008/analyze_real_fields.py)重新读取所有 PNG，核对当前 shader 和源字段哈希，先由法线图 G≥150 建湿区掩码，再向内收四个屏幕像素排除投影与抗锯齿过渡。结果见 [指标](W09_G01_实际岸线法线_20261008/real_field_metrics.json)。湿区内部每张图约 19.5–19.8 万像素：顶视法线/光方向差异大多逐像素为零；斜视中超过 12/255 的像素每张仅 2 个，tick300 顶视为 1 个。所有组平均通道差异 <0.003/255。独立复算 PASS。

同一探针的既有平面、正负 X/Z 坡面与转镜头回归以 `synthetic_regression` 再跑一次，退出码 0 且 PASS；本次扩展未破坏合成方向门。

原图可见岛边和岸边的蓝色诊断细线；其绝大部分处于湿干过渡，不能据内部指标声称边界片元完全无异常。此探针也没有复现完整地形遮挡、活动浪前的前翻面、真实场景高光；不能由空间数学通过推断动态外观满足参考。因此 G01、V03 与 WR-G0 保持未通过。下一步需要在完整场景中验证转镜头、移动岸线和高光外观。
