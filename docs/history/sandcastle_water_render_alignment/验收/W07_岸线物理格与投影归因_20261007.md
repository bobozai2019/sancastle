# W07 岸线物理格与投影归因（2026-10-07）

结论：**参考原型右岸的重复三角尖齿主要来自输入床面的周期沙脊改变了物理湿域边界，不是显示网格细分不足。** 默认关闭的近水位沙脊衰减变体在固定与活动耦合床面均显著降低尖齿，保留原始入口逐像素不变；变体却使海岸较直，浪前横剖仍是长坡，不能作为 V03/V06 放行方案。

## 根因与隔离变体

`reference_bed.gd` 用 `0.035*sin(world_z*2.2+world_x*0.35)` 造沙脊，同时海岸主坡的 x 梯度仅 `0.018 m/m`。沙脊高度可使水位交线在 x 方向移动近 2m，出现规则往复齿形。固定床面 tick120 的原始 F32 水深里，右岸每行最右湿格的相邻行跳变最大 30 格、沿 256 行绝对跳变总和 707 格；俯斜画面的白色水域诊断图在 y=450–999 的右边界单行最大跳 100px、总和 2065px。画面台阶与输入水深边界同向。

新增 `--smooth-reference-shore` 仅作用于 W07 参考床面初始化：按**不含周期沙脊的床高**与 0.14m 水位的距离，在 ±0.06m 带内逐渐压低周期沙脊；带外仍保留原沙脊。它同时生成固定/耦合床面对应的沙高和初始水深，未在 shader 中伪造湿度，也未改生产床面、求解器或默认原型。默认关闭。固定/耦合的同一变体初始 rock/sand/water 哈希相等；原始床面的固定/耦合初始哈希也相等。

固定床面白色水域俯斜 y=450–999 的右边界总跳变 **2065→347px**，最大相邻行跳变 **100→7px**。原始/变体[水域图](W07_岸线物理格与投影诊断_20261007/fixed_original_mask_tick120_water_oblique.png)、[变体水域图](W07_岸线物理格与投影诊断_20261007/fixed_smooth_mask_tick120_water_oblique.png)直观显示重复尖齿消失。固定 F32 差分：rock 完全相同；sand 13,245 格变化 >1e-5m，最大 0.0350m；water 7,942 格变化 >1e-5m，最大 0.0350m。这是**不同输入床面**，不可将两图当成相同物理状态下的渲染器 A/B。

[复算脚本](W07_岸线物理格与投影诊断_20261007/analyze_shore_source.py)核对摄像机、tick、波包请求、实际水 shader、原始 F32 与 PNG，[统计 JSON](W07_岸线物理格与投影诊断_20261007/shore_source_metrics.json)含 manifest 差异。捕图器现额外记录实际 shader 路径、`display_reconstruction` 读取值和水网格顶点数；本场景原本就为 2 倍细分、262,144 顶点，显式 `--subdivision=2` 的三镜头逐像素不变是预期结果。原有共床高/中点裁剪/4 倍细分失败证据仍成立。

变体可作为下一版**参考床面输入**的候选，但目前海岸过直，且没有 test35 底形/岸线 ROI 对位、复杂多岛、薄水沟脊、视觉独立复核和联合性能证据。不能用较低边界跳变代替 V01/V06，不能用输入平滑掩盖渲染器接触误差。V01/V03/V06、WR-G0 未通过。
