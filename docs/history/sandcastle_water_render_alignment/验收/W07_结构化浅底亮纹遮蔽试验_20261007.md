# W07 结构化浅底与亮纹同态遮蔽试验

日期：2026-10-07。结论：在固定参考床面 tick120、oblique 视角，折叠亮纹明显改变了浅底的局部形态读感。关闭亮纹后，画面高通形态与同一床面的直出图相关系数在整片可见浅水为 0.890、沟槽局部为 0.961；开启后分别只有 0.260、0.297。亮纹提供很高的自身对比，却遮住了床面沟脊的方向和轮廓。V01/V04/WR-G0 仍未通过。

基于[上一轮结构化床面](W07_床面消费与结构化浅底试验_20261007.md)的三镜头捕图，复用同一 Godot D3D12/GTX 1050、全屏 1920×1080、tick120、自然岸线、结构化床面、局部前缘屏幕光学、0.25m 浅水消光、折叠亮纹材质。唯一有效切换是 `--no-caustics` 将床面 shader 的 `phase2_caustics` 设为 false。两份 manifest 除 run ID、产物路径及亮纹启停字段外一致，revision 均为 360，初始 rock/sand/water 哈希一致。新捕图进程退出 0 且报告 PASS；日志只有已有图像导入警告，无 shader/script ERROR。

| 32px 高通绝对残差 p90，整片 / 沟槽局部 | 14.33 / 16.67 | 4.33 / 6.00 |

| 中位亮度，整片 / 沟槽局部 | 182.33 / 182.33 | 180.33 / 179.33 |

深度诊断图定义 0.02–0.08m 可见浅水，4px 腐蚀后整片 118,956 像素、预先记录的沟槽矩形 `[900,740,1350,930]` 内 34,916 像素。两个状态在整片浅水有 20,216 像素、沟槽局部有 6,703 像素的任一 RGB 通道差值超过 12/255。这些是形态代理与同态归因，不是参考画面相似度或 V01/V04 的自动放行门。无亮纹画面仍缺复杂沙舌与沟脊；不能靠永久关闭亮纹完成 V04。下一步应在视觉子任务内调亮纹面积/强度/尺度与床面形体的共同读感，性能部分按[总纲十轮上限](../总纲.md#性能迭代上限与移交)移交。
