# W07 实体浪唇截面与横向镜头试验

日期：2026-10-07。结论：**11 层附着截面明显增加近岸浪唇的白色面积，却仍呈宽坡/白带，未形成参考所需的前探、下翻厚芯。** 该原型不接正式入口；W07 G03、WR-G0 继续未过。

## 做法与证据

在 W07 显示原型中增加 `--crest-solid-lip`：使用每行 11 个截面点，从后肩经过浪冠、前探点、下翻面回到主水面；每点以自身 x 位置重建主网格高度。该开关自动启用既有上升带前缘字段、主浪面抬升、浪唇和深度写入。新增 `--crest-profile-camera` 两个横向近岸诊断镜头，检查原侧视沿推进方向观察造成的截面压缩。原型开关默认关闭，正式材质、求解器和 profile 未改。

同一耦合床面、合法波包、tick 390、revision 1492、初态哈希、泡沫统计与六个镜头完全一致的三组为：只有主水面抬升 `main_profile390`、旧薄浪唇 `thin_profile390`、11 层截面 `solid_profile390`。另拍 `solid_clear390`，仅关闭主水面着白以隔离颜色。四组 D3D12、1920×1080 均 exit 0、PASS；[PNG、manifest 和分析数据](W07_实体浪唇原型_20261007)保留。

横向[实体截面图](W07_实体浪唇原型_20261007/solid_profile390_coupled_crest_cross.png)相较[旧薄片](W07_实体浪唇原型_20261007/thin_profile390_coupled_crest_cross.png)明显扩张白面，但前探点、下翻面没有形成可辨认的中空曲线，近处仍是横贯画面的白坡。[俯斜图](W07_实体浪唇原型_20261007/solid_profile390_coupled_oblique.png)仍是沿岸白带和局部白色圆丘；关闭主面着白后的[俯斜图](W07_实体浪唇原型_20261007/solid_clear390_coupled_oblique.png)也保留白带，因此不能仅归因为主面的着色覆盖。旧侧视镜头确有观察方向限制，但新横向镜头仍不支持视觉验收。

[逐像素分析脚本](W07_实体浪唇原型_20261007/analyze_solid_lip.py)验证同态元数据并输出[结果 JSON](W07_实体浪唇原型_20261007/solid_lip_summary.json)。旧薄片→实体截面的 RGB 任一通道差 >12 的像素数：俯斜 9557/2073600、旧侧视 100652、横向 `crest_profile` 144735、`crest_cross` 206025。只有主面→实体截面分别为 16509、146405、197170、264272。这些数值只量化画面变化，不是卷曲质量得分。关闭主面着白后，横向镜头仍有大块白坡。

实体截面的透明叠加与主面重合、近岸交线和水面高度基底仍可能互相遮挡；当前证据不能分离全部原因。尚未做 30+60 秒三镜头成本、多相位、多波及恢复试验，因为首要 V03/V05/V06 视觉门已失败；V08 也未通过。下一路线应重建可观测的主水面与浪唇共有截面边界，并在横向和俯斜镜头同时验证前探、下翻和近岸交线，再进入正式成本门。
