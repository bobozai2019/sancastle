# W07 GPU 潮汐账本双缓冲批次试验

日期：2026-10-07。结论：**两个固定容量 GPU buffer 可在运行中轮流采集潮汐源汇增量，9 个连续批次和停止时的不足一批冲刷均与原逐 tick 账本精确一致。** 本试验仍保留原账本与 CFL 逐 tick 回读，未验证 V08 性能门或检查点结算。

W07 隔离原型 `reference_tide_ledger_batches.gd` 复用前次已经验证的 256 值复制 shader。每批 30 tick，两个 storage buffer 共 61,440 字节。满批立即发起异步读回并换槽；读回回调前不准复用该槽，两个槽都忙则显式失败。停止在不足一批时，探针在渲染线程冲刷尾批。探针按批次顺序及每 tick 原始 256 个 float32 值逐一核对原求解器回调账本，拒绝长度、序号、非有限值或源汇差异。原生产求解器、shader、profile 和项目配置未改。

## 仍需解决

这只是旁路验证。原求解器每 tick 仍请求潮汐账本和 CFL 数据，并且其账本值被 tick 完成、沙审计和检查点直接使用。若改由批次回调入账，必须在检查点/恢复/退出前冲刷并等待相关批次、按 tick 顺序结算，避免中途报告或保存陈旧账本；还需取消 CFL 的逐 tick CPU 决策并验证数值稳定性。本探针为逐项核对保留所有批次原始字节和 CPU 对照数组，因此只证明 GPU 双缓冲容量有界，不证明 CPU 内存长期有界。没有做正式三镜头 30+60 秒活动成本测试，WR-G0 和 W07 G03 均保持进行中。
