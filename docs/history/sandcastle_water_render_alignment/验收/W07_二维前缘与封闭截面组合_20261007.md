# W07 二维前缘与封闭截面组合（2026-10-07）

结论：**组合原型仍未达到 V03/V05/V06；W07 G03 与 WR-G0 不通过。** 把旧闭合截面与二维局部前缘抬升主水面叠合后，离水长管缩小了，但它成为沿岸细长青色竖脊；横截面仍见不自然的实心青面。缩窄圆环只缩小投影，不能生成目标的连续曲率、厚亮芯和碎裂前缘。

## 实现和固定对照

默认关闭的 `--local-front-volume` 同时启用 256×1 前缘、256² 局部场、二维主水面抬升以及闭合截面。新截面 shader 先用旧行场选位置，再在该位置读取二维场修正中心/活动强度；本地水深约束截面高度，前方湿格约束向岸半径。它与主水面共用岩沙水重建、写入深度。组合只在隔离捕图入口可选，不改生产水材质、求解或物理字段。

耦合参考床面、tick 390、单波包/无额外波、GTX 1050/D3D12、1920×1080 全屏、六机位。运行参数包括 `--eta-normals --local-front-volume --crest-height=0.25 --no-main-foam --irregular-foam --wavefront-camera --crest-profile-camera`。证据在[六机位与 manifest 目录](W07_二维局部封闭截面原型_20261007)：`local_volume_wave390_*` 为横半径 0.22m/纵半径 0.125m，`local_narrow_wave390_*` 为 0.12m/0.15m，最终无波为 `local_narrow_nowave390_*`。同态局部主水面基线为[上一轮 `local_depthcap_wave390_*`](W07_二维局部前缘原型_20261007)。捕图命令 `PASS` 仅证明执行成功。

各有波 manifest 的初始 rock/sand/water 哈希均为 `1625571958/2318428149/4161789743`，foam `sum=1555.24498982579`、`coverage_20=2425`、`dry_foam=0` 完全相同。最终无波与无波主水面基线六机位 RGBA 逐像素一致。相对二维主水面有波基线，RGB 最大通道绝对差 >12 的像素从宽截面到窄截面分别为：oblique 3789→2284、close 4972→4172、wavefront_side 41263→38876、crest_cross 44193→30658。缩窄只改变体量，未修复形状。[窄截面俯斜](W07_二维局部封闭截面原型_20261007/local_narrow_wave390_coupled_oblique.png)仍是青色沿岸棱线；[窄截面横剖](W07_二维局部封闭截面原型_20261007/local_narrow_wave390_coupled_crest_cross.png)仍有三角形青面。

用已保存的同 tick 1D RG32F 和 2D RG32F 回读按 shader 的七行加权位置复算：在 114 条二维局部强度 >0.005 的行中，新采样中心相对行场中心的位移绝对值中位约 0.294 格、p90 约 0.623 格、最大约 1.476 格；两条相邻强活动行的中心没有 >2 格跳变。因此这次组合并未真正获得分支感知的二维前缘拓扑；它主要在旧行中心附近增设活动门。青色实面来自闭合截面与主面遮挡/交叠，而非已证实的跨行大跳位。后续表示需要按二维湿水连通段决定每个浪片的支撑、端点与主水面连接，不能让整行圆环靠遮挡模拟贴合。
