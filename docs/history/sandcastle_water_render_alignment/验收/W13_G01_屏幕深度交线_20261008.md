tick600 [侧视视线深度图](W13_G01_屏幕深度交线_20261008/coupled600_contact_coupled_wavefront_side_contact_depth.png)的薄水区域有 **19,751** 个像素沿视线距不透明床面 ≥0.10m；低角视线距离不能当作竖直浮空高度。首份[高度图](W13_G01_屏幕深度交线_20261008/coupled600_height_coupled_wavefront_side_contact_height.png)把光栅水片与沙床 shader 的**解析三角插值**比较，侧视有 6,523 个 0.02–0.10m 档像素；它尚未包含沙床自身的 2 倍显示网格插值，因此不能直接代表可见床面交线。更严格的[同网格可见床面高度图](W13_G01_屏幕深度交线_20261008/coupled600_meshtrue_coupled_wavefront_side_visible_bed_height.png)按照 `_make_grid_mesh` 的实际 v00→v11 三角对角线复算，在同一 tick 侧视为 **6,498** 个 0.02–0.10m 档像素。以上高差仍包含该处实际水深、共享 profile 的 **0.006m** 水面偏置与浪脊抬升，不能把它全算作误差。先前一份可见床面草图使用了沙床解析函数的反向对角线，没有作为最终网格结果。

同 tick600 临时关浪脊、改水片床高为共三角插值的单项对照，解析床高的侧视 0.02–0.10m 档分别为 **6,391 / 6,580** 个像素，均未显著改变分布。[顶点与片元高度差分](W13_G01_屏幕深度交线_20261008/coupled600_delta_coupled_wavefront_side_vertex_fragment_delta.png)在该档仅 **15** 个侧视纯色像素，也不支持“大面积顶点插值错误”的推断。最终[实际交线残差图](W13_G01_屏幕深度交线_20261008/coupled600_meshtrue_coupled_wavefront_side_contact_residual.png)用光栅水片高度减去**可见沙床网格高度、水深、0.006m 偏置与浪脊抬升**：侧视 >0.02m 残差仅 **84** 个像素，俯斜/近景/掠射分别 **27 / 0 / 0** 个；所有镜头 <−0.02m 和 ≥0.10m 的纯色像素为 0。四镜头原图、遮罩和权威字段与先前严格捕图逐字节相同。颜色分档只计距纯色 ≤4/255 的像素，抗锯齿过渡未纳入，不是全域最大值证明。

**更正：**先前将 6,523 个像素称为“水片比可见沙床高 2–10cm 的异常”，并据此建议优先修顶点/片元高度差，证据不足。水深、偏置和浪脊是预期高度；更严格同网格残差已把大面积浮空排除为主要来源。接下来应在侧视、陡壁与岛脚沿可见交线 ROI 查透明覆盖、局部湿域重建、沙面遮挡和薄水光学；还需量测缝宽与干岸误盖。几何差分不能单独放行 V06 或替代参考形态比较。W07 的共床高、中点裁剪和 4 倍细分失败对照仍适用。
