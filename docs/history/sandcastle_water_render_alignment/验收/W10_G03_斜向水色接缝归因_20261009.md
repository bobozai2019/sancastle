# W10 G03 近景/掠射斜向水色接缝归因（2026-10-09）

结论：同完成态近景与掠射图中，从岛脚向右下角延伸的直线水色接缝位于**水片内部**，关闭折射偏移和反射混色后仍可见。追加连续水深/无波对照证明该线伴随**活动波包造成的水深陡变**，无波时消失；不是静态床面或折射/反射单项可以解释。它仍是 V02/V06 的明显视觉缺口，作为 W09 浪前深度与显示连续性返工输入。

耦合 staging、80 波包、tick240/revision924、D3D12/GTX1050、1920×1080 均与[当前三机位光学重捕](W10_G03_当前三机位光学_20261009.md)一致。[岸线遮罩](W10_G03_当前三机位光学_20261009/w10g03_edge240_coupled_grazing_shoreline_mask.png)显示接缝所在区域连续属于水片，岛体与远岸之外没有第二条水片边缘。`--write-refraction-edge` 的 -0.2 压力[调试图](W10_G03_当前三机位光学_20261009/w10g03_edge240_coupled_grazing_debug.png)在接缝附近也有深度回退带；该压力参数不是正式 0.02 折射，不作为默认来源证据。

捕图器新增仅诊断使用的 `--optical-multiview`，在默认关闭的光学贡献消融中追加 close/grazing 两镜头，原 oblique 文件名和默认行为不变。[正常掠射](W10_G03_当前三机位光学_20261009/w10g03_multiview_fixed240_coupled_optical_grazing_normal.png)、[关折射](W10_G03_当前三机位光学_20261009/w10g03_multiview_fixed240_coupled_optical_grazing_no_refraction.png)、[关反射](W10_G03_当前三机位光学_20261009/w10g03_multiview_fixed240_coupled_optical_grazing_no_reflection.png)、[两者均关](W10_G03_当前三机位光学_20261009/w10g03_multiview_fixed240_coupled_optical_grazing_neither.png)均保留同一斜向分界；反射关闭使大面积颜色改变，但接缝没有消失。[无折射床色直出](W10_G03_当前三机位光学_20261009/w10g03_multiview_fixed240_coupled_optical_grazing_neither_bed.png)还显示岛旁底床明暗区域不同，故需继续检查实际床高/水深与水面高度对分层着色的影响。严格包装器确认 manifest、revision、全新文件与日志；第一次多镜头捕图因局部变量类型推断编译错误而被拒，修复后以新 run ID 重捕并通过，失败日志保留作诊断。

上述光学消融只排除“单独关折射或反射即可去缝”，水深来源由下节追加对照判定；不把关闭两者的画面作为视觉候选。正式 profile 未改，不计性能轮。W10 G03、V02/V06、WR-G1 仍未通过。

## 连续水深与无波对照

捕图器在默认关闭的 `--write-depth-bands-multiview` 下，新增三机位[彩色深度分档](W10_G03_当前三机位光学_20261009/w10g03_gray240_coupled_grazing_depth_bands.png)和[连续水深灰度](W10_G03_当前三机位光学_20261009/w10g03_gray240_coupled_grazing_depth_gray.png)。shader 灰度为 `clamp(depth/0.5m,0,1)` 的显示值，PNG 经颜色变换，不把单像素灰度反推为精确米数。原正式画面与两诊断共享 profile、80 请求、tick240/revision924 和相机；诊断后材质开关恢复。彩色图中蓝色 `depth≥0.20m` 与绿色中浅水的分界沿可见斜线延伸，灰度图在该处也有明显突变，说明并非某个色阶阈值开关单独画出这条线。
