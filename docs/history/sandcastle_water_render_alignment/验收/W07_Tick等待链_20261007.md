# W07 耦合 tick 等待链诊断

日期：2026-10-07。结论：**持续波包将 CFL 子步从 2 提高到几乎每 tick 3 步，叠加显示候选后，tick 前段等待进一步增长；WR-G0 仍 FAIL。** 本报告只定位等待区间，不声称已剖析 GPU 各 compute pass 的耗时。

在复制的参考预览中增加可开关的主线程微秒时间戳：`_start_tick` 发起；tide ledger 与 CFL 回调；两者齐备并提交 `_render_finish_tick`；`_tick_finished`。同一耦合参考床面、`oblique`、真实全屏 1920×1080、VSync off、D3D12/GTX 1050，每组预热 30 秒、采样 60 秒。`boundary` 是从发起 tick 到两项回调齐备的墙钟，包含渲染线程排队、前次已提交 GPU 工作、边界/CFL 计算、读回及主线程回调；`finish` 是此后到完成通知的墙钟，**不等于 GPU 水沙计算实际完成时间**。时间戳仅在 `--tick-timing` 开启时记录，未改求解或物理参数。

| 负载 / 显示 | 采样 tick | 子步分布 | boundary p50 / p99 ms | finish p50 / p99 ms | 整 tick p50 / p99 ms | 帧 p99 ms | tick/s |
|---|---:|---|---:|---:|---:|---:|---:|
| 无额外波包 / phase2 | 1802 | 2步 1802 | 32.192 / 41.972 | 0.622 / 1.791 | 32.897 / 43.081 | 31.390 | 30.025 |
| 持续波包 / phase2 | 1732 | 2步 4、3步 1728 | 33.645 / 45.304 | 0.552 / 1.825 | 34.223 / 45.911 | 38.255 | 28.863 |
| 持续波包 / combined | 1620 | 2步 4、3步 1616 | 35.769 / 45.583 | 0.542 / 1.795 | 36.392 / 46.143 | 37.753 | 26.999 |

`combined` 为现有 phase2 光学/泡沫 + η 坡度法线、0.16 m 显示浪脊、不规则白沫调制。三组的 `sand_only_syncs=0`、`sand_prefetch_hits=0`；水沙脏块摘要均无错过，overload/nan 均为 0。故这次慢 tick 不是沙场回读/预取路径导致。`gpu_shallow_solver.gd` 的 CFL 计算从速度场决定子步数，每个子步均调用水流及耦合泥沙/材料 dispatch；但这里没有逐 pass GPU 时间，不能把全部等待差额直接算给新增子步。

时间线将后续剖析优先级明确为：渲染线程队列与 CFL 读回交界、每子步水/沙/材料 dispatch、显示 shader 与 compute 争用。不可通过减少物理子步、降低域分辨率或改质量账本来制造假达标；若将来优化调度/compute，须保持 30Hz 物理语义并重跑水沙守恒及恢复回归。
