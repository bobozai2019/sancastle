# W07 深度写入多相位与卷唇复测

日期：2026-10-07。结论：**写深度对浪前经过侧视镜头时的竖条抑制可在 tick 390 复现；0.20 m 主水面前移仍未形成卷唇。** 深度写入仍只是一项局部遮挡修正，V03/V05/WR-G0 未通过。

承接[深度写入试验](W07_水面深度写入试验_20261007.md)，在耦合参考床面同一合法波包、1080p D3D12 下捕捉 tick 120/240/330/390 的 `depth_draw_never` 与 `depth_draw_always` 成对图。八次运行均 exit 0、PASS；每对 tick、revision、初态哈希、波请求、foam 统计和镜头一致。运行时只切换 W07 原型 shader 的深度模式。

“明显变化”指全图 RGB 最大通道差 >16。tick 330/390 的俯斜变化像素分别为 0/1，近景 10/2，掠射 11/12；只在侧视前后水面重叠区产生实质画面响应。泡沫重心是全场统计，不能单独证明镜头浪前活跃；侧视图提供可见性的对应证据。tick 120/240 不用于宣称动态稳定通过。

另在 tick 390、写深度不变时，把主水面前移 `prototype_curl_forward_m` 从 0 提到允许上限 0.20 m。[0.20 m 侧视图](W07_写深度卷唇组合_20261007/tick390_curl20_coupled_wavefront_side.png)相对[零前移图](W07_深度写入多相位_20261007/tick390_write_coupled_wavefront_side.png)在浪前 ROI `[300,320,950,430]` 有 1707 个明显变化像素，但仍是平缓白色脊面，无明显卷唇/下翻厚芯。该组合不选为 V03 路线。两组初态、求解状态、foam 和镜头相同。
