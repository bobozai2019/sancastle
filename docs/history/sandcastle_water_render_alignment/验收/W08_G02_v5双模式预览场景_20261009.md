# W08 G02：v5 双模式直接预览场景（2026-10-09）

状态：**直接预览入口与确定性探针 PASS；最终视觉与性能 Gate 未通过。**这是既有 G02 接线的补充验证，不新增小目标或性能轮次。海浪效果保持当前配置。

## 固化入口

- `scenes/water_render_demo_v5_preview.tscn`：固定床面、80 个连续波包、显式 v5 profile。
- `scenes/water_render_coupled_v5_preview.tscn`：耦合床面、同一波包及 profile。
- 两个入口继承已有连续场景，固定节点及 profile 路径存于 `.tscn`；默认 v1 场景未修改。
- `tests/visual_water_alignment/prototypes/probe_v5_preview_scenes.gd` 验证实际加载的 profile、材质开关、波包数、tick/时间，并保存本次画面和 GPU 岩/沙/水 F32 字段。

## 实际运行

Godot D3D12、VSync off、1920×1080。tick30 与 tick240 的固定/耦合直接预览均 PASS。两次运行的 profile SHA256 均为 `7c6597708ec44b7be8ee0cc40aeda7c1c3eeb1ac1e828e13f42abc7f59164b88`，每场景 80 个波包；tick30/240 对应 1/8 秒视觉时钟。原始清单：[tick30](W08_G05_v5预览场景_20261009/w08g05v5preview30_manifest.json)、[tick240](W08_G05_v5预览场景_20261009/w08g05v5preview240_manifest.json)。

固定/耦合初态的岩、沙、水哈希相同。tick30 的 GPU 岩层仍相同，但沙层已有 6,914/65,536 格相差大于 0.00001m，最大差 0.3774m；tick240 为 34,010 格、最大差 0.4125m。水深也随耦合演化而分开。这符合固定模式不侵蚀、耦合模式侵蚀的行为，不能把运行后两张图直接当同态着色测试。

固定与耦合场景还使用不同的床面材质：固定为 `reference_terrain.gdshader`，耦合为 `reference_coupled_bed.gdshader`。两者使用相同的分片床高插值，耦合材质额外呈现细沙颗粒及颗粒法线。可见的固定床面台阶和耦合床面较柔和的视觉差异同时受真实侵蚀与材质影响；目前没有将两者贡献分离成可靠像素比例。

代表图：[固定 tick30](W08_G05_v5预览场景_20261009/w08g05v5preview30_fixed_oblique.png)、[耦合 tick30](W08_G05_v5预览场景_20261009/w08g05v5preview30_coupled_oblique.png)、[固定 tick240](W08_G05_v5预览场景_20261009/w08g05v5preview240_fixed_oblique.png)、[耦合 tick240](W08_G05_v5预览场景_20261009/w08g05v5preview240_coupled_oblique.png)。
