# W07 启动帧队列长度与异步读回试验

日期：2026-10-07。结论：**将 `rendering/rendering_device/vsync/frame_queue_size` 从 2 改为 1 没有显著缩短本机 D3D12 回读等待，也未通过 V08。** 同负载 60 秒 oblique 活动采样中，queue=2/1 为 26.381/26.488 tick/s、整帧 p99 39.653/39.486 ms；从读回请求提交到两个渲染回调到达的均值为 26.172/26.178 ms。该设置不选作当前成本修复，不改原项目启动配置。

[Godot 4.6 ProjectSettings 文档](https://docs.godotengine.org/en/4.6/classes/class_projectsettings.html)说明帧队列默认值为 2、仅启动时读取；[RenderingDevice 文档](https://docs.godotengine.org/en/4.4/classes/class_renderingdevice.html)说明异步纹理/缓冲区回调会在后续帧到达，延迟与帧队列设置相关。因此先做启动配置 A/B，而不是在运行中调用 `ProjectSettings.set_setting()`。文档是试验动机；结果只支持本机、本引擎构建和这组负载的判断。

## 隔离与状态

原工程 `project.godot` 未改，SHA256 为 `673965691c63546745e3e79f70b73589ede19865afbe55b177925f2e68ff11bf`；项目根目录没有 `override.cfg`。自动审批检查拒绝了在根目录临时创建覆盖文件，因此改用证据目录下两个独立最小项目副本。它们的 275 个实际源文件逐文件 SHA256 一致；生成的 `.uid`、`.import` 元数据不算源文件。两个 `project.godot` 除帧队列值 1/2 外配置一致，运行时 manifest 分别回读到 1/2；同一 D3D12、GTX 1050、可见全屏 1920×1080、VSync off。queue=2 副本的 headless 编辑器导入在完成资源导入后以 Windows 异常码退出，随后两个副本的实际探针运行均 exit 0、预期 PASS；该准备阶段的异常保留在 `queue2_import.log`，不当作运行通过证据。

两副本对同一合法 0.18 m/6 s 波包精确停在 tick 90，11 个完整字段 SHA256、revision、水源/汇账本和沙闭合值全部相同；两份[状态 JSON](W07_帧队列试验_20261007)和[分析脚本](W07_帧队列试验_20261007/analyze_frame_queue.py)可复核。这证明该单一确定性场景的状态等价，不证明工具事件、恢复或任意长程等价。

## 成本与等待链

两个独立副本都用耦合参考床面、combined 显示、每 180 tick 合法持续波包、oblique 镜头。短 2+10 秒确认入口后，各运行 30 秒预热、60 秒活动；活动段均超过 600 有效帧、`source_active_fraction=1.0`。后者只说明波源请求时窗，并非屏幕高泡沫占比。两组长运行 exit 0、探针预期 PASS，日志无 shader/script ERROR；manifest 均为 `meets_cost_bound=false`。

| 60 秒 oblique 阶段 | queue=2 | queue=1 |
|---|---:|---:|
| 有效帧 / tick 时间线行 | 3165 / 1583 | 3179 / 1590 |
| tick/s | **26.381** | **26.488** |
| 整帧 p99 | **39.653 ms** | **39.486 ms** |
| GPU 渲染 p99 | 7.414 ms | 7.402 ms |
| 读回提交→两个渲染回调均到达，均值 / p50 | 26.172 / 26.006 ms | 26.178 / 25.925 ms |
| 最后渲染回调→主线程两回调处理，均值 / p50 | 10.355 / 10.466 ms | 10.228 / 10.341 ms |
| tick 总时长 p50 | 37.437 ms | 37.201 ms |

两组预热按墙钟，活动起始 tick 753/807，波包相位未逐 tick 对齐；近似差值不能解释为 queue 设置的精确因果增益。短样本方向也很小：queue=2/1 为 26.717/26.890 tick/s、p99 38.271/38.195 ms。长样本的回调均值几乎相同，且两组均远低于 30 tick/s、远高于 33.3 ms，因此这个设置不构成 V08 路线。它没有覆盖 close/grazing、真实高泡沫墙钟或完整 profile，也不能为 WR-G0 放行。
