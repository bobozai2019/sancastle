# W07 屏幕折射可见面法线朝向复核（2026-10-07）

结论：在已修正 Fresnel 入射角的路径上，把可见水面法线转向视线只改变折射采样偏移；三镜头零折射对照逐像素相同。非零折射的差异集中于浅水及岸边，深水亮度中位数不变。这证明折射方向确实受反号法线影响，但现有画面未证明新方向达到 V02 的视觉质量要求。

## 方法

在隔离原型 `reference_water_local_front.gdshader` 加默认关闭的 `prototype_screen_face_normal`。若 `dot(VIEW,n)<0`，在折射偏移前翻转 `n`；捕图 `--screen-face-normal` 同时开启 `--screen-abs-fresnel`。后者已在[上一轮 Fresnel 归因](W07_Fresnel法线朝向归因_20261007.md)单独验证。正式水材质、模拟和默认画面未改。

耦合参考床面合法波包，tick390/revision1492，二维局部前缘 0.25m、eta 法线、折叠亮纹、白沫、屏幕光学，`visual_time_s=13.0`，D3D12/GTX1050，1920×1080 三镜头。主对照均为折射比例 0.02，manifest 除 `prototype_screen_face_normal` 外同态；零折射对照比例为 0，其余同态。四次捕图均 `PASS`，只有既有 caustic PNG 导出兼容警告。

[复算脚本](W07_水深投影诊断_20261007/analyze_facing_refraction.py)以[投影水深带](W07_水深投影诊断_20261007/analyze_projected_depth.py)的实际可见水像素内区分组，核对 manifest、逐像素 RGB 差异及深/浅亮度比。完整统计见 [JSON](W07_水深投影诊断_20261007/facing_refraction_metrics.json)。`>12` 指任一 8-bit RGB 通道差值超过 12。

| 镜头 | 全图 >12 像素 | 浅水内区 >12 / 总数 | 深水内区 >12 | 深/浅比：原 / 转向 |
|---|---:|---:|---:|---:|
| oblique | 8,339 | 4,128 / 68,311 | 0 | 0.706 / 0.706 |
| close | 189 | 100 / 24,052 | 0 | 0.723 / 0.723 |
| grazing | 0 | 0 / 2,163 | 0 | 0.701 / 0.702 |

零折射的 oblique、close、grazing 原/转向 PNG 均逐像素一致。这一负对照排除了 Fresnel、吸收、波形和捕图时序作为上述非零差异的来源。可直接查看原/转向[俯斜图](W07_水深投影诊断_20261007/screen_abs_deep100_wave390_fold_coupled_oblique.png)、[转向俯斜图](W07_水深投影诊断_20261007/screen_face_deep100_wave390_fold_coupled_oblique.png)及[转向近景图](W07_水深投影诊断_20261007/screen_face_deep100_wave390_fold_coupled_close.png)。俯斜浅岸及沙丘边缘的折射细节有可见位移，整体深水色层不变；没有足够的参考画面对位证据证明位移方向更正确。

可见面翻转作为显式候选保留。下一轮须对固定/耦合床面、多相位和参考图的岸边位置、浅底可读性、反射、浪前及性能联合复核。V02、WR-G0 保持未通过。
