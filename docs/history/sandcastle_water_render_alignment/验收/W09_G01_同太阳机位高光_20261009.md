# W09 G01：同太阳方向机位高光复核

状态：**同光源下的高光路径可见，但主三机位几乎无增量；G01/V03/WR-G0 未通过。**G01 已有合成坡度、实际曲折岸线字段、顶视/斜视坐标和反向光试验；本次只补当前太阳方向下的相机几何原因，不把一个阳性诊断机位当作目标画面通过。

在原固定/耦合场景的既有三机位之外，捕图器增加可选 `--sunward-camera`，复用已有诊断 player camera，位置 `(2,6,-13.9)`、目标 `(-3,0.18,-6.9)`。该机位的视线方向与床面太阳 `(-0.42,0.84,0.34)` 在水平面近相反，适合检查同一世界光源的镜面半角响应。场景、材质默认入口和太阳方向均未改。光照开关仍为已有的默认关闭 `--screen-world-glint`。

耦合参考床、80 连续波包、tick240/revision924、真实 D3D12/GTX 1050 及 1920×1080 下，[基线](W09_G01_同太阳诊断机位_20261009/sunbase240_coupled_verification.json)与[同太阳高光](W09_G01_同太阳诊断机位_20261009/sunglint240_coupled_verification.json)均由严格包装器 PASS；波包请求、水 shader SHA、水深 F32 和泡沫 PNG 两侧逐项相同。四机位 PNG 与 manifest 在[证据目录](W09_G01_同太阳诊断机位_20261009)；[脚本](W09_G01_同太阳诊断机位_20261009/analyze_sunward.py)和[指标](W09_G01_同太阳诊断机位_20261009/sunward_metrics.json)独立复算。

`pow(max(dot(n,h),0),42)` 是当前 shader 的镜面核；表中平面法线代理只解释视角选择的趋势，不代表每个像素的真实坡度法线。实际 PNG 证实原三机位基本没有可见增量，而[同太阳机位](W09_G01_同太阳诊断机位_20261009/sunglint240_coupled_sunward.png)在岛后浪脊附近有局部阳性（>12/255 包围框 x729–911、y301–481）。这排除了“世界光方向完全未进入 shader”的单一解释，也说明当前核太窄、主镜头与太阳几何不匹配；仍不能证明参考要求的宽亮芯或动态移动高光。

G01 既有多轮证据的累计主动耗时无法可靠追溯，按总纲记为**历史耗时未知、成果移交**，不继续在 G01 调高光参数。后续时序由 G03 验，若重新设计可见高光应作为新的受限视觉目标并与床面同光源、RDC 形态及成本一起验证。W09 0/5、性能 0/10、V03/WR-G0 不变；本次非性能轮。临时 `override.cfg` 已清理。
