# WR-G0 水体参考与验收标准板

日期：2026-10-07。状态：**候选冻结版，待非实现者复核**。本版在三项效果原型修改前写入；若需改容差，必须在决策记录说明原因并并列展示旧/新判断。这里没有效果 PASS 结论。

## 统一比对条件

- 参考为三份原始 RDC 最终重放图：`test35-frame20641.rdc` 的浅水/亮纹/右侧浪前，`test1.rdc` 的推进浪前，`testnew.rdc` 的多岛水沙接触。1920×1080 为原始输出；HUD/装饰可遮罩，水体贡献不可遮罩。逐绘制归因见 [RDC清单](../rdc_evidence/README.md)。
- 候选为同一参考型床面输入的 `reference_fixed` 与 `reference_coupled`，以及后续正式入口；相机固定为 prototype 的 oblique/close/grazing 三镜头，记录 transform/FOV/viewport。物理仍 256²、0.125m/格、30Hz。先用固定床面查效果，再在同初始床面耦合场景重新判定。
- 比对以可观察局部特征、相似屏幕投影尺度和同一曝光为准。候选 ROI 随新入口定稿记录在每次 manifest；不得为了通过任意缩放、改变色调映射或换更便宜镜头。1280×720 现有图只作失败起点，正式原型/最终判断用可见 1920×1080。
- Windows 桌面带边框窗口使用 `--resolution 1920x1080` 时，实际 root viewport 可为 1920×1055；正式证据须同时用 `--fullscreen` 并检查 manifest `viewport_px == [1920,1080]`。
- 数值图像统计仅为诊断；全项由可比截图、连续录像和人工视觉否决共同判断。既有 0.5 物理格岸线误差及内部误盖 <2% 仍须单独通过。

## 原型门与未证实项

原型按顺序测试真实坡度/浪前、透射反射折射与遮挡、完整联合成本。每项使用固定输入，保存效果开关对照、相机、源 SHA、profile、完成 tick、运行命令和新鲜 run_id。早期原型预热30秒，各代表镜头至少60秒；阶段 p99/tick 率按 V08 门。任何 V01–V08 P0 项未达到或 unknown/partial，WR-G0 不通过。

**仍待证：**RDC 只能证明静态绘制贡献，不能证明原作波速或白沫生命周期；原作 shader 常量/公式、反射与折射实现方式尚未解码。Godot 适配可不使用同算法，但静态图不能为“动态速度与原作一致”背书。WR-G0 与 WR-G3 的视觉结论须由非实现者复核并记录；当前未获该复核。
