# W07 固定床面光学实际消费复核（2026-10-07）

结论：**旧捕图器可把未被实际 shader 消费的诊断开关写进 manifest 并报告 PASS。** 修正捕图配置后，固定床面 tick120 的 Fresnel 可见面朝向修正把三镜头真实可见深/浅亮度比从 0.884/0.895/0.910 降为 0.708/0.759/0.737，均跨过当前 ≤0.80 数值线；浅底、岸线和真实反射视觉目标仍未通过。

## 失效路径与防护

最初 `--case=water --depth-bands` 和 `--screen-face-normal` 未加 `--local-front-profile`。`capture_reference.gd` 因此绑定 `reference_water.gdshader`：它有旧 `prototype_screen_optics` 分支，却没有 `prototype_depth_bands`、`prototype_screen_abs_fresnel` 或 `prototype_screen_face_normal`。三镜头深度带图没有红/蓝分类，所谓旧/修正图逐像素一致；这组 `fixed_depth_bands_tick120`、`fixed_screen_old_tick120`、`fixed_screen_face_tick120` **不得用于诊断修正效果**。它们展示了 manifest 参数值不能代替实际消费验证。

捕图器现对只存在于 `reference_water_local_front.gdshader` 的水深带、Fresnel/法线诊断、深散射及天空代理比例增加前置检查，缺少 `--local-front-profile` 即失败。用原错误命令做负例，进程退出码 1，报告 `requested optical diagnostic requires --local-front-profile`，未产新图。

## 有效同态对照

固定参考床面、无额外波，tick120/revision 360，折叠亮纹、eta 法线、局部前缘 shader（无活动前缘）、屏幕光学折射比例 0.02、D3D12/GTX1050、1920×1080。有效 `fixed_local_*` 四组均 `PASS`；同对照 manifest 只差预期诊断字段。[复算脚本](W07_水深投影诊断_20261007/analyze_fixed_optics.py)验证 shader 路径标志、水深标签非空及字段差异；[完整 JSON](W07_水深投影诊断_20261007/fixed_optics_metrics.json)。浅水为可见水深 0.02–0.08m，深水 ≥0.20m，均去边界 2px；亮度为 8-bit sRGB 三通道均值中位数。
