# W07 主水面跨向平滑试验

日期：2026-10-07。结论：**仅把浪脊几何所用 foam 覆盖沿 z 方向扩散 1–2 个模拟单元，没有消除侧视竖条，也未改善俯斜浪前。** 此候选默认关闭，不选作 W07 方案；V03/V05/V06/V08 与 WR-G0 未通过。

在 `reference_water.gdshader` 增加默认关闭的 `prototype_crest_span_smoothing`：浪脊抬升取相邻 z 行 foam 的加权最大值，着白仍受本地 foam 覆盖控制。`capture_reference.gd` 用 `--crest-span-smoothing` 开启。未改生产材质、求解器或默认画面。Godot 导入成功；固定和耦合参考床面均在合法波包、tick 360、1920×1080 全屏 D3D12 捕图。四次均 exit 0、PASS；每对初态哈希、revision、wave 请求、foam 统计和镜头相同。
