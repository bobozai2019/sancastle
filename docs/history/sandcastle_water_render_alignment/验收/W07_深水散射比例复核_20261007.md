# W07 深水散射比例 0.15 复核（2026-10-07）

**后续归因更新：**[Fresnel 法线朝向复核](W07_Fresnel法线朝向归因_20261007.md)发现本报告的旧光学路径几乎全屏最大反射。0.15 比值只适用于该错误路径；修正朝向后原散射比例 1.0 已取得 0.706/0.723/0.701。本报告保留为同态诊断证据，不作为参数推荐。

结论：**在现有耦合 tick390 原型里，深水散射色缩放 0.15 使三个镜头的真实可见深/浅亮度比均低于 V02 数值线 0.80；画面仍不具备参考的深色水层、可信反射和完整浅底层次，V02 与 WR-G0 不放行。**

## 同态试验

延续[水深投影诊断](W07_水深投影诊断_20261007.md)的耦合参考床面、合法 seed31/0.18m 波包、tick390/revision1492、二维局部前缘、0.25m 浪高、eta 法线、折叠亮纹、屏幕光学及白沫、折射标量 0.02、`visual_time_s=13.0`、D3D12/GTX1050、1920×1080 三镜头。只把 `--screen-deep-scatter-scale` 从 0.60 改为 0.15。新 run `screen_deep015_wave390_fold` 正常退出，日志 `PASS`；原有 caustic PNG 桌面加载仍发出导出兼容 warning。

[复算脚本](W07_水深投影诊断_20261007/analyze_deep015.py)先比较 manifest，允许新版捕图器新增且确为默认值的暂停/细片/连续浪唇字段，再用原 [depth-bands](W07_水深投影诊断_20261007/depth_bands_wave390_fold_coupled_oblique.png) 的同一可见水深红/蓝内区遮罩比较原始 PNG。完整逐镜头统计见 [JSON](W07_水深投影诊断_20261007/deep015_metrics.json)。亮度代理是 8-bit sRGB 三通道均值的像素中位数，未做线性化。

本次没有改 shader 默认值、正式 profile 或生产入口。0.15 只作为光学参数的数值诊断候选；要通过 V02，还须改善深水颜色/反射与浅底透射并完成固定及耦合场景、同曝光多相位和视觉复核。V03/V04/V05/V06/V08 及 WR-G0 不变。
