# W08 G01 staging 湿度与局部前缘实际消费（2026-10-07）

结论：固定和耦合 staging 场景在同一合法 seed31 波包、完成 tick240、表现时间 8.0s、真实 1920×1080、D3D12/GTX 1050 下，床面湿度纹理和水面局部前缘纹理均**实际影响最终像素**。每个模式只改一个显示输入，对比三机位主图；水、沙、湿度、双向动量、白沫历史和局部前缘历史七个 GPU 字段在全部 A/B 前后逐字节一致。两模式初始 rock/sand/water 哈希相同：`639217814/1069331530/774098242`。

| 模式 | 对照 | oblique | close | grazing |
|---|---|---:|---:|---:|
| 固定 | 湿度纹理→全零 | 271,964 | 397,114 | 24,254 |
| 耦合 | 湿度纹理→全零 | 141,779 | 160,028 | 292 |
| 固定 | 局部前缘采样关闭 | 8,076 | 37,425 | 109,976 |
| 耦合 | 局部前缘采样关闭 | 6,581 | 30,715 | 114,526 |

数字是任一 RGB 通道差值 >12/255 的像素数。湿度对照仅暂时把床面材质的 `wetness_state` 换成 256² 零纹理；局部前缘对照仅暂时把水面材质的 `prototype_use_local_front` 改为 false，之后恢复绑定。源码与运行时 shader 确认固定床面 `reference_terrain.gdshader`、耦合床面 `reference_coupled_bed.gdshader` 都采样湿度，水面 `reference_water_local_front.gdshader` 在开关为 true 时采样 `local_front_state`。两模式的请求 profile SHA256 均为 `b35b81cbd5831a48c361c98e8737096d7b5badd70db955429d5703cde179d8a7`。

[原始 manifest 与 18 张 PNG](W08_G01_staging湿度前缘消费_20261007)、[逐像素复算脚本](W08_G01_staging湿度前缘消费_20261007/analyze_consumption.py)及[指标 JSON](W08_G01_staging湿度前缘消费_20261007/consumption_metrics.json)保留字段、相机与差分包围盒。复算断言每个 A/B 的图像尺寸、profile、物理字段不变，以及每机位 >100 个阈值像素；全部 PASS。低角耦合湿度差异只有 292 像素，说明该视角湿沙区域可见较少，不可据此声称湿度视觉效果达到目标。
