# W08 G05：v6 双模式共用床面材质

日期：2026-10-09。结论：**[已完成：显式 staging 双模式床面着色统一]**。这是 W08 入口一致性的局部成果；V01/V03/V04/V05/V06、WR-G0/WR-G1/WR-G2/WR-G3 和完整性能门仍未通过。海浪沿用既有效果，未调整波浪形体或配置。

## 改动

- 新增 `water_render_staging_v6.json`，固定与耦合模式均指定既有 `reference_coupled_bed.gdshader`；波包、床面初态、水材质和浅水设置与 v5 相同。
- profile loader 接受 schema 6，并拒绝 v6 两模式不同床面 shader；存档白名单接受 v6。staging 入口按 profile 绑定已有材质资源。旧 v1–v5 的资源指定保持原值。
- 两条 `.tscn` 直接预览场景固化 v6 profile。此处仅选择预存场景与 shader 资源，不在运行时重建静态节点。
