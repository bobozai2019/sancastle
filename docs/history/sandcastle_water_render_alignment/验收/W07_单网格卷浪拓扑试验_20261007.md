# W07 单网格卷浪拓扑试验（2026-10-07）

## 问题与实现

[主面开口试验](W07_共享边界开口试验_20261007.md)证明独立浪唇无法覆盖主水面裁出的区间。本试验在 W07 预览夹具中生成一张连续水面网格：每行 128 个浪后水面点、11 个卷唇截面点、128 个浪前水面点，共 267×256 顶点。相邻列和相邻行直接用三角面连接；顶点 shader 从同一 256×1 前缘字段确定各段 x 坐标与卷唇高度，片元 shader 在同一材质中分别处理水面和卷唇。生产网格、求解器和正式 shader 均未改变。

`--unified-curl` 启用隔离网格与 `reference_water_unified_curl.gdshader`。首版沿用了叠加条带的端点透明渐隐，仍露出沙色缝。`--unified-debug` 把三段强制着成不透明红/绿/蓝，证实网格三段实际连续；沙色缝是可见性/透明度问题，不是这次网格的拓扑空洞。`--unified-sealed` 去掉卷唇端点渐隐并把卷唇透明度提高到 0.92–0.98，tick 390 的大片露底消失。首版无波时卷唇列塌到前缘，低角出现沙色带；之后修复为门控关闭时全部顶点回到规则网格、卷唇列使用普通水面着色。`--unified-variable` 只在活动时按本行上升强度与固定空间噪声调制卷唇高度及白度，尝试打破等高白带。所有开关默认关闭。

## 判定与限制

单网格共享边界解决了“两网格不能构成共同面”的结构问题，并找到了无波回退与透明封口的必要条件；保留为 W07 几何路线候选。它**尚未通过 V03/V05/V06/V08**：卷浪曲率和亮芯宽度未达参考、白沫仍偏规则、浅岸接触未作 >4px 门检验、只有两个活动截帧且没有正式 30+60 秒/30 分钟活动成本。当前 7 点窗口在大量顶点重复采样，只能作视觉原型；若继续，应先把连续门预计算成低成本字段，再设计随波相位变化的截面和冠部碎沫，而不能把现有白条接入 W08。W07 G03 与 WR-G0 仍不通过。

最终封口、规则回退与强度调制原型源码 SHA256：`reference_water_unified_curl.gdshader` `43D377B2D98956219A44732857B5BB68FB48802CFED748E5674F60DE7542C518`；`reference_preview.gd` `0FEFE51A5E50C64BED6C941AB49B506C64F773F68D64767391AC962E08C2D6B7`；`capture_reference.gd` `0B3D6ED0B8B616125671C477C13A7F907A96643B04C01C039BE03FF9BFF7858E`。早期渐隐与不透明调试图在同一轮迭代中生成，未逐次冻结源码 SHA，只用于缺陷归因，不能单独作为 G03 放行证据。
