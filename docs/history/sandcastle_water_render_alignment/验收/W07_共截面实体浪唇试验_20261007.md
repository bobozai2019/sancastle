# W07 共截面实体浪唇试验（2026-10-07）

## 目的与实现

[共前缘泡沫试验](W07_共前缘泡沫试验_20261007.md)将主水面抬升和泡沫收束到同一 256×1 前缘字段，但仍没有卷唇体积。此前 11 层实体浪唇的附着高度按 Gaussian 主面计算；本试验复制为 `reference_crest_shared_front_lip.gdshader`，让 `main_crest_lift()` 使用与 `reference_water_front_foam.gdshader` 一样的后侧 11 格长肩、推进侧 2 格短坡。这样实体浪唇每层顶点在各自 x 位置按实际主面边高附着；仍保留水色体、白冠和深度写入。

W07 捕图由 `--front-foam --crest-solid-lip --crest-water-body --crest-ribbon-depth-write` 组合启用。开关和 shader 默认关闭，正式入口无变化。耦合参考床面 tick 390，波/无波各拍六机位，对照同态无浪唇的 `front_foam_wave390` / `front_foam_still390`。Godot 可执行文件实际横幅 `v4.7.beta.custom_build.dff2b9bb6`，D3D12/GTX 1050，1920×1080。两次捕图均退出 0。manifest、PNG 和逐像素 [comparison.json](W07_非对称浪前原型_20261007/comparison.json)位于[证据目录](W07_非对称浪前原型_20261007)；比较脚本校验同态波场、初始 hash、泡沫摘要和相机。

## 判定

共截面附着是必要的几何一致性约束，但当前逐行条带拓扑和固定截面不选。下一候选应围绕连续的岸向边界、跨行形变和遮挡建模，并把泡沫限制在体积的实际冠部；不能再以白色描边或青色坡墙替代卷浪。W07 G03 与 WR-G0 不通过，V03/V05/V06/V08 未放行。
