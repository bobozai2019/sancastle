# W07 前缘加密亮沫片试验（2026-10-07）

## 原型与假设

[水平亮沫片原型](W07_水平亮沫片原型_20261007.md)把 32768 个片均布全域，活动浪前只有疏点。本轮在同一默认关闭的显示原型中加入逐行 32 个片、共 8192 个片的前缘密集层；每行由已有 256×1 GPU 前缘字段定位，宽 1.24m，本地泡沫历史和湿域仍决定片元是否出现。`--foam-front-only` 隔离密集层，`--foam-front-splats` 叠加全域扰动片，`--foam-front-smooth` 用七个邻行的强度与加权位置稳定前缘。`--foam-splats-fine` 把每片半宽 0.055m 改为 0.018m。全部开关默认关闭，只用于平面水面，和 unified curl 同时启用时入口拒绝。

## 对照与发现

耦合参考床面 tick 390，Godot `v4.7.beta.custom_build.dff2b9bb6`、D3D12/GTX 1050、1920×1080 全屏，eta normals/depth write/irregular foam，六机位。一个合法波包与无额外波负例均完成，所有 manifest 与 PNG 在[片层证据目录](W07_水平亮沫片原型_20261007)。有波各组的 `foam_summary`、初始 rock/sand/water 哈希与原全域片对照相同；无额外波的 `front_smooth_fine_still390` 对关闭片层基线六机位逐像素零差。

前缘字段旧读回在 tick 390 的本行阈值 `front.y>0.0025` 有 199/256 活动行；另有 57 行的泡沫最大值 >0.05，却不满足该本行门。七点加权强度以同一诊断阈值扩大到约 214 行，位置也由强行加权，但局部泡沫和湿域仍让画面断成几段。[前缘独立俯斜](W07_水平亮沫片原型_20261007/front_only_wave390_coupled_oblique.png)形成密集白段和明显空隙；[叠加全域片](W07_水平亮沫片原型_20261007/front_both_wave390_coupled_oblique.png)使周边散点保留；[邻行平滑版](W07_水平亮沫片原型_20261007/front_smooth_wave390_coupled_oblique.png)补了部分强度但仍有断段，低角的[横截面](W07_水平亮沫片原型_20261007/front_smooth_wave390_coupled_crest_cross.png)出现过大的近景白片。

原片完整边长随随机因子约 0.07–0.14m，比三份 RDC 中位 0.034–0.061m 大。小片版的完整边长约 0.023–0.047m；[小片低角图](W07_水平亮沫片原型_20261007/front_smooth_fine_wave390_coupled_crest_cross.png)白斑显著缩小，但亮浪芯退成稀疏点。Godot 场景与原捕帧相机/世界比例不同，此量纲只作试验尺度，正式需按投影像素和同尺度 ROI 校准。前缘密集层在这三个变体中都只是覆盖在平坦水面上的白沫，没有 V03 所要求的曲率、厚度或真实浪面高度变化；V05 连贯且碎裂的生命周期也未由静态图证明。

## 判定

前缘集中可增强亮沫局部密度，历史与湿域门保住无波负例；邻行支持与片尺寸调整均未给出可信的主浪。此原型不选为 W07 路线。下一步应先让前缘位置、湿域与水体形状共用稳定表示，再把亮沫贴在具有正确深度的浪背/前脸上；参考水平小片只能承担白沫细节。V03/V05/V06/V08、W07 G03、WR-G0 不通过；V06 的 4px 接触和 V08 活动成本未验证。
