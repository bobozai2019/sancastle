# W11 G01/G02：亮纹强度与浅底形体（2026-10-08）

状态：**固定/耦合同态候选量测 PASS；G01/G02 [进行中]，W11 0/3**。`0.4` 暂为候选，不进入共享 staging profile；V01/V04/WR-G0 仍未通过。

W07 已发现折叠亮纹遮住浅底沟脊。为同时比较“亮纹仍可见”和“底形较清楚”，固定及耦合床面 shader 增加默认 `1.0` 的 `prototype_caustic_strength`，只乘在水底亮纹贡献上，不改变湿域、床形、物理水深或水面光学。捕图器在同一完成 tick 临时采 `0/0.4/0.6/1.0` 并恢复原值；两个床面使用相同参数及纹理输入。

两场景均为 `water_render_staging_v1`、连续 80 波包、tick240、D3D12 / GTX 1050、可见 1920×1080、VSync off。每场景保存三层深度掩码、床色消融和四个亮纹强度的 PNG/F32/[manifest](W11_G01_亮纹强度_20261008)；[分析脚本](W11_G01_亮纹强度_20261008/analyze_caustic_strength.py)复算[指标](W11_G01_亮纹强度_20261008/caustic_strength_metrics.json)，PASS。耦合强度 1.0 的正常 PNG 与先前 W10 G02 tick240 逐字节相同；强度 0 与同次关闭亮纹的正常水色 PNG 亦逐字节相同。右侧干岸 ROI 在各强度下逐像素完全一致。
