# W13 G01：固定/耦合可见床面插值统一（2026-10-08）

状态：**床面采样规则统一并经实际捕图验证；V06、W13 G01 仍未通过；性能 0/10**。

`reference_terrain.gdshader` 固定模式原来对四格床高做 smoothstep 双线性重建，`reference_coupled_bed.gdshader` 耦合模式按显示网格对角线做分片三角形插值。两模式虽读取同一 rock/sand 初态，可见床高在格内并不相同，违反共同可见床面的接触基准。固定模式现改为与耦合模式相同的 `v00→v11` 对角线分片插值；不改物理字段、水面 shader、耦合 shader 或 staging profile。

D3D12、GTX 1050、1920×1080、严格 `water_render_staging_v1`、80 波包、固定/耦合 tick300 各捕图退出 0。两模式初态 hash 相同：rock `639217814`、sand `1069331530`、water `774098242`。固定水深 F32 与[旧动态岸线捕获](W13_G01_动态岸线遮罩_20261008)逐字节相同，耦合水深亦同；耦合三镜头正常 PNG 逐字节不变。固定正常 PNG 相对旧图 RGB 任一通道差值 >12/255 的像素：俯斜 237、近景 268、掠射 339；三图平均绝对通道差分别 0.0133、0.0103、0.0097/255。固定白色水片遮罩分别改变 15,356、6,508、5,919 像素，主要是几何/遮挡边界的细微移动，不能把遮罩变化直接当视觉改善。
