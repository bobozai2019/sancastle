# W11 G01/G02：床面亮纹信号单独恢复（2026-10-08）

状态：**深水信号与床面位置归因 PASS；候选默认关闭；V04/WR-G0 未通过，W11 0/3、性能 0/10**。上轮将床面与水面深度衰减一同放宽时，虽然深水亮纹略增强，关亮纹底色却改变约 40.6/255。本轮在不改正常透射和散射的前提下，只试恢复亮纹成分。staging profile 不变，水面 shader 的 `prototype_caustic_recovery_gain` 默认 `0`，仅捕图时绑定与床面相同的折叠纹理并临时设为 0.5/1.0。

首先用同一完成态的床面直出开/关图差值做[离线 oracle](W11_G01_双层深度衰减_20261008/recover_bed_signal.py)。耦合模式深水 200×200 ROI，差值以 0.5 倍叠加回默认水面后，亮纹开关平均最大通道差从 0.09 增至 1.84/255，>8 像素从 0 增至 2,471；1 倍为 3.65/255、7,125。干岸零差，关亮纹画面不变。但此计算使用了运行时尚不存在的“床面开减关”真值，只说明单独恢复信号可行，不是实现证据；浅水若无深度门也会过亮。[oracle 指标](W11_G01_双层深度衰减_20261008/bed_signal_oracle_metrics.json)。

运行时原型改为在水面 shader 重采样同一折叠纹理。直接用水面 `UV` 时，较深水 ROI 的新增亮纹与床面直出开/关信号相关只有 **0.195 耦合 / 0.210 固定**，虽能画出亮线，位置错开。改从已选的折射后 `sampled_uv` 读取场景深度，逆投影至实际可见床面点，再按 32m 域换算纹理坐标；相同 ROI 相关升至 **0.994/0.995**。这验证亮纹位置必须跟随可见床面采样点，不能只用水面 UV。深水衰减项保持原光学底色，只在约 0.14m 后逐渐开启新增分量，并加上视角余弦以降低掠射过亮。

固定、耦合严格 `water_render_staging_v1`，连续 80 波包、tick240、D3D12/GTX 1050、1920×1080、VSync off，俯斜/近景/掠射/俯视捕图均 exit 0/PASS。最终视角权重原型的 manifest 是[耦合](W11_G01_亮纹单独恢复_20261008/coupled240_reproject_angle_coupled_manifest.json)和[固定](W11_G01_亮纹单独恢复_20261008/fixed240_reproject_angle_water_manifest.json)；同态[复算](W11_G01_亮纹单独恢复_20261008/analyze_recovery.py)及[多镜头复算](W11_G01_亮纹单独恢复_20261008/analyze_multiview.py)核对初态/profile/80 波包/真实分辨率。两模式 F32 水字段与上轮逐字节相同；`gain=0` 正常图与既有图最大差≤1/255；各镜头 `gain=0.5` 的关亮纹图与 `gain=0` 关亮纹图逐像素相同。[位置/强度指标](W11_G01_亮纹单独恢复_20261008/recovery_metrics.json)、[耦合多镜头指标](W11_G01_亮纹单独恢复_20261008/angle_metrics.json)、[固定多镜头指标](W11_G01_亮纹单独恢复_20261008/angle_fixed_metrics.json)。
