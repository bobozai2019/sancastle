# W07 隔离原型：固定与耦合床面亮纹输入

日期：2026-10-07。结论：**耦合床面漏接亮纹的路径已在隔离原型补齐；当前亮纹形状仍未通过 V04，WR-G0 继续 FAIL。** 本次只验证床面效果消费与同状态开关图，不将此原型并入正式材质。

## 改动与输入

固定床面原型的 `reference_terrain.gdshader` 已有浅水亮纹，耦合床面的 `reference_coupled_bed.gdshader` 原先不读取 `water_state` 来绘制亮纹。现让耦合床面使用固定床面相同的相位、亮线、深度衰减函数，增加默认关闭的 `prototype_coupled_caustics`，捕图入口增加 `--coupled-caustics` / `--no-caustics`。沙/水物理字段、求解器和生产 shader 未改。该函数仍是带正弦周期的试验式输入，并非已确认的 RDC 算法。

四次运行均为实际可见全屏 1920×1080、D3D12 / GTX 1050、精确 tick 60，`visual_time_s=2.0`；无附加波包。固定两组与耦合两组的初始 rock/sand/water 哈希均为 `1625571958 / 2318428149 / 4161789743`，完成态 `revision=180`。每个场景的亮纹开/关 manifest 中 tick、revision、哈希、三镜头参数、分辨率、时间和波包列表逐项相同。四份日志都有预期 PASS，未见 shader/script ERROR；各运行 exit 0。
