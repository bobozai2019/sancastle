# W07 浪脊水深门槛隔离试验

日期：2026-10-07。结论：**旁路浪脊几何抬升的局部水深渐变门槛后，侧视竖条几乎未变。** 该门槛不是已观察竖条的主要来源；诊断开关默认关闭，V03/V05/V06 与 WR-G0 仍未通过。

在 W07 专用 `reference_water.gdshader` 增加默认关闭的 `prototype_crest_depth_gate_bypass`，仅把几何抬升中的 `smoothstep(0.012,0.08,water_depth)` 改成湿区阶跃；其余 foam、着白、求解和材质不变。`capture_reference.gd` 可用 `--crest-depth-gate-bypass` 开启。Godot 导入 exit 0，耦合床面 tick 360、合法波包、1920×1080 D3D12 捕图 exit 0、PASS。

将[基线侧视](W07_主水面跨向平滑_20261007/coupled_base_coupled_wavefront_side.png)与[旁路侧视](W07_浪脊水深门槛_20261007/coupled_bypass_coupled_wavefront_side.png)比较，ROI `[350,350,1050,520]` 中 RGB 最大通道差 >16 仅 **34/119000** 像素，亮白像素 5167→5190；竖条仍清晰可见。两次运行的 tick 360、revision 1372、初态哈希、wave 请求和 foam 统计相同。[原始捕图、manifest、日志、源码快照与 SHA256](W07_浪脊水深门槛_20261007)。这项反证仅排除当前几何抬升水深渐变作为主因，尚不能区分三角形插值、材质透明混合或前后表面遮挡；下一步须用网格/深度隔离图定位。视觉已失败，未做长成本采样。
