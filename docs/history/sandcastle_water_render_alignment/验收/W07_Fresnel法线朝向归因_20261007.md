# W07 屏幕光学 Fresnel 法线朝向归因（2026-10-07）

结论：**隔离屏幕光学的旧 Fresnel 计算把几乎全部可见水面算为最大反射；双面可见法线朝向修正后，深水灰青平板明显减弱，原始散射比例 1.0 已达到 V02 的深浅数值线。** 这是强的光学根因证据，尚不足以放行 V02/WR-G0。

## 原因与隔离开关

`reference_water_local_front.gdshader` 原式为 `pow(1-clamp(dot(VIEW,n),0,1),5)`，水面 `cull_disabled`，但可见面的 `VIEW·n` 在现有网格/法线变换下表现为反号：旧式 Fresnel 诊断在三个镜头几乎整块白色。由于旧屏幕光学把该因子以 `0.025+0.42*Fresnel` 混入固定天空色 `(0.55,0.75,0.86)`，水面被大面积灰青代理色覆盖。默认关闭的 `--screen-abs-fresnel` 在诊断原型中用 `abs(VIEW·n)` 得到可见双面入射角；`--screen-fresnel-debug` 将因子显示为灰度，`--screen-sky-reflection-scale=0` 只用于归因关掉代理色。均未改正式水材质或模拟。

耦合参考床面合法波包、tick390/revision1492、二维局部前缘 0.25m、eta 法线、折叠亮纹、白沫合并屏幕光学、折射 0.02、`visual_time_s=13.0`、D3D12/GTX1050、1920×1080 三镜头。各 run 的 manifest 除所列诊断开关、输出标识外同态，捕图 `PASS`、没有 shader/script ERROR。旧 [Fresnel 俯斜](W07_水深投影诊断_20261007/screen_fresnel_wave390_fold_coupled_oblique.png) 几乎纯白，修正后 [俯斜](W07_水深投影诊断_20261007/screen_fresnel_abs_wave390_fold_coupled_oblique.png) 为低值且有几何起伏；修正后 [掠射](W07_水深投影诊断_20261007/screen_fresnel_abs_wave390_fold_coupled_grazing.png) 的反射因子明显更高。

[复算脚本](W07_水深投影诊断_20261007/analyze_fresnel_orientation.py)在同一实际可见水深内区遮罩上核对 manifest、统计诊断图和光学图，完整结果见 [JSON](W07_水深投影诊断_20261007/fresnel_orientation_metrics.json)。灰度是渲染后的 8-bit sRGB 诊断值，不能直接当线性 Fresnel 常量。

旧 0.15 [俯斜](W07_水深投影诊断_20261007/screen_deep015_sky100_wave390_fold_coupled_oblique.png)仍是灰青平板；关代理的[俯斜](W07_水深投影诊断_20261007/screen_deep015_nosky_wave390_fold_coupled_oblique.png)变为过暗深青且失去掠射反射；朝向修正、散射 1.0 的[俯斜](W07_水深投影诊断_20261007/screen_abs_deep100_wave390_fold_coupled_oblique.png)恢复青色层次和角度起伏，朝向修正、散射 0.15 的[俯斜](W07_水深投影诊断_20261007/screen_abs_deep015_wave390_fold_coupled_oblique.png)则又过暗。因此[前轮 0.15 比值试验](W07_深水散射比例复核_20261007.md)只描述旧错误 Fresnel 路径，不再作为推荐光学参数。

修正方案仍为显式实验开关，未验证固定床面、多相位、无额外波、V01 底形、真实场景反射、V03/V05 浪前、V06 岸线与 V08 联合成本。屏幕光学仍用固定天空色代理，掠射角对比虽已恢复，也不能当真实反射验收。V02、WR-G0 保持未通过。
