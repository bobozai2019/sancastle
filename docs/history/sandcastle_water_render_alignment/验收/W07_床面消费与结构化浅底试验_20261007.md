# W07 床面消费与结构化浅底试验（2026-10-07）

结论：V01 的浅底可读性缺口同时涉及输入形体和材质，但在 0.02–0.08m 真正可见浅水内，当前床面直出已经只有很弱的局部对比。新增默认关闭的床面采样诊断确认这一点；新增默认关闭的结构化参考床面用两条不等形沟槽、邻接沙脊及薄沙露底提供物理/材质信号，局部浅水 ROI 的形态对比有增益。增益没有扩展到整片浅水，折叠亮纹又遮住部分暗沟，不能放行 V01/V04/WR-G0。

## 床面颜色实际消费

`--screen-bed-only` 在局部前缘水面材质的屏幕光学路径，直接输出水面片元按相同屏幕 UV 采到的床面场景颜色。它不改物理、几何或正常光学默认值。固定自然岸线 tick120、无亮纹的[床面直出俯斜图](W07_床面颜色实际消费_20261007/fixed_natural_bed_only120_water_oblique.png)和[正常光学图](W07_床面颜色实际消费_20261007/fixed_natural_optics120_water_oblique.png)的 manifest 仅 `run_id`、`artifacts` 与该开关不同。[深度图](W07_床面颜色实际消费_20261007/fixed_natural_depth120_water_oblique.png)标出真正的 0.02–0.08m 浅水。三镜头正常图与加诊断开关前的旧同态图逐文件 SHA256 相同。

[复算脚本](W07_床面颜色实际消费_20261007/analyze_bed_consumption.py)在俯斜浅水内区（4px 腐蚀）对灰度做 32px 高斯背景相减，局部绝对残差 p90：床面直出 **6.00**、正常光学 **5.67** 个 8-bit 级别；中位亮度分别 176.33 与 179.67。该代理只量投影形态，不代表最终视觉分数。床面直出中的浅水主要仍是规律沙脊与平沙色，正常光学不是这里唯一的形体损失源。近景[床面直出图](W07_床面颜色实际消费_20261007/fixed_natural_bed_only120_water_close.png)同样显示底色单调。[完整 JSON](W07_床面颜色实际消费_20261007/bed_consumption_metrics.json)列出三机位和各深度带。

## 默认关闭的结构化输入

`--natural-reference-shore --structured-reference-bed` 在 256²、0.125m 参考床面中加入两条位置/宽度不同的弯曲沟槽、邻接沙脊，并按沟槽把局部沙层变薄，让现有床面 shader 从真实 rock/sand 状态读出硬底；同时把近水位到浅水带的原周期沙脊衰减。它改输入床面，不在水 shader 中画暗线。固定[床面直出](W07_结构化浅底候选_20261007/fixed_structured_facies_bed120_water_oblique.png)、[正常光学无亮纹](W07_结构化浅底候选_20261007/fixed_structured_facies_default_recheck120_water_oblique.png)、[实际可见深度](W07_结构化浅底候选_20261007/fixed_structured_depth120_water_oblique.png)均为 1920×1080、tick120 三机位捕图。

对自然岸线基线 F32，[复算脚本](W07_结构化浅底候选_20261007/analyze_structured_bed.py)得 rock/sand/water 分别有 9,521/48,540/31,142 格变化 >1e-5m，最大水深差 0.0756m；4 格湿→干，0 格干→湿。这是不同物理输入，不能作渲染器同态 A/B。第二次仅扩展薄沙露底范围时，水深最大差 5.96e-8m、无格差 >1e-5m，rock/sand 则有 2,802/2,770 格位值变化；可用于观察材质范围影响。固定与耦合的最终结构化候选初始 rock/sand/water 哈希完全相同。耦合合法波包 [tick390 俯斜图](W07_结构化浅底候选_20261007/coupled_structured_wave390_coupled_oblique.png)捕图 PASS，revision 1495；浪前仍像细白岸带。

固定床面右岸每行最右湿格总跳变/最大单行保持 **175/5 格**，湿格数 46,649→46,645；局部床面变化没有重新制造之前的大范围周期尖齿。此项只检查物理边界，不能替代 V06 的可见接触与干岸误盖门。

在预先记录的沟槽局部俯斜矩形 `[900,740,1350,930]`，深度图红内区 34,916 像素的 32px 形态残差 p90：自然岸线正常光学 **3.67**，结构化床面 **4.67**，同床面浅水消光长度 0.11→0.25m 为 **6.00**，床面直出 **7.33**。局部改进真实存在；整片红内区却为自然岸线 **5.00**、结构化 **4.00**、浅水透射候选 **4.33**，没有全局改善。浅水专用透射在 ≥0.13m 仍用原 0.11m 消光长度；同床面 tick/相机/初始哈希一致，三机位默认 0.11m 图在增设参数前后逐文件 SHA256 相同。局部效果不等于 V01 通过。

[固定折叠亮纹联合图](W07_结构化浅底候选_20261007/fixed_structured_fold120_water_oblique.png)与[耦合折叠亮纹联合图](W07_结构化浅底候选_20261007/coupled_structured_fold390_coupled_oblique.png)表明亮纹在部分浅底暗沟上形成强白覆盖；需要调底形、亮纹强度和投影尺度的共同读感。当前只有两条较规则的暗沟，仍缺 test35 沙舌/沟脊的复杂连续形体、同尺度对位、0.25m 底形人工复核，以及 V06 全岸接触和 V08 联合性能。所有新增功能默认关闭；旧自然岸线三镜头逐字节一致。V01/V03/V04/V06/V08、WR-G0 均未通过。
