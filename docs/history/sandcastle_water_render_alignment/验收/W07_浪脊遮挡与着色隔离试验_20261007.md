# W07 浪脊遮挡与着色隔离试验

日期：2026-10-07。结论：**侧视竖条不是主水面网格孔洞，也不主要由 alpha 变化或实验性 eta 法线造成；原着色中的亮白成分将它显著放大。** 改为逐片元 foam 着白只能减少白像素，仍保留竖条，且损失亮芯体量。因此目前没有合格修复，V03/V05/V06/V08 与 WR-G0 均未通过。

固定耦合参考床面合法波包、tick 360、1920×1080 D3D12 侧视，全部 exit 0、PASS。每组与[原基线](W07_主水面跨向平滑_20261007/coupled_base_coupled_wavefront_side.png)的 tick、revision、初态哈希、波请求、foam 统计和镜头相同。所有测试开关仅在 W07 shader/capture 中，默认关闭，未改生产路径。

另用默认关闭的 `prototype_crest_fragment_foam` 将抬升面着白从逐顶点 `prototype_crest_lift_v` 改为逐片元 foam 覆盖，保留其余几何/光学。耦合[侧视](W07_浪脊遮挡隔离_20261007/coupled_fragment_foam_coupled_wavefront_side.png)局部亮白像素 1301→475；固定[侧视](W07_浪脊遮挡隔离_20261007/water_fragment_foam_water_wavefront_side.png) 2577→810，**竖条仍在**。该候选不选，不能把减少白像素当作 V03/V05 改善。两组状态与各自基线相同。

局部亮白统计 ROI `[450,405,670,485]`，阈值为三个 RGB 通道均 >220；[分析 JSON](W07_浪脊遮挡隔离_20261007/isolation_summary.json)及[脚本](W07_浪脊遮挡隔离_20261007/analyze_isolation.py)。[全图、manifest、日志、源码快照与 SHA256](W07_浪脊遮挡隔离_20261007)。不同纯色诊断图的亮白计数不可直接比较形体，只用于确认白条是否出现。

目前可确定不透明主网格在该视角连续，半透明时前后水面会重叠；原颜色路径独立于 alpha 变化已能呈现白条。下一实验应直接可视化浪脊前后表面的 UV、foam/着白贡献与深度次序，再决定如何重建连续的白沫/浪唇。当前不得直接把透明度、eta 法线或逐顶点值单独定为根因。
