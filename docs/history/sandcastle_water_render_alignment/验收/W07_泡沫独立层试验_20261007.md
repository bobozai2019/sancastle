# W07 泡沫独立层与浪脊几何一致性试验

日期：2026-10-07。结论：**将白沫绘制拆到第二张水面网格，并不能消除低角三角亮片。** 首版泡沫层几乎不可见，是因为它没有同步主水面的 0.25 m 显示浪脊，恰在高泡沫区被主水面深度挡住。同步几何参数后泡沫可见，也复现了三角亮片，并比单层多孔泡沫更亮。该双网格实现不选为 W07 路线。

## 原型与定位

在 W07 捕图入口增加默认关闭的 `--foam-overlay`：主水面 `phase2_foam=false`，复用同一 512² 网格作为独立泡沫层，读同一水/沙/泡沫 GPU 纹理，片元用[前轮多孔掩膜](W07_多孔泡沫试验_20261007.md)，深度不写，主水面仍写深度。`--foam-suppressed` 只关主面泡沫，用作同态空白对照；强制洋红和灰度覆盖诊断分别验证了覆盖层被绘制、能读取泡沫场。

首版 `overlay_wave390` 漏传主水面的 `prototype_crest_height_m=0.25` 等几何参数。强制洋红图证明覆盖层在普通水面可见，却在浪脊抬升处被主水面遮挡；灰度覆盖图证明泡沫纹理非空。[参数对齐后的 `overlay_matched390`](W07_泡沫分层原型_20261007/overlay_matched390_coupled_oblique.png)复用主面的浪脊高度、岸边门槛、前移、宽浪脊及床面重建参数，并在表面偏高 0.007 m。这是显示几何一致性的必要条件，不说明双网格方案已达标。

同一耦合参考床面、合法波包、tick 390、revision 1492、初态哈希、泡沫统计和六镜头；D3D12、1920×1080，各捕图 exit 0、PASS。[原始 PNG、manifest、分析数据与源码快照](W07_泡沫分层原型_20261007)保留。[分析脚本](W07_泡沫分层原型_20261007/analyze_foam_overlay.py)检查同态并计 ROI 的亮白代理 RGB > (190,200,200)：

| 对照 | oblique 岸边 ROI | crest_cross 前景 ROI |
|---|---:|---:|
| 只关泡沫 `suppressed_wave390` | 0 | 0 |
| 首版几何未对齐的独立层 | 433 | 24 |
| 几何对齐的独立层 | 30121 | 48850 |
| 单层多孔泡沫 | 24701 | 38660 |

ROI 与前轮相同：oblique `[1050,250,1450,1050]`，crest_cross `[0,350,900,800]`。初版覆盖层对“只关泡沫”在两全图仅有 974/37 个明显变化像素；几何对齐后为 40483/97873。对齐独立层较单层多孔泡沫在两 ROI **更亮**，其[横向图](W07_泡沫分层原型_20261007/overlay_matched390_coupled_crest_cross.png)仍有大三角亮片。独立层改变透明合成，但没修主网格的低角可见形体，也没得到参考型卷浪厚芯。亮白数只是诊断代理，不是 V03/V05 判定。

本原型没有做正式 30+60 秒三镜头或 30 分钟性能测试；第二张 512² 网格的成本尚无上界。因 V03/V05/V06 视觉门已失败，不能把它接入正式入口。后续应从共享水面几何、湿域裁剪和低角遮挡顺序改造，而不是直接增加覆盖网格。所有新开关默认关闭，生产 shader、求解器和 profile 未改。W07 G03、WR-G0 仍未通过。
