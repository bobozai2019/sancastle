# W07/W13：多尺度沙舌参考床面隔离候选

日期：2026-10-08。状态：**床面形体产生真实湿域变化；候选未选入 staging，V01/V06、WR-G0 未通过；W07 性能仍 10/10**。

[test35 参考画面](../rdc_evidence/test35-frame20641_color_after_5593.png)有宽沙舌、邻接浅沟和变化的浅底边界；现有 staging 输入主要是右岸与单岛。此前[轻度雕刻候选](W07_雕刻床面候选_20261008.md)变化太窄，俯斜仍像一条硬沙嘴。本轮增加默认关闭的 `--lobed-reference-bed` 隔离输入：两条不同宽度、沿 x 弯曲的沙舌与邻接沟槽逐渐并入右岸，直接改变沙床高度和由其初始化的水深；固定/耦合共用同一公式。不修改沙、水求解器或共享 staging profile。

D3D12/GTX 1050、可见 1920×1080、自然岸线与结构化床面，固定/耦合各捕 tick120 三镜头及 rock/sand/water R32F；耦合另在单包波后捕 tick300。三次进程均退出 0 并输出 PASS。[复算脚本](W07_多尺度沙舌候选_20261008/analyze_lobed_bed.py)检查基线条件、字段长度/有限值、三次相同初态及波包请求，结果 PASS；[指标 JSON](W07_多尺度沙舌候选_20261008/lobed_bed_metrics.json)与[全部原始文件](W07_多尺度沙舌候选_20261008)可复核。

基线固定湿格为 46,645。固定和耦合候选的初始化 rock/sand/water 哈希完全相同：`3904757401 / 2415546350 / 972275442`。固定[俯斜图](W07_多尺度沙舌候选_20261008/lobe120_water_oblique.png)相对原结构床面有 290,770 个 >12/255 像素变化，[耦合俯斜图](W07_多尺度沙舌候选_20261008/lobe120_coupled_oblique.png)也出现两条与右岸相连的宽浅滩。这是**物理床面与湿域形体**变化，非仅材质涂色或透明羽化。

视觉仍不满足参考：固定模式的沙舌边缘呈清楚的格状阶梯；耦合沙舌虽然较柔和，仍过于平滑、两条形体太规则，缺少参考中的多尺度分支、起伏和水底暗沟可读性。[耦合 tick300 单包波画面](W07_多尺度沙舌候选_20261008/lobe300_coupled_oblique.png)显示沙舌拓扑仍在，但岸侧产生重复大块白色泡沫，需与 W12 的接触/前缘问题联合修复。参考镜头、物体布局与此原型不同，不能作逐像素对齐。

对固定 tick120 再用 `--subdivision=4` 作同态消融：[4 倍俯斜图](W07_多尺度沙舌候选_20261008/lobe_sub4_120_water_oblique.png)与 2 倍图只有 865 个 >12/255 差异像素，近景/掠射为 359/327；三份 rock/sand/water R32F 逐值相同，初态哈希相同。岸线阶梯目视仍在。增加显示网格密度不是此候选的充分修复，也不能据此承担额外成本；这与先前 W07 共床高/细分诊断一致。

同一固定 tick120 另存[俯斜纯水片覆盖图](W07_多尺度沙舌候选_20261008/lobe_maskonly120_water_oblique_shoreline_mask.png)：白色水片与沙舌相交处仍呈阶梯轮廓；三镜头正常 PNG 和 R32F 水深与原候选逐字节相同。覆盖像素在俯斜/近景/掠射为 725,122/1,089,616/1,333,251。由此可见台阶已存在于实际水片覆盖与可见沙床的交线，不是只由沙色或亮纹贴图造成；尚不能把误差独立归因于物理湿格边界还是床面遮挡。该隔离入口使用的水 shader 不提供严格 staging 的湿格来源调试，尝试开启该调试被显式拒绝；未把失败运行当证据。

再临时把湿占比/水面高度的格内 smoothstep 权重换成线性权重，保持床高重建原样。在相同初态、水深字段与 tick120，[线性候选遮罩](W07_多尺度沙舌候选_20261008/lobe_linear120_water_oblique_shoreline_mask.png)与原遮罩的俯斜/近景/掠射异或仅 216/466/140 像素，正常图 >12/255 差异仅 3/0/76 像素；台阶目视仍在。**仅改湿域格内插值也不是充分修复**，临时开关已撤回。该消融为视觉/覆盖实验，不计 W07 已耗尽的性能轮次。

因此候选保留为**默认关闭的隔离场景输入**，不进入 staging，不完成 W07 G03/W13 G01，也不增加小目标或性能轮次。下一步需完善沙舌分支和水底色阶，并在同一床面下处理边缘阶梯与大块泡沫；W07 性能已达 10 轮上限，任何最终路线选择仍受 WR-G0/V08 成本门约束。
