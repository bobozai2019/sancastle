# W13 G03：岛脚近景透明度与可见阶梯归因（2026-10-09）

状态：**同态 alpha 消融定位 PASS；可见交线 V06 未通过。**耦合 `water_render_staging_v1`、80 连续波包、tick300、D3D12/GTX 1050、真实 1920×1080，严格捕图器新取[正常近景](W13_G03_当前岸线复验_20261009/shore300alpha_coupled_close.png)、[水片遮罩](W13_G03_当前岸线复验_20261009/shore300alpha_coupled_close_shoreline_mask.png)、[alpha 分档](W13_G03_当前岸线复验_20261009/shore300alpha_coupled_close_contact_alpha.png)。水、岩、沙 F32、正常近景 PNG 和白遮罩与[先前同态捕图](W13_G03_当前岸线复验_20261009.md)逐字节相同；诊断开关默认关闭，不改变正式 staging。

在岛脚近景 ROI `[780,350,1280,550]`，alpha 分档图中红色 `<0.05` 为 **139** 像素，黄色 `0.05–<0.20` 为 **161**，绿色 `≥0.20` 为 **52,529**。前轮[近景 8px 视线代理](W13_G03_当前岸线复验_20261009/close_visibility_metrics.json)标出的 16 个“纯干点仍有白水片”差异像素沿岛上缘排列；抽核其中 `(1016,368)` 至 `(1056,368)`、`(936,376)`、`(848,408)` 均为绿色高 alpha，而非低透明度薄水像素。该视线代理用最近格床高和 0.0625m 步长，差异也可能来自沙床遮挡或水片显示抬升，不能直接定性为 16 个真实干岸误盖。

追加交叉检查既有同 tick [湿域来源着色图](W13_G01_湿域来源着色_20261008/coupled300_source_coupled_close_shore_source.png)：16 个差异像素中 **15 个绿色**，表示屏幕上的水片来自权威湿格；仅 `(1200,416)` 为红色最近干格。既有[视线深度分档](W13_G01_屏幕深度交线_20261008/coupled300_contact_coupled_close_contact_depth.png)在前述抽核的绿色像素处为深水灰档（不评价底面距离），红点 `(1200,416)` 为蓝档（水片在不透明床面前 ≥0.10m 视线距离）。这说明 8px CPU 射线的“干”标签大多与实际水片 UV 来源不同，不能将 1.5% 代理数当作真实干岸误盖率；剩余一个红点也可能是合法的边界重建或视角遮挡，需同像素可见床面验证。

结论限于本同态画面：岛上缘的锯齿和这组可见水片差异不能靠抬高浅水 alpha 修复；右岸仍有低 alpha 细带，属于另一局部问题。下一步应核对岛脚真实可见沙床轮廓、前后遮挡与水片局部形体，必要时按 `rdc/test1.rdc` 的分层绘制证据设计独立候选；不能用透明羽化隐藏错误湿域。近景连续 >4px 缝宽、陡壁及参考形态仍需验收，W13 G03/V06/WR-G2 均不放行。

参照[RDC 绘制清单](../rdc_evidence/README.md)复看 `testnew` 的[亮边绘制前](../rdc_evidence/testnew_color_after_6931.png)与[亮边绘制后](../rdc_evidence/testnew_color_after_6943.png)：新增贡献是沿若干岛脚和障碍边缘的局部细亮线，而本场景岛脚主要是水 shader 中宽而连续的青色过渡。两者床形、相机与 HDR 映射不同，此处只能确定“参考有独立亮边绘制层”和当前需要区分遮挡轮廓/接触亮边，不能推断其生成算法或把亮线直接当几何修复。

[低 alpha 连通带复算](W13_G03_当前岸线复验_20261009/analyze_alpha_band.py)在同张近景分档图上补充岛脚与右岸两个 ROI 的行、列最长连续段，结果见[指标](W13_G03_当前岸线复验_20261009/alpha_band_metrics.json)。岛脚 ROI 仅 300 个低 alpha 纯色像素，行/列 95 分位最长段 4/2px，8 邻域侵蚀一次即无内部；右岸 ROI 有 **4,911** 个，行/列 95 分位最长段 **26/20px**，极值 61/42px，8 邻域侵蚀后仍可连续保留 5 轮，即至少局部有 11×11px 的低 alpha 区域。行列段长度受岸线斜率影响，**不是**法向缝宽；低 alpha 区域也不自动等于可见浮空缝。但右岸确有连贯的宽低透明度区域，而岛上缘主要不是这个机制。此前[透明度下限失败对照](W13_G01_薄水透明度下限失败对照_20261008.md)已排除单独抬 alpha 作为充分修复，下一候选需同时处理右岸可见床色/水色与实际接触亮边。
