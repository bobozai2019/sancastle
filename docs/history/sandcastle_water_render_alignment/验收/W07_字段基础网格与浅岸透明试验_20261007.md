# W07 字段基础网格与浅岸透明试验（2026-10-07）

## 问题与原型

[单调回退拓扑试验](W07_单调回退拓扑试验_20261007.md)用固定 x≈4m 中心消除无波接缝，但中心不随浪前和岸线变化。本轮把单网格两侧水面及非活动卷唇列统一锚到每行的 `rise_front_field.x`，在卷唇列内用 `mask` 从单调平面过渡到活动截面。字段 x 限制在 112–248 格，以免弱行的异常位置把边界拉出画面。此限制只是诊断保护，尚不能证明字段的分支、时间稳定性。

同时隔离两种片元处理：`--unified-alpha-seal` 让活动卷唇保留高 alpha；`--unified-fragment-wet` 再以当前 UV 的水深渐隐 alpha。三个开关均默认关闭，只在 W07 原型中使用。

## 字段和同态证据

耦合参考床面 tick 390 有波/无额外波，D3D12/GTX 1050、1920×1080；Godot 横幅 `v4.7.beta.custom_build.dff2b9bb6`。`frontbed_wave390` 与 `frontbed_still390` 同时导出水深和前缘字段：有波 `front.y` 达活动阈值的 199 行中，`front.x` 的 0/25/50/75/100 百分位约为 161.17/166.85/171.05/183.92/187.52 格；无额外波没有达到 0.0025 的活动行，但弱 `front.x` 仍随行变化，不能当作已验证的静止锚点。六组候选每组六机位捕图均退出 0，PNG、manifest 和[比较 JSON](W07_非对称浪前原型_20261007/comparison.json)保存在[证据目录](W07_非对称浪前原型_20261007)。[比较脚本](W07_非对称浪前原型_20261007/analyze_front_profile.py)核对夹具、tick、初始 hash、波请求、泡沫摘要及相机一致后才计算像素差。

## 判定

字段锚点加单调回退可作为默认关闭的拓扑诊断组件；当前弱前缘 x、局部门和湿域片元门还没有可迁移的稳定约束。两种 alpha 处理均不选为正式岸线方案。V03 厚亮芯、V05 生命周期、V06 浅岸接触和 V08 正式活动成本均未通过；W07 G03 与 WR-G0 不通过。下一路线需要给每行前缘位置、活动强度、湿域覆盖和跨行三角连接一个一致契约，并验证多相位、分支与岸线。
