# W09 G02：局部前缘自由水面判据与床高历史（2026-10-08）

状态：**前缘来源判据修复，GPU 合成正负对照 PASS；V03/G02 仍未通过**。这是正确性和完成态画面验证，W09 性能轮次仍为 0/10。

局部前缘 X pass 原先用 `max(depth_now - depth_previous, 0)` 定位上涨带。耦合床面若降低而自由水面 `eta=bed+depth` 不变，也会让水深上涨，误报为活动浪前。W12 主泡沫来源已使用上一床高修正自由水面，但 W09 局部前缘未同步，且前缘被主水面抬升与 W12 离岸泡沫候选消费。

现修改普通和 ±12 格宽窗两份 `reference_local_front_x*.glsl`：在每个邻域格取当前岩高、沙高以及主泡沫字段保存的上一床高，令 `score=max((depth_now+bed_now)-(depth_previous+bed_previous),0)*wet_gate`。`reference_local_front_field.gd` 按求解器与泡沫 ping-pong 当前索引绑定六张纹理；泡沫前分派和泡沫后分派分别读取正确的上一完成态。Z pass、物理求解、泡沫生产 shader 与正式 profile 参数均未改。[旧深度差 shader 快照](W07_曲流入海口床面候选_20261008/reference_local_front_x_depth_only_snapshot.glsl)和[旧宽窗快照](W07_曲流入海口床面候选_20261008/reference_local_front_x_wide_depth_only_snapshot.glsl)留存。

新增 [D3D12 GPU 探针](../../../../tests/visual_water_alignment/prototypes/probe_local_front_bed_drop.gd)，对普通和宽窗 X shader 各运行三种均匀 256² 输入，并串联实际 Z shader：

| 输入 | 上一床高/水深 | 当前床高/水深 | 中心峰值（普通/宽窗） |
|---|---|---|---:|
| 稳态 | 0.10/0.10m | 0.10/0.10m | 0 / 0 |
| 床降，eta 不变 | 0.10/0.10m | 0.08/0.12m | 0 / 0 |
| 真实 eta 上涨 | 0.10/0.10m | 0.10/0.12m | 0.019999996 / 0.019999996 |

两次进程退出 0、打印 PASS；三组 RG32F 原始读回及 shader SHA 在[普通窗证据](W09_G02_自由面前缘_20261008)与[宽窗证据](W09_G02_自由面前缘_20261008/wide)中。逐格复算：稳态与床降的 65,536 格峰值全零，真实上涨的 65,536 格峰值全为 0.019999996。命令需可见 D3D12 RenderingDevice；`--headless` 下主 RenderingDevice 不存在，不能用于此探针。
