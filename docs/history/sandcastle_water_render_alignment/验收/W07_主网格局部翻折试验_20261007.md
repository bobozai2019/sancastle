# W07 主网格局部翻折试验

日期：2026-10-07。结论：**在主水面网格的泡沫前缘直接前探/抬升顶点，仍未得到连续卷唇。** 侧视仍是几座分离圆丘，俯斜浪前沿岸形成零散亮块；V03/V05/V06 未通过，W07 G03 与 WR-G0 保持进行中。

承接[附着浪唇失败对照](W07_附着浪唇试验_20261007.md)，本次不用独立覆盖网格。W07 独立的 `reference_water_integrated_fold.gdshader` 以写深度水面为起点，在主网格每顶点从现有泡沫场取 +x 梯度及后肩，局部按湿水深门槛前探最多 0.35 m、额外抬升最多 0.20 m；相邻未变形顶点仍是同一个网格的连接边。开关 `--integrated-fold=0.35` 默认关闭，只在启用 0.25 m 浪脊和 `--depth-write` 时允许，生产 shader/求解器/泡沫状态均未改变。

耦合参考床面、tick 390、D3D12、1920×1080 的捕图 exit 0、PASS。与[前次写深度基线](W07_附着浪唇原型_20261007/base_coupled_wavefront_side.png)相比，tick、revision、初态哈希、波请求、泡沫统计、四镜头完全一致；强泡沫覆盖 `>0.20` 为 2425 格。全图 RGB 最大通道差 `>16` 的像素：侧视 31179、俯斜 3186、近景 3180、掠射 3097。见[分析脚本](W07_主网格局部翻折_20261007/analyze_fold.py)与[结果](W07_主网格局部翻折_20261007/fold_summary.json)。

[翻折侧视图](W07_主网格局部翻折_20261007/fold35_coupled_wavefront_side.png)有明显变形，但白面仍随沿岸泡沫形成分离圆丘，缺少连续下翻厚芯。[翻折俯斜图](W07_主网格局部翻折_20261007/fold35_coupled_oblique.png)仅沿岸局部亮块改变，并暴露尖锐突起；[近景](W07_主网格局部翻折_20261007/fold35_coupled_close.png)与[掠射](W07_主网格局部翻折_20261007/fold35_coupled_grazing.png)可复核局部影响。像素差证明开关生效，不证明参考形体达标。此原型不作为正式几何路线；未做长活动成本测试。

当前泡沫前缘是局部、断续的着色场。仅依它在原网格做顶点变形，不能建立横贯浪前的连贯截面；下一步需从波相位/湿域构造可追踪的连续浪前及宽度，再决定共享边界的表示。保留[PNG、manifest、日志、源码快照和 SHA256](W07_主网格局部翻折_20261007)作失败证据。
