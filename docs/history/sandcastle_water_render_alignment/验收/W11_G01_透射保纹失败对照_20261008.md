# W11 G01 / W10 G01：加大浅水消光长度的失败对照（2026-10-08）

状态：**同态诊断与复算 PASS；候选未选型，V01/V04/WR-G0 仍 FAIL**。固定/耦合 W11 维持 0/3，正式性能迭代 0/10。

观察同一耦合完成态的[床面直出图](W11_G01_亮纹尺度_20261008/coupled240_coupled_bed_only.png)与[水面合成图](W11_G01_亮纹尺度_20261008/coupled240_coupled_caustic_scale_10.png)：床面直出已有密集弯曲亮纹，合成后显著变淡。因此在继续做 V04 分叉计数前，先隔离浅水透射是否能保住亮纹与床形。

严格 profile 禁止 `--shallow-extinction` 命令行覆盖；捕图器新增默认关闭的 `--write-extinction-sweep`，在同一 tick240 完成态临时把水面 `prototype_shallow_extinction_m` 设为 **0.25/0.30/0.35m**，每档采亮纹开/关两图，亮纹强度固定 0.4，完成后恢复水面和床面原参数。0.25m 是 staging profile 的**实际**值，已由 manifest 回读；未加载 profile 前的捕图器变量默认 0.11m 不参与本对照。固定/耦合均为连续 80 波包、D3D12 / GTX 1050、可见 1920×1080、VSync off。

[证据目录](W11_G01_透射保纹_20261008)含六档组合、三层深度掩码、床色消融、水深 F32 和 manifest。[分析器](W11_G01_透射保纹_20261008/analyze_extinction_sweep.py)复算[指标](W11_G01_透射保纹_20261008/extinction_sweep_metrics.json)，PASS。0.25m 的亮纹开/关 PNG 与此前对应候选逐字节相同；默认图也相同，水深 F32 与有效 profile SHA 未变，干岸 ROI 六档零差。

0.35m 对 0.08m 层的亮纹可见影响比基线增加约 16%，但固定床形几乎没有改善，耦合相关略低。0.25m 层各档图像指标逐数相同，因为 shader 在较深水处过渡到同一个 `phase2_extinction_m`。提高单一浅水消光长度不能同时解决底形可读与 V04 明亮分叉，因此不写入共享 profile。下一路线应检查水面散射/反射与床色合成的空间频率损失，并用同曝光的参考投影和局部可见亮线验证；不能用床面直出图代替最终水面画面。
