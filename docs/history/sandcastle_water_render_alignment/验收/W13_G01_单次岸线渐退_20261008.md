# W13 G01：重复湿域 alpha 渐退消融（2026-10-08）

结论：**淘汰**。水面 shader 先以重建湿份额衰减水深，正常光学分支又把 alpha 乘以 `smoothstep(0, 0.8, wet_fraction)`。隔离试验只去掉后者，不改变 `discard`、权威水深、波包、床面或湿域重建；tick300/600 岛脚与右岸外观几乎不变，不能修复 V06 接触。试验开关已从源码撤回，当前水面 shader SHA256 与试验前旧证据记录的 `78bad61606c376cb009a318c74368d8061d75a1d384a1c30d37eef184d602120` 一致。

严格 staging、耦合场景、80 连续波包、D3D12/GTX 1050、可见 1920×1080，tick300 与 tick600 两次捕图 exit 0/PASS。候选[近景 tick300](W13_G01_单次岸线渐退_20261008/coupled300_singlefade_coupled_close.png)、[近景 tick600](W13_G01_单次岸线渐退_20261008/coupled600_singlefade_coupled_close.png)与[旧同态图](W13_G01_湿域来源着色_20261008/coupled300_source_coupled_close.png)并排审阅。六张俯斜/近景/掠射正常图的任一通道差值均不超过 9/255，>12/255 像素均为 0；初态、完成水深 F32、白遮罩、最近湿格来源图逐字节一致。[复算脚本](W13_G01_单次岸线渐退_20261008/analyze_single_fade.py)及[指标](W13_G01_单次岸线渐退_20261008/single_fade_metrics.json)留存。白遮罩与湿格来源只约束真实覆盖；几乎无画面变化说明此 alpha 因子在这些活动完成态不是岸线尖齿主因。
