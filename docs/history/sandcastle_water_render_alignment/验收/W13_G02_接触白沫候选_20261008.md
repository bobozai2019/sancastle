# W13 G02：动态岸脚接触白沫候选失败对照

状态：[候选否决，G02 未通过]。W13 性能仍 0/10；本轮只对已有 staging 路径做同 tick 视觉候选对照，不计性能轮。

## 候选与捕图

在 `reference_water_local_front.gdshader` 加入默认关闭的 `prototype_contact_foam_candidate`。候选从当前水深、上一 tick 水深和四邻干格取动态接触，限于浅水，叠加破碎噪声；不复用主泡沫强值。`capture_reference.gd` 的 `--write-contact-foam-candidate` 在同 tick、同机位先存正常图，再短暂开启候选存配对图，自动绑定并保存上一张泡沫历史 RG32F。staging profile 保持原值。

Godot D3D12/GTX 1050、可见 1920×1080、耦合模式，连续 80 波包 tick300/600 与无波 tick600 均捕图 PASS。两档有波的正常三机位 PNG 和水深 F32 与[既有严格 staging 证据](W13_G01_湿域来源着色_20261008.md)逐字节一致。独立[复算脚本](W13_G02_接触白沫候选_20261008/analyze_contact_candidate.py)与[完整结果](W13_G02_接触白沫候选_20261008/contact_candidate_metrics.json)核验配对图、波包数、同态与无波严格档，PASS。

## 决定

保留候选开关供隔离诊断，但默认关闭，不选入 staging profile。简单的单 tick 水深上涨门槛在“无波误着白”和“有波过稀”之间无法同时满足 G02。后续应寻找能积累短时入浪接触、又能在无波时衰减的独立权威来源，和浪前主泡沫分层验证；不能把静态近干水线直接着白。W13 G02、V06、WR-G2 仍未通过；未实施性能候选，W13 保持 0/10。
