# W07 翻卷截面遮挡与浪背试验（2026-10-07）

## 假设与原型

[卷浪截面高度隔离试验](W07_卷浪截面高度隔离试验_20261007.md)表明单纯把旧截面加高只会得到陡坡。本轮在同一连接网格内尝试 11 点翻卷路径：冠部升至约 0.50m，唇缘前探后回折，下端接到按本行湿域收缩的前水面；另把浪背起点从前缘后 0.70m 延至 2.00m，分离浪背坡度与前脸。所有改动仅在默认关闭的 `--unified-overturn`、`--unified-broad-back` 中。`--unified-layer-debug` 依截面参数把上升面、冠部/前脸和回折下段标成绿/黄/紫；`--unified-overturn-cap` 把稀疏白沫限制到冠部参数段。原水沙求解与生产 shader 未改。

## 判定

此版开放折面在低角视角暴露了遮挡与着色的耦合：回折下表面无法在正确深度次序下形成可辨体量，几何加宽又把按截面参数的白沫涂抹扩大。当前两个截面和冠部限制均不选；关闭深度写入只作失败归因。下一表示需为浪背、前脸、下翻与入水点提供明确的可见面/深度契约，并让泡沫依实际物理宽度与相位分布，不能仅靠截面参数范围。仍须同时约束湿域、跨行连接、生命周期和正式活动成本。V03/V05/V06/V08、W07 G03、WR-G0 不通过。
