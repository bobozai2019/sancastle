# W07 径向岸线与浪脊深度渐退试验

日期：2026-10-07。结论：**现有径向岸线重建几乎不改变 V06 岛脚/右岸轮廓；0.08 m 薄水浪脊渐退显著削弱 V03 侧视亮芯，均不选为当前修复。** 这两项是 W07 默认关闭的显示原型；物理求解器、沙模型和生产 shader 未改。

`reference_water.gdshader` 已有 `radial_shore` 分支但捕图入口未暴露。本次给 `capture_reference.gd` 增加 `--radial-shore`、`--shoreline-debug`，在白色水面/沙床底色的 debug 图中与现有重建对照。另加 `--crest-shore-depth=0.08` 实验参数，只让显示用抬升浪脊在薄水处渐退，不修改原 foam 场或波物理；0 保持旧表现。

## 同状态对照
