# W07 异步读回后工作线程交接试验

日期：2026-10-07。结论：**淘汰工作线程交接候选。** D3D12 耦合参考场景的匹配 30 秒预热 + 60 秒活动采样中，worker 路径为 26.682 tick/s、整帧 p99 39.269 ms；原主线程 deferred 路径为 26.825 tick/s、38.179 ms。两者均未过 V08，worker 没有解决异步读回后的帧交接成本。

## 隔离实现与状态核对

仅 W07 `prototypes/reference_preview.gd` 增加默认关闭的 `prototype_worker_handoff`。两个读回回调在渲染线程齐备后，原型用 `WorkerThreadPool.add_task()` 从 worker 调用 `RenderingServer.call_on_render_thread()`，随后复用原 `_render_finish_tick` 计算；这避免在异步读回回调内直接递归提交 GPU 命令。任务 ID 在 tick 完成/退出时 `wait_for_task_completion()` 回收。成本探针用 `--worker-handoff` 选择此分支，manifest 记录实际开关；为避免旧跨线程时间线字段语义混用，此开关与 `--tick-timing` 或同步读回互斥。生产求解器、shader 和 profile 未改。[Godot RenderingServer](https://docs.godotengine.org/en/stable/classes/class_renderingserver.html#class-renderingserver-method-call-on-render-thread)允许从其它线程推送 render callable；[WorkerThreadPool 文档](https://docs.godotengine.org/en/stable/classes/class_workerthreadpool.html#class-workerthreadpool-method-add-task)要求等待任务完成以回收资源。

新增 `probe_worker_state.gd` 在两条路径都执行同一个从 tick 8 开始的合法 0.18 m/6 s 波包，精确停在 tick 90；在完成态异步回读并验证字节长度后，逐字段计算 SHA-256。D3D12 下 11 个字段的哈希全部完全相同：rock、sand、water、momentum_x/z、sediment、wetness、compaction、obstacle、flux、foam_history。revision、水源/汇累计（12.0391714940779 / 0.513112458167598 m³）与沙账本闭合值亦相同。两组状态探针 exit 0、预期 `PASS`、无 shader/script ERROR。**这是单一确定性波包在 tick 90 的状态核对，不证明任意长程、暂停/恢复或工具事件等价。**

## 同负载活动成本

耦合参考床面、oblique、combined 显示与持续合法波包；真实可见全屏 1920×1080、VSync off、D3D12/GTX 1050。两组独立预热 30 秒、采样 60 秒。均 exit 0、探针预期 `PASS`、无 shader/script ERROR；overload、NaN、无效/负水沙格均为 0。`PASS` 表示数据收集成功，manifest `meets_cost_bound=false` 为成本判定。

| 60 秒 oblique 阶段 | 原主线程 deferred | worker 交接 |
|---|---:|---:|
| 实际时长 / 帧数 | 60.018 s / 3219 | 60.003 s / 3202 |
| tick/s | **26.825** | **26.682** |
| 整帧 p99 | **38.179 ms** | **39.269 ms** |
| 已测渲染 GPU p99 | 7.095 ms | 7.102 ms |
| source_active_fraction | 1.0 | 1.0 |

5 秒短烟测曾显示 worker 27.139 对原路径 26.283 tick/s、帧 p99 41.680 对 47.305 ms；60 秒同负载结果没有维持这个方向，因此不能以短样本选择路线。预热按墙钟，长采样起始 tick 分别为 821/801，波包相位未逐 tick 对齐；`source_active_fraction` 只覆盖请求波包时窗，不是高泡沫屏幕活动占比。本试验也未覆盖 close/grazing 镜头。原型保留作失败对照，不接正式入口。
