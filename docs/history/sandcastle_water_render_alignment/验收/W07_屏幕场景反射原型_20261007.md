# W07 屏幕场景反射原型复核（2026-10-07）

结论：**12 步屏幕空间反射射线可以命中部分不透明场景，但覆盖仅限岸缘和岛周围，当前原型不通过 V02。** 开阔水面依旧使用固定天空色回退；掠射视角有狭窄、断续的环状取样痕迹。保留为默认关闭的诊断开关，不并入正式水面。

## 同态捕获

耦合参考床面、seed31/0.18m 波包、tick390/revision1492、二维局部前缘主水面 0.25m、eta 法线、折叠亮纹、屏幕折射 0.02、可见面法线/Fresnel 修正、D3D12/GTX1050、1920×1080。三组仅分别关闭反射、开启场景反射、开启反射命中灰度调试。运行使用 `--local-front-profile --screen-optics --screen-face-normal`；后两组分别追加 `--screen-scene-reflection`、`--screen-reflection-debug`。有效三组均退出 0、无 shader/script ERROR，manifest 对应 shader 路径为局部前缘水面。初次尝试曾因辅助函数不能直接使用 `PROJECTION_MATRIX` 编译失败，虽然捕图脚本仍打印 PASS；修正为由 fragment 传入矩阵后重新捕获，已删除编译失败的图像。**因此不能单独以捕图 PASS 判定 shader 有效。**

射线在视空间反射视线，最多采样 12 个深度点；投影出屏或无深度交点时回退旧天空代理色。命中计数采用调试图 RGB 三通道均 >245；水面分母采用调试图近黑或近白的像素，排除天空与裸沙。全图差异是基线与开启场景反射的任一 RGB 通道绝对差。

根据 [Godot 空间 shader 约定](https://docs.godotengine.org/en/4.6/tutorials/shaders/shader_reference/spatial_shader.html) 和 [反向 Z 深度重建说明](https://docs.godotengine.org/en/4.3/tutorials/shaders/advanced_postprocessing.html)，该路径使用视空间 `VIEW`/`VERTEX`、投影矩阵及深度重建；屏幕纹理缺少透明物体和屏幕外场景。即使增加步数，也不能从当前屏幕数据恢复这些信息。现有命中判定的 0.35m 厚度和离散步长还可能造成错位环。尚未运行 V08 成本门，因此 12 次水面深度采样也没有预算证明。

下一反射路线须先明确可覆盖岸岛与天空的场景来源，再按参考机位核对倒影位置、遮挡、浅底透射以及实际 GPU 成本；当前试验不作为 V02 或 WR-G0 放行依据。源码 SHA256：`reference_water_local_front.gdshader` `E3E07498F48CC9A90F1FA900C8A8C5C2A1CEAFA16CAE0161FBE0676F12E43ADB`，`capture_reference.gd` `CE82F342E92357A5C88CD61519CD1A295870F5D186766AA197D14E9632BF4FE6`。
