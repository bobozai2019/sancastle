# W11 G05：v7 水底亮纹柔化粗效果

日期：2026-10-09。状态：**[已完成：显式 staging 粗效果接入]**。V04/WR-G2 与完整活动成本仍未通过。用户要求保留当前海浪，本目标未改浪形、水面材质、波包或物理求解。

## 候选与选择

在既有水底亮纹贴图采样上加默认关闭的 `prototype_caustic_softness`，候选用 mip 2 的柔和亮线混合 mip 5 的大尺度亮度；结合旧试验建议的投影 `1.1×` 与强度 `0.5`。先在 v6 同完成态采固定/耦合、俯斜/近景/掠射、基线/候选/关亮纹三组图。单独柔化收益很小；组合候选减弱高对比细环，沙面纹理更易读，仍可辨水底亮纹。参考 `test35` 的柔和亮带方向吻合，但 ROI 并非同床形/精确水深，**不能据此判 V04 尺度、分叉和生命周期通过**。

将组合值写入严格 `water_render_staging_v7.json`，并在 loader 校验及 effective 回读中加入 `caustic_softness=1.0`、`caustic_strength=0.5`、`caustic_uv_scale=1.1`。固定与耦合共用 v6 的床面材质，两条直接预览 `.tscn` 固化 profile；旧 v1–v6 缺省柔化为 0。v7 profile SHA-256 以各次 manifest 为准。
