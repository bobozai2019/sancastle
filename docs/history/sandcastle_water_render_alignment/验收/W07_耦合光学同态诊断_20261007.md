# W07 耦合波包同态屏幕光学诊断（2026-10-07）

结论：**现有屏幕光学分支不能直接作为耦合水面的联合候选。** 在合法单波包 tick 390 与折叠水底亮纹同时开启时，它覆盖了原水面分支的白沫处理，使右岸浪前明显消失；深浅层次也没有达到可确认的 V02 改善。V02/V03/V04/V05、W07 G03、WR-G0 均未通过。此试验没有修改生产 shader 或正式 profile。

## 同态对照

两次运行都在耦合床面、同一初始 rock/sand/water 哈希、seed31 的 0.18m 波包、tick 390/revision 1492、`visual_time_s=13.0`、GTX1050/D3D12、可见全屏 1920×1080 下完成。均开启二维局部前缘、0.25m 浪高、真实 eta 法线、耦合床面折叠亮纹。唯一差别是水面 `prototype_screen_optics=false` 对 `true`，后者折射标量为 0.02。解析两份 manifest 时，除 run ID、图片路径及这两个预期光学字段外，没有其他字段差异。两个日志均有 `PASS` 且无 shader/script ERROR；`Image.load_from_file()` 发出导出兼容 warning，不影响这次桌面捕图，但正式导出路径仍待处理。

俯斜图中，phase2 的右岸白沫和浪前亮芯连续可见；屏幕光学图大部分被平滑青色覆盖。源代码 `reference_water_local_front.gdshader` 的 `prototype_screen_optics` 与 `phase2_optics` 是互斥的 `else if` 分支，前者没有后者的白沫混合逻辑。这给出了可检查的原因，不能把效果缺失误判成波包没有活动。水底折叠亮纹仍能在右侧薄水区看到，但水面覆盖减弱了它的对比。

选取两处**未由 GPU 水深投影核实**的俯斜水域代理 ROI，深 `[300,550,600,800)`、浅 `[1000,690,1140,860)`。8-bit RGB 均值的像素中位亮度：phase2 为 171.0/183.67，深浅比 0.931；屏幕光学为 177.0/192.0，比 0.922。它只能说明这些固定画面区域均变亮，不能作为 V02 正式判定。先前固定床面 tick120 的 0.887 也没有经深度回读证实。当前可靠视觉结论是联合效果倒退，故不再单独调折射强度来争取 V02 数值门。
