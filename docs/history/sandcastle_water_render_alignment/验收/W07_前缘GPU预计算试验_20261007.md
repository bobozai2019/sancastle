# W07 前缘 GPU 预计算试验

日期：2026-10-07。结论：**把相邻 tick 水深上升带压缩成每行一个 GPU 前缘位置/峰值，能消除显示 shader 内重复搜索的大部分短测成本，且保留有波/无波隔离。** 目前画面仍是白脊和薄唇，整帧成本仍未过门；该组件只保留为默认关闭的 W07 候选，G03/WR-G0 不通过。

## 字段与一致性

承接[权威上升带试验](W07_权威上升带与浪唇试验_20261007.md)，新增 W07 显示专用 compute：每 tick 在泡沫更新后读当前求解水深及泡沫历史纹理的上一 tick 水深，在每个 z 行扫描 x=112–247 的已湿格，输出 256×1 RG32F：R 为正上升分数平方加权的 x 格位置，G 为该行最大正上升量。主水面与浪唇共读此纹理。求解器、泡沫演化、沙模型、正式材质和 profile 均未改；`--front-field` / `--write-front-field` 默认关闭。

耦合参考床面 D3D12、1920×1080 的波包 tick 330/390 与无额外波包 tick 390 均 exit 0、PASS。原始 `water`、上一 tick 泡沫历史及前缘 RG32F 与 PNG、manifest、日志见[字段证据目录](W07_前缘GPU预计算_20261007)。用导出原始纹理在 CPU 复算完全同一公式，256 行最大位置误差分别为 0.000085/0.000072/0.000061 格，峰值误差均 <1×10⁻⁹ m，符合 GPU 浮点舍入范围；见[分析脚本](W07_前缘GPU预计算_20261007/analyze_front_field.py)与[结果 JSON](W07_前缘GPU预计算_20261007/front_field_summary.json)。

| 输入 | 逐行前缘 x 格 p10 / p50 / p90 | 逐行峰值 m p10 / p50 / p90 | 峰值 >0.0025 m 行数 |
|---|---|---|---:|
| 有波 tick 330 | 136.36 / 146.05 / 159.47 | 0.00381 / 0.00707 / 0.00919 | 252/256 |
| 有波 tick 390 | 159.99 / 168.42 / 186.13 | 0.00089 / 0.00492 / 0.00785 | 199/256 |
| 无额外波包 tick 390 | 118.85 / 138.30 / 158.14 | 0.00052 / 0.00108 / 0.00164 | 0/256 |

前缘位置在无波组仍有数值，但强度未过此负例门槛，不作为可见浪前。该门槛仅由当前床面和波包的负例支撑，不是通用检测器。两个有波相位的中位位置前进约 22.4 格；只证明两个状态的推进方向，不证明连续速度或参考录像一致。

## 画面与短成本

字段单独开启的 tick 390 四镜头与[写深度旧基线](W07_附着浪唇原型_20261007/base_coupled_wavefront_side.png)逐像素相同。接入字段的[有波俯斜图](W07_前缘GPU预计算_20261007/front_render_wave_coupled_oblique.png)、[侧视图](W07_前缘GPU预计算_20261007/front_render_wave_coupled_wavefront_side.png)仍显示连续但较平的白脊；相比逐顶点版形状有所改变，未形成参考型下翻厚芯。接入字段的[无波俯斜图](W07_前缘GPU预计算_20261007/front_render_still_coupled_oblique.png)与前版无波负例四镜头逐像素相同，没有假白线。上述成对 manifest 的 tick、revision、初态哈希、波请求、泡沫统计和镜头一致；同态像素变化见分析 JSON。

同一耦合 oblique 负载、VSync 关、真实 1080p、连续合法波包，四组各预热 2 秒、活动采样 10 秒，结果如下。源活跃比例均为 1.0，表示波请求时间窗，并非屏幕高泡沫覆盖证明；样本长度也不足正式 30+60 秒门。

| 组 | 整帧 p99 ms | GPU 渲染 p99 ms | 模拟 tick/s |
|---|---:|---:|---:|
| 写深度旧基线 | 36.847 | 7.118 | 26.798 |
| 逐顶点上升带显示 | 43.099 | 8.340 | 24.678 |
| 只计算 256×1 字段 | 38.209 | 7.046 | 26.785 |
| 字段驱动主水面 + 浪唇 | 39.645 | 7.104 | 26.486 |

小字段减轻了重复搜索的短测负担，但四组均未满足 p99≤33.3 ms、模拟≥30 tick/s；不要把短测差值当作稳定的正式成本上界。原始[逐帧 CSV、manifest 与日志](W07_上升带短成本_20261007)均保留。[最终源码快照及 SHA256](W07_前缘GPU预计算_20261007/source_sha256.txt)覆盖 compute、绑定、两个显示 shader、捕图和成本探针。
