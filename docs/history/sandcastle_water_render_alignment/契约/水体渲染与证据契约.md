# 水体渲染与证据契约

角色：contract。状态：draft；W07 G03 冻结。日期：2026-10-07。

## 1. 状态、单位与采样

| 字段/接口 | 类型与单位 | 约束 |
|---|---|---|
| rock / sand / water | 同完成态 Texture2DRD，米 | rock为高程，可负；sand/water非负沿原契约；bed=rock+sand，eta=bed+water |
| momentum_x / momentum_z | Texture2DRD，原动量单位 | 计算流速时沿原水深保护；同 generation/revision |
| wetness / compaction | Texture2DRD，[0,1] | 沿原物理湿度/压实度；渲染不修改 |
| foam_history | 现有 RG32F | R 覆盖 [0,1]；G 上次深度，米；平流、衰减只属视觉 |
| visual_time_s / tick | float 秒 / int | 固定时间可重复捕图；墙钟随机不参与确定性 |
| generation / revision | int | 只读取 GPU 已完成态；跨代和半完成态拒绝捕图 |
| normal / view / light | vec3 | 明确世界、视图或切线空间；dot 前必须同空间，真实 eta 坡度参与法线 |
| bed sampling | 可见床面为共同基准 | 厚度、接触覆盖、亮纹位置引用同一实际可见床面；计算方法不同须有误差界/补偿，陡岸剖面与ROI达标，不能只记录差异 |
| scene_color / scene_depth（若选用） | 渲染输入 | W07 冻结采样阶段、分辨率、颜色空间、深度恢复、遮挡与回退；不能把它们当权威水深 |

保持物理 256²、32 m、0.125 m/格、30 Hz、CFL 0.35。显示网格和光学开关改变前后，权威水/沙/动量等状态哈希一致；若改 foam 源项，其差异仅允许在视觉历史字段。

岩高可为负高程，非负要求不应错误套用到rock；water/sand等量沿原约束。固定/耦合参考入口共用新床面初始数据与相机；不改旧water_v1/sand_coupled_v1输入。新床面至少包含浅沙底、沟脊、连续海岸梯度、岛/陡岸与绕流接触区。

### 表现时钟与动态读取

正式实时、录像、回放与恢复共用由完成tick驱动的表现时钟；固定捕图显式锁定时间，暂停冻结细波/亮纹/泡沫纹理相位。不得让直接演示依赖引擎TIME而验收录像另用tick/30。恢复保存或可重建profile、seed、时钟偏移/相位；旧存档默认规则明确。

如需tick间显示插值，只读取同generation的前/后两个完整完成态及alpha；原求解器ping-pong中的未完成子步不能冒充上一完整tick。动态流水检查30Hz阶跃、拖影及相位跳变，是否采用插值由原型结果决定。

## 2. Profile 字段

拟新增 `water_render_v2`，由 W07 定义、W14 冻结；旧 water_profile_v1 / sand_profile_v1 不覆盖。当前没有声称以下字段已经接线。

| 字段 | 类型 | 必填与规则 |
|---|---|---|
| profile_id / schema_version | string / int | 必填；版本明确，旧基线只读 |
| phase / capability_status | enum / map | prototype、staging、release；组件为pending/implemented，最终release无P0 pending |
| target_fixture_ids | string[] | 必填；包含拟建water_render_demo_v2/water_render_coupled_v2及旧夹具兼容入口 |
| grid_size / cell_size_m / sim_hz | int / float / int | 必填；256 / 0.125 / 30 |
| render_subdivision / surface_bias_m | int / float 米 | 必填；起点沿原 2× / 0.003 m；改变须重验岸线 |
| optics | object | 消光、深浅色、反射折射模式与回退；路径在 W07 冻结 |
| normals / caustics / foam | object | 启用值、尺度单位、时间与状态依赖；不得只有开关名没有实际实现 |
| lighting / render_state | object | 光源空间、阴影、透明深度顺序、色调/曝光/抗锯齿设置 |
| fixture_capabilities | object | 独立/联合材质实际消费的效果与输入；发现缺失须报错或记录 FAIL |
| source_sha256 | map<string,string> | 正式交付时记录所有相关 shader、脚本、场景与资源 |

W07冻结完整字段schema（各object子字段、默认值、枚举、单位、范围及资源必需性）；W08实现唯一运行时loader与校验，不以写JSON或检查源码字符串代替。未知版本、缺必填/资源、越界值、P0参数无消费均FAIL。显式定义未知字段处理与旧版迁移。manifest记录requested_profile、effective_profile、各shader实际参数/资源、配置hash，直接启动/捕图/录像/性能探针全部复用同loader。

上述缺资源/无消费规则用于已实现且请求启用的能力；W08允许显式staging profile，未实现组件pending且禁用，不计P0视觉完成，尝试启用pending必须FAIL。最终release `water_render_v2` / WR-G3要求全部P0启用并实际消费，不能携带pending或用阶段通过冒充完整效果。

## 3. 波浪命令与恢复

沿用 `request_wave(request) -> {ok, code, request_id, effective_tick}`。

请求字段：domain_id（当前域）、generation（当前代）、request_id（单调唯一）、start_tick（未来固定 tick）、profile_id（small_packet/test_packet）、amplitude_m（米，profile 限内）、duration_s（秒，profile 限内）、seed（确定性整数）。响应与错误语义沿原契约，不为渲染绕开源汇或幂等检查。

如调波包，记录输入水量与新参数；如新增视觉持久字段，先确定格式、版本、旧存档默认值和重启恢复规则。保持原 foam_history、旧检查点与支持事件版本兼容。视觉随机序列用固定 seed/时间驱动。

恢复探针必须断言字段齐全、非空、字节长度正确、generation/revision匹配；超时或两边字段都缺失必须FAIL，不能默认空数组相等。活跃泡沫保存点先证明覆盖达到冻结下限；验证恢复瞬间、短程多个tick及长程末尾的状态与相位，不能仅在白沫消退后比较。

回读匹配的是其各自源实例的generation与完整revision；原/恢复实例允许不同generation及内部revision计数。双方在同逻辑tick比较字段，支持/命令事件generation正确重映射，不要求两个实例代号数值相同。

foam源项需区分水深增加与eta/床面变化：新增无入浪稳态流水+侵蚀/床面变化负例，与固定床面推进浪对照；选择补偿或接触来源须有可见因果证据。

## 4. 沙侧边界

允许：新参考场景的沙/岩初始输入、水底亮纹、必要水下颜色/法线/阴影接口、湿度读取、共享显示采样和profile接线。禁改：旧夹具沙堡输入、沙粒材质主方案、屈服/塌落、侵蚀/沉积账本。灰壁归因另记，不能通过增加水面不透明度遮住。

## 5. 证据清单

每份捕图/录像 manifest 必须包含：

| 字段 | 规则 |
|---|---|
| profile_id / schema_version / source_sha256 | 明确真实配置及源码 |
| fixture_id / seed / grid_size / cell_size_m / sim_hz | 可复现输入 |
| generation / revision / tick / visual_time_s | 完成态与显示时间 |
| camera | transform、投影、FOV/正交尺寸；记录不能与 RDC 严格匹配的部分 |
| viewport_px / lighting / render_settings | 实际尺寸、灯光、曝光、色调映射、抗锯齿、VSync |
| effect_flags / consumed_resources | 实际启用且材质消费的效果与资源 |
| wave_requests / simulation_audit | 波包与水沙账本、异常格 |
| hardware / engine / driver / frame_stats | 真实硬件、引擎、后端与采样方法 |
| rdc_reference / roi / criterion / result | 参考文件与 event/resource ID、局部区域、冻结目标及 PASS/FAIL/partial |
| artifacts / limitations | 日志、截图、录像及未知/未通过项 |

补充必填：run_id、requested/effective_profile_hash、workload_phase、active_wave/foam覆盖统计、旧证据目录执行前后hash。output/profile/run_id贯穿父包装器、子探针、分析器与基线读取；run本次产物的新鲜性须检查。

包装器必须联合验证exit code、预期PASS、新日志无SHADER/SCRIPT ERROR/ERROR/FAIL、产物时间/run_id与manifest/config/source hash。探针遇到缺数据直接FAIL；旧JSON或截图存在不能证明本次运行成功。

RDC 未能提取 shader 源码或解码常量时记录原因及可确认绑定，不伪造算法。以原图局部特征和匹配的简化床面比较，不用不同关卡整图 SSIM 宣称复刻度。

## 6. 验收标准冻结

W07按 [视觉目标与可行性门](视觉目标与可行性门.md) 填写并冻结 `验收/WR-G0_参考与标准.md`：参考/候选ROI、水色与底形、浪前轮廓、亮纹尺度、泡沫宽度、接触边缘、失败示例、镜头、测量阈值、判定人和三个原型结果。后续更改须ADR、原因和旧/新结果；主要差距不能通过放宽门限消失。

原岸线偏移≤0.5物理格、内部误盖<2%与原遮挡探针继续有效；新增视觉门不能只用覆盖正确或状态保形代替。最终性能按视觉契约的代表性负载测量，总体及活动阶段p99≤33.3ms、各阶段模拟≥30tick/s；参考耦合场景同1080p长稳30分钟。
