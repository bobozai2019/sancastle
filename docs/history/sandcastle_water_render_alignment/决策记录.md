# 水体渲染对齐决策记录

角色：execution_state。日期：2026-10-07。

## ADR-WR01：单独建立后续水体计划

- 状态：accepted。
- 决策：采用 W07–W14 编号衔接既有 W01–W06；旧 T09/T10 完成报告保留为 source / execution_record，不重写其完成状态。
- 影响：本目录实施进度从 0/24 开始，旧视觉自评分不是新 Gate 证据。

## ADR-WR02：先冻结参考，再选择实现

- 状态：accepted。
- 决策：W07 定位 RDC 绘制与资源，冻结局部目标、对照方法和技术路线。确证原作方法、Godot 适配方案与未知项分开写。
- 影响：反射、折射、粒子和后处理不提前宣称已查明，也不因当前 shader 名称而默认路线。

## ADR-WR03：最终联合场景必须独立验收

- 状态：accepted。
- 决策：独立水场景用于调试；联合场景使用同一个水体 profile 并重新验收水底、白沫、光照和遮挡。
- 影响：任何成本优化须记录效果变化，不能仅凭独立水场景的通过记录放行联合场景。

## ADR-WR04：水体表现与物理边界

- 状态：accepted。
- 决策：保持 256²/0.125 m/30 Hz 与原质量账本、命令和恢复语义；显示字段不反写水沙物理。沙侧仅水底着色和湿度接入。
- 影响：若参考浪形需要调整物理波包或新增持久字段，先补充契约、版本与对应回归，再实现；提升物理域或重做沙模型不自动进入本计划。

## ADR-WR05：参考型场景与隔离原型先行

- 状态：accepted；来源：用户授权的两名独立审核。
- 决策：新增合法床面数据的水体演示场景，同输入固定/耦合两模式；旧方塔/平岩海床夹具保留回归。W07可在独立原型目录验证浪形、光学和联合成本，不覆盖生产shader或旧profiles。
- 影响：WR-G0未同时证明效果与1080p成本时不能进入正式实现；新增床面属于水体验收输入，不扩展沙材料模型。

## ADR-WR06：完成状态由逐项效果和真实消费证据约束

- 状态：accepted。
- 决策：冻结视觉目标板与失败样例；WR-G0/WR-G3由非实现者复核；P0未达标或目标unknown/partial不得全通过。共享profile/time由运行入口、录像和探针实际消费，GPU回读/产物缺失必须FAIL。
- 影响：增加持续活动负载及活跃泡沫恢复，整体p99、退出码和旧文件存在不能独立判成功。新包装器参数须传递到所有子探针，旧证据只读。

## ADR-WR07：阶段能力和跨实例恢复语义

- 状态：accepted；来源：两名审核者的review-r2复核意见。
- 决策：staging profile允许pending/禁用组件但不计视觉完成，已实现/请求启用项严格验证；最终release全部P0开启并达标。恢复回读校验各自实例的完整态，在同逻辑tick比较，generation允许正确换代。
- 影响：消除W08等待W11/W12的循环和错误要求原/恢复代号一致的歧义；最终质量门不降低。

## ADR-WR08：不采用单纯泡沫横向扩张作为浪前路线

- 状态：rejected candidate；证据：[W07 宽浪前试验](验收/W07_宽浪前试验_20261007.md)。
- 判断：固定/耦合床面同 tick 证实肩部采样和提高显示浪脊可增加亮面积/高度，但侧视未形成厚亮芯，岸线锯齿仍在。增加纹理采样无法单独满足 V03/V05/V06，且已有耦合活动成本超标。
- 影响：保留可关闭原型开关作失败对照，不接入生产 shader 或正式 profile；后续路线须同时验证三维浪前、泡沫生命周期、岸线接触与 1080p 成本。

## ADR-WR09：胞界亮纹淘汰，曲率折叠图暂留候选

- 状态：partial candidate；证据：[W07 亮纹形状试验](验收/W07_非周期亮纹试验_20261007.md)。
- 判断：胞界纹理虽增加分叉却形成明显蜂窝伪影；连续曲率生成的折叠线消除此特征，固定/耦合同状态开关均有效，岛内局部无泄漏、深水衰减。参考投影尺度、动态、全域干岸及成本尚未验证。
- 影响：仅保留可关闭原型和生成器作后续对照，不接生产 shader/profile，不提前宣布 V04 或 WR-G0 通过。

## ADR-WR10：淘汰边界/CFL 同步读回路线

- 状态：rejected candidate；证据：[W07 同步读回试验](验收/W07_同步读回试验_20261007.md)。
- 判断：同耦合负载短 A/B 中，两个小字段改用渲染线程同步 `texture_get_data`，请求提交中位数从 0.037 增至 25.990 ms，整帧 p99 从 37.226 增至 51.165 ms，tick/s 也下降；没有改善 V08 成本。
- 影响：保留默认关闭的隔离原型开关作失败对照；不接生产求解器或正式 profile。下一路线先细分异步回调到主线程执行的等待，并核对完整状态与长期成本。

## ADR-WR11：不以切换 Vulkan 单独解决活动成本

- 状态：rejected candidate；证据：[W07 后端对照](验收/W07_渲染后端对照_20261007.md)。
- 判断：同耦合 oblique 候选各预热 30 秒、采样 60 秒，Vulkan tick/s 从 D3D12 的 26.877 提高到 29.232，但整帧 p99 从 38.039 增至 41.059 ms；两者都未同时满足 V08 的 30 tick/s 和 33.3 ms。
- 影响：保留原 D3D12 基线；后端切换不能作为当前路线冻结依据。后续性能优化仍须完整视觉与三镜头活动成本验证。

## ADR-WR12：淘汰读回后 worker 交接路线

- 状态：rejected candidate；证据：[W07 worker 交接试验](验收/W07_工作线程交接试验_20261007.md)。
- 判断：原型从 worker 向渲染线程排队后续 GPU pass，tick 90 的 11 个字段与源汇/账本匹配；但匹配 60 秒活动采样反而从 26.825 降至 26.682 tick/s，整帧 p99 从 38.179 增至 39.269 ms。
- 影响：默认关闭原型，只留可复现对照；不接生产路径。下一路线须处理读回引起的队列同步依赖，而非仅改变线程交接调用点。

## ADR-WR13：不以降低 FPS 上限解决活动成本

- 状态：rejected candidate；证据：[W07 帧节奏短诊断](验收/W07_帧节奏试验_20261007.md)。
- 判断：三组同负载短样本均约两帧完成一模拟 tick；40 FPS 上限把模拟率从不设上限的 27.521 降至 20.041 tick/s，帧 p99 从 37.073 增至 41.168 ms。60 FPS 上限未提高实际渲染率。
- 影响：生产帧率配置不改；后续路线需提高实际帧处理吞吐或解除异步边界/CFL 的跨帧依赖，并重新证明视觉与正式活动成本。

## ADR-WR14：抬升面着白暂留，单层顶点前移淘汰

- 状态：partial candidate；证据：[W07 浪前着白/前移试验](验收/W07_卷浪面试验_20261007.md)。
- 判断：固定/耦合同 tick 着白使抬升浪面的侧视亮芯出现，但仍为斜坡和沿岸宽白带；0.12m 前移仅轻微移动轮廓，不能生成连续卷唇或立体厚度，且 V06 接触锯齿未改善。
- 影响：只保留默认关闭的亮面着色供后续表示方案比较；前移只作失败对照。不接生产 shader/profile，不宣告 V03/V05 或 WR-G0 通过。

## ADR-WR15：淘汰逐格竖立的浪前帘面

- 状态：rejected candidate；证据：[W07 浪前帘面试验](验收/W07_浪前帘面试验_20261007.md)。

- 影响：默认关闭，仅保留隔离原型作失败对照；不接生产 shader/profile，不计 V03/V05/V06 或 WR-G0 通过。下一候选先证明两个镜头中的连续曲率、碎裂和接触，再测正式活动成本。

## ADR-WR16：连续卷唇网格只留作局部形态候选

## ADR-WR17：共床高插值、湿域中点裁剪及加密网格不选作岸线修复

- 状态：rejected candidates；证据：[W07 共床高接触试验](验收/W07_共床高接触试验_20261007.md)。
- 判断：同 tick 耦合近景在切换床高插值或叠加中点裁剪后只改动少量像素；2→4 倍网格细分也未明显改善岛脚/远岸锯齿。现有证据不支持这些简单显示开关是 V06 主修复。
- 影响：所有开关默认关闭，不接生产 shader/profile。下一路线需直接定位湿域边界与可见床面相交误差，并验证 720p 近景缝宽和干岸误盖。

## ADR-WR18：不以缩小启动帧队列解决异步读回成本

- 状态：rejected candidate；证据：[W07 帧队列试验](验收/W07_帧队列试验_20261007.md)。
- 判断：两个仅帧队列设置为 2/1 的隔离副本在 tick 90 的 11 字段与账本相同；匹配 30+60 秒 oblique 活动样本的回调等待均约 26.18 ms，tick/s 26.381/26.488、整帧 p99 39.653/39.486 ms，均未过 V08。
- 影响：原 `project.godot` 保持默认设置。后续优化应处理回读跨帧依赖本身，并单独验证数值、账本、恢复和三镜头活动成本。

## ADR-WR19：保留 GPU 原始源汇增量批量采集作成本路线组件

- 状态：partial candidate；证据：[W07 GPU 账本批量采集试验](验收/W07_GPU账本批量采集试验_20261007.md)。
- 判断：tick 90/270 的 ring 一次读回与原逐 tick 账本源汇完全相等；tick 270 的每个 tick 源汇误差均为 0，11 个完整字段及沙闭合值与无 ring 对照相同。当前两条逐 tick 回读仍在，短成本没有通过 V08。
- 影响：只留默认关闭的 W07 诊断组件。若尝试正式减少回读，必须先解决滚动批次、检查点/退出结算和 CFL 决策，并以完整状态、恢复和 1080p 活动成本验证。

## ADR-WR20：双缓冲滚动账本仅作为已验证组件

- 状态：partial candidate；证据：[W07 GPU 账本双缓冲试验](验收/W07_GPU账本双缓冲试验_20261007.md)。
- 判断：两个 30 tick GPU buffer 在 95 tick 尾批冲刷与 270 tick 九批轮转中，逐 tick 源汇误差均为零；270 tick 全状态、revision 和账本与既有基线相同。现有求解器的账本/CFL 逐 tick 回读仍在。
- 影响：只留默认关闭的 W07 旁路原型。正式减少回读前，须解决批次入账与检查点/退出结算、CFL 决策，再做状态/恢复/三镜头活动成本验证。WR-G0 不通过。

## ADR-WR21：移除单条账本回读仍不能解除 tick 跨帧等待

- 状态：partial candidate；证据：[W07 去逐 tick 账本回读试验](验收/W07_去逐Tick账本回读试验_20261007.md)。
- 判断：W07 专用路径不再调用逐 tick 潮汐账本读回，批次入账的 tick 270 全状态及源汇、tick 95 自动检查点均与基线一致。但同负载短 A/B 仅约 27 tick/s、整帧 p99 38–40 ms；仍需等待逐 tick CFL 读回。
- 影响：保留隔离原型，不接生产入口；下步须验证 CFL 决策的替代方式与全数值/恢复契约，再重测正式活动成本。WR-G0 不通过。

## ADR-WR22：固定 3 子步只作去等待诊断，不冻结物理路线

- 状态：rejected as production route；证据：[W07 固定子步无等待试验](验收/W07_固定子步无等待试验_20261007.md)。
- 判断：在持续波包负载，2702 tick 的异步 CFL 旁路审计最大需求为 3、无越界；固定 3 的 tick 270 水深平均差约 0.000079 m，水体积差与净边界源汇差相合。30+60 秒 oblique 活动审计/无审计 p99 36.758/36.418 ms，仍超 33.3 ms；固定子步对未测负载没有事前 CFL 安全保证。
- 影响：仅保留默认关闭的 W07 成本诊断。正式方案仍需无逐 tick CPU 等待且保证自适应安全的数值调度，随后重做状态、恢复、三镜头活动与视觉验收。WR-G0 不通过。

## ADR-WR23：径向岸线与薄水浪脊渐退均不选

- 状态：rejected candidates；证据：[W07 径向岸线与浪脊渐退试验](验收/W07_径向岸线与浪脊渐退试验_20261007.md)。
- 判断：tick 360 同状态径向重建的 close 岛脚 ROI 仅 127/100000 像素明显变化，右岸锯齿保留；0.08 m 浪脊渐退把侧视亮芯 5167 降为 617 像素，同时俯斜沿岸白带仍在。
- 影响：两项默认关闭，不接生产入口。后续须显式构建贴合可见床面的水/沙交线和有独立体量的浪前，再验证三镜头和活动成本。WR-G0 不通过。

## ADR-WR24：独立卷唇覆盖网格不能代替主浪面体量

- 状态：rejected candidate；证据：[W07 卷唇独立表示试验](验收/W07_卷唇独立表示试验_20261007.md)。
- 判断：关闭主水面抬升后竖条消失，说明原竖条来自主浪面采样；独立薄片加宽至约 0.85 m 并提高底部不透明度后，在侧视呈悬空浅色枕片，俯斜仅局部变化、沿岸白带与接触问题保留。
- 影响：`prototype_full_body` 与卷唇网格均默认关闭，仅留 W07 失败对照。下一路线需要共享浪前边界的连续主水面几何，不能靠覆盖薄片继续加宽/调色。WR-G0 不通过。

## ADR-WR25：浪脊 foam 跨向平滑不足以消除竖条

- 状态：rejected candidate；证据：[W07 主水面跨向平滑试验](验收/W07_主水面跨向平滑试验_20261007.md)。
- 判断：固定/耦合床面 tick 360 同态图中，沿 z 方向扩散 1–2 个单元的浪脊 foam 几何覆盖后，侧视竖条仍在；俯斜 ROI 明显变化仅 47/143 像素。
- 影响：`prototype_crest_span_smoothing` 默认关闭，仅留诊断。下一步隔离局部水深门槛与网格连接的影响。V03/V05/V06/V08、WR-G0 不通过。

## ADR-WR26：局部水深渐变不是侧视竖条主因

- 状态：diagnostic result；证据：[W07 浪脊水深门槛试验](验收/W07_浪脊水深门槛试验_20261007.md)。
- 判断：旁路几何浪脊 0.012–0.08 m 水深渐变后，同态侧视 ROI 明显变化仅 34/119000 像素，竖条未变。
- 影响：`prototype_crest_depth_gate_bypass` 默认关闭，不作为修复；下步隔离网格插值与深度遮挡。WR-G0 不通过。

## ADR-WR27：浪脊竖条主要显现在颜色路径，片元泡沫着白不足以修复

- 状态：diagnostic result / rejected candidate；证据：[W07 浪脊遮挡与着色隔离试验](验收/W07_浪脊遮挡与着色隔离试验_20261007.md)。
- 判断：固定纯色不透明时主水面连续；纯色保留原 alpha 无强竖条，原色固定 alpha=1 仍有白条；关闭 eta 法线仍有白条。逐片元 foam 着白把耦合/固定侧视局部亮白像素 1301/2577 降至 475/810，但条纹仍在。
- 影响：所有隔离开关默认关闭，片元泡沫替换不选。后续须定位前后表面 UV、foam/着白及深度次序，再设计连续浪前。V03/V05/V06/V08、WR-G0 不通过。

## ADR-WR28：透明主水面写深度能消除侧视竖条，但不能单独过浪前门

- 状态：promising diagnostic, not accepted route；证据：[W07 水面深度写入试验](验收/W07_水面深度写入试验_20261007.md)。
- 判断：固定/耦合床面 tick 360 侧视亮白横向跳变分别由 537→43、356→68；`depth_prepass_alpha` 耦合侧视与基线逐像素相同。写深度后的俯斜画面几乎不变，侧视白面更连续但仍是圆丘，不满足 V03/V05。
- 影响：深度写入只保留 W07 原型和遮挡归因，默认 `depth_draw_never` 不变。需进一步验证多时刻、浅水透视、透明叠加与成本，并重做浪前几何/白沫表示。WR-G0 不通过。

## ADR-WR29：深度写入多相位复现，主水面前移上限仍无卷唇

## ADR-WR91：单条浅底沟脊与透射加长不能满足 V01

- 状态：verified diagnostic rejection；证据：[浅底形体归因](验收/W07_浅底形体归因_20261007.md)。

## ADR-WR92：浅底直出也缺底形，全局增亮不足以替代结构化输入

- 状态：verified input/optics attribution; structured candidate default off；证据：[床面消费与结构化浅底试验](验收/W07_床面消费与结构化浅底试验_20261007.md)。
