# T10 沙体保形与受损松散

负责人：主执行者。状态：[未开始]。进度：0%。依赖：T09。T12 可在接口冻结后独立推进。

## 目标

先修沙体“站不住/成型后变矮坡”的结构性差距，让压实模具沙保持陡侧面，在支撑被破坏后才松散并转为守恒塌坡。

| ID | 小目标 | 状态 | 交付物/证据 |
|---|---|---|---|
| G01 | 最小黏聚/屈服模型 A/B 与参数冻结 | [未开始] | 松散/压实、干/适湿/饱和湿对照 |
| G02 | 去支持触发松散与守恒塌落 | [未开始] | 高度/体积/支持曲线及录像 |
| G03 | 碰撞、工具、重放与 GPU 主链整合 | [未开始] | 回归日志、显示/碰撞差异 |

## 输入与实施

`gpu_material_coupler.gd`、`slope_relax.glsl`、`structure_state.gd`、`structure_field.gd`、T09 夹具和效果契约。

1. 记录现模型塔顶高度与轮廓随 tick 的变化，区分低初始体量和实际塌坡。
2. 对照现休止角模型和最小材料屈服扩展：允许压实沙具备有界陡坡保持能力，材料阈值考虑格尺寸/子步；松散沙仍进入原守恒松弛。湿度曲线先列假设，特别检查饱和湿是否需要减弱保形，不能直接宣称原作物理规律。
3. 结构支持丢失改变材料稳定状态；边通量两侧计算一致。若使用新权威字段，先改版本化数据/检查点契约，再实施，禁止只做 GPU 字段。
4. 处理当前支持判定读取滞后 CPU 影子床面的边界：只采局部支持摘要/必要脏区，记录 revision 和延迟，避免每 tick 全图阻塞回读。
5. 工具堆/挖/拍实及支持事件都保持账户、脏块、碰撞、重放链路；不附加一座静态装饰沙塔来替代模拟。

## 修改边界

允许：材料 pass/coupler、构件支持/松散路径、必要 CPU 参考和版本化数据边界、专用探针。公共 `gpu_water_preview.gd` 串行接线。禁止：水内核、水量阈值、原三场景输入、仅显示放大高度、全局体素重构。

## 验收

压实塔和等体积松沙对照达到冻结保形门；60 秒高度保留 ≥90%、轮廓 IoU ≥0.85。完整支持不自行坍塌；去支持后 30 秒内出现局部松散/塌落，两次相同输入事件一致。无负沙/NaN，沙账本误差 ≤1%；对子步减半有差异解释。工具与碰撞的原阈值不放宽。
