# T11 沙材质与表面重建

负责人：主执行者。状态：[未开始]。进度：0%。依赖：T10；公共显示接口冻结后可与 T13 独立推进。

## 目标

沙子形成有照明和细颗粒的实体表面：消减近景格子锯齿，保留塔顶、沟渠和陡坡轮廓，并表现干湿/压实区别。

## 实施

- `gpu_terrain.gdshader` 的正常画面从无光照手工明暗改为一致光照响应，使用来自权威床高的法线；保留原调试配色语义。
- 对照连续重建与显示细分，避免把高沙体削平、填掉沟渠。陡坡处允许专门边界规则；显示高度和拾取/碰撞误差必须量化。
- 用世界空间米尺度细噪声/法线表达砂粒和轻微粗糙度，不用 UV 固定频率造成缩放后颗粒变大。远景降噪，避免镜头移动闪烁。
- 按 wetness 控制颜色、粗糙度、有限湿亮，按 compaction 表达紧实程度；退潮暗带连续干燥。处理水底重复吸收的责任边界。
- 太阳光、阴影、基础环境填光只为读沙体，不扩充关卡美术。

## 修改边界

允许：沙材质、共享重建辅助、profile、基础光照与显示 mesh 路径、专用捕图探针。禁止：改沙量/材料物理来迁就 shader、改变水内核、增加布景资产。

## 验收与验证

三镜头均能读出高沙体陡侧面、塔顶缺口、沟槽；同镜头相对基线格子感减少，达到冻结轮廓/拾取误差门。干→湿→退潮→干燥阶段可区分，颗粒不闪烁。显示开关/时间变化前后沙水纹理哈希和账户一致。
