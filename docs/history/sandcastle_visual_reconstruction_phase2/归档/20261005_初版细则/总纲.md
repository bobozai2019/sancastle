# [未开始] Sandcastle 第二阶段：沙子与水效果优化

日期：2026-10-05。文档角色：execution_plan。当前只完成调查和计划，未实施效果改造。

## 1. 项目目标

把现有水沙数值原型推进到接近 RDC 中可观察的沙子和水：沙子能形成有体积、能保持的陡坡和沙塔，近景有细颗粒和连续干湿变化；水呈清澈青绿色，浅水能读出沙底，岸线连续，波浪有推进的前沿、白沫及退潮湿痕，并能冲刷沙体。

用户最新范围：**主要优化沙子和水，其他内容暂缓。**本阶段不建设完整原作沙盘，不做植被、道具、任务 UI、漂浮物或任意体素雕刻。基础光照、固定相机和少量沙堆/沟渠只作为水沙效果的测试条件。

建议执行顺序：**可比基线 → 沙体保形 → 沙材质 → 水体光学 → 波浪与白沫 → 耦合演示 → 回归性能**。两个首要问题是形态与水体层次，单纯调色不足以覆盖。

## 7. Gate 门禁

### SW-G0：可比较的基线（T09）

- [ ] 近景、斜俯、低角三镜头；干沙/湿沙/浅深水/波浪/高沙体均有当前基线。
- [ ] 当前默认功能开关和效果入口有运行证据；效果入口开启侵蚀、材料、构件。
- [ ] 视觉评分、几何探针、冻结 tick、显示时间、wave profile 定义完整。
- [ ] RDC 观察与算法假设分开记录。

### SW-G1：沙体轮廓与质感（T10/T11）

- [ ] 松散沙会塌坡；压实模具沙在支持完整时保持陡侧面与塔顶轮廓，达到契约中的 60 秒保形标准。
- [ ] 去掉支持后松散、坍塌、体积重分配可见且守恒；不靠固定装饰 mesh 遮挡物理变化。
- [ ] 平滑与颗粒不让沟渠、塔顶缺口、干湿分界消失；真实阴影和法线反映沙高。

### SW-G2：水体与浪前（T12/T13）

- [ ] 浅水下沙底连续可见，深水仍有青绿色层次、亮纹和反射。
- [ ] 岸线阶梯相对基线显著减少，无越岸、浮水、干地泛蓝或低角漏盖。
- [ ] 波包能推进和绕沙体改变局部流动；白沫跟随产生、迁移、消退，静水不画永久白圈。
- [ ] 退潮后湿痕连续；表现细波不改变水量和沙账本。

### SW-G3：水沙共同作用与收口（T14/T15）

- [ ] 60–90 秒无剪辑：堆/挖 → 涨浪 → 绕流/冲刷 → 退潮湿痕 → 支持损失后塌落。
- [ ] 固定视角评分沙子和水各 ≥8/10，所有 P0 维度有截图/录像佐证；评分细则在 T09 冻结。
- [ ] 原数值阈值、命令账户和存档继续有效；必要的物理扩展有新增对照。
- [ ] 1080p 可见窗口长测 p99 ≤33.3 ms、模拟 ≥30 tick/s；三原场景各 30 分钟稳定。
- [ ] SCN-03 历史 8.6 MB 单次阶跃随长测观察；无法解释时如实保留未通过项，不标最终全通过。
