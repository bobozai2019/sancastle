# [已完成] Sandcastle 第二阶段：先水体，后沙子

日期：2026-10-06。角色：execution_plan。实现进度以 [执行状态](执行状态.md) 为准。

## 1. 项目目标

按用户明确顺序，拆成**两个大任务**：T09 水体效果优化 → T10 沙子效果优化。先让水的透底、岸线、波浪和白沫达到可验收效果，再处理沙体保形、表面质感、冲刷与塌落。每一步有独立交付和检查，不把两个方向混在一次改造中。

其他内容继续暂缓：植被、装饰石头、道具、UI、漂浮物、完整关卡美术。基础光照、相机和少量测试地形只为水沙验收服务。

## 4. 运行模式

| 模式 | 沙状态与开关 | 用途 |
|---|---|---|
| water_only_fixture | 固定 bed；关闭侵蚀、沙坡松弛、结构破坏 | T09 独立迭代水体，不等待新沙模型 |
| frozen_visual | GPU 完成态、固定 tick/visual_time；表现开关可切换 | 同输入画面对比和显示不改质量验证 |
| sand_effect_fixture | 复用 T09 水体 profile；启用版本化沙材料与支持状态 | T10 保形/材质与水沙相互作用 |
| numerical_reference | 保留原 64² 参考和三标准场景输入 | 正确性回归 |
| release_effect | 256² / 32 m / 30 Hz、可见全屏 1080p、VSync off | 各任务完成时验证本阶段配置性能 |

水阶段可以使用固定起伏、沟槽和高地作为测试床面；这些是夹具输入，不是提前开发沙保形。原标准场景形状、种子、哈希不变。
