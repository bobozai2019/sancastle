## 干湿过程与三镜头

真实 GPU 材料时间线见 [S01 GPU A/B](S01_sand_shape_gpu_ab.json) 的 `wetness_timeline`：干态湿度 0.05，2 秒浅水润湿到 1.0；撤水后第 5/10/15 秒分别为 0.767/0.336/0.05。压实度保持约 0.950，沙量闭合，过程不是仅替换颜色贴图。

用于材质阅片的四阶段截图在初始化时以该时间线的湿度值作**测试夹具输入**，各自运行 30 tick；它们是独立固定输入截图，不冒充同一连续录像。GPU 回读的压实塔平均湿度为干 0.050、湿 0.810、退水 0.606、干燥 0.050。每阶段均有[斜俯](S04_stage_wet_oblique_t30.png)、[近景](S04_stage_wet_close_t30.png)、[掠射](S04_stage_wet_grazing_t30.png)镜头；其余图按 `S04_stage_{dry,retreat,dried}_{oblique,close,grazing}_t30.png` 命名。近景干/湿、干/退水、干/再干的图像平均绝对 RGB 差值分别为 10.320、3.180、0。轮廓随湿度改变属于材料屈服规则的物理结果，不将图像差值全算作着色贡献。

12 份 JSON 中同阶段三个镜头 GPU 沙哈希一致。最大显示采样/碰撞误差 0.00019 m、无漏射，低于 0.02 m 门。压实塔和松沙对照仍保留陡侧、缺口与坡面；近景可见颗粒，远景噪声被导数淡出。固定视角截图不能独立证明运动时完全无闪烁，S05 连续演示继续检查。
