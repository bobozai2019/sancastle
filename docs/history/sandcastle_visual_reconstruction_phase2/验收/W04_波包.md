# W04 波包推进与绕流：通过

日期：2026-10-06。夹具 `water_v1`，固定床面 256²、格宽 0.125 m，模拟步长 1/30 s；侵蚀、材料演化和结构均关闭。W04 的波包进入 GPU 浅水状态后，按原保守通量推进。下一步 W05。

## 接口与状态

`request_wave` 接受 `domain_id`、`generation`、单调 `request_id`、未来 `start_tick`、`profile_id`、`amplitude_m`、`duration_s`、`seed`，返回 `{ok, code, request_id, effective_tick}`。`small_packet` 的振幅上限 0.06 m、时长 0.5–3 s；`test_packet` 为 0.20 m、0.5–6 s。相同 ID 重发返回 `duplicate_request`，不再次注水；旧代返回 `inactive_generation`。非法 profile 和旧 tick 分别返回 `invalid_profile`、`past_tick`。有限 sin² 包络结束后边界回到原潮位，重叠波包总高限制 0.25 m 并记录 `wave_clamp_events`。

开放海边 x=0 同时施加水位和入域法向动量 `amplitude * sqrt(g * background_depth)`；边界水量变化进入原 source/sink 账本。检查点包含波命令历史和最高 ID；载入时换成新 generation。撤销/重做以活动场景完整波命令历史重放，不受工具命令检查点选择影响。旧 v1 存档中没有波字段时默认为空，格式号不变；新增字段严格校验。未来 tick 的波命令在 tick 20 保存并重启后续跑至 tick 60，GPU 水数组逐字节一致，源汇账本一致。

## 物理探针

运行命令：

```powershell
pwsh -NoProfile -File tests/visual_phase2/run_wave_packet.ps1
pwsh -NoProfile -File tests/visual_phase2/run_wave_checkpoint.ps1
pwsh -NoProfile -File tests/visual_phase2/run_wave_arrival.ps1
```

三项均输出 PASS。短程 tick 60 对照中，`test_packet` 的内部最大增深 0.0570 m、最大 x 动量增量 0.1096 m²/s，2882 个内部格增深超过 0.005 m；`small_packet` 最大增深 0.0289 m。测试档 source 4.65065 m³、sink 0.02000 m³，体积闭合比例 1.13×10⁻⁸；两档最大 CFL 子步数均为 2，负水/非有限格为 0，限幅事件 0。原始数值见 [短程 JSON](W04_wave_probe.json)。

长程使用振幅 0.18 m、时长 6 s 的 `test_packet`，与同 tick 无波状态对照。5×5 格均值在 x=48、88、120、高地两侧 x=140 及背后 x=160 取样，tick 120/240/360/480/600/720 到达序列为近端 120、中段 240、高地前和两侧 360、背后 480；固定高地中心全部保持干燥。两侧 tick 360 增深分别 0.1047/0.1070 m，x 动量增量分别 0.1897/0.1963 m²/s；背后 tick 480 增深 0.0311 m。长程 source 44.2972 m³、sink 18.8203 m³，闭合比例 5.98×10⁻⁹，最大子步数 3，负水/非有限格 0。完整前后深度和局部动量曲线见 [到达 JSON](W04_wave_arrival.json)。曲线是离散时间样本，首到达 tick 仅代表这些取样点。
