# S05 冲刷沉积与局部塌落：通过

日期：2026-10-06。新增 `sand_coupled_v1` 耦合夹具：两座原尺寸沙塔、海侧低矮松散支撑趾部、潮水和 T09 冻结的 `test_packet` 波包。岩面改为 −0.12 m 以让水接触趾部；水体、悬沙、湿度、压实和沙高仍由原 GPU 链更新。原 `sand_v1` 保形夹具不改输入。

## 波浪路径、支撑与堆积

[有波 GPU 探针](S05_coupled_toe_probe.json)和[无波对照](S05_coupled_toe_probe_no_wave.json)保持同夹具、同初值和同 tick。初始趾部 0.1434375 m³；有波第 240 tick 趾部损失 0.015595 m³，超过冻结 0.015 m³ 门；无波到第 900 tick 仍未越门。检测来自完成态 GPU 沙纹理及 revision 903，下一完成态以 revision 904 将塔海侧 102 格压实度降到 0.1，事件记录 generation、sensor revision、应用 revision、趾部沙量和影响格数。事件不直接删沙，后续保守坡面交换形成局部塌坡。第 150→300 tick，塔原占地沙量减少 0.9360 m³，趾部和外侧堆积；无波塔到第 300 tick 仍保留 7.9858 m³。悬沙第 900 tick 有波 0.05063 m³、无波 0.02495 m³，与水流路径及冲刷强度差一致。

[定量分析](S05_coupled_analysis.json)通过：四个 GPU 采样点床沙加悬沙最大闭合误差 7.76×10⁻⁸，水量减初始量与累计源汇后的最大相对闭合误差 1.53×10⁻⁷，无负沙或负水；海侧格心碰撞最大误差 0.000261 m。采样的碰撞回读加形状替换最大 59.48 ms，低于 100 ms 门。该值是四个完成态样本的最大值，不声称覆盖每一次中间批次。
