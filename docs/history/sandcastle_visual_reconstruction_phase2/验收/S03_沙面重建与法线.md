# S03 沙体表面重建与法线：通过

日期：2026-10-06。`sand_v1` 使用独立受光沙面 shader，从同 revision 的 GPU 岩/沙高度纹理重建 2× 显示网格和坡面法线；模拟仍是 256²、0.125 m/格。斜俯、近景、掠射镜头均有 1×/2× 同 tick 300 对照，压实塔陡侧、顶角缺口和中央沟槽保持可见。2× 边缘较连续，物理格尺度造成的陡壁折角仍存在；颗粒/干湿细节留在 S04。

初版复用 W03 水体的平滑双线性床面采样，陡角半格处显示/碰撞高度最大差 0.418 m，未过原候选 0.02 m 门。沙面改用与高度场碰撞相同的低 x/高 z 至高 x/低 z 三角划分，两片平面线性插值；`SandcastleSandDisplaySampler.sample_bed/sample_world` 是 CPU 拾取镜像，shader 仅负责显示。水体 W03 的平滑采样保持不变。

最终 [近景 1×](S03_close_1x_t300.png) / [2×](S03_close_2x_t300.png)、[掠射 1×](S03_grazing_1x_t300.png) / [2×](S03_grazing_2x_t300.png)、[斜俯 1×](S03_oblique_1x_t300.png) / [2×](S02_sand_fixture_t300.png)。同工况的 [近景数值](S03_close_2x_t300.json) 包含 722 条中心/半格碰撞射线，无漏射；与 CPU 显示采样的最大高度差分别 0.000691/0.000345 m，半格 p95 0.000333 m，均低于 0.02 m。1×/2× 六份清单中的 GPU 修订和压实/松沙形态数值一致。命令 `pwsh -NoProfile -File tests/visual_phase2/run_sand_fixture_capture.ps1 -Camera close -Subdivision 2`（其余镜头/网格仅改参数）均通过。

沙场景增加定向光阴影和高度导数法线，调试视图保持高度/湿度/压实度色图入口。原 W03 水体床面采样 224 个格心检查、W04 波包回归通过。沙面材质当前是基础受光色；沙粒、粗糙度和湿痕不作为本步完成依据。
