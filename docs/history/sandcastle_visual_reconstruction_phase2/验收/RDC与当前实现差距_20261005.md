# RDC 与当前水沙效果差距

日期：2026-10-05。文档角色：verification_evidence。范围：只调查和计划，无效果实现变更。

编号说明：本文 T09–T15 建议为初版调查时的任务编号，保留作历史证据。现行执行已改为 [T09 水体 → T10 沙子](../总纲.md)，步骤见两份现行细则。

## 结论

现实现已具备守恒水沙、侵蚀、湿度/压实、支持破坏的基础，但与参考相比主要缺少两层：**沙子的高体积陡坡保形与表面质感；水的透底层次、连续岸线和动态浪前。**应先修形态与重建/光学，再加细颗粒、亮纹和白沫，随后验证水沙相互作用。

用户要求其他内容暂缓；原作的植被、石头、桶、玩具和 UI 只用于识别水沙可观察表现，不列为本阶段交付。

## 当前代码支持的差距与优先级

| 差距 | 源码/现有画面证据 | 影响 | 下一任务 |
|---|---|---|---|
| 沙塔初始就过矮，轮廓不似原作 | `standard_scenarios.gd` 的“塔”仅抬高 0.35 m，直径约 4.8 m（256²、32 m）；旧主入口图几乎像平面圆印 | 靠调色无法获得高沙体 | T09/T10 |
| 陡沙体会被休止角松弛推平 | `gpu_material_coupler.gd`：干沙 tan=0.674、湿沙 tan=1.0、压实增益 0.3、relax=15/s；`structure_state.gd` 明确因竖墙被推平改为收分棱锥 | 模具保形和水后破坏缺少区别 | T10 |
| 当前沙表面像平色面片 | `gpu_terrain.gdshader` 为 unshaded；有限坡度明暗，无砂粒法线/真正受光投影；T07 近景可见岸边三角阶梯 | 体积、粗糙度、干湿质感弱 | T11 |
| 水主要是颜色/透明度混合 | `gpu_water.gdshader` 为 unshaded、depth_draw_never；当前截图为平蓝；0.09 m 吸收尺度且地形也染水色 | 浅水不够清澈，水底层次和光照不足 | T12 |
| 岸线和薄水膜是格子形 | 沙/水 filter_nearest，显示 mesh 与 256² 物理网格相同，格宽 0.125 m；旧 T07 承认掠射阶梯 | 近景明显降低效果 | T11/T12 |
| 白沫没有生命周期，细波只是调亮暗 | 水 shader 是 speed × thin 的瞬时混白；ripple 为 UV 正弦乘颜色，无平流泡沫字段/反射法线 | 白沫和浪前不成连续运动 | T13 |
| 原默认运行未开启完整耦合 | `sandcastle_main.gd` 的 enable_gpu_erosion/enable_structures 默认 false；`scenes/main.tscn` 无覆盖；捕图脚本显式 true | 正常启动与完整验收演示不是同档 | T09（源码确认，运行待验证） |
| 支持驱动与 GPU 沙形存在滞后边界 | 旧 T08 记录支持度用滞后影子床面，主预览按需同步 | 塌落时机与可见冲刷可能不连贯 | T10/T14 |

## 建议和限制

1. 优先“压实沙能成型”和“浅水能看到底”，这两项改变最大；之后再加颗粒、亮纹和白沫。
2. 数值场景保持原签名，新建仅水沙的视觉夹具，统一镜头/尺度/光照/显示时间。
3. 参考内已有锯齿，目标不是宣称原作完美平滑；本项目应减少近景规则网格感，同时保留陡轮廓。
4. 单帧可观察浪缘和亮纹，不能给出波速、焦散算法或侵蚀因果。波包/保形参数必须以本项目试验冻结。
