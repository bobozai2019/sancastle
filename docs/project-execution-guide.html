权威状态与读者边界

边界实际职责
编辑执行器只在公共决定允许时提交沙/材料等字段；拒绝保留原场。
水响应 / 水tick前者共享编辑事务决定，后者拥有明确的水/侵蚀/材料子步；实际时钟由GPU完成态推进。
预览 / 表现 / 碰撞读取同generation完整完成态。编辑无需等待CPU通知或碰撞收敛；消费者各自保留资源租约。
native保存 / 恢复SANDUE06容器保留有效配置和原始资源字节。候选还是同一种Pipeline；完整64块新代物理槽准备后才切换。
关闭 / unknown先关闭接纳，等待真实终结与最后读者证明。unknown不重放，不伪造GPU结果，不强制free未知所有权。
