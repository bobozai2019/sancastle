同一个域，同一条沙水执行流程

两个正式入口默认MUSCL MC与SSPRK2二阶水传播，可启动前显式选择一阶。面板保波程度0–1混合MC/Superbee重构，默认0；独立水参数窗保存后由用户重启生效，窗口不调用热重建，存档记录当前有效值。main默认动量B；test1_geometry默认连通排水。编辑、水tick与显示共用统一Pipeline。

两个正式场景由直接继承Node3D的统一入口加载。玩家工具只产生声明；域Runtime协调生命周期，Pipeline决定录制顺序，公共数值阶段完成候选、校验、条件提交与发布。

MUSCL在同一未接受初态的连续CFL重试中复用第一阶段与dt无关的边通量、压力修正、床源项和速度上界，drain、Euler及第二阶段仍按新dt计算。GPU在新tick、接受和故障时集中使缓存失效；自定义／包装耦合完整重算。三份私有纹理增加1,581,056 B有效载荷，另有16 B状态缓冲，均随Water释放，不进入检查点。尝试上限默认64，水窗口允许1–64；CFL默认0.2，允许0.05–0.5，大于0.2属实验调节。两项保存重启生效并纳入配置与恢复校验。CPU按上限录制候选链，底层64槽容量及清零保持；预算耗尽只推进已接受时间。原双槽、审计、完成时钟及账本保持原语义。详情见数值规格。

水面内白沫与岸脚读取共享泡沫历史；两个正式入口的独立细沫节点PrototypeFrontFoamDense均隐藏，不提交该层绘制，对应细沫参数禁用。

水面泡沫使用共享历史R控制覆盖，并以线性mip孔洞纹样破边；两个正式场景静态绑定foam_detail.png。完成态时钟和限速流速驱动双相位局部流动，默认周期4秒、密度1/m、破碎程度1；岸脚增益0.55。覆盖统一参与颜色、透明度、直射和高光抑制。水参数窗口的纹样密度、破碎程度和流动周期实时生效；模式0保留原路径。三项参数可用性以bind_scene时模式判断，模式0禁用；正式窗口不提供模式开关，诊断修改模式后重新bind_scene同步可用性。该表现不改变权威水沙和历史演化。

冲岸水花

冲岸水花是独立的只读GPU表现层：固定ShoreSplash批量节点从1024槽纹理池绘制小水滴，按朝向干岸的流速分量与浅水条件发射，重力与阻力驱动弹道，触床、落水或越界时终止。统一成功发布阶段使用实际接受dt推进，暂停冻结；不回写水沙、动量、源汇或账本。水参数窗口可实时开关显示并调整尺寸；恢复或重进清空瞬态水花，不保存粒子轨迹。

水花四张64×16 RGBA32F图像共65,536原始字节；每成功完成工作追加一次小dispatch，control[1]失败不写，control[9]接受dt推进；dt为零的编辑仅裁掉新床埋入的水滴。发射须有0.004–0.18 m浅水、沙厚大于0.02 m、床面坡度大于0.04、朝岸速度超过0.28 m/s与前方0.25 m干岸或近水位床面；速度q/max(h,0.02)限长3 m/s。每空槽每工作最多尝试8个候选点，概率按实际dt缩放。水滴寿命0.25–0.60模拟秒、重力9.8 m/s²、水平阻力系数0.65/s，落地使用原三角床面及已有水深。水滴材质render_priority=2，在水面0及岸脚1后透明合成；保留正常深度测试及depth_draw_never，不穿透实际遮挡物。单槽独立更新并写published，未引入邻槽写入、逐滴刚体、碰撞高度图或运行时CPU粒子读回。上述参数属于项目适配。

UI显示开关仅隐藏绘制，池仍继续更新；尺寸默认1、范围0.5–2。入口shore_splash_enabled为启动前冻结开关，false停止该阶段计算。瞬态不写检查点，恢复新generation时清空；原生ABI未扩展，新增源码与配置仍参与原有严格来源校验，旧档不自动兼容。图像字节数不等于驱动显存或帧成本，完整负载成本需独立实测。

动量资源与存取

GPU权威动量使用两张256² RG32F ping-pong纹理，R/G分别保存qx/qz（hu/hv），每分量仍为Float32；Views另持有一张RG32F完成态动量，供材质、查询、白沫、碎石、植被及溅水读取。三张动量纹理合计原始载荷1,572,864 B，数量减少不代表像素载荷或物理显存减半，也不保证帧率提升。

CPU与磁盘保留momentum_x、momentum_z逻辑字段及现有native3、SANDUE06/07版本。初始化和恢复分别将current/spare两个分量按uint32位型交错打包；捕获每份RG一次，长度及全部异步回执完整后再无损拆分。公开查询仍返回原逻辑分量。每tick不做拆分，不增加pack/unpack dispatch；发布、完成态身份、源汇和动量账本不变。严格配置与来源校验仍生效，字段格式未变不代表所有旧档自动兼容。

确定性与完整负载限制

检查点恢复原始字段与恢复后继续演算的逐位确定性是不同保证。已有固定检查点对照中，同机同后端使用精确旧水面与水侧shader原件，继续填沙、挖沙后仍出现约1e-7量级的水沙及动量字段差异，具体根因未知；这不证明新表现对演算无影响，也不能据此放宽逐点比较。恢复继续遵守既有原始字节、配置、账本和时钟校验；体积账本容差不适用于逐格字段，当前不承诺恢复后任意演算序列逐位一致。

新泡沫路径沿用既有水面绘制与历史场，增加两次细节纹理采样，没有新增水面表现节点、历史RT或compute阶段；这些结构信息不能换算为固定帧率或零额外成本。现有D3D12、GTX1050完整负载对照的旧路径自身时序仍不稳定，部分整帧尾部和模拟吞吐超出原成本边界，尚不能确认新路径完整负载性能达标。视口GPU区间不包含全部异步compute；需分别观察整帧分位数、实际完成模拟时间/墙钟时间及覆盖明确的GPU区间，暂停画面的GPU改善不能替代实时负载结论。
