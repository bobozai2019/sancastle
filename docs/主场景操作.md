# 主场景操作

适用统一正式入口。运行默认 [main.tscn](../scenes/main.tscn)，场景菜单提供两个入口，差异见[场景说明](场景切换与功能复用.md)。无需旧后端开关。

## 工具

左侧选择工具，左键点击或拖动。UI点击不产生世界编辑；切换工具、转向相机等操作结束当前笔画，已接纳工作继续结算。队列满时新样本可能拒收，笔画END保留重试；停止输入后等待碰撞和画面收敛。

| 工具 | 当前用法 |
|---|---|
| 挖沙 / 填沙床 | 自由源汇，无背包要求；单次体积0.01–1m³，默认0.1；拖动按距离折算，不可挖rock |
| 投流沙 | 增加水中悬沙，随水输运/沉降；干足迹拒绝，不直接填床 |
| 投碎石 | 每次1–128颗，默认16；最大1024，容量不足拒绝；不改变沙量、不阻水、没有逐颗刚体 |
| 城堡 | 每次按下单次放置；固定世界标高补至模板，保留更高原沙；同位置重复不叠高；完整足迹须在域内，补沙最多48m³ |
| 沙墙 | 拖动补至本笔基准目标，同笔重复不无限增高 |
| 铲子 | 拖动中央开沟，两侧各自堆沙；某侧达到堆高上限后停止加沙，中央仍能继续挖，放不下的沙移除。已挖区域可接沙，回填后可再铲开 |

参数使用面板合法范围。`[`、`]`每次旋转城堡15°，数值框焦点期间不触发相机移动。平滑、压实可从左侧工具按钮选择；参数在独立工具窗口修改。

主场景默认动量B（策略2）：填沙向外推水、挖沙向内拉水。独立工具参数窗口的水响应策略可切回原策略3。推水力度默认0.25，可调到1.0放大观察；在有水的中央水道操作，干沙不推水。模式/力度切换会结束当前拖拽，从下一笔生效，保存恢复同步两项设置。策略2/3允许速度，策略0/1在提交时使用速度0。绿色/黄色/红色预览是完成态参考，不能保证下一命令必定准入。暂停时可编辑和投碎石，恢复播放后继续输运。

## 相机、时间与界面

- WASD移动、Q/E升降、Shift加速，按住右键转向；Esc或失焦释放鼠标。
- F5切固定/自由视角，SPACE暂停/继续，F6显隐HUD。两场默认启用自由相机。
- 独立水参数窗口设置幅度、持续时间后，在场景右侧点击“触发波浪”，暂停时请求排队，继续后按模拟时间生效。
- 碰撞可落后于GPU完成态，拾取使用上一份完整物理面；短暂版本差不代表下一笔必须等待碰撞。
- 性能面板显示帧统计、队列、在途和完成态；具体口径见[性能面板](性能面板.md)。

## 保存与场景切换

两个正式场景自动显示海草、海带、红藻及六种岸上草本，按初态水深和地形分布。挖沙降低草根，填沙可埋住草；水流推动草叶弯曲，暂停时摆动保持。恢复或重进时根据恢复后的床水重新分布，不保存每丛此前的姿态和遮埋历史。当前没有种草/擦草或拨草工具，配置与限制见[水草与岸草](植被.md)。

入口提供 `save_gpu_checkpoint(path)` 与 `restore_gpu_checkpoint(path)`。保存会关闭笔画，取得完整GPU状态；使用尚不存在的文件路径。恢复同时保留已保存工具/水设置、时钟和身份高水位，格式及来源校验见[技术规格](当前技术规格.md#检查点与兼容性)。未知或不兼容来源明确拒绝。

数值路径在启动前通过入口`water_solver_id`选择，空值跟随`water_numerics.gd`的默认；显式`rusanov_first_order_v1`可使用一阶，`muscl_mc_ssprk2_v1`使用二阶。切换算法需先保存完成态，关闭旧域，再用目标算法创建新域并恢复受支持的检查点，编辑字段和实际时钟保持；活动域不原地切换。程序调用方应在实例加入场景树前赋值。直接修改并保存场景文件会改变来源身份，兼容映射需覆盖该实际来源，不能靠忽略hash加载旧档。

场景菜单选择目标后切换，会先保存、关闭当前域，再加载目标；目标失败返回原正式场景。各场景本次运行分别保留进度，重新启动从默认初态开始。关闭或保存遇到无法确认的资源终结时保留所有权并重试，不强制释放。

## 保波程度

独立水参数窗口的“保波程度”范围0–1、步长0.1，默认0保留原MC重构；数值越高越偏向锐利的Superbee重构。它不是推水力度或衰减秒数，也不保证所有波长都更持久。该参数标记“需重建／重启”，保存参数后由用户自行重启游戏生效；窗口不调用保留现场的热重建API。一阶模式要求保波为0。

## 参数窗口

场景右侧“参数窗口”菜单打开工具、水、沙、道具、环境与显示、性能与诊断六个原生桌面窗口。关闭子窗只隐藏；F6只显隐场景操作HUD。窗口标明“实时生效”“下次操作生效”或“需重建／重启”，保存参数与保存沙场是不同操作。配置与范围见[独立参数窗口](参数窗口.md)。

## main三件漂浮物

main固定水瓶、木板、木棍各1件，随水与沙床运动；沙刷穿过道具拾取Terrain。暂停与保存会保持三件，暂停编辑可能产生有界填沙解重叠。检查点不保存道具姿态，成功恢复和重进按布局重置，失败恢复保留原状态。道具故障仅保持道具，仍可保存或恢复沙场。test1_geometry默认没有道具；完整机制和当前验收边界见[漂浮道具](漂浮道具.md)。

右下角“漂浮道具·自由摆放”面板：

1. 点击水瓶、木板或木棍槽位，再左键点击水面或沙地投放。已有道具会移动到新位置，每类始终1件。
2. [ / ]每次旋转15度；绿圈表示可尝试摆放，红圈表示离其他道具太近或超出活动范围。
3. 点击“拾取道具”，再左键点场景中的道具，收入对应槽位；重新选择槽位即可再次投放。
4. 右键、Esc或“返回沙刷”取消；选择沙滩工具也会退出道具模式。道具模式中的右键优先取消，退出后恢复相机转向操作。
5. 拖动面板标题可调整UI位置。暂停时可摆放/拾取，继续后恢复漂浮；保存不记录本轮摆放和槽位状态，成功恢复/重进按初始三件重置。
