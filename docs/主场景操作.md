# 主场景操作

主入口：scenes/main.tscn。UI和相机节点、信号均保存到场景，不由脚本临时生成。

2026-10-13：右上角场景下拉框可选主沙滩、test1沙床可编辑版、上滩回流可编辑适配版。三个入口共用下述工具和相机/波浪/恢复功能。切换会保留本次运行各场景独立沙形、水场、沙源汇、tick和相机；挖填量等工具设置沿用。切换期间等待在途编辑/模拟结算。具体入口、实验版边界与验证见[场景切换与功能复用](场景切换与功能复用.md)。

- 在右上角选择“挖沙/填沙”，左键使用选定工具；每次体积各自设置，范围0.01–1.00m³，步进0.01，默认0.10m³。右键用于相机。
- 按住左键拖动形成连续笔刷，体积按移动距离折算，0.75米对应一次设定体积。
- 自由挖填，无背包沙量限制，可直接填沙，无需先挖沙。实际沙体增减分别记外部源汇；挖沙仍受不可挖基底约束。
- 自由相机默认启用。WASD直接移动，Q下降/E上升、Shift加速；按住鼠标右键转向。松开右键或Esc释放鼠标；失焦也释放鼠标。输入数值期间，移动键不影响相机。
- 手动波浪：设置“波幅（m）”后点击“触发波浪”。范围0.01–0.20m，默认0.10m，一波持续3秒，沿现有海边边界推进；可与自动波浪叠加，总波幅仍遵守既有0.25m上限。暂停时先排队，继续模拟后生效。
- F5切换自由/固定视角，SPACE暂停/继续，V调试视图，F6显隐HUD和沙量面板。
- 左下角“性能 / Profile”每0.5秒刷新：FPS、平均/峰值帧耗时、引擎CPU与物理耗时、主视口渲染CPU/GPU、模拟tick/s与实时倍率，以及水流、侵蚀、沙坡、白沫等GPU阶段耗时。默认开启“分阶段采样”，可在面板关闭；F6隐藏时停止采样。暂停保留最后有效阶段数据，标记“上次”；未采到数据显示“—”。详细口径和复验见[性能面板](性能面板.md)。

UI点击不进入世界笔刷；相机控制会终止当前笔刷，并拦截编辑输入。即使鼠标在UI上释放，也会结束之前的世界拖动。
