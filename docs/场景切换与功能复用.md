# 场景切换与功能复用

四个正式入口共用[统一技术方案](当前项目技术方案.md)，场景身份由[unified_scene_routes.gd](../scripts/beach/unified_scene_routes.gd)准确路径定义。

| key | 正式场景 | 初态与边界差异 |
|---|---|---|
| main | [main.tscn](../scenes/main.tscn) | 项目沙滩初态、自动波包及手动波浪 |
| test1_capture | [test1_capture.tscn](../scenes/playable/test1_capture.tscn) | 捕帧沙床/水深/动量映射到项目域，保留其适配边界 |
| test1_backwash | [test1_backwash.tscn](../scenes/playable/test1_backwash.tscn) | 捕帧适配初态，16模拟秒回流水位周期 |
| test1_geometry | [test1_geometry.tscn](../scenes/playable/test1_geometry.tscn) | 30×15可见范围、原始绝对Y适配，低水位起步与20模拟秒上岸/回落 |

场景不是旧main运行类的继承变体。它们直接挂统一入口，分别实例化已固化表现；manifest和seed来自 `assets/unified_edit/presentation/<key>.json/.variant`。四场默认erosion/brush_water/foam/gravel/local_front开启、render_subdivision=2、自由相机开启；main默认水策略2，三个test1默认策略3；main/capture/backwash初始512颗碎石、普通内聚高度0，geometry初始0颗、内聚高度2m。

四场默认水传播为`muscl_mc_ssprk2_v1`，入口`water_solver_id`空值使用该默认。启动前可显式选一阶，场景服务将当前有效算法带到目标构造；既有缓存检查点按目标算法通过来源校验恢复，不原地修改活动generation的算法。

## geometry几何适配

可见X=-15..15、Z=-7.5..7.5，256²权威域中使用240×120格；完整ground数据双线性采样，高堆沙细节不声称逐点等价。原作坐标按(x,y,z)→(-x,y,z)映射，基底Y=0，初始水深max(0.95−床高,0)、动量0。项目将原场景数值作为米，是Godot适配，原作现实米制/可挖底界未知。

海侧低位0.95m、抬升0.45m、周期20模拟秒：0–1秒低位、1–4秒抬升、4–5秒高位、5–9秒回落、9–20秒低位；实际岸边响应有传播延迟。配置见[water_cycle.json](../assets/test1_geometry/water_cycle.json)。Z外侧干燥障碍、X侧隐藏延续段连接现有边界；编辑限制在可见矩形内。

## 共享能力与切换

四场均预存同一VegetationLayer和九种植物的代理网格与多视角图集。main在近30×30m范围生成候选，三个test1限定到约30×15m可见区；实际数量由各自初态床水、坡度、障碍和分布参数决定。植被只读公共水沙完成态，暂停时仍可随挖填更新根部；切换或恢复按目标完整床水重新生成，不从会话检查点读取单丛姿态。详见[植被机制](植被.md)。

所有场景共用输入、工具声明、流水线、水沙模拟、材料、完成态表现、碰撞、预览、相机、暂停和原生检查点。水材质静态参数相同不代表画面相同：水深、动量、沙形、边界与机位均影响观感。生命周期与所有权见[当前技术规格](当前技术规格.md#发布碰撞与生命周期)。

服务按“结束笔画→保存完整状态→shutdown并确认旧域→加载目标→恢复目标进度”处理，阻止重复切换。保存失败保留当前场景；旧资源未确认释放则停止目标加载；目标初始化/恢复失败，用刚保存检查点沿原正式路径重建。工具/UI设置与每场域状态由服务和入口各自保存，不能跨域直接套检查点。

正式与测试候选按准确PackedScene路径分formal/candidate族，缓存使用family:scene_key。同族场景本次运行独立续进度，新进程从默认初态开始；不存在“关闭统一模式回退旧后端”的选项。

## 新增场景

先离线生成静态表现、初态及来源manifest，定义域、合法配置和边界；创建只挂统一入口/固定Runtime的wrapper，注册统一路由与场景内静态菜单。验证全部工具、可见域拾取、水/沙预算、暂停、保存恢复、切换失败、旧代读者与关闭。不能通过旧入口继承链再构造第二个求解器。

固定床面的 `scenes/test1_water_motion_trial.tscn` 是独立512×256运动实验，不属于四正式入口，也不是当前可编辑系统的物理后端。其来源与原判定及geometry早期交付记录保存在[历史文档](history/README.md)。

## 漂浮道具的场景范围

只有正式main实例化固定FloatingProps组件，三个test1继续使用原有场景内容。切换前保持并终结公共读者，再释放水沙域；返回main重置三件，不从会话检查点还原姿态。成功恢复换代会重建采样身份与零积分预算，失败恢复保留原代三件。详见[漂浮道具](漂浮道具.md)。

## 独立参数窗口

窗口归Parameters Autoload持有，跨场景保留布局。旧场景退出前解绑，目标场景绑定其实际配置；普通工具状态沿用会话共享，外观与待重启值按场景保留。需重建项保存后不参与本进程后续初始化，用户自行重启后加载。已有检查点仍按当前冻结配置严格恢复；详见[参数窗口](参数窗口.md)。
