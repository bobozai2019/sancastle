# Sandcastle 当前技术规格

版本日期：2026-10-18；适用正式main与三个test1统一入口。本文整理当前生效实现，不给历史任务追加通过。架构解释见[技术方案](当前项目技术方案.md)。字段偏移以[layout.gd](../scripts/simulation/unified_edit/layout.gd)为唯一源码；契约详见[统一流程契约目录](../task/sandcastle_unified_edit_pipeline/契约/)。

## 域、坐标与单位

| 项目 | 规格 |
|---|---|
| 权威网格 | 256×256，65536格，cell_size=0.125m，域32×32m |
| 坐标 | XZ为水平面，Y为高度；索引z×256+x；格心=((x+0.5−128)×0.125,(z+0.5−128)×0.125) |
| 面积/体积 | 单格面积0.015625m²；等效厚度×面积得到m³ |
| 床面/表面 | bed=rock+sand；water存水深；水面及表现共用可见床面基准 |
| 速度 | qx/qz存水平动量hu/hv，单位m²/s；速度为动量/有效水深，干格按数值核处理 |
| geometry显示 | X=-15..15、Z=-7.5..7.5；权威域内240×120可见格，不把显示细分当模拟加密 |
| 碰撞 | 8×8共64块，每块33×33高度采样，包含共享边界 |
| 时钟 | sim_tick、revision、state_seq各自独立；表现使用GPU完成态累计actual_dt，暂停冻结 |

入口按1/30秒请求水步；GPU CFL Courant=0.35，子步1–64，safe_dt=Courant×cell_size/最大传播速度，actual_dt=min(requested_dt,64×safe_dt)。超限缩短实际推进时间，不能用tick/30代替完成时钟。非有限/非法CFL或身份耗尽会设置故障标志。

## 物理字段与资源

| 字段 | GPU格式 / 槽 | 语义 |
|---|---|---|
| rock | R32F，单槽 | 不可挖基底高度m，可为负 |
| sand | R32F，双槽 | 非负等效沙厚m，也用于当前几何 |
| water | R32F，双槽 | 非负水深m |
| sediment | R32F，双槽 | 非负悬沙等效厚度m |
| momentum_x、momentum_z | 各R32F双槽 | 水平动量m²/s |
| wetness、compaction | 各R16F双槽 | [0,1]；原始half字节恢复，不经CPU解码重编码抹掉细值 |
| obstacle | R8_UNORM，单槽 | 二值阻水掩码 |
| flux | RGBA32F，双槽 | 四向非负出流m³/s |
| mold_support | RG32F，双槽 | 成型材料标记/参考数据，按材料codec解释 |
| edge_x/z、drain、cfl_tiles | RGBA32F或R32F工作纹理 | 共享边通量、缩放和CFL归约；非公开工具字段 |

格式与初始化由[state.gd](../scripts/simulation/unified_edit/state.gd)定义。只读发布、白沫和碎石另有资源，不能把上表当完整显存预算。纯视觉改动不得改变权威水沙、动量或源汇。材料配置来自 `assets/brushes/molded_material_candidate.json`：compaction_target=0.95，R16F实际存储值0.9501953125；成型内聚高度0.9m，饱和标记深度0.125m。场景普通内聚高度独立：main/capture/backwash为0，geometry为2m。

## 身份、ABI与容量

物理协议family=unified_edit、ABI v1、little-endian。int64用低/高两个uint32传GPU，绝不经float；positive signed int64上限9223372036854775807。generation为正，其余计数遵守各自非负/正值约束；seed允许signed int64位型。耗尽返回identity_exhausted。

| 物理命令 | 512B |
| 逐命令结果 | 384B |
| 输入批次头 / GPU完成头 | 各96B |
| 原生水控制区 | 128B，与命令不同 |
| 每物理批次最大命令 | 64；按队首类型/tick及递增command_id合批，没有固定2笔默认值 |
| 最大输入/输出槽 | 32864B / 24672B |
| pending接纳上限 | 64 |
| 终结结果总预留上限 | 512，含尚未领取结果 |

## 声明、能力与权限

Intent绑定domain、generation、command_id、tick、profile_id/version/hash及起点；可包含终点、参数、受限features、authorization、笔画身份/基准/sample和seed。未知键、错误类型、NaN/Inf、非零float32下溢、非法组合或超范围拒绝，不静默修正。

| operation | 形状与目标 | 行为 |
|---|---|---|
| VOLUME_DELTA | DISK/SWEPT_CAPSULE；床沙或只增悬沙 | 普通挖填、投流沙 |
| TARGET_HEIGHT | HEIGHT_STAMP固定世界高度；或SWEPT_CAPSULE笔画基准 | 城堡/沙墙补到目标，保留更高原沙 |
| TRANSFER | SWEPT_CAPSULE，床沙 | 固定基准，中央供沙→两肩，材料保留 |
| REDISTRIBUTE | DISK，床沙 | 守恒平滑 |
| FIELD_ADJUST | DISK，材料 | 压实，不改变沙量 |

默认产品[default_catalog.tres](../assets/unified_edit/default_catalog.tres)含11物理profile。G7扩展catalog含14 profiles/2 templates，是验证夹具，未替换产品catalog。精确模型script绑定、冻结副本和来源hash必须验证；profile不得携带Callable、执行器、shader路径或第二个调度器。

水策略允许0–3，具体数值路径由公共water_response定义；策略2（仅速度）和3（位移＋速度）允许非零speed_m_s，策略0/1的speed_m_s必须为0。悬沙、平滑和压实的声明水策略为0。write mask从operation/destination/有效policy推导，调用方无权缩小自报掩码绕过审计。authorization只能降低amount/add/transfer预算，0是有效限制；不能增权或绕过有限值、非负、守恒、原子性与消费者检查。

主沙滩沙形工具面板提供默认开启的“连通排水（实验对比）”。关闭时使用策略2，跳过湿区连通与水量重分配，编辑阶段保留原水深和悬沙、继续执行现有局部速度响应及公共审计，随后由常规水tick搬运水量；暂停时不额外推进水tick。切换结束当前拖拽，仅影响后续命令，策略仍进入命令有效hash与检查点selection。此开关用于对比当前算法，不代表移植了竞品Water.Paint或已验证高沙堆回落效果；策略3的默认数值路径保持原样。

2026-10-18 开关专项验证：profile 100项、protocol 212项、实际D3D12 GPU 90项、主沙滩UI/拖拽切换/存档恢复15项通过。关闭时填沙与铲子的水深和悬沙双槽逐字节保持，动量发生变化；重新开启后恢复packed排水。验证索引见[drainage_toggle](../test_output/drainage_toggle_20261018/verification.json)，测试入口为`tests/integration/unified_edit_drainage_probe.gd`及`unified_edit_drainage_ui_probe.gd`。首次GPU测试因测试用填沙命令误选材料策略被拒绝，原失败记录保留在同目录`gpu/`，修正后为`gpu_v2/`。全项目架构检查仍有其他在途资源/方法与既有封存不一致，未宣称全项目验收通过，也未批量更新其封存。

关闭连通排水的策略2现使用独立[water_velocity_prepare.glsl](../scripts/simulation/unified_edit/water_velocity_prepare.glsl)：256组×256线程逐格复制候选、清理暂存并汇总首个非法格，再以1组×256线程生成128字节回执。新增私有检查缓冲2048字节，两阶段特化pipeline由Response持有并释放；按工作组统一读取拒绝/致命状态后决定是否执行，阶段之间没有CPU读回等待。后续速度响应、速度归约、守恒审计和共同提交保持原流程。它不构建连通域，因此没有每行8湿段/32分量边界；开启后的策略3仍使用下述原排水路径。21组固定输入的候选/回执逐字节对照与拒绝保护共168项、开关集成92项、NaN/非法材料40项、与修改前五条命令18个输出字段对照90项通过。性能、复验入口和适用范围见[优化记录](湿区排水并行优化.md)末节及[本轮验证索引](../test_output/velocity_prepare_parallel_20261018/verification.json)。

开启连通排水的并行实现保留256²域、4邻接湿区、每行最多8湿段/最多32分量的快速路径边界，以及原通用回退。分量索引、供受分配、逐格补偿求和、残差行序与ULP修正上限、容量和守恒预算不变。新增私有暂存为 `65536×48 + 16+32×96 = 3,148,816` 字节，约3.003MiB；不进入权威字段或检查点。1024组逐格阶段、最多32组分量阶段和1组全局汇总顺序录制，11份特化pipeline由Response持有并释放；不改变三工作槽、回执时机和碰撞策略。当前版本的逐字节对照及成本边界见[优化记录](湿区排水并行优化.md)。

配置必须unrestricted_sand_tools=true。enable_structures、rise_front_history、contact_history当前仅支持false；erosion、brush_water、local_front、foam、gravel按合法能力校验。diagnostics不计入stable configuration_hash；实际来源文件、声明、模板、环境与材料身份参与冻结。修改运行中资源不能改变已排队快照。

## 事务、回执与账本

- freeze成功只说明数据有效；submit仍检查域/代次、后端、关闭和背压。队列满返回queue_full，结果容量满返回results_backpressure，不分配假GPU成功。
- BEGIN/sample/END走同队列；目标高度/搬运持有baseline与累计coverage。圆盘使用当前点，只有capsule连接两端。形状笔画段≤2m；普通sweep使用独立有界声明。
- APPLIED=1必须有权威变化，revision增加1；NO_CHANGE=2可仅改变coverage，revision不变；REJECTED=3须无沙/水/材料/coverage变更。控制不能APPLIED，允许合法NO_CHANGE或无副作用REJECTED。
- 结果必须匹配命令、代次、租约、domain/effective hash、profile版本及实际tick；state_seq指批末完整发布。旧代、重复或错误回执不能再次结算。
- 普通体积编辑使用APPROXIMATE_EXTERNAL：已知GPU录制的原请求×strength记名义源汇，包含业务拒绝，不能当精确物理沙量。
- 目标高度使用EXACT_EXTERNAL，按实际增减记源汇；TRANSFER保持source/sink为0并检查两肩/预算；平滑、材料和控制账本不变。
- GPU公共审计核对实际变化、ULP预算和授权，不能由decoder检查或导出成功替代。容差沿既有契约，不用扩大touched并集放宽沙量误差。
- fatal/unknown保留原始诊断和租约，不产生普通业务ACK，不授权重放、结算或强制释放。

## 发布、碰撞与生命周期

表现/预览/碰撞读取同generation完整版本；GPU录制顺序不等于CPU通知顺序或碰撞就绪。worker仅在is_task_completed之后回收，不在编辑主流程阻塞等待物理。

恢复候选必须备齐64块同代高度和材质绑定，在physics阶段原子交换。当前未变化块允许较早seq；候选整体要求完整同代准备，不能混用规则。旧代关闭接纳/录制后仍持有最后读者，直到真实GPU结束、解绑和worker证明完整。未知证明按维护节奏重试，不将超时当完成。

正式与候选通过准确PackedScene路径分族，缓存key为family:scene_key；场景服务保存→shutdown→加载，目标失败按原正式路径回滚。当前会话进度不等于跨进程自动续档。当前支持保存恢复，不对外提供任意逐命令撤销保证。

## 检查点与兼容性

[SANDUE06 codec](../scripts/simulation/unified_edit/checkpoint_codec.gd)：edit version6、native3、container1；8B magic+u32容器版本+u32长度+32B SHA256组成48B头，payload最大32MiB。Variant对象反序列化关闭；文件create-only，临时文件写入/flush后rename。

保存包含原始current/spare字段、材料/白沫/受支持历史、控制完成态、账本、实际时钟、波包、选择、有效配置/来源及highwater。恢复验证当前磁盘配置身份和数据后建立候选；highwater不重置，generation换代。

仅已登记来源的edit5/native3、edit4/native2可通过[legacy_sources.gd](../scripts/simulation/unified_edit/legacy_sources.gd)数据校验迁移。来源catalog为 `assets/unified_edit/legacy_source_catalog.variant`。旧codec/Recovery的受限静态验证函数不构成旧后端fallback；未知来源、跨域、损坏、配置或来源不匹配明确拒绝。新增兼容格式须补迁移策略和证据，不能改magic/版本号伪装兼容。

## 漂浮道具新增消费者契约

正式main固定三件、9采样点；公共Probe ABI3请求1152B/输出3200B、最多32点，Height快照ABI3仍69828B/16块/两槽。新增累计床变上界是私有消费元数据，不改native3权威字段。Profile v2与严格身份校验、真实Jolt时钟、5mm总床面差预算、暂停/恢复语义见[漂浮道具](漂浮道具.md)及[机器ABI](../task/sandcastle_floating_props/契约/probe_ABI_v3.json)。

旧G0–G8数字保持原测试范围；漂浮道具G1–G5通过，G6功能与成本尚未通过，不把历史成本用于新增负载。原生旧来源只允许离线登记的精确配置投影：完整来源/目标source map和声明值均须匹配，派生模型hash重绑有单独数值等价证据；未知来源、改变的声明和未审阅目标仍拒绝。
