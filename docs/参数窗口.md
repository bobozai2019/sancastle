# 独立参数窗口

两个正式入口将操作与参数分开：场景内选择和使用工具、触发波浪、切换场景及暂停；右侧“参数窗口”菜单打开工具、水、沙、道具、环境与显示、性能与诊断六个原生桌面窗口。窗口可移到副屏，关闭只隐藏，游戏继续运行。F6仅显隐场景HUD。

固定布局位于 `scenes/parameters/parameter_windows.tscn`。Parameters Autoload 持有窗口、参数与帧采样，场景销毁前解除绑定，目标场景可用后重新绑定。参数窗口不持有模拟writer，也不拥有第二个求解器、提交队列或GPU回读器。

## 生效标记

| 标记 | 行为 |
|---|---|
| 实时生效 | 材质、相机、光照及采样配置立即更新当前消费者；水面相关光学输入同步到有同名输入的接触、悬沙和水边材质 |
| 下次操作生效 | 工具设置变化先结束旧笔画，下一笔使用新值；造浪幅度、持续时间只供下一次点击“触发波浪”使用 |
| 需重建／重启 | 保波、求解器、MUSCL CFL及尝试上限、边界、侵蚀／材料演化、内聚高度、白沫历史及道具物理参数保存后等待用户手动重启 |

重启项分别显示当前有效值、编辑值和已保存状态；未保存显示“尚未保存”，保存后显示“待重启生效（已保存）”。保存不改变本次运行的物理配置，也不在切场景时自动应用待重启值。该UI不自动重建、不自动重启、不承诺保留重启前的沙场或道具动态状态。已有保波API仍存在，但独立窗口不调用该热重建API。

工具参数来自公共声明允许的范围。策略0/1在提交时使用零速度，策略2/3使用所选力度。普通圆盘与扫掠刷读取半径、力度；平滑和压实读取独立的半径、力度。工具参数页不改变当前工具。

## 参数与实际消费者

`assets/parameters/catalog.json`定义稳定标识、中文名称、单位、类型、默认值、范围、生效方式及消费目标。`parameter_schema.gd`校验数值、颜色、枚举和交叉约束；墙顶宽不能超过底宽，一阶求解器不能保存非零保波程度。材质参数读取显式覆盖值，无覆盖时使用RenderingServer提供的shader默认值。窗口中的默认值以场景实际材质、相机、边界和道具配置为依据。

| 参数组 | 消费路径 |
|---|---|
| 工具 | 入口共享工具状态 → PlayerInput → 已冻结Intent；不再从SpinBox反向读取 |
| 造浪 | 入口幅度与持续时间 → 公共波包请求；已接纳波包保持原快照 |
| 侵蚀、沉积、湿润、干燥、扩散、压实、塌落 | 启动配置 `environment.coupling_parameters` → State快照 → Coupled编译常量及push constants |
| 表面湿痕 | 沙子参数中的湿色保持时间0–300秒（默认18）与褪色时间0.1–300秒（默认12）→ 启动配置 `environment.surface_wetness_profile` → 发布push constants；两场景独立保存，保存后重启生效 |
| 白沫历史 | 启动配置 `environment.foam_parameters` → Visuals消散时间及生成增益 |
| 普通内聚、边界、求解器 | 启动前冻结到原有environment与water_numerics，按原校验构建运行域 |
| 材质 | 实际ShaderMaterial的uniform；沙色、颗粒、粗糙度和高光使用从原公式提取、默认值相同的输入 |
| 漂浮物 | 启动前复制道具profile，更新声明值与摩擦材质，再由原服务attach创建采样快照；有效覆盖值计入 `environment.prop_parameters` |
| 环境、相机 | 当前场景相机、太阳和WorldEnvironment属性 |

场景2（test1_geometry）的边界平均水位、振幅和周期可编辑，保存后重启生效；当前活动域及本次运行的场景切换仍使用启动时冻结值。角频率和相位在该场景的分段周期模式中不参与计算，禁用并显示“当前水边界模式不使用此参数”。场景1仍可修改正弦角频率和相位，其不使用的周期项禁用。场景2的自动退水阈值保持water_cycle.json配置中的绝对水位，不随基础水位自动平移，较高水位可能触发退水。其他不适用项也按实际消费路径禁用。当前RDC光学路径不消费的备用散射和亮纹柔和度／缩放禁用，当前亮纹使用独立的rdc_caustic_scale纹理密度；像素直径控制白沫大小时，世界半宽禁用。未开启的算法能力不会因为显示某项参数而新增；网格尺寸、容量、ABI、守恒容差及安全限制不开放。

水参数窗口提供三个实时材质项，参数服务在 `bind_scene` 时按 `foam_detail_mode` 判断可用性：模式1可用，模式0禁用。正式窗口不提供模式开关；诊断脚本修改模式后须重新调用 `bind_scene` 同步参数可用性。它们随当前场景适用参数保存，不修改白沫历史生成或消散。

| 标识 | 中文名称 | 默认值 | 范围 |
|---|---|---|---|
| `visual_foam_detail_scale_per_m` | 泡沫纹样密度 | 1/m | 0.5–12/m |
| `visual_foam_hole_strength` | 泡沫破碎程度 | 1 | 0–1 |
| `visual_foam_flow_cycle_s` | 泡沫流动周期 | 4 s | 0.5–8 s |

“水沙接触白边”（`visual_natural_contact_enabled`）默认开启，实时控制 `ShoreContactOverlay.natural_contact_enabled`，沿用按场景保存、加载与恢复默认。关闭时仅隐藏岸脚接触白边，保留接触强度等设置，水面泡沫、冲岸水花和共享白沫历史继续按原设置生效。

## 保存与启动

水窗口在求解器下方提供两个MUSCL调试参数，保存后重启生效，选择一阶时禁用。CFL系数默认0.2，可调0.05–0.5，步长0.01；大于0.2属于实验调节，不保证稳定性或性能提升。每tick最大尝试次数默认64，可调整数1–64，包含接受和拒绝尝试；降低上限会减少CPU录制的尝试链，预算耗尽时只累计已接受的实际时间，可能减慢模拟推进。两个参数不会修改一阶求解器的CFL或子步预算。

参数标识为`muscl_cfl`和`muscl_max_attempts`。启动后冻结进`environment.water_numerics`并参与配置hash与检查点匹配；非默认调试值使用schema=3，原schema=1/2继续采用0.2和64。运行中保存不会改变有效值或本进程启动快照；保波程序API重建时保留这两个数值。默认参数的含义与原有数值路径一致，调试范围不等于所有场景的稳定范围。

两个正式入口的独立细沫层当前隐藏，细碎白沫强度、像素直径、半宽和聚簇强度均禁用；参数调整不会重新显示该层。水面白沫、岸脚及共享白沫历史参数仍按各自消费路径生效。

各窗口“保存参数”先提交数字输入框中尚未按回车确认的文字，再校验并保存当前场景所有适用参数；提交失败会阻止写盘并显示错误。“加载已保存参数”恢复本次运行可应用的项，将重启项保留为待生效；“恢复默认”仅修改本窗口参数，不自动写盘。参数文件为 `user://parameters/startup.json`，格式为 `{version:1, scenes:{场景key:{参数标识:值}}}`，不保存GPU场状态。数值以完整精度序列化，临时文件flush后替换目标。错误格式、未知场景、未知参数或非法值拒绝加载并显示错误，无有效用户配置时使用默认初态。

启动时只读取一次已保存配置，后续保存不会改变该进程的启动快照。新进程按同一入口将重启值注入配置，再构建运行域；实时及工具项在场景绑定时应用。开发探针可用 `--parameter-config=<路径>` 指向隔离文件，`--ignore-parameter-config`跳过启动覆盖。

场景切换使用各场景冻结配置和当前会话检查点；各场景外观及待应用值分别保留，工具选择与工具参数沿用会话共享。检查点继续严格校验配置与来源，不自动投影任意参数差异。参数保存不等于沙场保存，改变物理配置后不保证旧检查点可恢复。

窗口位置、大小和显隐单独保存到 `user://parameters/windows.cfg`，不随参数保存按钮控制。窗口打开时校正位置以保证标题区域可见。主窗口失焦后结束笔画、释放鼠标捕获并隐藏指针预览；相机全局按键轮询与世界事件入口均要求主窗口获焦，模拟和维护重试继续运行。

## 冲岸水花

水窗口新增“冲岸水花显示”（visual_shore_splash_enabled）和“水花尺寸”（visual_shore_splash_size），均实时生效并沿用现有按场景保存规则。UI显示开关仅隐藏绘制，池仍继续更新；尺寸默认1、范围0.5–2。入口shore_splash_enabled为启动前冻结开关，false停止该阶段计算。瞬态不写检查点，恢复新generation时清空；原生ABI未扩展，新增源码与配置仍参与原有严格来源校验，旧档不自动兼容。图像字节数不等于驱动显存或帧成本，完整负载成本需独立实测。

## 参数目录维护

`python tools/parameter_windows/build_windows.py`从生成器中的参数声明离线生成目录JSON和静态窗口场景，`--check`核对生成物，不在游戏运行时创建控件。新增参数必须同时接通消费路径并验证生效方式，不能仅添加目录项。完整标识与范围见[机器参数目录](../assets/parameters/catalog.json)。
