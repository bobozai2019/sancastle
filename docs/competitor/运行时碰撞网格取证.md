范围为沙面碰撞输入、采样缓存、网格发布及物理查询。GameAssembly.dll SHA256 `147030ecf9527a25250238120364eb761390b99688b1812c4ea555b3b04e56a0`，metadata SHA256 `aa4457307746c4552541b6cedd4809fdaccf33eef03964a9e2300de5a09e1606`；布局仅适用于该模块组合。

来源为[已记录字段与物理观测](brush_hit_evidence_inventory.json)。原观察中的绑定／几何／查询按来源为C3，编辑贡献解释为C2；当前索引不包含全部可直接重验的运行时数组，因此不承诺具体误差上限、输入次数或完整生命周期。

## CPU缓存与网格

沙面使用PlaneChunk关联的MeshCollider。所记录输入按每顶点四个readbackIndices读取CPU ReadbackCells中的sandAmount并作float32平均，不是让PhysX直接读取GPU渲染纹理。

| ReadbackCell偏移 | 字段 | 类型 |
|---:|---|---|
| 0 | waterVelocity | float2 |
| 8 | groundTangent | float2 |
| 16 | waterAmount | float |
| 20 | sandAmount | float |
| 24 | groundHeight | float |
| 28 | crestSpawn | int32 |

stride32，crestSpawn不能按float有限值解释。记录中存在65536项／2 MiB与32768项／1 MiB配置；不能把它们和test1单帧辅助输出混成同次状态。碰撞分块观察包含16×8、128项，不代表任意时刻固定配置。

## 发布与共享输入

多个chunk可共用meshC对象。必须在目标块完成Job／SetVertices／sharedMesh绑定后的窗口，核对chunk、collider、Mesh、变换和绑定序号，再读取输入；全部chunk更新后任意抓取共享Mesh，不能证明它就是某个较早collider消费的状态。对象或数组重建后，旧指针不能继续充当身份。

实际getter的顶点、索引、submesh、indexFormat、baseVertex、localToWorld、bounds、enabled、layer、trigger及convex应分别核验。OBJ是这些数组的派生表示，不是独立物理证据；PhysX cooked payload／BVH没有取得。

## 查询与因果边界

应按真实Physics.Raycast返回的collider和face ID选导出几何的相交面，再比较交点、距离和法线。公共边／顶点可关联不同三角形，任意选一个最近面可能制造法线差异。其他collider也可能成为更近命中，单次命中目标不代表该位置始终无遮挡。

记录中的中央拾取还包含参考平面回退与Readback法线补充；补充后的normal不能当成未经处理的物理面法线。相同对象、XZ和拓扑只建立前后几何对应，不能证明所有Y变化都来自一次编辑。背景模拟、其他输入与采样间隔仍需排除。
