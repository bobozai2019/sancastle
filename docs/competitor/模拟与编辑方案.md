# 竞品沙水模拟

范围为test1沙场、水场与编译程序。来源捕帧SHA256 `761aa980c2426f75a1fa7364bf6d2655ff4dd20ea76566e630ee5b53ea0ec5b2`，源程序与有效常量见[核心程序索引](evidence/shader_execution_20261025/selected_v1/manifest.json)。以下指令和绑定为C3，可读机制解释为C2；不包含工具业务算法。

## 沙场与水场

沙场1024×512、每格16 B；水场512×256、每格16 B。两者共享30×15场景单位的域，分辨率不同。沙更新先于这段水更新，随后床面核把沙高度映射到水格；它不是每个水积分子步都执行一次完整沙交换。

Ground.VelocityIntegration结合邻格沙状态、水场采样、坡面、阻尼和限速更新沙运动及悬沙输运。Ground.HeightIntegration同时包含上风搬运、平滑、容量交换和高度限制，不能将其解释为单纯复制高度。

## 容量侵蚀与沉积

E1478的有效结构可写为：

```text
h = max(A_raw - 0.05, 0)
C = min(30h, 1) * sedimentCapacity * |v|^gamma
```

本帧sedimentCapacity约0.003、gamma=1。悬沙低于容量时取沙，高于容量时沉积；所选交换系数约0.015／0.005，交换段未另乘dt。海侧权重通过`1-alpha`抑制交换。沙高最终限制在本帧0..10并量化。

这一局部成对交换不证明完整沙量链严格守恒；上风搬运、平滑、边界及量化须分别考虑。高度限制也不等于任意工具都能挖至Y=0，更不证明物理基岩或所有位置的可挖厚度。

## 水床反馈

E1484把水格中心映射到沙场，四点插值两种高度通道，取较大值作为水所见床高。原沙缓冲和完整字段重编码都必须保留；不能把“主要更新床高”解释为其他位永远不变。[六核原程序及依赖](evidence/water_solver_reconstruction/t03_six_kernel_audit_20261025_v2/reference_set.json)。

## 编辑边界

常规床面更新与专用GPU笔刷不是同一操作。test41的Ground.Paint、Water.Paint来源记录支持参数／纹理驱动的编辑路径，但当前正式证据不能补齐全部笔刷原输入、CPU放置规则或一笔编辑的完整水沙结算。固定标高、自动补底、体积账本、库存及工具门控不列为原作已确认算法。
