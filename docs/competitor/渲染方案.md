# 竞品沙滩渲染结构

来源为test1捕帧SHA256 `761aa980c2426f75a1fa7364bf6d2655ff4dd20ea76566e630ee5b53ea0ec5b2`。[全帧程序与资源索引](evidence/shader_execution_20261025/evidence_index.json)支持所选绑定、程序与帧内结构，不能视为原始HLSL或全部运行时状态。

## 数据流

沙场／水场更新 → 高度场及公共光照 → 沙底绘制 → 场景色与深度副本 → 水面光学 → 独立泡沫片 → 体积效果与后处理。

这是带保留状态的数据依赖，不表示所有输入均在本帧首次生成。例如源汇核可读取既有障碍图，光照也可混合既有结果；跨帧延迟不能只由箭头推断。

## 沙体与水面

沙面由多个读取高度场的patch绘制。所选完整帧中沙面主绘制117次、水面主绘制64次；次数不是物体数量或系统全部成本。沙场尺寸和高度解码见[几何](test1场景尺寸与沙深度.md)，水传播见[水求解](水求解实现方案.md)。

沙底先产生颗粒、湿色、焦散及受光颜色。水面读取场景色和深度后作折射、RGB吸收、掠射色混合与太阳高光；细法线随流场做双相位合成。所选水PS无独立环境cubemap及屏幕反射射线步进，也未见额外青色散射加法；该范围不能推广到其他绘制和后处理。[材质公式](水体材质_RDC详解.md)。

焦散是沙底材质的3D纹理动画采样，受流场、时间、厚度和光照调制，不是水PS内独立生成的物理光线求解。纹理制作方法未知。

## 混合、深度与光照

所选水面使用SrcAlpha／InvSrcAlpha、Add，GreaterEqual深度测试且写深度；独立泡沫片同类混合但不写深度。低分辨率公共光照由高度场相关compute生成并滤波，再被沙和泡沫等消费者使用。泡沫更新和绘制详见[泡沫](泡沫.md)。

捕帧主HDR为1280×720 RGBA16F，最终交换链1920×1080；体积／景深工作纹理640×360，公共光照256×128。不同阶段图像不能在不说明分辨率、曝光和色彩空间的情况下直接比较。

## 重放成本的适用范围

GTX1050／D3D12的RenderDoc GPU事件计时中，高度场光照约5.372 ms、体积散射约2.726 ms、完整所选水更新约0.813 ms；这些是工具插桩的离屏重放中位数。图形事件时间包括几何、像素与固定管线，不是单独的PS耗时。[计时来源](evidence/shader_execution_20261025/timing_v1/manifest.json)、[事件汇总](evidence/shader_execution_20261025/summary_v1/summary.json)。

这些值不代表原游戏实时窗口耗时、VSync等待或GPU利用率原因，不能据此计算与其他实现的速度倍数。完整运行成本、原作资源制作流程及所有绘制的视觉贡献仍未闭合。
