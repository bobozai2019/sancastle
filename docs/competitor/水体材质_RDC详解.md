# test1 水体材质：RDC 指令、有效参数与 Godot 差异

更新：2026-10-11。角色：confirmed_visual_shader_analysis。范围：test1 沙底 E5006 与水面 E6083；当前 Godot 默认 main 的 reference_v1 配置。此次仅取证和分析。

这次直接复取了编译材质、常量、有效纹理和像素调试轨迹。竞品本帧水面主体是“已受光的水底颜色 → 折射查询 → RGB 吸收 → 少量掠射颜色混合 → 极窄太阳高光”，没有在水 PS 中加入我们的青色散射补色。焦散在底面材质中完成，使用随时间变化的 3D 纹理和水流偏移。当前 Godot 虽然已换用竞品法线纹理，光学、动画和焦散公式仍有明显结构差异。

这里的“已确认”针对捕帧内具体指令和数据，不表示已经取得原始 HLSL、真实焦散生成器、米制尺度或完整动态效果。

## VIS-WATER-04：透底靠分通道吸收，Alpha 不是清晰度的唯一开关

分类：观察事实及编译指令等价式，C3；E6083 PS 指令42–75、81–116及像素复算直接支持。

折射先用最终法线 XZ 乘0.0121得到 UV 偏移，Y方向乘实际宽高比。查询偏移位置的深度；如果落到水面前面的物体，就回到原 UV。随后在最终选定的同一 UV 读取颜色和深度，用 cb66–69 反投影出不透明表面世界位置，计算与当前水面位置的欧氏距离 `L`。

它没有用模拟深度简单除以视角余弦作为主体光程，也没有在这段代码按水深把折射倍率放大。其固定 UV 偏移不是完整 Snell 折射。当前 Godot 另有越界保护与原 UV 光程选择，不能当作原作公式。

指令中的 `exp` 是底数2，等价式为：

```text
T_rgb = cb131.rgb × exp2(-8.656170 × L × cb132.rgb)
      ≈ (0.758970, 0.883854, 0.968461)
         × exp(-L × (6.000000, 0.856013, 0.336771))
B = scene_color(selected_uv) × T_rgb
```

这个 `T_rgb` 是乘到水底色的有效 RGB 乘数，含 cb131 的固定着色，不是严格物理归一透射率。红色很快被压低，绿色和蓝色保留较多；水的颜色来自原底色的有色过滤。**此 PS 没有 `scatter_color × (1-T)` 的附加水色项。**

当前 Godot 默认链：main → reference_v1 bundle → style_reference_v1 → reflection_compiled_v1 → foam_combination → optics_selected。所选光学仍是：

```text
T = exp(-L / mix(0.25m, 0.4m, depth_gate))
C = bed × T + mix(shallow_cyan, deep_cyan, depth_gate) × (1-T)
```

它对 RGB 使用同一个 T，并用青色补足损失。浅水保护在0.03–0.18m之间逐渐退出，不能保护整个可见河底。此后水底纹理对比会随着 T 一起减弱，青色底座变强；“水很快糊成色块”有明确的公式机制。当前光程改成原 SCREEN_UV 重建已经比旧垂直近似更稳，但仍没有更换这套着色配方。

示例只比较**同一数值公式输入 L**，竞品场景单位尚未校准到 Godot 米制，不能当作同物理水深对照；Godot浅水保护/受光/反射未计入：

| L | 竞品有效 RGB 乘数 | Godot 0.4m 的纯指数项 |
|---:|---|---:|
| 0.1 | (0.417, 0.811, 0.936) | 0.779 |
| 0.2 | (0.229, 0.745, 0.905) | 0.607 |
| 0.5 | (0.038, 0.576, 0.818) | 0.287 |

这不表示竞品所有通道吸收更少：竞品红色吸收反而更强。差异在于保留其他通道的底纹信息，而不是统一抹去对比再补上水色。

反证与未知：单帧和三个岸边样本不能证明整个游戏任意水深都清晰；此处无散射加法也不排除其他 draw 或后处理的颜色变化。默认 Godot 链与源码已快照；本次未启动 Godot，不把静态配置分析冒充新的实机像素对照。

## VIS-WATER-06：表面反射很克制，高光极窄

分类：观察事实及编译指令等价式，C3；E6083 PS 指令76–116、纹理槽和像素轨迹完整。令 `V` 为表面到相机方向、`N` 为最终法线、`S` 为阴影可见度，`c=saturate(dot(V,N))`：

```text
base = B × (0.9 + 0.2 × c^6)
F = 0.75 × (1-c)^5 × min(S+0.25, 1)
H = normalize(V - cb123.xyz)
spec = cb125.rgb × S × saturate(dot(N,H))^1500
water_rgb = mix(base, cb121.rgb, F) + spec
```

本帧的“反射颜色”目标是固定 RGB `(0.801526,0.649696,0.506065)`。因此不能说竞品没有固定颜色；它的自然变化主要来自真实输入法线、视角、阴影和非常窄的高光。该 PS 没有映像式环境反射，固定颜色的物理来源仍未知，不自动命名成天空或真实环境采样。

当前 Godot 仍以 `(0.025 + 0.42 × (1-c)^5)` 混合平面反射/背景，默认 reflection_strength=1。平面反射主要绘制三个 rock，其他区域多是背景色；细法线扰动已启用，但背景恒色区被扰动也不会出现纹理变化。当前新候选已修复颜色编码和 UV-Y 方向，不能再把它描述为完全未扰动的旧反射。

| c | 竞品全受光 F | 当前 Godot 反射权重 |
|---:|---:|---:|
| 1.0 | 0% | 2.50% |
| 0.75 | 0.073% | 2.54% |
| 0.5 | 2.344% | 3.813% |
| 0.25 | 17.80% | 12.47% |

竞品并非所有角度反射都更少；掠射时反而可以更强。俯视到中等视角，竞品很少用表面颜色覆盖底面，而我们的2.5%基底始终存在。阴影 S=0 时竞品 F 再降为全受光的1/4，太阳高光归零。

当前 reference_v1 高光 gain=1.92、exponent=192；竞品指数1500。只比较 `cos(theta)^p` 的半峰宽：192约4.87°，1500约1.74°。当前亮区的法线角度范围更宽；gain不能弥补宽度差。不同照明、HDR与法线分布未统一，不能仅据参数计算最终亮度倍率。

三个已调试岸边像素的 F=0.2897% / 0.1873% / 0.1120%，太阳高光约零；这三个位置的清晰与自然无需强表面反射。改变光向/视角后结果会不同。

Godot适配方向：先隔离反射和高光，验证低反射基底/更窄高光；保留受阴影影响与法线动态。此建议不要求扩建SSR，也不把真实岩石倒影需求混进原作水PS的证据。

## VIS-WATER-05：同一张法线纹理，动画和合成仍不同

分类：观察事实及编译指令等价式，C3；E6083 PS 指令3–41和 VS66–105。WaterNormal2D681 raw hash与历史复取一致。令 `P=world_position.xz`，`t=cb113.y`，`flow=clamp(v4.xy,-0.5,0.5)`。在本帧正时间范围内：

```text
phase = normal_texture(P × 0.05).b + 0.8 × t
a = frac(phase)
b = frac(phase + 0.5)
A = normal_texture((P - flow × (2b-1)) × 0.2 + 0.25).rg
B = normal_texture((P - flow × (2a-1)) × 0.2 - 0.25).rg
rg = mix(B, A, 2 × abs(a-0.5)) × 2 - 1
detail_normal = (rg.x, sqrt(1-dot(rg,rg)), rg.y)
N = normalize(macro_normal + detail_normal)
```

原指令包含有符号小数处理；上式限本次正 phase，不扩展到任意负时间。v4.xy在水VS由状态缓冲解码，确实参与水PS；它不是任意美术设定的统一滚动方向。纹理蓝通道用来打散相位，两路错半周期交替混合。把循环 UV 重置处的采样权重压低，是该公式的直接数学效果；实际长时间无缝性还需连续观察。

当前 Godot 的 RG解码确实读取同一纹理，但用两层不同尺度/方向/固定速度：原尺度0.18/0.47乘当前频率2，原gain0.06/0.025乘8；实际尺度0.36/0.94、gain0.48/0.20。它不使用上述蓝通道 phase，也不读取该 flow 来驱动细法线动画。

另外，竞品先把两个 RG 采样混合，再恢复一条完整单位法线并与 macro 相加；Godot是把两层局部XZ斜率加到已有法线。这两套幅度不能一比一对照。“已换成竞品贴图”只能证明输入资源复用，不能证明微波形态、速度或高光碎度等价。

未知：时间输入与真实秒数、流速单位、纹理最初生成法仍未校准。不要直接把0.8称为Hz，或把0.2称为每米。

## VIS-SAND-04：焦散是底面材质中的 3D 动画采样

分类：观察事实及编译指令等价式，C3；E5006 PS指令0–39、54–64与末段受光链。运行时 R1105为256×256×64 R8_UNORM、9 mip；mip0为4194304字节，hash与历史记录一致。切片是从原始texel派生，不是AI图：

![运行时焦散体纹理的六个切片](../../test_output/competitor_water_material_20261011/analysis_v1/caustic_volume_slices.png)

这张图显示不同 z 层内的亮线结构变化，不能独立证明变化秒数。纹理是否来自离线物理光线模拟、程序生成或其他制作方式仍未知；包内Caustics932与运行时1105全部texel同一性仍待复验。

令 `P=床面世界XZ`、`g=Sand纹理(P×0.3).g`、`f=v5.xy`（VS从水状态解码的向量）、`q=v4.xy`（VS从水状态解码的法线分量）、`h=v4.w`（渲染厚度字段），正 phase 情形的等价采样是：

```text
phase = g + 0.5 × t
a = frac(phase)
b = frac(phase + 0.5)
base_uv = P × 0.25 + q × 0.1
A = Caustics3D(base_uv - f × (2b-1) × 0.1 - 0.5,
               (g + t - 0.5) × 0.2)
B = Caustics3D(base_uv - f × (2a-1) × 0.1 + 0.5,
               (g + t + 0.5) × 0.2)
pattern = mix(B, A, 2 × abs(a-0.5))
```

两路查询不仅在 XY 受 flow 偏移，Z 也随时间改变，并且用沙纹理绿色通道错开局部相位。不是仅将同一张二维图匀速平移。

亮纹还乘 `exp2(-1.731234×h)≈exp(-1.2×h)`、太阳颜色长度、厚度门控及沙面法线Y门控，再加到沙色并saturate，之后进入底面的光照/阴影。它的可见度随水层、床面朝向和光照共同变化；完整底面 PS 另有状态纹理贡献，本条不把它们都叫焦散。

当前 Godot 使用 [caustic_fold_v1.png](../../tests/visual_water_alignment/prototypes/caustic_fold_v1.png)：二维亮线的白边粗、强弱较一致；这是源纹理观察，不是不同分辨率下的最终画面对比。shader以床面UV×3加 `t×(0.0013,-0.0007)` 平移，用mip2/5与sqrt柔化，按 `exp(-depth/0.17m)` 衰减，再以strength0.8加到ALBEDO。柔化能改变边缘和频率，不能恢复竞品体纹理的结构演化、水流偏移和局部相位。

Godot适配方向：优先验证已复取的3D纹理及两路相位采样，在床面材质中表现；用本项目现有可见床面/水流字段和统一表现时钟适配，保证冻结/暂停/恢复一致。先清理透射遮盖，再评价焦散，否则底面上的细亮纹会被上层水色吞掉。真实焦散求解器不是复现这个捕帧材质的前置条件。

## VIS-WATER-07：岸边混合与实际像素

分类：观察事实，C3；水VS73–78、PS0–2/117及管线blend。VS输出 `v4.w=max(decoded_amount-0.05,0)`；PS在v4.w<1e-5时discard，否则 `alpha=saturate(100×v4.w)`。原0.05是场景单位，不宣称物理5cm。管线使用 SrcAlpha/InvSrcAlpha、Add，深度写入开启、GreaterEqual。

| E6083像素 | 光程L（原作单位） | 有效RGB乘数 | F | Alpha |
|---|---:|---|---:|---:|
| (721,460) | 0.092056 | (0.4369,0.8169,0.9389) | 0.2897% | 0.3496 |
| (772,465) | 0.054040 | (0.5488,0.8439,0.9510) | 0.1873% | 0.0879 |
| (821,466) | 0.047328 | (0.5713,0.8488,0.9531) | 0.1120% | 0.0652 |

表内RGB是水PS乘到底色的系数；shader输出随后仍按Alpha与目的颜色混合，表不是最终Present色。三个点位于同一patch岸边，不代表深水统计。

当前Godot使用 `smoothstep(0.001,0.015,depth)` 再乘coverage作为Alpha；主体区域即使Alpha≈1，也可以靠scene_color透底。因而“降低Alpha”不能单独替代光学修正；同时也不能忽略竞品岸边极薄渲染层的低Alpha混合。直接复制竞品0.05偏置可能改变我们已有水沙接触契约，适配必须以可见几何与同generation完成态为准。

## 当前差距的归因与下一步顺序

| 用户观察 | 已证实的材质差异 | 因果判断及适配优先级 |
|---|---|---|
| 焦散更自然 | 竞品3D时变图案+flow偏移+局部相位；我们2D平移+滤波柔化 | 结构差异C3；贡献大小需Godot同态消融。第二优先，先保住底纹 |

| 能看清河底 | 竞品RGB过滤、无该PS散射补色、岸边低Alpha；我们统一T+青色补色，保护只覆盖薄层 | 配方C3；当前浑浊的机制解释有明确数学依据，实际画面占比待同态对照。第一优先 |

建议做三个独立候选：A只替换吸收/补色配方；B在A上替换底面3D亮纹采样；C再替换细法线相位及窄高光/低反射基底。固定seed、tick、相机、床面、曝光及profile，比较底纹对比、阴影内外、岸边/深区、朝光/背光和连续运动；不改权威水沙或旧Gate。原作单位先校准，不直接把数值套进Godot米制。
