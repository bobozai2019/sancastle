# 悬沙投放约束

“投流沙”是统一`VOLUME_DELTA`操作的悬沙目标，使用圆盘或扫掠声明，增加sediment而不直接填床。声明、目标枚举及字段权限由公共注册表和Intent校验，物理协议为512B命令／384B结果。

仅水深大于0.001m、无障碍的有效格参与足迹分配；全干足迹拒绝。投放不直接改变rock、sand、水深、动量或材料，也不执行抬床排水。普通体积请求沿用名义`APPROXIMATE_EXTERNAL`账户，不能把投放回执描述为每笔精确外部源汇。

后续输运随数值求解器运行：一阶路径在`sediment_step_momentum.glsl`中搬运和交换；MUSCL在两个Euler阶段分别搬运，再对接受步调用`sediment_exchange.glsl`进行床沙交换。干格渐进沉降，不瞬时清空。暂停允许投放，输运和沉降等实际水时钟继续后推进。

沙云材质`suspended_sand_cloud_momentum.gdshader`读取同generation完成态的水深、二维动量、床面与悬沙，使用共同表现时钟。这是二维深度积分悬沙的可视化，不表示三维沙粒轨迹。

状态、账户及检查点规则见[技术规格](../../当前技术规格.md)，交换公式见[容量侵蚀](ADR_竞品容量侵蚀_v2.md)。
