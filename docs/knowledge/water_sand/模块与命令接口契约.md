> 从 `docs/history/sandcastle_water_sand_coupling/契约/` 迁入。文中 `验收/` 路径指向该历史任务包的验收记录；`frozen v1` 只约束接口，不代表当前 test1 验收通过。当前状态见[项目现状](../../README.md)。

状态：frozen v1（Gate 1B，2026-09-28）。本项目无网络 API；此文件定义等价的字段级运行时接口。实现从 CPU 队列迁移 GPU 时不得改变字段/排序/错误语义，变更须新 ADR 与版本号。

## 模块职责

| 模块 | 权责 | 不得承担 |
|---|---|---|
| `SandWaterDomain` | 坐标、边界、固定时钟、generation | 具体 shader pass |
| `SimulationBackend` | pipeline/RID、ping-pong、pass 顺序 | UI/输入解释 |
| `ToolCommandQueue` | 校验、排序、批量上传、重放 | 直接改渲染网格 |
| `TerrainVisual` / `WaterVisual` | 采样最新完成态 | 写权威物理状态 |
| `CollisionProxy` | 脏块、异步回读、低精查询 | 每帧全图同步回读 |
| `AuditRecorder` | 账本、错误、性能、回放证据 | 修改模拟结果 |

## ToolCommand schema

```json
{
  "domain_id": "main_beach",
  "generation": 1,
  "sim_tick": 0,
  "command_id": 1,
  "kind": "remove_sand",
  "shape": "circle",
  "transform": {"position_m": [0.0, 0.0, 0.0]},
  "radius_m": 0.25,
  "strength": 1.0,
  "amount_m3": 0.01,
  "seed": 1
}
```

| 字段 | 类型 | 必需 | 允许值/校验 |
|---|---|---:|---|
| `domain_id` | StringName | 是 | 活跃域 |
| `generation` | int64 | 运行时可选、GPU 提交时必填 | 与活跃域 generation 一致，否则 `inactive_generation`；持久 JSON 不保存此易失值，加载时绑定当前 generation |
| `sim_tick` | int64 | 是 | ≥当前已完成 tick |
| `command_id` | int64 | 是 | 域内唯一、单调 |
| `kind` | enum | 是 | `remove_sand`,`place_sand`,`smooth`,`compact`,`debug_add_sand` |
| `shape` | enum | 是 | `circle`,`swept_segment` |
| `transform.position_m` | Vector3 | 是 | 可转换到网格 |
| `transform.end_position_m` | Vector3 | `swept_segment` 时是 | 线段终点；与起点相同则退化为圆 |
| `radius_m` | float | 是 | >0 且 ≤4 m |
| `strength` | float | 是 | [0,1] |
| `amount_m3` | float | 条件 | 取/放沙必需，>0 |
| `seed` | int64 | 是 | 确定性 |

排序键固定为 `(sim_tick, command_id)`。跨格拖动必须使用扫掠线段或按距离补采样。同格多命令须确定性聚合，不依赖无序浮点原子写入。

`submit(command)` 成功返回空 `StringName`，仅表示已入队；失败直接返回错误码，不产生 `CommandResult`。`apply_due_commands(tick)` 返回该 tick 已处理命令的结果数组，只有 `applied` 会改变权威状态。`command_id` 在一个域内严格递增，场景重建后 `generation` 必须递增；旧异步回调和带旧 generation 的工具命令不得触碰新域。CPU 原型的 JSON 回放格式版本为 1，仅保存命令及域尺寸，不含初始场景/种子或权威水体检查点；调用者必须重建相同初态，不能当完整存档。

`swept_segment` 的 `amount_m3` 是整个命令的总搬运量，不随线段长度或补采样数重复计费；覆盖权重按单元中心到线段的最近距离归一化。详见 ADR-005。

## CommandResult schema

| 字段 | 类型 | 必需 | 说明 |
|---|---|---:|---|
| `command_id` | int64 | 是 | 对应命令 |
| `status` | enum | 是 | `applied`,`rejected`；入队接受由 `submit` 空返回值表示 |
| `applied_tick` | int64/null | 是 | 实际生效 tick |
| `sand_delta_m3` | float | 是 | 工具账户变化 |
| `dirty_chunks` | PackedInt32Array | 是 | 碰撞/显示更新范围 |
| `dirty_cells` | PackedInt32Array | 是 | CPU 参考及局部调试范围，GPU 实现可只用于调试 |
| `error_code` | StringName | 是 | 成功为空 `StringName()`；失败为下表错误码 |

错误码：`invalid_command`、`insufficient_sand`、`out_of_domain`、`stale_tick`、`inactive_generation`、`backend_unavailable`。

跨 tick 撤销/重做仅在暂停状态允许。CPU 参考实现对同 tick 最后一条命令用快照快速撤销，跨 tick 将有序命令及被拒绝尝试从相同初态离屏重演到当前 tick；只有水/沙/二维动量、潮汐相位、账本和每条结果状态全部一致才原子替换当前域，并推进 generation。当前全量重演约 7 秒/100 tick，不是生产延迟承诺；T03/T08 可换有界检查点/差分实现，但事务和状态语义不变（ADR-006）。

## 生命周期

1. 主线程创建场景节点和空 `Texture2DRD`。
2. 渲染线程取得主 `RenderingDevice` 并创建资源。
3. 每个 pass 只有明确输入和唯一输出；完成态才暴露给材质。
4. 场景重建增加 `generation`；旧异步回调必须丢弃。
5. 快照在 tick 边界冻结新命令，等待该 tick 完成后读出。
