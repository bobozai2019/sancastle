# 统一流程模块与命令约束

适用main与test1_geometry。接口以[DomainRuntime](../../../scripts/simulation/unified_edit/domain_runtime.gd)、[Intent](../../../scripts/simulation/unified_edit/intent.gd)和[layout.gd](../../../scripts/simulation/unified_edit/layout.gd)为准，完整字段见[技术规格](../../当前技术规格.md#身份abi与容量)。

| 所有者 | 职责 |
|---|---|
| PlayerInput／注册表 | 将手势转换为Intent，验证并冻结声明、模板及参数 |
| DomainRuntime | 当前域、恢复候选、退休代与消费者换代 |
| Pipeline | 唯一有界队列、三工作槽、顺序录制和完成回执 |
| Executor／Water／Coupled | 公共编辑事务、水数值阶段及耦合；不另建调度队列 |
| Views／Height／Probe | 只读完整完成态、预览、分块碰撞及批量采样 |
| Checkpoint | 原始状态捕获、配置／来源验证与候选恢复 |

## 命令与结果

Intent携带domain、generation、command_id、tick、profile身份及位置；其余参数由操作声明约束。身份为int64，不经float传输；未知字段、非法组合、非有限值和越界值拒绝。物理命令512B、结果384B，批次输入／完成头各96B，每批最多64条。

接纳与完成分别报告：成功接纳不代表GPU已执行；APPLIED必须有权威变化，NO_CHANGE可以只更新coverage，REJECTED不得留下半笔字段修改。BEGIN／sample／END沿同一队列，背压时END保留重试。fatal／unknown保留原始故障和所有权，不能伪装成可重放的普通拒绝。

结果必须匹配命令、generation、slot／lease、配置身份与实际tick。旧代、重复或不匹配回执不得重复结算。command_id高水位随检查点保存，恢复换代不从1重用。

## 消费者与生命周期

编辑、水tick和显示工作沿同一RD有序流录制，后继不等待CPU回执或碰撞收敛。材质与读者只消费同generation、完整state_seq及实际完成时钟。碰撞允许在既定误差／版本规则内滞后，恢复候选须完整备齐64块后在物理边界换代。

工作槽仅在GPU真实结束、回执消费和Transport同租约回收确认后复用。退休代等待解绑、最后读者及worker真实终结；超时不是释放证明。当前提供检查点保存恢复，不承诺任意逐命令撤销／重演的逐位确定性。
