## 已验证范围与剩余边界

- 四入口、十一物理profile、显示碎石、保存恢复/切换/关闭与故障所有权通过本轮功能冻结。平滑/压实为API能力，产品面板没有对应按钮。
- 实际180.557秒混合输入、355次手势、909个GPU结果，以及之后十轮完整生命周期通过；生命周期耗时不混入三分钟输入时长。
- 48次成本对照只覆盖GTX1050、D3D12、1280×720、VSync1、暂停干地与规定输入。墙/铲输入帧P50改善，挖填未见超过噪声门的退化；P99和其他负载的整帧成本未知。详细数字见[规格中的验证范围](当前技术规格.md#验证范围与性能边界)。
- 接近test1的长期视觉目标仍暂停。历史母任务 **14/15、RG4未通过**，详见[收尾记录](history/sandcastle_test1_reverse_rebuild/收尾记录.md)。本轮流程完成不改变其视觉或旧性能判定，也未确认原作未来动作时序、现实单位或完整算法。
