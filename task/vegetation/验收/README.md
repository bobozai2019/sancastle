# 植被验收

四种原创草簇已接入四个正式场景。覆盖确定性分布、水流弯曲、挖沙根部下移、堆沙遮埋、暂停和恢复；植被仅读取权威沙水数据。

运行配置：Godot 4.7.2、D3D12、GTX 1050、可见窗口 1280×720。四场景启动与渲染检查通过；主场景交互、恢复及损坏存档拒绝共 59 项检查通过。连续观察窗口为 60.343 秒，不代表小时级长稳。

成本按完整场景暂停后开/关/开对照，VSync=1，每段 90 帧：主视口 GPU 中位数约 12.48/10.93/12.48ms，增量约 1.55ms；该结果不是模拟吞吐。

`运行验证索引.json` 定位通过运行及其哈希；`运行证据.zip` 保存运行日志、配置与源码指纹、检查结果、交互二进制快照和正常/损坏存档。失败与被取代的运行日志也保留在归档中。正式资源与运行均不依赖 test_output。归档内源码快照压缩包路径属于原始测试输出位置，源码以同次提交和指纹复验。

成本及连续观察使用规范化前的源码；`换行规范化.json` 与 `eol_sources_before.zip` 保留 CRLF→LF 的等价变更证据。最终交互运行使用规范化后源码。架构结论以 `架构审查.md` 和归档内 architecture_final_v2/report.json 为准，场景结构见 `场景结构_最终.json`。

当前技术说明见 [植被](../../../docs/植被.md)，竞品证据及适配边界见 [水草与岸草功能分析](../../../docs/competitor/水草与岸草功能分析.md)。
