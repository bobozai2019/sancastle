共同规则：

1. 开始前在执行状态.md登记唯一修改锁；先读依赖验收与被冻结契约。
2. 不改竞品原包/RDC、历史报告、用户已有未提交改动；共享接口变化先新ADR，再复验受影响项。
3. 源码/资源属于运行目录，验证工具属于tests，机器数据属于test_output；不能让main依赖task机器产物。
4. 小目标完成后更新本任务细则、执行状态的小目标索引/总量和实际证据；总纲保持计划起点。
5. 默认不启用subagent，也不因“可并行”字样启动任何其他agent。
6. 每项回报：完成内容、修改文件、G01–G05状态变化、实际命令/结果、契约变化、问题与遗留、Gate证据路径。
