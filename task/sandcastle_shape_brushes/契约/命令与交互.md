## 1. 资源边界（C01）

BrushDefinition是可编辑Resource，内置资源绑定保存在.tres中。定义与实例参数分开：定义描述模板/截面和合法范围，命令保存该次实际消费参数。UI不能直接指定任意文件或GPU纹理RID。

| 字段 | 类型 | 必需 | 含义/校验 |
|---|---|---:|---|
| schema_version | int | 是 | 明确版本，不接受未知版本 |
| brush_id | StringName | 是 | castle_v1、shovel_v1、wall_v1白名单 |
| operation | enum | 是 | stamp_target、wall_target、shovel_transfer |
| template_id | StringName | 城堡 | 内置模板ID，解析资源后核对hash |
| template_size / sample_spacing_m | Vector2i / float | 城堡 | float32样本网格和局部XZ单位，有限且正 |
| template_height / foundation_mask | float32数据 / mask | 城堡 | 高度≥0；基础mask与形状mask独立，不能用0高度判定是否覆盖 |
| default_params / param_ranges | Dictionary | 是 | 尺寸、高度、深度、宽度、旋转；字段白名单 |
| max_add_m3 | float | 增沙刷子 | 有限安全配额，不等于当前UI旧工具amount |
| max_transfer_m3 / max_ridge_height_m | float | 铲子 | 每段有限搬运上限和肩部接纳高度上限 |
| material_profile_id | StringName | 是 | G4定案的有限压实/支持策略，不能关闭全域物理 |
| definition_hash / template_hash | SHA256 | 是 | 对真实消费的内容计算；恢复与manifest使用 |

资源不得位于task/、test_output/。数据与索引同时保留：生成器版本/命令、参数、样本布局、尺寸/体积统计、hash。第一版程序生成一个模板，允许以后添加白名单预设。

## 2. 运行时接口（C02）

拟定接口：begin_stroke(definition, params, hit) → StrokeAdmission；append_path_sample(stroke_id, hit) → SampleAdmission；end_stroke(stroke_id, reason) → draining；submit_brush_command(command) → StringName；最终结果由异步BrushResult交付。

资源/参数和screen→world解释由主线程处理；GPU读取同一完成态的沙、基底及材料，计算形状候选；回执与账户结算由现有唯一所有者处理。没有HTTP、数据库、OpenAPI步骤。

### BrushCommand v2

| 字段 | 类型 | 必需 | 校验/意义 |
|---|---|---:|---|
| schema_version | int | 是 | 2；旧ToolCommand仍走旧分支 |
| domain_id | StringName | 是 | 当前活跃域 |
| generation | int64 | 是 | 与当前域一致；旧回调无效 |
| command_id / stroke_id | int64 | 是 | command_id沿用域内单调身份；stroke_id不能通过float传输 |
| sim_tick | int64 | 是 | 不早于当前完成tick；排序仍按(sim_tick,command_id) |
| sample_index | int | 是 | 笔内有序；重复样点不二次应用 |
| input_revision | int64 | dispatch时 | 实际执行时绑定最新完整完成态，不能把入队时revision当执行revision |
| brush_id / operation | enum | 是 | ID与操作类型一致，拒绝未知字符串 |
| definition_hash / template_hash | SHA256 | 是/城堡 | 在白名单资源中解析，不信任仅名字相同 |
| start_xz_m / end_xz_m | Vector2 | 是 | 米制有限值；stamp两者相同；shader只用XZ几何 |
| yaw_rad | float | 城堡 | 有限，规范到统一区间；只绕Y轴 |
| scale_xz / height_m | float/Vector2 | 城堡或墙 | 与冻结预设范围一致；模板采样细节不能低于最小可读尺度 |
| bottom_width_m / top_width_m | float | 墙 | 0<top≤bottom；截面定义在C04 |
| trench_width_m / depth_m / shoulder_width_m | float | 铲子 | 全部有限且正；沟/肩掩码互不重叠 |
| baseline_token | int64 | 墙/铲子 | 属于同stroke与generation的GPU基准，不可用CPU过期shadow替代 |
| add_budget_m3 / transfer_budget_m3 | float | 条件 | 从资源合法上限派生的有限配额；搬运不能授权外部增沙 |
| seed | int64 | 是 | 可复现；MVP不加影响体积的随机噪声 |
| water_policy / speed_m_s | enum/float | 是 | 冻结已消费配置，沿用现有合法范围 |
| material_profile_id | enum | 是 | G4定案规则，写材料必须包含在同事务 |

运行时Vector类型与持久化数组格式分别校验。必需字段不能靠隐式默认伪装成功；未知字段按G1A白名单规则拒绝或忽略非权威诊断字段，不能混用。

### BrushResult v2

| 字段 | 含义 |
|---|---|
| schema_version、ticket_id、command_id、stroke_id、generation | 类型与请求身份一致 |
| input_revision、output_revision、applied_tick | 成功仅推进一次revision；拒绝保留输入态 |
| status、error_code | applied / no_change / rejected，传输失败另记transport_error |
| added_m3、removed_m3、transferred_m3 | 根据最终float32实际状态归约；铲子added/removed字段是内部量，不据此记外部源汇 |
| left_received_m3、right_received_m3 | 铲子双侧实际接收量 |
| external_source_delta_m3、external_sink_delta_m3 | 城堡/墙为实际增沙/0，铲子均为0 |
| requested_budget_m3、capacity_status | 有限权限与截断/接纳情况，不能只报告请求量 |
| dirty_rect、dirty_chunks、edited_cells | 覆盖全部正/负变化及材料变化；碰撞按实际床高变化 |
| displaced_water_m3、retained_water_m3、water_error_m3 | 同事务水候选的量核对 |
| impulse_x_m4_s、impulse_z_m4_s、clamp_count | 实际动量变化与限幅；单位沿用已澄清的hu×A |
| sand_error_m3、eps_sand_m3、eps_water_m3、invalid_flags | 量化后闭合预算、非有限与越界检查 |

submit成功只表示入队。最终applied也不等于碰撞已可拾取；publish与collision_ready另有可观测阶段。UI等待状态必须遵守该区分。

### 错误白名单

沿用invalid_command、inactive_generation、out_of_domain、backend_unavailable及现有关闭/保存错误。新增拟定：unsupported_brush_version、unknown_brush、template_mismatch、invalid_placement、budget_exceeded、receiver_capacity、stroke_buffer_full。具体字符串映射在G1A定案。

碰撞落后是可重试的collision_pending，不把旧高度hit当有效命令；CPU/GUI可显示等待但不提前结算。未知版本/非法尺寸/非有限值/资源不一致必须明确拒绝。

## 3. GPU ABI与版本路由

当前transport v1为128字节，kind编码0=remove、其他=place，shape编码0=circle、其他=segment。新brush类型不得直接塞入旧编码，否则会误变成普通填沙。

T01需交付新transport v2的字节数、每字段offset/alignment/type、shader绑定表、push constant布局、回执布局、endianness和版本检查。int64身份保持整数低/高位，不经float。旧128字节分支继续按旧规则解码。

新事务拟复用“prepare → 固定序归约 → candidate apply → 校验 → sand/water/material条件提交 → 结算 → 发布”，新编辑器与旧管线通过显式路由共存。同域总容量仍64 pending/1在途，不新增绕过旧调度的第二写者。

## 4. Stroke生命周期（C03）

状态：idle → capturing → draining → settled；cancel只停止未提交部分，已经在途的事务遵守现有完成/回滚规则。

取消在capturing和draining均有效：释放或背压进入draining后，切工具/失焦/Esc仍须丢弃尚未入队缓存；保留已入队/outstanding身份直到结算。重复正常结束不再追加尾段。

| 事件 | 行为 |
|---|---|
| 墙/铲子左键按下 | 捕获刷子参数、当前位置与stroke基准，暂不生成无方向铲子或大圆形起点堆 |
| 有效移动 | 根据XZ路径距离重采样，保留角点，按有序sample_index分段提交 |
| 城堡左键按下 | 验证位置后只提交一次stamp；长按/移动不连续复制 |
| 正常左键松开 | 停止采样，排完已接收有效路径和已入队命令，完成后释放基准 |
| 光标进入GUI/离开合法区域 | 中断当前子路径，不跨GUI/无效区连接；返回有效区需重新建立锚点 |
| collision_pending | 暂停该子路径提交，保留有界待核对数据；只用当前generation/revision有效hit继续，不偷用旧床面 |
| 右键相机、Esc、失焦、切换工具 | 停止采样，丢弃尚未提交缓存；已入队/在途命令按既有明确策略终结；不产生新点 |
| 暂停/继续 | 结束当前采样段，编辑可在暂停完成态执行；模拟和表现时钟不因预览前进 |
| 保存/场景切换 | 正常结束stroke并drain，等待一致完成态再保存；不保存半条路径 |
| 关闭/重置 | 停止接受，取消未执行队列，等待在途所有者清理；新generation拒绝迟到回调 |

“缓存路径点”和“已入队GPU命令”是两个接受层级。面板须区分待提交与已提交；终止策略不能静默丢掉已应用结果。

### 路径与背压

- 固定XZ采样间距，长线段可扫掠，转折处不以端点直连剪掉弯曲。不同事件密度对同一几何路径应产生等价形状。
- 路径缓存拟定上限256点，队列沿用64命令，单段长度上限/每帧提交预算G1A确定。允许合并同方向点，必须保留超过角度阈值的拐点。
- 超过缓存上限不无限增长，明确停止接收并提示，不能覆盖最新点假装轨迹完整。
- baseline以stroke开始的完整GPU沙场构造，允许一次GPU侧基准复制；每笔热路径不读回全域CPU沙。基准生命周期/峰值内存记录。
- 目标基准不读取本刷子已经抬高的表面作为下一段新底座。无模拟时重复覆盖应幂等；有模拟时继续受真实当前沙量和基底约束。
- 普通挖填仍使用其amount语义；只有通过旧行为对照后才共享采样器，不静默改其强度。
