## 材料子记录 v1 精确布局

Dictionary恰有9个key，不接受额外/遗漏key：

| key | 类型及约束 |
|---|---|
| version | int，1；float 1.0不接受 |
| format | string，RG32F_tagged_depth_reference_sand |
| grid_size | int，256 |
| cell_size_m | 有限数值，精确0.125 |
| profile_id | String/StringName，molded_v1 |
| profile_sha256 | string，实际profile源文件SHA256；必须与当前验证者身份一致 |
| ever_used | bool，记录曾进入材料执行图；非零tag时必须true，hot-zero时仍保持true |
| current_support | PackedByteArray，524288 bytes；65536个little-endian float32×2 |
| spare_support | PackedByteArray，524288 bytes；同格式 |

每格x=tagged_depth_m，y=reference_sand_depth_m。按各自对应sand current/spare原始float32字段检查有限性与0≤tag≤sand；tag>0时reference等于该槽sand；tag=0时两个float的原始位模式均为0（不是负零）。完整完成态support双槽字节一致。sand槽可以有原协议允许的历史差异，但有tag的cell必须分别满足reference条件。故障测试人为构造的不同support spare只用于回滚，不能保存为完成态。

初始化与审计共用codec：错误类型/长度/NaN/负值/tag>sand在创建RD资源前拒绝。空PackedFloat32Array代表全零；输入负零规范成正零。初始化源来自domain元数据时，reference只从同域实际sand计算，不接受外部reference或模板高程作为事实。
