# 三种形状刷子验证与证据计划

日期：2026-10-14。角色：validation_plan。状态：frozen v1；矩阵、门槛及[G1A补充ROI/公式](契约/G1A_冻结细目.md)已冻结，测试结果只写验收/。

## 1. 固定条件与判定层级

用户优先级补充（2026-10-14）：先完成功能，性能在功能完整、配置稳定后集中执行，以两轮收敛为目标，最多三轮。第一轮统一测量代表性负载，第二轮针对定位问题修正复验，第三轮仅作必要的最终复验；每轮可包含同一候选的多个代表用例，统一记录配置和结论，不拆分计数规避限制。达到上限仍未达标则记录遗留及证据，结束性能迭代。编译、短运行和必要正确性检查继续按受影响范围执行；重复长时观察或性能诊断受此上限约束。既有失败与验收门槛保持原判定。

固定场景、seed、命令轨迹、tick、完成态、相机、预设与真实消费profile/hash。几何/搬运先暂停水沙演化逐笔验证，再开启耦合观察。输入快慢对照不混入不同模拟时间，避免把侵蚀差异误判为笔刷差异。

CPU纯数据、GPU数值、真实UI、视觉轮廓、保存恢复分别判定。脚本导出成功只证明操作成功；缺字段、空图、missing计时、无实际GPU不能计为功能通过。

## 3. 数值与形状门槛

| 类型 | 判据 |
|---|---|
| 逐笔沙量/水量 | 使用G1A冻结的float32量化与归约预算，记录具体eps，不以全域相对误差掩盖小笔 |
| 铲子 | abs(removed−left−right)≤eps_transfer，源汇/库存精确不变；左右量差≤冻结量化预算 |
| GPU/CPU形状参考 | 逐格按eps_cell对照，另报告体积与支持范围；模板采样/截面定义相同 |
| 输入速度对照 | 暂停模拟、同XZ轨迹；固定ROI高度差≤0.02m、增/移体积差≤1%，同时遵守逐笔守恒门；G1A已冻结 |
| 同笔重复 | 无模拟时不额外增加高度/挖深，仅允许量化预算；next stroke允许新目标 |
| 保形 | 干态30模拟秒峰高≥初始80%、轮廓IoU≥0.8，固定阈值/ROI/相机 |
| 回滚与无编辑 | 受影响权威字段、双槽/历史与账户按既有严格范围逐位不变 |
| 保存恢复 | 同构建完整raw字段与账本精确配对；严格继续失败不得改用视觉近似比较 |
| 连续观察 | 队列/缓存/RID有界且能终结，tick有完成时间戳，旧数值上限继续约束 |

2cm/1%用于不同输入离散化的外观一致性，不用于放宽沙量搬运守恒。最终冻结的数字、输入序列和profile签名必须写入G1A报告。

## 5. 证据内容与索引

每个run至少有manifest.json、result.json、commands/consumed_parameters、stdout/stderr、逐笔receipt/ledger、有效状态/资源hash及失败说明；几何/数值组另存有关raw字段，视觉组有固定机位截图与带时间戳连续片段。

manifest包括：场景/用例ID、命令/轨迹、网格/单位、seed、generation/revision/tick、模拟与墙钟时间、源码和模板/profile/hash、SPIR-V身份、引擎/驱动/GPU、实际窗口/输出尺寸/VSync、受影响格、eps、阶段时钟、缓存/队列/资源峰值。

英文机器路径统一放在test_output/shape_brushes/，报告放本任务验收/并链接真实数据。失败run保持原样，修复使用新run ID，不覆写失败为PASS。无实际first_visible计时就标missing，不用publish时间冒充真实画面反馈。

Gate报告必须分别写功能、数值、视觉、恢复和新增负载观察结论，并注明旧性能/恢复限制是否复现及归因边界。没有数据不创建PASS报告。
