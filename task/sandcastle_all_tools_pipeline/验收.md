# 全工具接入新流水线验收

2026-10-17。结论：本次七类旧操作迁移完成，功能验证通过；卡顿尚未完全消除，未通过或申请新的性能门。原始失败、旧专项判定和其他任务状态保持原样。

## 实现范围

沙墙、城堡、守恒铲子、投流沙、投碎石、平滑、压实已接入当前有界命令队列、三个持久工作槽和同一有序RD执行流。普通挖填继续使用原新流水线。形状连续段不再逐段进入旧事务、同步CPU影子或等待碰撞完成；GPU实际revision/tick及独立笔画状态约束提交，工具回执在共享暂存复用前复制到各槽。水模拟可在开笔期间推进。

保存、恢复、切换、退出仍按完整状态和消费者所有权排空；GPU完成与物理碰撞追平分开。平滑/压实改为GPU候选验证后提交，碎石有界预留容量并异步结算。兼容函数apply_legacy_command保留名称，默认实际执行GPU工作；显式禁用新流水线时的旧实现保留。协议、材料/账本及资源约束见[接口与验证](接口与验证.md)。

主要入口是scripts/beach/async_pipeline_entry.gd、frame_pipeline中的async_controller.gd、async_tools.gd、async_transport.gd及对应工具shader。HUD改为显示实际GPU Tick和模拟时间。
