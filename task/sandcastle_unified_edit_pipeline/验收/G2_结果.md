## 唯一隔离执行链

`pipeline.gd`持有一个有界64待处理队列和3槽，所有profile声明进入同一个批次入口，不按工具ID选择另一执行器。`api_adapter.gd`只转换旧公开名称/字段，校验旧shape definition/template身份，保留限制性授权与精确int64；不创建旧editor/controller/writer。schema1 circle/sweep的挖填/悬沙、smooth/compact及schema2三个形状均有规范命令编码证据，BEGIN/END/CANCEL为数据转换，实际笔画基准/coverage生命周期在T03/T06实现后才能接到产品API。

真实transport固定512B命令、384B逐笔结果和96B头；不可变domain hash guard在录制开始检查，完成包绑定generation/batch/lease，控制字节和物理布局保留native3。`state.gd`只分配物理资源与水核绑定，没有旧CPU patch或旧编辑初始化链。`executor.gd`调用固定公共阶段，`edit.glsl`当前实际实现bed volume_delta的disk/sweep；其余原语、水策略和完整效果能力在实现前明确拒绝，不能把静态catalog存在视为已迁移。

| 阶段 | 当前输入/输出与权威边界 |
|---|---|
| select（mode0） | 读取同流实际revision/tick，复制命令并初始化独立结果；不预测前笔是否成功 |
| candidate（1、4） | 读取局部矩形中的床/水/材料，写64B公共Candidate；REMOVE保留4轮权重/余量分配，ADD按总权重分配 |
| reduce/merge（2、3、5） | 每块256lane归约，使用128B公共Summary；取真实old/new差异、ULP预算和脏块，合并只扫最多256块 |
| validate（6） | 有限值/非负、数量/限制授权及版本耗尽检查；只有候选和decision可变 |
| commit（7） | 通过后写双份权威沙与材料reference，不备份后CPU回滚 |
| result（8）与seal | 每笔实际revision链、数量、字段、真实dirty及独立结果；seal推进完整state_seq和GPU时钟纹理 |

水tick是同一transport里的零编辑结果工作，复用原edge/drain/update、GPU CFL、normalize和实际dt逻辑。CFL决定后、物理写入前增加tick/revision signed-int64耗尽保护；数值公式保持。按due tick排序同一待处理编辑段，必要水步在同流录制，不等CPU逐笔授权；显式水工作保持流屏障顺序。

## 真实运行结果

normal：4笔disk/sweep挖填→真实water→后续编辑，3个工作单元可在CPU消费前全部录制。实际回调被探针重排为batch2、batch2重复、batch1、batch3；结果仍按实际有序流消费，重复不重复结算。读回沙量与逐笔结果净量一致，双沙槽和发布纹理一致，水/动量确有变化且有限非负。未来tick4与随后接纳的较早due tick1保持应有顺序；旧API填沙实际经过公共结果。零授权业务拒绝后，下一笔仍成功且revision链连续。64笔command_id>2^53的实际逐笔结果身份完整，65笔背压明确；准入后未录制可取消，已用ID不重用，关闭拒绝新输入并排空释放。

water_1/2/3/64/100：分别验证实际GPU CFL选步、64上限及超载截断、actual_dt时钟。另建隔离物理bundle，用原始水核直接执行相同子步，比较完整水深与X动量字段；五种配置最大差均为0，日志保留REFERENCE_MAX_ERROR。该独立调度对照证明水工作编排，不单独证明侵蚀/边界/表现全负载已迁移。

upload/readback/truncate/identity/unknown_state/fatal/counter/tick_counter/revision_counter/bad_cfl：覆盖录制前失败、已录制未知、真实回调坏数据、GPU fatal、state/tick/revision上限和非有限CFL输入。故障后停准入、无伪造业务结果、没有命令重放。读回未知且终结探测不可用时租约和GPU资源保持；恢复探测后只有真实有序栅栏确认才可退租清理。未知回执的实际沙场已写入时保留其事实，不以CPU回滚掩盖；fatal/计数器耗尽/坏CFL在提交前保持沙场不变。
