## 提取修正与失败保留

`g6_presentation_bake01`出现原生Container内部连接被断开错误，虽然原始操作JSON的局部检查为真，整次结果不予通过；改为仅移除指向旧根/旧性能读者的持久连接。

`g6_presentation_runtime01`至`04`在后端完成关闭后仍出现节点/渲染资源泄漏。显式释放根节点和调整反射资源后仍能复现；`04`的verbose日志直接列出UI、视觉子场景和SurfaceA/B的重复孤儿子节点。原因是提取时已把内部节点owner展平，但仍保留子场景scene_file_path。提取器现同时清空所有嵌套实例标记，最终packed文件不再包含node实例标记；`bake04/runtime05`及最终四场景复验均无新增孤儿节点。各阶段日志和当时helper源码保留，不回写旧PASS字段或失败结果。

反射资源另作静态修正：不序列化旧运行时World3D，SubViewport继承新根的世界；ViewportTexture保存为scene-local的ReflectionViewport路径。材质的其他参数保留原生Variant类型，manifest中的JSON参数只作诊断，不用于重建有类型材质。

## 交付代码与复验

- `tools/unified_edit_pipeline/bake_presentation.gd`：离线提取及固定节点保存。
- `scripts/simulation/unified_edit/presentation.gd`：文件/Shader身份、数据初态、材质绑定和依赖读取；不创建旧writer。
- `tests/integration/unified_edit_presentation_probe.gd`：实际材质、native恢复和释放检查。
- `tools/unified_edit_pipeline/run_presentation.py`：四场景串行、全新输出目录、退出码/日志核验及源码封存。
- `tools/unified_edit_pipeline/audit_presentation.py`：独立校验日志、来源ZIP、生成场景结构、图片尺寸和诊断像素差；自身源码副本与hash另存于证据目录。

复验命令（输出目录必须不存在）：

```powershell
python tools/unified_edit_pipeline/run_presentation.py --output test_output/unified_edit_pipeline/presentation_fresh
python tools/unified_edit_pipeline/audit_presentation.py test_output/unified_edit_pipeline/presentation_fresh
```
