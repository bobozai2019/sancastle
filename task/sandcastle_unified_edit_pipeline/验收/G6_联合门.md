## 关键收尾观察

1. 在首次候选尚未发布时关闭，没有commit事件，候选八类资源归零。恢复验证的真实读回暂扣时，关闭保留候选；实际回读返回后，旧域与候选均归零。
2. 录制确已发生但原结果注册失败时，前端停写；终结证明不可得期间不free、不发布CPU完成态、不虚构APPLIED。证明可得后，原命令只返回一次recorded_result_unknown；原生恢复后新代次可安全复用相同命令号，旧结果不能再次消费。
3. 旧域解绑未确认时，新域可以提交但旧资源仍保留；关闭维护重试取得确认后才释放。真实预览查询跨恢复换代，迟到旧结果不能覆盖新代次预览，未知预览读者关闭完成。
4. 已知edit5/native3和edit4/native2旧档经正式main进入统一候选，重存后的原始物理、材料、白沫、历史、碎石双槽及来源保真；geometry对这些main域旧档明确拒绝。未知来源/格式仍拒绝，不构建旧运行对象。
5. 真实回执以乱序、重复方式到达；CPU按原顺序发布一次。原始完成包被保存后再次投递到已消费旧租约、错误代次和新域，完成态/命令结果不重复。保存会结算真实GPU水量账本，跨恢复比较以已保存账本为准。
