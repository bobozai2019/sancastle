# G6 正式旧路径退役清单

范围：正式main和三个test1入口及其菜单切换。实验场景、历史测试和数据验证依赖保留，不宣称整个仓库没有旧实现。完整可执行writer可达审计仍属G7。

| 对象 | 切换前 | 当前处理 |
|---|---|---|
| `scenes/main.tscn` | 继承旧rdc表现/运行场景并挂async_pipeline_entry | 改为固化main表现加unified_playable_entry，保留原UID |
| `scenes/playable/test1_capture.tscn` | 继承旧main并修改场景设置 | 独立固化capture表现与统一入口 |
| `scenes/playable/test1_backwash.tscn` | 继承旧capture | 独立固化backwash表现与统一入口 |
| `scenes/playable/test1_geometry.tscn` | 继承旧main并挂test1_geometry_entry | 独立固化geometry表现与统一入口，保留已提取的几何/侧壁/相机/水位配置 |
| 主入口和菜单 | project.main_scene + SceneService四路径 | 项目入口路径保持main；四目标统一定义于unified_scene_routes.gd |
| 根运行类 | 旧脚本链及可选异步执行 | 四正式根为直接Node3D统一类，无legacy基类或async_pipeline_enabled字段 |
| 碰撞/物理消费者 | 旧GpuCollisionProxy及其RD所有权 | 固定UnifiedEditRuntime两个高度槽；旧代理节点不再实例化 |
| PerformancePanel | 旧solver阶段采样依赖 | 只读统一状态和帧统计，不建立旧solver/readback |
| 场景服务释放 | 判断旧solver/collision/gravel/async所有权 | 只接受统一工厂，统一shutdown后验证unified_release_complete |
| 场景服务设置 | 传递async_pipeline_enabled等旧运行开关 | 删除旧开关传递与_async_*判断，保留合法工具/相机/显示设置 |
| 路径选择 | 缺少新方法时fallback到旧SCENES | 删除回退；实际PackedScene路径决定formal/candidate族，未知路径返回空 |
| 场景进度缓存 | 仅scene_key索引，文件后缀sandcp | `family:scene_key`索引与sandue文件，正式/候选配置身份不混用 |
| 旧存档读取 | 旧运行类承担恢复 | 固定来源目录+数据验证/投影，再由统一候选构建与交接；没有旧运行fallback |

`assets/unified_edit/presentation/*.json`保留原始场景与原脚本身份，作为离线提取来源，不把这些历史hash改成新入口hash。提取前的四正式场景hash均与这些来源记录一致，确认没有漏接后续场景改动后才替换。旧文件原字节与旧服务/入口版本封存在`test_output/unified_edit_pipeline/g6_formal_cutover_sources01/before.zip`及before.json；after.json记录新wrapper身份。没有删除或重写旧验收数据。

旧`async_pipeline_entry.gd`、`test1_geometry_entry.gd`及其旧业务/录制器文件仍留在仓库供历史证据与实验依赖使用，正式根和菜单不再实例化它们。`legacy_sources.gd`必要的旧Codec/Recovery/Gravel静态数据验证引用保留；读取这些类不等于构建其旧场景或frame pump。复用旧数值shader与视觉资源也不作为旧控制流可达的证据。

静态审计`audit_formal_scenes.gd`实例化四个正式PackedScene但不加入树，检查实际节点脚本白名单、唯一统一Runtime、无旧代理/开关、固化表现/初态身份及服务退役分支，共33项通过。它只证明此表对应的入口/节点范围，不能替代G7对执行调用和权威writer的完整审计。实际GPU启动、保存恢复和场景往返结果另列正式接线组件。
