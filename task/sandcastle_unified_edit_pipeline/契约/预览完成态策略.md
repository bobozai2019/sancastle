# 只读预览完成态策略

查询仍使用既有96B GPU回执，generation、query_serial、state_seq、revision、tick、时钟、足迹及baseline字段布局不变。新增策略仅改变回执交付时的版本判据。

| 策略 | 数值 | 交付条件 |
|---|---:|---|
| CURRENT | 0，默认 | state_seq不低于请求minimum及交付时completed_floor |
| SNAPSHOT | 1，显式选择 | state_seq不低于请求minimum；允许交付期间完成态继续推进 |

两者均保留格式、有限值、代次、query_serial、上下文、关闭状态及请求minimum检查。SNAPSHOT返回真实state_seq及交付时state_lag，advisory=true；查询内容只用于提示，不能授权编辑、冻结GPU状态或免除公共准入/候选校验。CURRENT请求不会暴露不满足自身版本下限的旧SNAPSHOT缓存。

前端最多保留一个当前请求，约10Hz合并最新目标。位置、形状参数、起终点及笔画身份绑定几何key；工具/参数、结束笔画、恢复和关闭使上下文失效。回执仅用于其绑定几何；Root独立单调序号防止旧代次回执清除新请求状态。正常预览不预留公共command_id，不产生任何写入、账本或模拟时间推进。

未开笔形状查询使用未准入的下一身份作为查询信封，不产生BEGIN；活动笔画查询使用真实stroke/baseline身份。墙/铲只有回执确认发布baseline后才显示其基准；否则显示等待。CASTLE沿用固定世界标高。无效范围和障碍显示无效提示，最终操作始终进入公共GPU校验。

GPU查询读者的资源所有权留在Views。读回注册未知时保留缓冲区并重读同一结果，不重放查询或编辑。Root定时调用Runtime既有重试接口；关闭等待期间也重试旧读者/解绑证明。换代后新域可查询，旧域仍由Runtime.retired保留至实际回读和解绑完成；晚到旧回执不替换新结果。

范围：快照提示允许滞后，不证明鼠标到预览延迟、最终放置一定成功或视觉成本达标。实际验证见[G6持续预览](../验收/G6_持续预览.md)。
