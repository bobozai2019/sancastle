# 读者维护与终结证明

补充C06；不改变物理ABI、数值、结果状态或最后消费者规则。

前端在已有维护节奏中调用公共Runtime，不另外录制水沙工作。运行中（含暂停、保存等待）沿用约1秒维护；关闭等待沿用约500ms维护。该计时是所有权维护，不推进模拟tick或表现时间，也不是性能延迟保证。

| 所有者 | 维护入口 | 允许的动作 |
|---|---|---|
| current | retry_retirement | 重试当前高度通道的未知读回/ACK、当前检查点的未知终结证明 |
| candidate | retry_retirement | 原初始化清理证明、高度/预览未知读者、检查点生命周期证明 |
| retired | retry_retirement | 高度/预览/检查点读者及未确认的材质解绑证明 |
| current预览 | retry_preview_readback | 沿用当前独立只读查询的同一结果重读，不预约编辑命令 |

各通道保留自身identity与pending/proof_pending防重入规则。重试读取同一缓冲区或取得同一借用关系的真实GPU终结证明，不改代次、不伪造ACK、不释放仍可能被使用的RID，也不把未知工作猜成成功。

检查点注册失败后，即使后来取得终结证明，原保存仍返回注册失败；确认只是允许安全收尾，不能把不完整快照写成成功存档。新的保存必须由调用者重新请求。当前保存失败后，健康的原域保持可用；关闭期间则等待读者与证明全部结束再释放。

记录器工作本身未知时的停写、显式恢复/关闭与cleanup_fault规则保持原样；此维护不自动给未知编辑合成终态。源码和结果见[正式在途/读者重试组件](../验收/G6_正式在途与读者重试.md)；观察超时不作为提前free或终结证明。
