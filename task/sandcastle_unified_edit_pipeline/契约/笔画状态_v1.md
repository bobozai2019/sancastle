# GPU笔画与目标候选 v1

2026-10-18。角色contract。适用当前T03目标高度及守恒搬运组件；恢复/正式接线仍待T06，不声明活动笔画已进入存档格式。

每域一个GPU笔画状态，绑定统一域guard/control/generation和同一RD流，不为工具另建调度。64B scratch word0为active；2/3为stroke_id低/高，4/5为baseline_token，6/7为最后sample，8为has_sample；其余当前零。正int64身份不经过float，工作槽lease不复用。BEGIN仅在未活动时接受，捕获当前完成床的R32F world高度并清RG32F coverage；结束后可显式重开旧公开身份。活动期间重复BEGIN、错token或非递增sample返回零变化业务拒绝。合法形状被选取后消费sample，预算拒绝也不撤销已消费样本；未知结果绝不据此重放。

BEGIN/END/CANCEL使用统一控制信封和完整结果，成功NO_CHANGE、失败REJECTED；控制不产生权威变化、dirty、coverage变化或任何数量/误差预算。公共结果codec对此检查。控制作为待处理队列屏障，不参与越过其他控制的due排序；普通编辑仍可在控制之间按due排序，模拟时间依赖由同流真实水tick满足。

max_buffer_points约束pending点容量，不是整笔累计sample上限；提交/排空后释放该输入容量。GPU只保存当前样本身份、基准和全域coverage，长笔不累计任意长度折线数组。profile参数仍快照化，不能通过参数选择任意shader/阶段。产品输入重采样及已接纳END的关闭边界在T05/T06整合。

城堡采样已注册65²、spacing0.0625的payload，固定world datum；墙取固定baseline加截面，并与既有coverage世界目标取最大。有效墙段处理累计coverage，不能只裁最新线段。零长度墙段保持旧无操作规则。候选coverage与活动coverage分别保存，只有公共提交允许替换；拒绝不能破坏旧coverage。

搬运按最新胶囊局部rect生成候选，累计coverage保留已触及沟槽的world目标及最大profile；旧供体覆盖格不转作肩部接收。供体目标按旧profile取旧目标或与新目标取低，再以实际缩放后的new bed回填候选coverage。提交只替换本笔rect，其他coverage保持原字节；零长度段不借旧coverage挖沙。R32F world coverage减rock可能在复访产生极小实际差异，按原量化预算和真实变化回执处理，不隐藏为NO_CHANGE。目标为零时必须没有接收量。七类GPU与独立证据见G3搬运记录。

Template缓存由注册表已验证字节构建，按hash排序并使用相同1-based index：总头16B（count及零保留），每层16B头（mask count及零保留）加65²×16B原始RGBA32F。当前仅原模板有真实GPU几何对照；多模板配置复用必须在T07另验，不能仅凭数组容量宣称通过。
