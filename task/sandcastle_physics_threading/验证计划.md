# 多线程优化验证与证据计划

角色：validation_plan。状态：C03 frozen v1（2026-10-14 G1）；T00已实测，后续候选尚未验证。

## C03 环境与完成态

T00固定当前可见main的代码/场景/profile/资源hash，实际Godot二进制路径、版本、SHA256，硬件、CPU逻辑核、GTX1050实际型号、D3D12、Jolt、输出尺寸、VSync、帧上限、物理Hz、线程池有效设置。不靠目录名认引擎版本。不得同时运行基线和候选游戏；登记外部GPU负载，未授权关闭他人进程。

正式成本维持既有真实1920×1080、VSync关闭、当前完整浪/侵蚀/编辑负载，保留1/30s模拟步。1280×720用于快速功能与用户当前默认体验，另成报告，不合并数字。测试采用同一预录命令、坐标、体积、间隔、seed、相机、tick和初态。

配对以十个权威字段的原始字节、账本、输入prefix和完成tick为依据；源码变化导致旧检查点签名拒绝时，用匹配模式重新构造同态或受控导入经验证原始字段，不能伪造签名。原始GPU场有历史间歇继续差异，先区分模拟非确定性与碰撞worker是否更改数据。未能匹配的窗口进入失败记录，不用cold/warm混合做收益判断。

## 指标与时钟

| 指标 | 起止/口径 |
|---|---|
| 输入到首次可见 | 命令准入到该命令revision首次用于实际可见帧；render回调执行不直接冒称用户已看到 |
| 编辑完成 | 准入到回执、发布、所需碰撞revision与两物理帧全部满足 |
| 碰撞GPU pack | 成对GPU timestamp；记录时间单位与捕获帧 |
| 回读等待 | 请求→回调，包含排队/复制，不叫GPU纯计算 |
| 主线程准备 | 输入快照、调度、结果收集、重查数据的各CPU段；不把跨帧墙钟当CPU计算 |
| worker排队/执行 | schedule→start及start→end；记录实际并发任务数、抢占可能 |
| 形状提交CPU | 主线程尺寸/height/transform/shape赋值与版本记录，和完整apply分开 |
| 提交到物理完成 | apply→两次physics_frame，用真实射线验证，非形状构建独占CPU成本 |
| 整体 | p50/p95/p99/p99.9/max帧间隔、>100/250/500ms次数、完成tick/s、输入接受/拒绝率、事务延迟分布 |
| 资源 | 活动/等待任务数、净payload、RSS趋势、回收ID数量、在途读回和RD释放 |

GPU与CPU不同钟源不能直接相减，嵌套CPU段不相加重复计算。默认性能面板采样本身有开销：归因窗口允许开启详细诊断，正式成本窗口使用冻结的相同采样配置并另做关闭对照，不混用。

## 窗口顺序与门槛

1. T00先做编译/短运行，10秒无输入和20笔暂停编辑定位；30秒连续输入复现。先检查是否CPU准备主导，不重复已有无变化跳过优化。
2. T02/T03先纯数据和功能负例，通过后每模式10–30秒真实窗口诊断；错误立即回修，暂不跑完整长稳。
3. T04测serial、worker1、worker2、worker4，按1/4/16块分析调度和旧快照拷贝；候选默认不使用全部CPU核或high_priority=true，线程配置有效值留证。
4. 核心代码稳定后采用至少3对交错300秒窗口（A/B、B/A、A/B）；D另与A和已获选单项模式比较。每对完成初态、warm程序、命令和时钟边界一致，重新启动不同物理线程模式。
5. 仅获选最终配置进行30分钟完整负载观察，覆盖周期堆挖、暂停/继续、保存恢复、场景切换、关闭。若发现新问题，只重跑相关功能和受影响成本。

既有硬门：完成吞吐≥15tick/s；p99帧间隔≤63ms；暂停单笔编辑碰撞反馈≤100ms。验收不偷换为30Hz/33.3ms，也不把固定步改为1/15s。

本轮收益门已于G1冻结：至少3对交错300秒窗口的主线程准备p95同方向改善，每对改善超过下表对应case的噪声；同时真实编辑到两物理帧反馈p95或整帧p99在三对中同方向且超过对应噪声。输入接受率与完成吞吐不得系统性退化；硬门仍全部单独检查。不得测完后把门槛改为微基准、平均FPS或单次没600ms。准备份额过小或无真实收益时，G4拒绝/限用，不宣称卡顿优化成功。

| case | 准备p95最小可辨改善 μs | 帧p99最小可辨改善 ms | 两物理帧反馈p95最小可辨改善 ms |
|---|---:|---:|---:|
| idle_live | 113 | 7.931 | 不适用 |
| dig_paused | 131 | 6.146 | 104.170 |
| fill_paused | 762 | 6.794 | 148.570 |

这些数值是T00三个同态A重复的range，不是置信区间；连续吞吐噪声range3.899tick/s、无输入6.446tick/s只供退化解释，不能免除15tick/s底线。正式窗口应记录外部负载/时钟，若被污染需保留并作invalid，不能靠临时放宽阈值放行。不同块数的CPU微基准另分组；微基准只选候选和小批阈值，不代替此收益门。

严重停顿如仍可复现，采单个自有Godot进程的线程/栈与GPU队列证据，不自动提权，不查竞品业务；确定是GPU fence后另列后续任务。更换Vulkan、帧上限、减少碰撞块或改编辑完成语义不属于这轮单变量证据。
