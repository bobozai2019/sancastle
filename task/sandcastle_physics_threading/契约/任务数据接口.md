# 碰撞准备任务数据接口草案

角色：contract。状态：frozen v1，2026-10-14 G1冻结。内部API，无HTTP或数据库依赖。

## C02 PrepareRequest

| 字段 | 类型 | 验证/所有权 |
|---|---|---|
| schema_version | int | 候选v1，不与保存格式版本混用 |
| request_id | int64 | 主线程递增，仅一次回收；不得float转换 |
| generation | int64 | 准入代际，只读 |
| captured_revision | int64 | GPU/CPU实际数据版本，非猜测 |
| grid_size | int | 正整数且整除32，块域大小=(grid_size/32)²；v1实际256 |
| chunks | PackedInt32Array | ≤16，域内不重复；与数据slot一一对应 |
| raw_heights | PackedByteArray | 长度=chunks.size×1089×4；快照，后续不修改 |
| previous_chunks | 独立块数据数组 | 可选；复制旧高度、shape_id、revision、尺寸/position/scale；worker不能访问资源对象 |
| queued_usec | PackedInt64Array | 长度与chunks对应，仅墙钟诊断 |
| requested_usec/readback_done_usec | int64 | 同一单调时间源，不与GPU时钟相减 |
| task_policy | enum | serial / worker1 / worker2 / worker4，由主线程选择 |

v1不生产previous_chunks；只准备纯高度，保留主线程精确比较。queued_usec允许长度0（诊断关闭）或与chunks相同。原字节/块数组在准入时复制为独立快照，worker输出逐位保留float32；未近似、未量化。身份字段必须TYPE_INT，不接受float伪装int64。

## PrepareResult

| 字段 | 类型 | 含义 |
|---|---|---|
| request_id/generation/captured_revision | int64 | 必须与请求完全一致 |
| status | enum | prepared / invalid_length / invalid_chunk / non_finite / worker_failed |
| chunks | PreparedChunk数组 | 数量顺序与请求一致；失败不含可发布子集 |
| chunk_id | int | 原slot对应块 |
| heights | 独立PackedFloat32Array | 1089个有限值，逐位保留输入，不量化、不近似比较 |
| previous_identity | 可选结构 | 与请求旧快照一致；仅供主线程二次验证 |
| unchanged_hint | bool | 仅数据建议，不能独自推进revision |
| scheduled/start/end/collected_usec | int64 | worker排队/执行/结果回收墙钟；执行用时与CPU忙碌口径区分 |
| worker_count/bytes_copied | int | 调度/拷贝开销诊断，固定有界统计 |

负高度允许，因为rock+sand可以低于零；NaN/Inf必须拒绝。组内每slot单一写者，整体status由完成后主线程汇总，不用无序共享增量决定成败。

## 调度API与状态机

冻结接口：enqueue(request)→StringName（空值accepted，否则backpressure/closing/invalid_request/invalid_length/invalid_chunk）；poll_completed()→Array[Dictionary]；stop_admission()；has_in_flight()→bool；queued_count()/payload_bytes()诊断。poll只在完成检查true后wait一次，再返回该ID的一份结果；重复poll不重复返回。准备中的关闭继续poll异步drain，旧queued请求取消发布不确认revision。准入request_id严格递增，拒绝准入不占ID；单活动+4等待，净payload预算2MiB含raw/输出最坏双份，未实现previous hint。

```text
queued → preparing → prepared → validated_on_main → applied/unchanged_ack → reclaimed
                         └→ stale_discarded/invalid_rejected → reclaimed
```

关闭或代际变更只取消发布权，不假装取消已经运行的CPU工作。完成后回收task ID一次；同ID结果不得二次应用。背压不改变命令status或账本。同批的有限值验证先于任何apply；不同块的过期revision过滤保留现有语义。

需要记录的错误分别包括invalid_length、invalid_chunk、non_finite、worker_failed、stale_generation、stale_revision、backpressure、closing。前三者计非法数据，worker_failed单独计；后四者是生命周期/调度状态，不能都算作非法GPU读回。完成结果status=prepared/non_finite/worker_failed；主线程前置元数据/长度拒绝不启动任务。失败结果chunks为空，不保留可发布子集。worker执行段是墙钟，可能含抢占，不冒称线程CPU采样时间；bytes_copied计逻辑快照/切片字节，不冒称物理内存带宽。
