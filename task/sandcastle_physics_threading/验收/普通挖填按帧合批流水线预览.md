## 当前过程

普通鼠标输入持续进入原有有界队列（最多 64 笔）；可使用上一份完整碰撞面取得 x/z，碰撞尚未追上新地形时不直接丢弃普通挖填。形状刷子/砾石仍要求其原有有效碰撞与事务。GUI、场景切换、暂停、关闭保护保留。

取队列中已到期、同水策略的普通挖填前缀整批提交；主场景每批最多 **2 笔**，剩余输入继续排队。可在 main 根节点 `edit_frame_batch_limit` 调整（1–64）；没有把所有挖填相加。每笔原始沙、水、速度和 molded 材料事务仍按顺序计算，整批上传一次、回读一次，发布与碰撞脏区合并一次。GPU 单队列内部仍有多个 dispatch，并非一个 kernel。

GPU 拍下本批碰撞高度后，释放编辑提交锁；CPU 继续应用这份不可变高度快照、等一个实际物理边界，同时可以提交下一批普通挖填。代理尚有未拍下高度的区域时禁止下一批写入，避免版本与内容错配。按完成状态消费，未强制假定上一帧已经完成。Jolt 常规物理步保持固定时钟；只合并地形编辑的收尾等待。

保存、恢复、形状笔画、砾石投放、常规直接编辑 API 仍等待所需碰撞完成；每笔保留原始回执和当前 v4 材料前缀。快速预览未另行生成保存文件验证整个存档生命周期。

## 实现与限制

`edit_frame_pipeline_enabled = true` 已写入 main；设为 false 恢复逐笔调度。后端由旧已验证回执合批实验移植到当前 BrushMaterialSolver，添加 mold_support/compaction 双槽共 14 纹理的 RAM/GPU 回退保护，以及材料阶段间接派发，保证拒绝后的尾部不写入材料。
