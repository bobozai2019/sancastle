# 水传播保波程度面板

结果：已完成。四个正式入口与对应候选场景均有静态场景组件，右上角“沙量 · 波浪 · 视角”面板提供“保波程度”，范围0–1、步长0.1、默认0。调参保存原始沙水与完成时间，短暂替换generation；浮物按现行恢复语义重新就位。可先试0.5，再试1，0恢复原MC路径。一阶模式禁用此项。

## 实现与边界

参数混合MC与Superbee重构坡度，r=0直接使用原MC计算。未减小Rusanov信号速度、修改CFL、湿干阈值、速度帽或非负保护，也未修改工具冲量。它不是指数衰减秒数，不保证所有波长或地形中的振幅、可辨持续时间单调增加。非零值使用严格数值schema2，有限数[0,1]且仅限MUSCL；schema1及历史缺失字段语义保留。

调参结束当前笔画，取得完整检查点；Runtime只允许同域、同完整源码、同solver及相同非数值配置的新候选。候选提交才更新有效配置，失败保留原域与参数。存档包含有效设置，恢复读取存档值；场景切换保存各自设置，新场景沿用当前值。源文件或场景变化仍须精确来源映射，未开放任意旧档通配加载。
