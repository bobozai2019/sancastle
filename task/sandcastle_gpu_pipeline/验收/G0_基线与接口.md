## P00.3 实施布局与兼容

物理布局、容量、所有权见[接口与状态契约](../接口与状态契约.md)新增冻结部分。普通命令复用 128B 数值 payload，**不**复用 v4 prefix 语义；GPU 选取时覆盖版本。command_id/batch_seq/state_seq/sim_tick 各自独立。协议源码 async_protocol.gd 为后续单一常量入口。

写点审查起点：sand_prepare/apply 写工作 cells，sand_commit、water_commit 和 legacy_material_transaction phase 1 才能修改权威场；材料 phase 0 写持久 backup/candidate，phase 3 可拒绝 receipt。P02 仍需逐字段动态拒绝验证，当前不声明可安全移除备份。

| 功能 | 旧语义 | 新模式边界 |
|---|---|---|
| 普通自由挖填 | 前缀失败取消尾部、精确 receipt、14 张批次备份 | 逐笔独立拒绝、GPU 完整发布、近似统计；P02 验证后移除批次备份 |
| 库存/形状/流沙/碎石 | 自身事务、库存、材料和可视扩展 | 低频 drain、同步必要影子、沿用事务；不使用自由挖填估算充当库存 |
| 保存/恢复 | edit v4/native v2 带精确 prefix | 新 edit v5/native v3 无 prefix 恢复依赖；旧完整签名匹配候选显式迁移 |
| 数值/单位/碰撞 | 256²、0.125m、33² 块采样、64 块 | 沿用；高度真实、非有限保护保留；不承诺固定反馈帧数 |
| 视觉和物理设置 | 当前完整负载 | 不更改，不引入独立物理线程 |

ADR 草案：采用固定 3 批次槽、2 高度槽，单 RD 有序 compute list，GPU control 版本和完成边界；不使用 CPU await 确认作为常规批次间屏障。存档代次恢复时重建，不重用租约。此决策仍需 G1–G6 运行实证，不能提前视为功能成立。
