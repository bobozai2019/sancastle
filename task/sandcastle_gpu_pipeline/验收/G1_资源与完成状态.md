## GPU 关键证据

可见 Forward+ D3D12/GTX1050，4.7.2 stable；依次提交三批，每批两个128B输入，到第一批 CPU consume 前三批均已 submit。未消费时第四批 no_slot，三份 GPU 完成到齐后仍 no_slot；consume/retire 后第四批完成。每批读取持久输入，累计到同一 control，结果分别302/606/912/1220，证明上传未被后批覆盖且共享工作流顺序成立。GPU state_seq 从0xfffffffe开始，依次0xffffffff/0x100000000/0x100000001/0x100000002，低字进位正确。
