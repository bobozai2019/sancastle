# 原包植被验收

九种原包多视角图集与代理网格已接入四个正式场景，替换先前原创宽叶网格。主场景实际存活计数按海草、海带、水牛草、灰色丛草、红藻、柳枝稷、麦草、蓍草和黄花排序为 [965,59,621,289,106,243,38,21,19]，其中水下三类合计1130丛。容量18432不等于可见数。

Godot 4.7.2 / D3D12 / GTX1050，可见窗口1280×720，VSync=1。四场景启动与像素贡献通过；主场景61项交互和恢复检查、九种正反视角截图、约一分钟连续运行均通过。权威水沙无植被写回，损坏存档拒绝不破坏旧代资源。测试范围不代表小时级稳定或竞品运行时行为。

性能使用完整场景暂停后开/关/开各90帧：最终主视口GPU中位数15.842/10.891/15.909ms，帧间隔约19.8–19.9ms；不是模拟吞吐。双面候选约20.2ms，唯一变化为代理背面剔除，候选密度和类型不变。原先四种程序网格版本的成本数字不能当成此版结果。

原始运行报告、日志、配置/来源指纹、关键候选植被代码、交互二进制快照及正常/损坏存档见运行证据.zip；验证索引记录哈希。完整来源闭包sources.zip的原路径为临时测试目录，正式源码/图集依靠同次Git提交与哈希复验，归档只摘取植被候选代码，不冒称完整运行快照。
