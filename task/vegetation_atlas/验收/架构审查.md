# 图集植被边界审查

审查范围：九类固定场景资源、原包图集与代理网格、配置容量/缩放字段、既有只读GPU更新及表现Shader。导出器仅离线读取已核对hash的Plant视觉对象，不读取竞品业务方法。

vegetation.gd::initialize仅把原草高配置改为原网格缩放，缓冲容量由Profile决定；资源创建、Water所有权、dispatch入口及发布/释放契约不变。profile严格版本2、九类与2048候选，不执行回调。GPU仅写roots/motion及其发布纹理，权威水沙输入仍readonly。

分布改为64×32候选和共享0.30频率场，密度在草甸边缘衰减；不改变tick、源汇、账本或碰撞。渲染Shader只读图集、根部、姿态和完成时钟，输出颜色、裁剪与深度。线性剪切与局部射线逆变换一致，地形只允许根部下降。

新增材质、代理网格、MultiMesh、Species和PNG为数据资源；九个节点在场景固化，无运行时节点工厂、私有调度、存活压紧或LOD。图集导入关闭Alpha修补，该通道是深度。

策略仅更新本次植被资源、initialize敏感方法与四份表现清单身份；后者的九个材质绑定逐项核对。其他已封印边界不重签。形式场景审计检查九类和2048容量，证据转到本目录，旧验收保留。水沙越权、私有调度、profile回调等负例继续执行。

候选v4仅把渲染从双面改为剔除背面，其余分布、源资源和机位不变；开/关/开对照降低重复代理片元开销，主视口GPU从约20.2ms降至15.9ms。正反方向图像另行保存；没有通过减少种类或密度取得该差异。同步四份表现清单的shader指纹。
