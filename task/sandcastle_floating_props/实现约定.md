# 水瓶、木板、木棍第一阶段实现约定

更新：2026-10-18。角色：contract。状态：C01接口/数据结构及C02原始采样ABI于G1冻结；水瓶数值/C03于G2冻结；C04/C05仍draft，C06仅冻结公共owner边界。本文件规定待实现边界，不记录测试PASS。当前[技术方案](../../docs/当前项目技术方案.md)、[规格](../../docs/当前技术规格.md)和[既有契约](../../docs/knowledge/README.md)继续有效。

## C01 场景接口与配置

正式交付main各1件，其他三入口默认关闭道具。节点、模型、Collider、采样点、固定布局和信号连接预存为.tscn/.tres；不在_ready重建固定层级。道具动态积分用Jolt；场景只传生命周期意图，受力、探针、时间预算由一套公共服务管理。

| 接口（候选名） | 输入 | 完成语义 |
|---|---|---|
| attach(runtime, registry, layout) | 当前DomainRuntime、3件body_id/Profile/预存节点、固定布局 | 同代水样与必要碰撞就绪后可运行 |
| set_paused(paused, reason) | bool；user/save/restore/close原因 | 在服务共同物理边界保持或恢复；结束save保持不得解除user暂停 |
| reset(layout, domain_id, generation) | 成功换代后的身份及布局 | 清旧样本/预算，按新床水初始化位置、速度、睡眠 |
| shutdown() | 无 | 禁止准入；在途读者与物理引用有真实终结证明后结束 |

异步结果统一为`{operation_id:int, error:StringName, domain_id:StringName, generation:int}`。主线程调用，等待让出执行权，不阻塞GPU主流程。操作ID为正int64，身份不经过float。每次已接纳调用恰有一次完成；重复相同暂停目标可合并，冲突返回busy；shutdown优先停止新准入，负责已有操作收尾。错误至少含invalid_registry、busy、closing、stale_generation、backend_failed。

Profile精确绑定项目自定义Resource，不是ToolProfile；禁止Callable、shader路径或后端工厂。字段至少包含type_id/version、mass_kg、center_of_mass_m、每点local_position_m/half_height_m/effective_volume_m3/mass_weight、drag_time_horizontal_s/vertical_s、friction、angular_damping、速度/角速度安全界及采样误差预算。有限值、质量/半高/体积/阻力时间为正；质量权重和为1，体积覆盖不重复计量。

水瓶按封闭、固定排水体积建模，2点；木板4点覆盖长宽；木棍3点沿长度。宽板4点是本项目适配。模型根scale=1，物理尺寸按项目米制校准，不把原作Transform.scale直接当半径。

## C02 公共批量探针与读者

扩展现有views公共只读owner，读取同一有序RD流上的完整发布态。新服务不直接接触writer，不创建独立水/编辑队列或私有读回循环。预览保持原功能；道具探针有独立有界槽与回收计数，不占用preview.pending。首版最多32个点、1批在途、1份待发最新姿态；未接纳待发请求可合并，已接纳请求必须终结一次。

| 请求字段 | 类型/校验 | 语义 |
|---|---|---|
| request_id、owner_token、generation、pose_seq | 正int64，不以float传输 | 请求/服务生命周期/域代/姿态身份 |
| domain_id | 冻结域身份 | 绑定本域资源 |
| minimum_state_seq | 非负int64 | 可接受的最低完整状态；不要求恰等于最新全局状态 |
| points | 1–32项 | body_id、point_id、世界位置Vector3；ID唯一，坐标有限且在约定有效域 |
| footprints | 3件的有限XZ范围/相关chunk集合 | 同次采样的支撑版本需求 |
| limits | 冻结Profile引用或其有效摘要 | 最大样本时间差、姿态位移/转动误差；客户端不得增权 |

| 响应字段 | 类型/校验 | 语义 |
|---|---|---|
| error、request_id、owner_token、domain_id、generation、pose_seq | 全部对应请求 | 旧代不能污染新代，重复不能重复施力 |
| captured_state_seq、captured_tick、captured_revision | 非负int64 | 实际捕获身份；tick不是秒数 |
| captured_time_s | 有限非负数 | 发布完成态实际累计时间 |
| points | 数量/顺序/ID严格匹配 | sample_position、bed、h、eta、u_xz、可选bed_normal、valid |
| footprint_versions | chunk→相关床面变化版本及同代身份 | 交公共height消费者核对，不把无关全局state_seq当碰撞要求 |

bed=rock+sand；eta=bed+h；u由同态动量与有效水深求得。干格速度/浸水力为0。采样插值、格心偏移、边缘策略和可见床面基准在G1逐项验证；几何可见范围与32×32权威域不同，离开允许活动范围应明确保持/报错，不夹到边缘伪造有效水样。

错误至少包含invalid_request、probe_busy、invalid_sample、stale_generation、stale_owner、stale_pose、stale_sample、out_of_domain、readback_failed、closing。GPU未知结果只重试同一读者的终结/读取证明，不重新提交未知事务；失败不得用零数组冒充成功。

T01交付probe ABI机器表：schema版本、各字段偏移/类型/stride、int64拆装、保留字、最大字节数、错误位与完整长度。真实GPU哨兵核对后冻结。新增槽必须进入views.can_release、关闭、候选失败、退休维护和资源释放证明，不能仅靠“丢弃回调”认为资源可释放。

## C03 受力与实际时钟

力采用明确的Godot近似：每点竖直体积区间与[bed,eta]水柱相交求浸水比例；浮力=rho×g×有效体积×比例；流阻=质量份额×比例×(水速−点速度)/阻力时间。点速度含角速度叉乘相对重心位置，竖直水速首版取0。浮力/阻力施加在点位形成转矩；使用引擎重力一次，不重复加重力，不把force重复乘dt后再交引擎积分。正常运动不用每帧改position或硬设速度；异常保护触发需要记录原因。

权威时钟是同代完成态captured_time_s/advanced_time_s。禁止tick/30、每水步固定两个物理步、墙钟追赶补步，也禁止让水/编辑准入等道具完成。道具消费者持有共同时间预算，只消费可用时间，记录实际state.step和累计有效物理时间；等待时不得偷偷积分重力/接触。

G2必须在真实Jolt单瓶上选择并验证有界延迟、样本保持/插值与物体保持/恢复方案。预算、冻结/解冻相位和速度保留未获证据前，C03维持draft，禁止用公式包装宣布同步已解决。禁止修改全局Engine.time_scale或全树暂停来替代局部协调。

同代共同边界的累计时间误差预算：不超过一个实际物理步加float32时钟舍入预算；暂停期间有效积分时间不增长，恢复后不补偿暂停墙钟。原始日志同时保留GPU完成时间、样本捕获时间、物理消费时间及姿态，显示插值不能掩盖物理超前。

样本陈旧度与姿态偏移阈值在T02按目标速度实测后冻结。允许有界旧完整样本；不要求回包永远是当前最新state_seq，避免连续水步导致永久拒绝。超界保持并重采样，连续超界先定位采样策略，不能无依据扩大阈值。所有物体使用一份时间准入策略，避免互碰双方有效时间不一致。

## C04 碰撞、编辑与拾取

复用公共height的64块HeightMap，不新建一份CPU沙床权威数据。足迹包含碰撞体水平包围范围和本步运动裕量；核对generation及真正影响相关块的床面版本。未变块可保留较早全局seq，不能为道具要求全域每块追到最新状态。shape写入和物理可用边界需单独验证，不能从worker完成直接推断接触有效。

退水后重力/实体接触承托；水重新覆盖或支撑消失时唤醒。休眠物体仍保留低频/变更驱动的水床观测。填沙瞬间嵌入仅允许有记录、有界的解重叠，检查其他道具碰撞；挖空后唤醒下落。保持water/bed同基准，不能同时每帧拉到床面又让Jolt接触解算。

接触容差候选为max(0.005m,最小实体shape半径×0.05)，在T04用0.125m格距、实际可见沙面与物理面误差校准并冻结。持续超过预算或无界抛飞不得通过，不能只凭截图无明显穿插判断。

Terrain、Prop和交互拾取分层；沙刷射线显式只查Terrain，道具仍配置地形/道具互碰。单纯换Prop层但保留全层射线无效。当前阶段不新增道具点击/拖拽交互。

## C05 生命周期与存档兼容

- 初始化：预存三件保持；main完整域和相关碰撞就绪后按布局XZ及实际床/水面确定初始高度。
- 暂停：停止新的有效道具积分，在共同边界保持；已接纳水工作排空与道具保持有明确相位。暂停仍可编辑，更新水床/碰撞及支撑失效信息；正常落体与漂移在继续后恢复。若编辑必须解重叠，位移作为编辑响应单独记账，不宣称“暂停姿态绝对不变”。
- 保存：道具进入save保持；结束后按原user暂停状态恢复。第一阶段检查点不保存道具姿态。
- 成功恢复/重进：在新代碰撞原子切换的同一生命周期交接中，作废旧样本/时间余额，按新床水重置三件的姿态、线/角速度、睡眠和owner_token。
- 恢复失败：旧道具姿态/速度/睡眠不提前清空；解除restore保持后回到原user状态。
- 关闭：停止准入、处理在途请求/读者与物理引用，取得真实终结证明后释放；未知证明保持所有权并由公共维护节奏重试。

旧计划edit4/native2和gravel/shape继承链已过时，不恢复旧后端。当前SANDUE06/native3只允许已登记结构，不能把props塞入仅接受gravel_v1的visual_extensions。未来保存道具姿态须另立版本化schema。

即使不保存道具姿态，场景/公共源码/配置改变仍可能使旧档configuration_hash不匹配。T05冻结旧来源并验证显式窄范围迁移：只接纳能证明水沙语义兼容的已知来源，保留provenance并在目标配置初始化后重置道具；未知来源继续拒绝。不能改header、删除hash检查或批量放行任意旧档。若当前变更影响水沙语义，兼容门需返工，不静默清空用户进度。

## C06 架构与验证边界

统一Pipeline继续拥有水/编辑/显示调度；道具仅成为公共完成态的消费者。道具开关不得改变权威水沙、动量、材料、源汇和沙量账本；在相同输入和实际完成边界比较原始字段，而非不同墙钟截图。

新Profile类型、场景、服务、probe核及敏感方法经语义审阅进入架构policy，不能仅重生成seal。同类只改配置；不得按bottle/plank/stick名称分流成三套受力、采样或恢复工厂。

成本与功能分别按[验收计划](验收/README.md)判定。G2失败先处理时间/接触，G6性能失败先定位采样/物理/等待，历史门禁不改判。编译/headless/导出成功均不代替真实可见GPU和Jolt验证。

## G1 冻结补充（2026-10-18）

- 机器表：[probe_ABI_v1.json](契约/probe_ABI_v1.json)。Views独占公共Probe组件；请求1152B，结果3200B，32点/64块版本、一批在途。与preview.pending无关。未接纳最新姿态暂存在T02服务，不在GPU owner累积队列。
- 原始采样入口为`DomainRuntime.request_probe(request, callback)`；请求严格8键：request_id/owner_token/generation/pose_seq/domain_id/minimum_state_seq/points/footprints。points每项严格body_id/point_id/position(Vector3)；footprints为1–3个Rect2。ID按owner递增，已终结request_id不可重用。owner_token和pose_seq单调，切换上下文不丢弃在途读者。
- limits归服务侧冻结Profile/C03有效性判断，**不作为原始采样请求可增权字段**。原始采样层只保证同一完整捕获态；陈旧时间/姿态误差由T02按实际完成时间验证。接收旧完整样本不自动意味着允许施力。
- XZ活动域[-16,16)，域外拒绝；格心映射world/0.125+127.5，双线性插值bed/h/qx/qz。在边缘半格内重复边界格心；不将域外点夹进域。先插值动量/深度，再求u=q/h；h<=1e-6时u=0，h原值保留。
- 回包sample_position严格等于请求编码float32字节。eta=bed+h；初始态为state_seq/tick/revision/time=0。时间是完成态GPU时钟，非CPU tick推测。域身份通过固定SHA256字节和CPU绑定核对。
- footprint_versions记录公共Height dirty元数据中各块最后变化state_seq，同代已应用碰撞版本>=所需版本即可；不要求未变块追全局seq。shape真正进入物理可用边界仍属T04待验证。
- 读回注册失败保留未知reader，公共retry_preview_readback/退休维护只重读同一输出，不重新dispatch。readback到达（即使内容损坏）证明GPU读取终结，再给一次错误回调；未录制上传失败单独终结。关闭/退休/候选失败均受can_release约束。
- C01类型化Resource字段已落在`scripts/props/floating_prop_profile.gd`，验证有限正值、数组长度和质量分配；数值默认值不代表水瓶校准。attach/pause/reset/shutdown的异步接口语义冻结，实际行为必须继续通过G2/G5，G1不声称完成道具生命周期。

实际证据与失败记录见[G1报告](验收/G1_公共采样.md)，不在契约中写PASS。
