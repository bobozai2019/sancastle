## 执行约束与锁

- 当前锁：主执行者 T01；diagnostic_scene_v1 串行测量中。Water/Muscl 仅新增开发诊断观察入口及标签，尚未实现优化候选。
- 默认单主执行者；共享 shader、录制器、耦合和有效 profile 不并行修改；性能进程串行。
- 用户首要约束：性能优化必须优先保证架构稳定和完整。职责、状态、生命周期与恢复链路不完整的候选，即使更快也不合入。
- 用户已通过 /goal 指定执行本计划；按 T00–T07 串行推进。
- 不修改已有历史证据，不回写用户配置，不清理其他工作区改动。

## 已确认的规划依据

- 当前录制器保留 64 候选容量、标准耦合展开缓存和每阶段独立计算列表。
- 上一轮三项优化已经存在，不能重复算作本轮成果。
- `scene_profile.gd --detail-gpu` 会替换标准耦合 Callable，影响现有缓存展开路径；T01 必须避免这种归因偏差。
- 现有 CPU 探针默认引用历史录制器，精确探针支持 `--reference`；本轮必须显式固定新基线。
- 共享缓存、重试复用、局部复制融合与列表整理尚无本轮性能数据。
