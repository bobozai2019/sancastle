# C03 验证与成本

状态：frozen v1。以下为设计验收门槛，不是候选实际结果；T00输入/测点与T01仪器容差已冻结。改变门槛必须记录原因并保留失败，不按候选表现反向挑选口径。

## 统一比较条件

使用相同床面/水场初态、同工具、同动作、同源项、同模拟时间、同相机与 profile，仅更换数值算法。基线/候选独立初始化；需要海侧输入时，各自带同 tick 的未编辑控制组。

时间全部来自完成态 advanced_time_s；采样目标时间附近的实际时间必须保存，不将“请求了四秒”视为“完成了四秒”。每次 run 保存源码/profile hash、引擎/硬件/后端、原始字段/索引和失败日志。

## 水传播门

| 用例 | 输入 | 门槛 |
|---|---|---|
| 小振幅平面波 | H=0.1 m、A=0.0001 m、λ=1/2/4 m；无源/无床变 | t=2 s：λ1 振幅≥25%，λ2≥85%，λ4≥95%；所有输入同幅度归一 |
| 相速 | 同上，沿传播方向相位连续解包 | 与本浅水模型 √gH 比，λ1误差≤5%，λ2/4≤2%；不拿有限深度真实频散作此数值验收目标 |
| 深度/幅度扫描 | H=0.05/0.1/0.2 m，A=0.0001/0.0002 m | 深度波速趋势正确；小幅响应比例误差≤5%，细网格/短时参考辅助排除测量污染 |

| 二维精度 | 光滑周期波，X/Z/斜向传播，至少三档等物理域网格 | 平滑湿区适当细化后误差阶≥1.7；不得以改物理域代替网格细化 |
| 静水/负例 | 平床、缓坡、台阶、干湿岸线、障碍 | 短测无自发可增长流；最终5分钟最大水深漂移≤0.0001 m、无负值/NaN |
| 强波/强挖填 | 干床溃坝、陡坎、近干格、强编辑、CFL容量触发 | 有限/非负，界面与前沿符合参考解；过载只缩短 actual_dt，不伪造完成 |

谱振幅测量采用完整波长区间，远离边界影响；相位按多时点连续解包，不用单时刻包裹相角误认整周期误差。圆波的自然几何衰减不计入平面波数值门。

## 水沙与通量门

- 短固定床封闭测试：水相对闭合误差≤1e-5；悬沙相对闭合误差≤1e-5；计算误差分母分别为初始正存量与源输入的明确定义值。
- 浓度 c=0.01、0.05 两档，h≥0.01 m 湿区：恒定浓度最大绝对误差≤1e-5，变化床面/交换关闭；不得用总量通过代替局部一致性。
- 每子步净水通量重建深度：最大差≤2e-6 m；阶段反向测试同时验证真实供沙侧、非负与质量闭合。
- 5分钟水闭合≤0.5%；5分钟 sand+sediment 总账闭合≤1%，沿用已有严格源汇分类。无源量为零时采用事前冻结的绝对容差，不除零。
- 所有非有限量/实质负值为失败；roundoff 修正逐次计数和累计体积，容差在 G1 冻结。不得放宽现有更严格的适用契约。

## 实际铲沙与浮物门

标准动作：`shovel_v1`，trench_width=0.5 m、depth=0.15 m、shoulder_width=0.5 m，动量B/policy2、speed=0.25，沿1 m笔画；连通排水关闭。先在固定0.1 m水深验证，再在冻结的 main/用户入口实际状态验证。侵蚀开关等按有效 profile 记录。

G0 选定可持续湿润的远场测点（距笔画1.5–3 m，至少三个）与相机，保存坐标后不得为候选挑点。以相同算法的“有编辑－无编辑”差分排除背景潮汐。

计划效果门：

1. 远场测点在0–6秒内的峰谷起伏中位数达到一阶基线的≥1.5倍，且不是孤立尖峰；先到近点再到远点，抵达顺序与物理传播相符。
2. 在每个1秒滑动窗口内计算 `delta_eta` 的半峰谷值，阈值为0.5 mm，并要求至少两个相邻测点有依次抵达的相干波形；满足条件的远场可辨窗口总时长相比基线增加≥1个模拟秒。保存完整0–6秒序列，静态水位偏移不能当成持续波。
3. 若基线太接近仪器噪声或场地没有三个合格湿点，G0 先按统一选点规则调整基线/候选共同初态并封存；不得在候选结果后改标准。若标准动作物理上无法满足效果门，保留失败并进入分辨率/源形状归因。
4. 固定镜头连续画面能辨认外传前沿和衰减过程；水面原字段也须支持，不能只靠细法线动画。
5. 现有浮物记录采样时间/代次、eta/u、浮力/阻力、位置/速度；与无波控制组及波到达时间一致，存在可测的受力和运动响应。物体可以因惯性/阻尼滞后，不要求逐帧贴波面；保持/过期样本不得伪装为无响应。

## 生命周期门

至少覆盖活跃波中暂停/继续、完成边界保存并重启恢复、活动编辑排空、切场景、旧generation回调、候选构建失败、读者延迟与关闭。恢复原字段/时钟/账本按既有 contract；算法切换只按明确来源转换。RK scratch 不泄漏、不进入已发布视图。

## 性能目标、优化限时与长稳

依据用户2026-10-20指示“性能部分可以降低标准，优化最多执行半小时”，本任务采用以下局部例外；不修改项目其他任务的全局性能契约。原1920×1080、p99≤33.3 ms、推进比例≥0.95只保留作历史参考，不再作为本任务交付硬门。

- 开发交付测量使用实际可见1280×720、GTX1050档、D3D12 Forward+、关闭VSync，保持完整水沙/白沫/碎石/浮物负载；记录实际引擎、驱动和客户区尺寸。按明确的新标准降低输出尺寸，不冒称通过1080p旧门。
- 预热后测量60秒，目标p99整帧≤50 ms、完成模拟时间/有效墙钟时间≥0.80；两项均为尽力目标。未达到时报告实际数值、交互/队列与模拟变慢程度，不因此无限返工或阻止已经正确完成的功能交付。
- 先测用户复现入口；如与main相同不重复跑。第二个不同入口仅在预算足够时补测，未测范围明确列出。shader首次编译单列，主动暂停和初始化不计稳定窗口。
- 记录整帧、实际dt/substeps、队列和模拟推进比例；能直接获得的CPU/GPU pass、显存及浮物采样年龄一并保存。优先现有探针，不为完整profiling另建大系统。

**性能专项累计上限1800秒**，覆盖定位、优化修改、编译、工具等待和复测；性能工作跨任务/回合累计，不重置计时，也不能通过改称“性能验证”继续执行。每段开始/结束按墙钟写入执行状态，首次性能专项开始时才启动预算；计划编写与普通数值功能实现不计入。五分钟水沙正确性长稳属于原有功能验证，但不得借其名义追加性能调优。

预留最后5分钟确认或恢复最近已验证正确的候选并整理测量结果；剩余时间不足以完成修改及必要回归时不再启动新优化。达到上限立即停止性能探索/改码/追加复测，使用已有证据报告未达目标或未测项。不能因预算耗尽把未验证的最后一次优化切成默认；保留或恢复已验证版本。性能不足不自动启动512²、替代求解器或全项目优化。

G6可在G0–G5、守恒/稳定性、恢复及默认接线符合要求时，以“功能完成，性能目标未达/存在限制”的明确结论交付；性能子项不得伪写PASS。崩溃、NaN、守恒破坏、资源失控、无法完成交互等功能缺陷不作为性能豁免。

五分钟水/沙长稳及其数值阈值保持不变，集中在参数稳定后执行；本次放宽不降低数值正确性和生命周期要求。

## G1仪器与算术规则

reference固定基准为`验收/reference_fixture_v1.json`的`fixed_bed_2d_v1`，由归档reference.py/verify.py定义静水、同8 m域X/Z/斜向32/64/128/256细化、常浓度、干床与近干短例。CLI精确校验fixture对象，未实现suite拒绝；该基准不是G0的24例波长矩阵，不得混称覆盖。

CPU基准使用float64，另以float32执行拒绝试算、最终速度帽、浮点修正等策略检查。单变量空间细化使用同一物理域/波/完成时间，最细一档误差阶仍需≥1.7，原先未达的粗档保留。不能因加密通过就将生产域或网格静默改为参考网格。

GPU/CPU水算子对照首先从GPU audit读取所有接受dt，CPU按同序列重放，避免“相同tick但不同子步”污染误差。固定床短0.1秒，光滑湿区h最大绝对差≤2e-6 m、q≤2e-5 m²/s；强波/近干h≤2e-5 m、q≤1e-4 m²/s。阶段比较使用一个预先小于阶段界的单接受步，保证阶段原场与audit对应。独立两秒保幅/相速仍按本契约原门槛，不用短场误差替代。

roundoff采用C01的8ε局部规模界与2e-6 m绝对上限，次数和按RK权重实际增加的体积同时记录；超限、非有限或未计量clamp均失败。仅当初始正库存和分类源输入均为零、相对误差分母为零时，水/沙短闭合绝对容差分别1e-8 m³/1e-9 m³；有正库存则继续使用原相对门；长稳仍按原0.5%/1%门。netflux重建误差2e-6 m不变；需同时报告roundoff体积与原始库存误差，不能把数值修正记成物理源以隐藏不闭合。

恢复检查以容器、完整字段/控制/时间字节和完整配置验证为依据，引用原Variant白名单，不以JSON重建配置。新counter和scratch生命周期按C01归零不进入native3。正式迁移/生命周期仍由G4验证，此处只冻结规则。
