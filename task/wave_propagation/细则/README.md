# 任务细则

全部由主 agent 串行推进；每项四个小目标。开始时在[执行状态](../执行状态.md)登记写入锁，完成时用独立 Gate 报告证明交付，不仅勾选表格。

| 任务 | 依赖 | 小目标 | 状态 |
|---|---|---:|---|
| [T00 基线与测量](T00_基线与测量.md) | 无 | 4/4 | [已完成] |
| [T01 数值与接口契约](T01_数值与接口契约.md) | G0 | 4/4 | [已完成] |
| [T02 GPU二阶水传播](T02_GPU二阶水传播.md) | G1 | 4/4 | [已完成] |
| [T03 悬沙与耦合](T03_悬沙与耦合.md) | G2 | 4/4 | [已完成] |
| [T04 完成态与恢复](T04_完成态与恢复.md) | G3 | 4/4 | [已完成] |
| [T05 铲沙与浮物体验](T05_铲沙与浮物体验.md) | G4 | 4/4 | [已完成] |
| [T06 成本与交付](T06_成本与交付.md) | G5 | 4/4 | [已完成] |

各任务回报：变更行为与文件、逐个小目标状态、命令/退出码、结果索引、失败与未知、契约变更、写入锁是否释放。不得以候选 CPU 简化模型或竞品 shader hash 通过代替生产 GPU 或主场景验收。
