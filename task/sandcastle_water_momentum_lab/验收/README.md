## 量化判据（拟定，G1冻结）

1. 编辑层：h与悬沙以及支持域外q逐字节保持；无效／重复输入无新增修改。CPU/GPU候选q比较起点 `abs误差≤2e-6 m²/s + 2e-5×abs参考值`，另保留最大误差位置与分支；具体浮点运算差异在G1确认，禁止事后按失败值放宽。
2. 水步层：无NaN/Inf、负水深／沙厚；封闭水域五分钟水量相对闭合误差≤0.5%（沿用项目上限），同时报告绝对误差和A0差异。源汇工况按账户闭合；近零存量不使用失真的相对数。TRANSFER误差预算在G1按夹具冻结，不用扩大笔刷区域放宽阈值。
3. 连续性：相同accepted样本只改变上传分批，应满足候选数值容差；改变采样密度时，在暂停水步的同一几何路径上，累计注入量范数差目标≤1%，并检查空间分布差异。实时30/60/144渲染帧率的结果另按实际水时钟比较，不能与暂停精确对照混算。
4. 效果：预先为各夹具给出速度方向、响应ROI和时间曲线预期；冲量使局部速度出现可测变化、停止后源项归零，水量变化来自水步。凹坑允许蓄水，平顶堆允许暴露求解器局限。效果曲线、画面和人工评议分别记录，不给“完全像竞品”虚构阈值。
5. 成本目标：GTX1050／D3D12／可见1280×720／VSync1、256²条件下，候选**水编辑段（含其必要校验）GPU P95目标≤2ms**；完整实验拖动帧P95目标≤33.3ms。均为本实验拟定目标，不是已有测量或主场景承诺。更换硬件须单列基线。
6. 渐进退化：预热后首／末各30秒的相同操作窗口，GPU水编辑P95、整帧P95、队列年龄分别比较；增长超过 `max(10%基线, 3×配对重复噪声MAD)` 必须定位并给出通过／失败判定。不得用平均FPS掩盖长帧；不接受因湿区复杂度触发百毫秒串行排水回退。
7. 稳态资源：队列有上限、命令不静默丢失、显存／对象数无持续增长；退出完成后自有RID全部释放，旧代回调被隔离。GPU未完成不能按超时宣称释放成功。

G1记录最终数值判据、理由及适用输入，G4冻结profile后才集中测成本。未达到目标如实保留FAIL／未知和瓶颈，不能改旧报告。

## 对照节奏

- 先编译、短运行、CPU参考和小域负例，再固定参数做可见短对照；只重跑受影响验证。
- 首轮封闭静水、无侵蚀／额外源；第二轮只加入受控水输入。A0/A1/B复位至同初态，固定相机、seed、轨迹和模拟完成时钟。
- 成本至少三次交替配对，分别报告响应核、校验、正常水tick、发布与CPU；记录样本数，P99不足样本时不声称稳定分位数。
- 自动轨迹与手动试挖分开标记。手动结果必须记录实际接纳命令数，零接纳不能当作捕获交互；人工复现说明与GPU证据分开。
- 详细时间戳／场快照用于定位；低扰动模式用于成本，禁止每帧全场同步读回。
