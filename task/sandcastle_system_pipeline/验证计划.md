# 全系统调度验证

角色validation_plan。实际结果只写验收目录。旧结果保留源码身份，不累计新Gate。

1. CPU内核：同stream录制依赖与跨stream完成依赖分开，读读共存/写hazard，显式依赖/未来/错代次/重复/容量/耗尽/重入/取消/unknown。无Node、工具类或GPU环境依赖。
2. GPU provider：原普通编辑混合拒绝、水CFL1/2/3/64/超限、权威双槽与GPU时钟、共享scratch及完整发布。不是空job计数。
3. 形状：墙/城堡/铲子连续多段及交替，实际沙/水/动量/材料、基线、库存/守恒和拒绝后续段；事件证明不依赖逐段CPU ACK准入。
4. 全功能：普通、shape、悬沙、compact/smooth、碎石和水tick交错，CPU阶段真实读取正确版本；业务层无legacy选择/全局忙锁旁路。
5. 消费者：真实64块高度、共享边、Jolt射线，双槽饱和/乱序/坏数据、worker/preview/显示最后消费者。
6. 生命周期：queued/recorded/完成未消费/物理未应用下保存恢复、候选失败、切换及关闭，各owner部分初始化/注册失败/终结不可用，不重发未知工作。
7. 最终三入口真实可见窗口，全工具，至少10次生命周期完整循环、至少3分钟混合操作（IO/切换时间不计），活动资源回基线；代码/配置/引擎hash冻结，日志错误分类。

纯内核可headless GL Compatibility；真实GPU用Steam Godot 4.7.2、项目默认D3D12 Forward Plus、Jolt，保留实际命令/配置。无性能KPI，不重开旧成本专项，不改视觉/物理参数。当前用户运行实例不作为本任务探针，不结束或混用其日志。
