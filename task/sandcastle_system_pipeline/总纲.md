# [进行中] 全游戏底层统一流水线调度

日期：2026-10-17。角色：execution_plan。来源：用户要求“整个游戏都是新流水线”“流水线属于更底层的系统调度级别，业务层不应有非流水线”。

目标：正式main及两个可编辑入口的普通编辑、水模拟、沙墙/城堡/铲子、投流沙、压实/平滑、碎石、预览/碰撞、保存恢复、场景切换与关闭，共用底层作业/依赖/所有权调度。业务只提交意图、领域参数与业务结果消费，不再管理legacy切换、GPU忙锁、逐段全局收尾或场景内第二套执行循环。CPU/GPU/物理/IO允许不同执行器，但都登记到同一依赖图；真实数据依赖、原子提交和生命周期仍保留。

旧sandcastle_gpu_pipeline为“普通挖填+水模拟，其他工具兼容交接”，原32/32及失败记录保持原范围，不能计为本任务完成。

## 运行模式

正式新系统仅在接线与真实集成验证后切换；未接线的新内核CPU测试不计游戏已迁移。旧pipeline_v1及显式旧模式只作兼容/历史验证，不得把新类外包旧全局模式切换宣称为统一完成。迁移顺序允许中间态，但每一中间态明确记录。
