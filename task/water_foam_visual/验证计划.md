# 泡沫验证计划

角色：verification_plan。以下为计划方法，全部用例[未开始]；没有本轮实现测试结果。

## 用例与判据

| ID | 用例 | 控制与观察 | 通过口径 |
|---|---|---|---|
| V01 | 当前基线/关闭分支 | 两场景，固定seed/tick/profile/相机，记录实际time_s与三层开关 | 点状层隐藏；新模式关闭回到当前基线；身份、参数完整 |
| V02 | 形态与强度扫描 | 固定床面、零/弱/强泡沫，静止纹样；输出覆盖图和自然光画面 | 零覆盖不生沫，覆盖总体单调，弱历史开孔消退，强区保留破碎轮廓 |
| V03 | 正反流/相位周期 | 恒流夹具与正式浪，局部ROI追踪，连续≥2周期 | 运动方向正确、位移有界，重置点无同步全域跳变 |
| V04 | 冻结、慢帧、暂停/恢复 | 相同完成时刻比较纹理相位，冻结期间固定机位 | 完成时钟不动时图案不动；同版本恢复相位一致 |
| V05 | 近远景、光照和边缘 | 固定两档距离、720p/1080p、阴影/亮处、纹理接缝 | 无明显闪点/锯齿/平铺接缝；泡沫不重复发白，清水高光保持 |
| V06 | 上岸/退浪/静水 | 两正式入口连续观察，分别关闭主水沫/岸脚作归因 | 无等宽永久白圈、过亮双边或全水面乳白；退浪有可读残沫 |
| V07 | 动态堆挖 | 沫区内堆沙/挖槽，实时及暂停编辑各一次 | 跟随当前可见水沙接触，不在新干沙悬浮，不偷走时钟 |
| V08 | 正式启动/参数负例 | 两入口，隔离参数配置；默认、保存值、非法值、缺纹理 | 实际消费一致，错误明确；小白点不会被参数重启 |
| V09 | 权威隔离/生命周期 | 同输入完成tick对照权威字段；保存、恢复失败、切换和退出 | 权威结果一致，恢复规则保留，资源回收正常 |
| V10 | 正式PCK | 匹配引擎/模板，项目外启动，检查原始字节与导入对象 | 新纹理和manifest实际可用、GPU运行有效，不依赖工作区文件 |
| V11 | 成本与优化时限 | 固定完成态渲染隔离＋真实完整负载，各两场景/两尺寸；记录优化累计时间 | 满足C05且优化≤1800秒；超时未达标或计时无效不判通过 |
| V12 | 最终长稳与文档 | 稳定版本各10min，≥3浪周期，5轮切换/退出 | 无新视觉漂移/增长性泄漏，现行文档准确且生成器检查通过 |

形态的连续性与自然程度需要标注ROI的画面审阅，不能用整图相似度或白像素总数替代。比较画面必须同尺度、曝光与机位；人工判断注明观察者和条件。

建议辅助量化：
- 恒流ROI纹样位移方向与给定速度投影一致；受双相位混合影响不要求每个图案有永久身份。
- 记录相位边界前后ROI覆盖/亮度变化；突变若明显高于相邻非重置帧，标记返工并人工检查，不把自然浪强度变化误判为重置。
- 记录透明draw、细节/场读取和纹理实际导入字节；不能只凭shader源码行数估算GPU耗时。

## 测量节奏

每个材质候选：导入/编译 → 短运行 → 相关负例 → 同完成态单变量对照 → 连续观察。G3形态稳定后，才集中执行V11和V12。性能运行不并行游戏实例，不录屏，不在计时区同步抓图；为证明视觉另跑同源同配置录像。

首次性能优化启动前记录计时起点、已用秒数和剩余秒数，整个计划共用30分钟上限。诊断、修改、编译等待、优化候选的性能和视觉复测均计入，跨任务或换方案不重置。发起探针前校验剩余时间并限制超时；到期中止优化，未完成样本保留为不完整，不能延长到采样结束。初次基线/成本验收及停止优化后的只读验收不计入，但禁止借其继续调优。报告同时给出性能结果和时限遵守情况，二者分别判定。

C05中的P50/P95分别对各段有效原始样本计算，再报告两次A/B差异与A/A噪声。A/B统一从同一初态和输入序列开始，记录completed_time起止边界，不能用提交tick数量替代完成吞吐。
