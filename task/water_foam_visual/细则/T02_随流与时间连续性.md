# T02 随流与时间连续性

负责人：主执行者。初始状态[未开始]，0/4，0%。依赖G1。

| 小目标 | 初始状态 | 交付 |
|---|---|---|
| G01 米制速度与双相位UV | [未开始] | 有界位移和权重实现 |
| G02 相位重置与重复纹样控制 | [未开始] | 至少两个周期的连续证据 |
| G03 暂停/慢帧/恢复时钟 | [未开始] | 同完成时间的相位一致 |
| G04 近远景和正反流验收 | [未开始] | G2报告、采样统计 |

输入：G1纹理/覆盖、C01/C03、当前完成态水深/动量/async_clock。本阶段只改变流动方法，不重新调整覆盖阈值或泡沫来源。

实施：双相位权重在对应重置点为0；使用q/max(h,epsilon)并做明确的薄水正则化与视觉限速。位移单位是米后再乘纹理频率，禁止持续累计t×velocity。从零流、恒定正反流到空间变化流依次观察，最后接正式浪。相位纹样混合先保持两次采样；确需第二尺度才增到四次，记录必要性。

允许修改：水面shader的新泡沫函数、已冻结的参数字段、本任务运动夹具/探针。禁止改compute历史、权威速度、发布链及其他水光学效果。

验收：V03/V04/V05。局部追踪与连续画面同时证明方向正确；跨相位边界无全域同步跳白。暂停固定相机时图案不滚动，慢帧仅跟已完成模拟时间走；恢复后同完成态相位一致。远景不开锐化、不出现闪烁白噪点。

G2证据保留带模拟时间/完成身份的序列和时间曲线，单帧截图不用于证明运动。
