# final_cost_v3 成本审计

结论：整体不通过。20 个运行齐全、来源未漂移，但每组实时 A/A 至少一端未通过稳定性预算；部分 A/B 也超预算。不能把这些结果单独归因为新 shader 回归，也不能据暂停 GPU 改善宣称完整性能达标。A/B 同时包含接触增益 1.0→0.55 的选定配置变化。

## 原始数据与运行有效性

- 核对 20 份 `*/capture.json`、`*/result.json` 和各自 `sources_before.json` / `sources_after.json`：退出码均 0，无 timeout、fatal_log、source_drift；前后及跨 20 运行来源映射完全一致。每组 configuration_hash、相机相同。
- 引擎 4.7.2 stable steam、GTX 1050、D3D12；窗口与 viewport 对应 1280×720 / 1920×1080；全部正式 VSync=1、max_fps=0。所有采样帧 focused=true，last_error 和 props_error_before/after 均为空。
- 40 个暂停/实时区间使用单调墙钟 deadline，时长范围 30.002307–30.336639 s，每区间 306–1799 帧。时间戳严格递增，所有样本处于各自 start_us/end_us 内；暂停固定 tick240，实时吞吐按区间完成模拟时间差/墙钟时间差计算。
- A 为集成前原始水 shader + contact_gain=1，B 为正式 shader + contact_gain=0.55；GPU 指标为 viewport 渲染计时，不证明覆盖异步模拟 compute。温度/频率等外因未被本审计归因。

原始相对路径：`{main,test1_geometry}_{720,1080}_{A1,A2,B1,B2,A3}/capture.json`、同目录 `result.json`、`sources_before.json`、`sources_after.json`、`timings.csv`；统计和判定见 [analysis.json](analysis.json)。执行顺序每组 A1→A2→B1→B2→A3；初始 A/A 为 A2−A1，末端 A/A 为 A3−A2。

## 分析器判定边界

`tools/water_foam/analyze_final_cost.py:21` 的 valid 判定未纳入 focused_fraction、VSync/viewport身份、props_error、timeout、区间样本时间戳包含性/单调性，也未要求所有计时字段的有限样本数等于总样本数；来源稳定性信任 result.json 的 source_drift，而不自行复核前后映射。因此该 valid 不能单独证明这些条件。本审计已独立核对本批实际数据的焦点、正式配置、props/退出状态、来源映射与时间区间，上述遗漏未把本批结论变为通过。

本次仅新增此审计报告，未改分析器、运行代码、阈值或既有原始数据；未启动 GPU 工作。
