生产文件基线见 [production_identity.json](../../../test_output/approx_gpu_edit_trial/baseline/production_identity.json)。包含 project.godot 及 configuration_signature 扫描的全部资源路径、字节数、SHA256。扫描实现定位 scripts/beach/beach_recovery_entry.gd:27、:37；tests/experiments 与 tools/approx_gpu_edit_trial 不在扫描根内。最后交付须重核全部基线，不能仅凭路径隔离判 PASS。

复用边界：compiled_worker_entry 的视觉验证链、reference_preview 的初始化与正常 tick、lab_solver 的确定性初始化、staged_slope_coupler 的侵蚀后材料更新。实验 lifecycle 显式复制并适配 _render_setup、_render_finish_tick、_record_sand_audit：去掉碰撞 setup、dirty-height 回传、沙高度预取；近似账本只报告偏差，不调用生产库存闭合断言。正常 CFL、潮汐账本和定期数值审计仍保留，不能称整个程序零读回。

场景继承保留一个未初始化的旧 proxy 节点及空 StaticBody 占位；没有调用 setup_render、没有 shape 分配、没有碰撞高度请求。功能探针检查 CollisionShape3D 数量为零、proxy.rd 为 null。这不是禁用其 process。后续可进一步移除占位，但不得由此宣称尚未验证的碰撞开销收益。

契约冻结数值：域 256×256、cell 0.125m、原点 (-16,-16)，XZ 闭开 [-16,16)，cell-center = (i+0.5-128)*0.125。平面高度 0m；相机 (-6,6,10) 看向原点。半径 [0.125,1]m，默认 0.3；单笔名义量 (0,0.06]m³，默认挖/填各 0.015；pending 64、batch 8，不合并。每批后优先消费一个已到期 tick，暂停只编辑。strength固定1、seed固定101。按每 0.75m 路径折算名义量，每段最多 0.06。准确核逐pass诊断批量1，正式运行最多8。SceneTree内每次复位增加epoch；关闭优先于未完成复位。

沙模板：线性径向 capsule 权重，连续积分 πr²/3+Lr；幅值 amount/integral，限 0.1m/笔，沙厚 [0,4]m。边界、离散采样、无沙与限高均不补偿。水模板：湿单元 h>0.0001m 时 h'=clamp(h-Δsand,0,4)，干单元不造水；速度模板叠加径向 sign(Δsand)*0.25*w m/s，局部速度长度限 1m/s，动量重新写为 h'v。正常模拟仍以编辑后的状态取 CFL，保留 64 子步预算及失败路径。模式 none 不改水/动量。C05 公式冻结为候选，连续稳定性与视觉取舍待 T03/T04 实证。

准确 GPU 中间对照：独立 exact_dispatch_adapter 保留生产沙归约、水位移/速度核和 GPU control/receipt，直接有序提交并发布，无 CPU receipt 读取。submission revision 表示提交序列，拒绝/实际体积只能由窗口末诊断确认。它同时保留准确沙编辑，故不能把其与近似候选的总差异全部归因水核；另做 exact policy 0/3、approx mode 0/1/2 的单因素核对。

新初态由同一 reference_bed 原生 CPU 字段和确定性零初始化获得，启动 tick 0，不沿用历史 tick60 微差夹具。后续索引须记录初态各字段 hash、有效视觉 profile、实际 80 浪请求、渲染尺寸与负载。
