# G5 碎石MVP交付

日期：2026-10-15。范围：T05 / V12–V14及受影响回归。结论：PASS。默认512颗，容量1024；完整实现按Godot适配交付，不冒称原作公式已复原。

## 行为与入口

直接运行scenes/main.tscn、scenes/playable/test1_capture.tscn或test1_backwash.tscn即有GPU碎石，不依赖probe入口。碎石贴可见床面、随局部q/h搬运，退水水平停留、再次覆盖且有流速后起动；挖填只重贴床，暂停/重复publish不偷步；检查点保存双状态，候选验证/失败/场景回退保持完整。

运行结构：gravel_playable_entry继承原刷子完整入口，reference_preview只新增完成态virtual hook，GpuGravelField及visual_gravel_step独立只读水沙，静态GravelLayer/MultiMesh/实体mesh/material负责显示。未引入逐粒CPU碰撞或常规位置回读。已冻结契约与实际接口见[契约入口](../契约/README.md)。

## 限制与兼容

颗粒是无反作用的贴床表现，不提供逐颗碰撞/堆叠、真实滚动、埋沙/释放、阻水/排水或道具浮力。斜坡网格足迹为近似接触。1024为验证配置，未新增用户业务UI。

旧存档缺扩展时按profile重新seed，不能声称恢复旧颗粒；原权威configuration严格校验保留，仅明确G0旧配置有精确白名单迁移。其他不兼容历史源码存档仍拒绝。512/1024或enabled配置不匹配的有扩展存档拒绝，以免静默丢弃状态。

180秒期间每段末颗粒纹理2、uniform组2、pending0，node/resource count稳定；静态内存约164.8–166.7MB，观察未见持续单向增长。这是本轮代表性稳定性证据，不代替无限时长泄漏证明。

交付文件身份、最终复验入口及报告汇总见[交付manifest](../../../test_output/gpu_gravel/delivery_20261015/manifest.json)。最终数值复验transport_1792039002_966仍33项通过，包含实际compiled_compute_sha256；最终组件继承复验visual_1792039007_425仍11项通过。原包/RDC未改，其他任务未提交改动保留。原作未知与本项目适配已分别记录到[竞品知识入口](../../../docs/competitor/README.md)。
