# 碎石绘制契约

状态：frozen_v1（2026-10-15，G0）。T00/G0冻结。以下为Godot适配。

1. scenes/components/gravel_layer.tscn预存GravelLayer/MultiMeshInstance3D，网格、材质、最大实例容量、静态实例buffer保存在.tres。同一组件挂到三个可编辑场景；runtime仅绑定GPU纹理、实际count与domain变换，不在_ready重建静态层级。可变的MultiMesh/ShaderMaterial设置resource_local_to_scene，Texture2DRD包装属于各自owner，避免切换/candidate把活动场景绑定改掉；candidate提交前不修改活动显示资源。
2. mesh使用闭合低面数实体，原点约定为床面锚点；ID决定半径、色差和水平朝向。正常受光、写深度，法线随缩放/朝向正确变化；不沿用白沫的unshaded透明片。
3. 所有静态instance transform一致；顶点着色器用INSTANCE_ID计算texel并精确采样当前RGBA32F位置（nearest/texelFetch等价取数，无插值混入其他粒子）。顶点偏移在domain-local中完成，然后走一致MODEL变换；使用Texture2DRD与主RenderingDevice，不使用local RD纹理冒充可直接显示。
4. MultiMesh custom_aabb覆盖整个允许xz、当前床高范围及半径余量；床高变化后仅调整批量AABB必要元数据，避免CPU逐粒位置回读。超过允许床高时不能静默消失；更新界限或明确报错。渲染shadow/reflection与color pass取同一粒子位置。
5. 碎石先作为不透明床面几何进入场景色/深度，再由当前水体透射/吸收/折射合成。水面是否正确遮挡碎石、反射支路可见性及深度读取必须用实际材质验证；本轮不修改水光学公式来掩盖错误。
6. 锚点y与当前可见床面一致；可冻结少量嵌入偏移帮助接触观感。近景不得明显悬空或深穿床，斜坡足迹误差记录并单独归因。MVP不保证每个网格顶点都不与倾斜沙床相交，也不保证粒间互不重叠。
7. 常规tick无texture_get_data(_async)碎石位置回读、无每颗set_instance_transform。CPU只提交批量compute与材质纹理/版本绑定；save和主动diagnostic探针例外，需单独统计。
8. 初版512颗、容量1024，一个批量主体即可；实际draw数量含shadow/reflection，不能将“一次实例绘制”冒称全场永远一个draw。区域拆分、LOD、真实滚动留到有成本/观感证据后决定。

T02/T03实际接线：组件layer=5，主窗口与reflection_camera第3层读同一个Texture2DRD。默认静态AABB床高[-32,64]m；owner以rock上下界及(初始全域沙量+所有外部添加)/cell_area保守扩大高界，generation/源账本变化时更新批量元数据，无逐粒回读。关闭或count=0时layer=1且隐藏，避免空组件触发动态反射支路。候选与活动组件材质独立；提交前仅bundle持有候选纹理，不改活动绑定。

官方路径依据：[MultiMesh浮点纹理/INSTANCE_ID](https://docs.godotengine.org/en/stable/tutorials/performance/using_multimesh.html)、[Texture2DRD](https://docs.godotengine.org/en/stable/classes/class_texture2drd.html)、[MultiMesh AABB和批量裁剪](https://docs.godotengine.org/en/stable/classes/class_multimesh.html)。T00验证实际4.7/D3D12支持和命令屏障，T02验证显示贡献；两者不互代。
