# 碎石生命周期与检查点契约

状态：frozen_v1（2026-10-15，G0）；T03按实际接口回填。以下均为Godot适配。

## 1. 模块接口

GpuGravelField由主RenderingDevice创建/访问，GPU调用在render线程；owner控制tick与异步主线程回调。粒子位置不作为CPU每帧响应返回。

| 操作 | request字段 | result/错误 | 语义 |
|---|---|---|---|
| initialize | solver、spirv、profile、generation、tick、revision；optional restore_state | bool + last_error | 创建完整ping-pong与uniforms；失败释放已创建RID；domain变换由静态同级场景节点提供（当前identity） |
| advance | target_tick:int、revision:int、generation:int、dt:float>0；同态solver纹理 | bool + last_error | 旧token拒绝，重复target_tick幂等；成功后current_index切换 |
| reproject | completed_tick:int、revision:int、generation:int；同态床/水纹理 | bool + last_error | dt=0、只贴床/湿润判断，不移动xz |
| current_texture / owner._publish_textures | owner核对generation/tick/revision | texture:RID；field保存版本metadata | 仅完整状态能被Texture2DRD绑定；pending不发布；publish不推进时间 |
| capture_async | callback、immutable request_id | Error；callback(bytes,key,identity Dictionary) | identity含request_id/generation/tick/revision；保存/诊断专用；成功/失败均结算pending计数 |
| GravelCodec.validate | checkpoint Dictionary、optional expected_profile、expected_domain | StringName（空=通过） | 纯检查，不替换活动世界 |
| release | 无 | bool；pending>0返回false，0后幂等完成 | owner先解绑显示引用，先释放uniform/pipeline再texture/shader；不会二次free |

错误至少区分invalid_gravel_profile、gravel_generation_mismatch、gravel_state_invalid、gravel_capture_failed、gravel_restore_failed、gravel_profile_mismatch、unsupported_gravel_version。初始化/tick失败进入现有owner错误流程；保存失败不替换已有活动状态。正常重复publish/advance不得误报致命错误。

## 2. 可选检查点扩展

checkpoint.visual_extensions.gravel_v1（Dictionary）。保留现有Store envelope及gpu_beach_native既有版本（当前刷子main使用2，原入口1仍受原校验）；不向其fields/spare/foam添加键，避免严格字段数量校验被破坏。

| 字段 | 类型 | 必须/检查 |
|---|---|---|
| version | int | 1；未知版本提交前拒绝 |
| enabled | bool | false时无GPU state；true须完整后续字段 |
| domain_id | String | 必须匹配当前场景domain，不跨场景消费 |
| profile_id / profile_sha256 | String | schema/profile身份；与当前兼容配置匹配，否则拒绝 |
| profile_values | Dictionary | 冻结字段白名单/类型/单位，含seed/count/capacity/布局/阈值；与hash对应 |
| tick / revision | int | 必须等于同检查点水沙完成态 |
| source_generation | int | 记录来源；恢复后重映射为新generation，不沿用旧token |
| current_index | int | 0/1 |
| state_0 / state_1 | PackedByteArray | 每份width×height×16字节；解码值有限、xz在域内、wet_state为0/1 |
| width / height / count / capacity | int | 布局与profile一致；未用texel确定；禁止payload长度欺骗 |

兼容当前权威配置的旧存档缺visual_extensions/gravel_v1：读取照常成功；启用碎石时按当前profile和恢复床/水场重新初始化，记录legacy_seeded状态，不能声称保留了旧存档中本不存在的碎石。既有完整configuration/source hash约束继续有效：仅对assets/gravel/legacy_configuration_20261015.bin中确切G0旧配置做白名单迁移，不能放行任意不同物理代码的历史存档。迁移目标为owner本次启动冻结signature，随后仍完整验证权威/刷子字段。新存档有扩展：严格恢复，不因扩展损坏静默随机重建。enabled=false不申请碎石资源，扩展只允许version/enabled两键，owner还校验当前开关匹配。

本兼容承诺为新代码读取旧存档；不承诺旧版本代码重新保存时仍保留碎石扩展。Store保存完整Dictionary，但该项的专门语义校验须接入所有save/load/restore入口。形状刷子等新存档扩展由最新基线决定，共存时保留其字段。

## 3. 保存、恢复、切换与关闭

1. 保存前停止新tick/input，等已有tick和编辑publication/碰撞约束完成。捕获同一revision/generation的水沙与两个碎石状态；碎石回读用单独expected/pending集合，不混入checkpoint_entry当前capture_raw==22固定判断。全部完成且通过校验后才写原子检查点。
2. 恢复先做全部CPU schema/值/身份检查；构建candidate solver、碎石纹理/uniform与显示绑定准备，验证state原字节。candidate失败等pending清零再释放，活动碎石不改变；已有完整候选恢复契约继续生效。
3. commit同步切换所属资源与metadata，发布后重绑GravelLayer，再释放旧资源；新的generation和tick去重元数据从恢复状态建立。不得保留引用旧solver的uniform set。
4. scene switch自动存各场景碎石状态；shutdown等待碎石在途回调和GPU release完成。加载目标失败时从已保存的旧场景检查点回退，碎石也恢复。扩展release_records的核对口径，不能仅凭旧solver释放判断全部资源已释放。
5. 任意旧generation/request的回调不得写入活动状态、计错活动pending或绑定已释放RID。pending按请求所属对象结算；关闭期间保留对象至最后回调结算。
6. 暂停/冻结没有水平推进；编辑只执行reproject。初始化、恢复及重复_publish_textures均不能触发advance。执行前核对实际继承链，避免在_publish_textures里用dt推进。

7. owner.shutdown先置shutdown_requested，再等待正在进行的候选恢复通过closed_before_restore_commit中止并discard，及所属碎石保存回调结算；随后进入已有活动solver/碰撞关闭链。不能只等活动field.pending而让候选回调引用已销毁owner。诊断回读由_render_release的field.pending检查排空。实际在途关闭探针见G3补验。
