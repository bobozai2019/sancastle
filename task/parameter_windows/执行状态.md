# 独立参数窗口执行状态

运行功能已实现。当前使用与技术说明见[独立参数窗口](../../docs/参数窗口.md)，原需求见[需求与方案](需求与方案.md)。

## 交付

- 场景保留操作，六个原生参数窗由Parameters Autoload持有，静态布局与固定信号保存到场景。
- 目录包含114项参数，按场景和实际材质分支启用；工具窗口跟随当前工具。已有算法常量、材质输入、道具声明和环境属性接入对应消费者。
- 实时、下次操作、需重建／重启三类标记已接入；重启项手动保存，用户自行重启，不自动重建或重启。
- 参数文件与窗口布局分开保存，启动快照在同一进程中保持；普通工具会话共享，场景外观及待应用值分别保留。

## 验证

Godot 4.7.2 steam ed1daf0bf、D3D12、GTX1050，真实1280×720游戏窗口及六个原生参数窗口。测试使用隔离的 `user://parameter_windows_final03/` 与 `user://parameter_windows_matrix_final03/`，未覆盖正常用户参数文件。

| 项目 | 结果与证据 |
|---|---|
| 功能、焦点、GPU编辑、检查点 | `test_output/parameter_windows/final03_smoke/result.json`，41项通过；力度0.5实际挖填体积约0.050000019m³；水tick推进、保存恢复与释放通过 |
| 新进程加载 | `test_output/parameter_windows/final03_restart/result.json`，19项通过；已保存侵蚀速率进入State与Coupled配置，材质恢复，水tick推进 |
| 四场景往返 | `test_output/parameter_windows/final03_matrix/result.json`，41项通过；每场推进tick、窗口绑定、场景缓存、geometry边界禁用和待重启值隔离通过 |
| 场景结构 | [场景结构.json](验收/场景结构.json)，39项通过 |
| 架构 | `test_output/parameter_windows/architecture_final03/report.json`，1668项通过，失败列表为空；语义审阅见[架构审查](验收/架构审查.md) |
| 资源与生成物 | 四场表现hash、侧面几何生成器、参数窗口生成器检查通过；技术全景来源检查与HTML指南检查通过 |

三轮最终运行均exit0，日志未发现引擎ERROR、脚本错误或资源泄漏报告。截图位于相应结果目录的 `game.png` 与 `water.png`；主场景操作面板与独立水窗口已视觉检查。上述结果不代表长稳或各参数极值的性能保证。
