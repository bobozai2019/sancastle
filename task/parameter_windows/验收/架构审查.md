# 独立参数窗口架构审查

本记录对应当前参数窗口实现的源码语义审阅与架构封存，不替代运行验证。原有历史结果不修改；运行产物单独位于 `test_output/parameter_windows/`。

## 界面和所有权

- Parameters为静态PackedScene Autoload，六个原生Window及参数控件离线生成并保存到场景；固定控件信号也保存在场景。服务只持有窗口、参数、布局与进程帧采样。
- 场景操作读取入口的共享工具参数，PlayerInput仍只生成公共Intent。参数页不选择世界工具，不创建执行器、独立队列、GPU字段副本或私有writer。
- 材质写入仅针对已有ShaderMaterial输入，环境与相机仅写当前场景属性。道具声明覆盖在原服务attach之前应用，摩擦材质同步，实际值计入冻结环境；不存在道具对水沙的写入。
- 场景释放前解除参数绑定，关闭子窗不停止游戏服务。全局按键轮询和世界事件要求主窗口获焦；失焦结束笔画，维护重试仍继续执行。

## 数值与恢复

- 新增启动参数由固定目录校验，已有Coupled侵蚀、沉积、材料和坡面公式不变，仅将既有常量作为编译值和push输入。State只增加CPU配置快照，native物理字段与GPU布局不变。
- Visuals使用配置中的既有白沫寿命、生成增益，录制顺序与提交所有权不变。沙材质将原文字常量提取成同默认值uniform，bed采样及水侧几何函数保持一致，侧面生成器校验通过。
- 新配置进入environment并参与冻结hash，未知来源及不匹配检查点仍拒绝。UI重启项仅写配置文件，启动快照在进程内不更新，不调用现有受限保波热重建API。
- 统一检查点选择校验扩展到普通刷半径／力度及平滑／压实；仍保留旧普通工具空参数的验证，不修改历史codec及原生字段校验。新增字段不会授权额外沙量或放宽守恒容差。
- 常量配置化文件中部分敏感方法hash变化来自换行规范化；除明确记录的参数传递、初始化配置和选择校验变化外，数值阶段、资源退休和共享提交未改。

## 场景与来源

- 四正式表现场景只移除参数及旧性能面板子树，保留操作与场景消费者。新增参数菜单、暂停／视角及既有平滑／压实操作按钮。
- 四份表现清单同步当前场景布局身份及已审阅的沙材质输入变化；不回写seed、原始数据或历史验收结果。
- `scenes/shape_brushes/brush_playable_candidate.tscn`仅移除已从其正式父场景消失的PerformancePanel覆盖，避免失效继承节点警告。
- 架构policy按上述职责封存修改后的资源和敏感方法；新增参数服务、行控件、schema及静态窗口资源一并纳入。场景结构证据为同目录[场景结构.json](场景结构.json)。

## 验证边界

真实Godot 4.7.2 D3D12窗口验证了子窗焦点、参数消费、工具GPU回执、检查点、跨进程启动和四场景往返；参数窗口截图支持布局检查。帧统计只报告进程样本，不构成长稳或单窗口GPU性能结论。Word技术全景已更新生成内容，但本机缺少LibreOffice，渲染器报soffice.exe缺失，无法完成Word分页视觉复核。
