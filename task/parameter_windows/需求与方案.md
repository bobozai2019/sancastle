# 独立参数窗口需求与方案

状态：已实现，验证与限制见[执行状态](执行状态.md)。本文保留需求与设计约束；当前运行实现以[独立参数窗口](../../docs/参数窗口.md)、其他 `docs/` 生效文档及源码为准。

## 目标与范围

操作类 GUI 保留在游戏场景中，参数类 GUI 使用同一游戏进程内的多个原生桌面窗口，可移动到副屏。仅开放现有配置、材质输入和现有算法中的可参数化常量，不增加新的模拟机制，不改变原公式与默认效果。

## 操作与参数划分

| 场景 UI 保留的操作 | 独立窗口中的参数 |
|---|---|
| 工具选择、挖沙、填沙、铲沙及世界点击／拖动 | 半径、体积、力度、沟深、沟宽、两侧堆沙宽度等已有工具参数 |
| 沙墙、城堡等塑形操作与世界预览 | 高度、宽度、缩放、旋转及现有材料选择 |
| 触发波浪 | 波幅、持续时间及现有造浪配置 |
| 投流沙、投碎石、道具选择／摆放／拾取 | 投放量及已有道具质量、浮力采样、阻力、摩擦、阻尼等参数 |
| 暂停／继续、场景切换、检查点保存／恢复 | 模拟、材质、光照、相机、显示质量和诊断设置 |

场景 UI 保留当前工具、运行状态和必要错误提示，并提供“参数窗口”入口。独立参数窗口不重复提供挖填、造浪等世界操作按钮；“保存参数”“恢复默认”等参数管理操作放在参数窗口内。

独立窗口分为：工具参数、水参数、沙参数、道具参数、环境与显示、性能与诊断。查看工具参数页不改变当前工具，默认跟随场景中选择的工具。

参数清单以四个正式入口实际使用的配置和消费路径为依据。现有算法常量可以提取为配置，但须保持原公式与默认值。未接通实际消费者的参数不能显示为可调；不适用于当前场景的项明确禁用并说明原因。协议布局、守恒容差、固定容量等实现约束不作为普通调参项。

## 生效方式

每个可调项标明单位、范围、默认值和生效方式。

| 标记 | 行为 |
|---|---|
| 实时生效 | 修改后直接应用到当前运行实例；界面显示实际有效值 |
| 下次操作生效 | 工具参数用于下一笔，造浪参数用于下一次触发；已接纳操作继续使用原快照 |
| 需重建／重启 | 保存为启动配置，显示“待重启生效”，由用户自行重启游戏 |

工具参数变化时结束当前笔画，从下一笔使用新值。造浪参数变化不修改已接纳波包。

需要重建才能改变的参数统一走用户手动重启路径。本任务不增加自动保留现场重建、自动重启或复杂失败回退流程，也不承诺重启后保留当前沙场及道具动态状态。已有检查点能力及兼容校验保持，不能为了加载新参数而绕过配置身份检查。

## 窗口与控制接口

- 固定窗口布局保存为 `.tscn`，使用原生 `Window`，不在 `_ready()` 中重建静态 UI 层级。
- 子窗关闭只隐藏，可从场景入口重新打开；切场景保留窗体及布局，解绑旧场景并绑定目标场景，切换期间禁用参数写入。
- 主窗口失焦时结束笔画、释放鼠标捕获并清理世界指针预览。主窗口未获焦时不处理世界操作、全局按键轮询或相机移动，避免子窗文字输入触发游戏快捷键。
- 场景操作和参数窗口共用参数服务：场景操作读取有效参数快照，参数窗口提交修改并显示有效状态，不直接互读控件或写 GPU 权威字段。
- 清理场景服务、工具、道具和性能采样对固定 GUI 路径及父节点的依赖。窗口隐藏不应终止游戏服务；采样开关与界面刷新分别管理。

## 保存与加载

- 参数手动保存，窗口位置、尺寸和显隐布局可单独自动保存。
- 参数预设／启动配置保存到 `user://`，包含格式版本、适用场景及参数值，不包含 GPU 沙场状态。
- “实时生效”和“下次操作生效”的修改无需先保存即可用于本次运行；希望下次启动沿用时显式保存。
- 重启项区分“当前有效值”“编辑值”和“已保存的待生效值”。未保存不得显示为下次启动必定生效；保存成功后显示“待重启生效”。
- 直接启动及其他正式运行入口使用同一参数加载规则。无用户配置时使用原默认值；非法配置明确提示，不静默接受越界或不适用参数。
- 场景相关模拟与外观配置按场景保存，切场景读取目标配置，不自动覆盖为上一场景整套参数。跨场景工具选择及参数共享沿用现有行为，窗口显示目标场景最终有效值。
- 检查点保存／恢复继续作为独立的场景操作。恢复仍要求已有配置兼容校验通过，不将参数预设当作检查点，也不自动迁移不兼容旧档。

## 实施与验证

先拆分场景操作与参数控件，建立独立窗口、参数服务和输入隔离；再接通已有配置与材质参数；最后将确需开放的算法常量配置化，并补启动加载。全过程不新增自动重配置系统。

保留审核中适用的固定 GUI 路径解耦、实际消费者检查和窗口焦点要求，移除针对已取消的自动重建流程提出的异步回退要求。

| 验证项 | 完成条件 |
|---|---|
| 操作留场景 | 不打开参数窗口也能选择工具、挖填铲、触发波浪及摆放道具 |
| 实时项 | 修改后实际消费者收到新值，代表性参数产生可解释变化，不只改变控件显示 |
| 下次操作项 | 下一笔／下一次造浪使用新值，已接纳操作保持原参数 |
| 重启项 | 保存后本次运行有效值不变；手动重启后实际加载已保存值，待生效标记同步更新 |
| 默认一致 | 无用户配置时保持原默认公式、物理与表现 |
| 窗口与输入 | 可见原生窗口中输入 WASD、空格、方括号等不触发主窗操作；失焦不遗留笔画或鼠标捕获 |
| 场景绑定 | 四正式场景切换、子窗隐藏／重开、暂停及退出后无旧场景引用或重复回调 |
| 配置校验 | 非有限值、越界值、不适用参数和错误格式明确拒绝；未接通项不能伪报生效 |
| 保存恢复 | 参数配置与检查点边界清楚，不绕过既有来源身份及兼容性校验 |

验证只覆盖相关改动；原生多窗口输入需在真实可见窗口下检查，不能用 headless 结果替代。
